## 使用流程

### 审核任务流程

1. **查看待审核任务**
   - 访问看板系统的"审核"页面
   - 查看所有待审核任务卡片

2. **审核任务**
   - 点击任务卡片打开详情
   - 阅读任务描述
   - 添加审核备注（可选）
   - 点击"✅ 批准执行"或"❌ 拒绝任务"

3. **执行任务**
   - 审核通过后，任务状态变为"已批准"
   - 系统允许执行该任务
   - 审核被拒绝，任务状态变为"已取消"

### API调用示例

```bash
# 获取待审核任务
curl /api/audit/tasks/pending

# 批准任务
curl -X POST /api/audit/tasks/46/approve \
  -d '{"reviewer": "admin", "notes": "审核通过"}'

# 拒绝任务
curl -X POST /api/audit/tasks/46/reject \
  -d '{"reviewer": "admin", "reason": "资源不足"}'
```
