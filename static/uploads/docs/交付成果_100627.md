## 四、 执行SOP（人工操作清单）
1. **内部对齐**：填写上表“当前状态”与“截止日期”，明确我方唯一对接人（避免多头沟通）。
2. **发送跟进**：使用第一部分模板，通过微信/邮件发送给黄东升，并抄送双方技术/商务接口人。
3. **会议预约**：若24小时内未回复，电话跟进：“黄总您好，邮件已发，主要想跟您对齐课题里程碑和NDA流程，看本周三或周四哪个时间方便？”
4. **材料归档**：将BOE反馈的审批要求、技术修改意见、财务节点录入公司CRM/项目管理系统。
5. **风险预警**：若BOE侧流程超过5个工作日无进展，启动备选方案（如先以“横向课题/技术咨询”形式小步推进，再升级至联合实验室）。
