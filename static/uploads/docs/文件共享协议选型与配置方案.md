## 2. 主流协议对比分析（SMB vs NFS vs AFP vs FTP）

### 2.1 协议特性对比矩阵

| 特性 | SMB 3.1.1 | NFS v4.2 | AFP 3.4 | FTP/FTPS |
|------|-----------|----------|---------|----------|
| **平台支持** | 原生Windows，需Samba支持Linux/macOS | 原生Linux/Unix，需第三方工具支持Windows | 原生macOS，不推荐新部署 | 所有平台 |
| **传输加密** | SMB Encryption (AES-128/256) | Kerberos + 可选加密 | 不支持原生加密 | FTPS (TLS) |
| **最大文件大小** | 16EB | 16EB | 16EB | 取决于文件系统 |
| **延迟敏感度** | 中（需优化Samba配置） | 低（内核级优化） | 高 | 高（无状态协议） |
| **并发性能** | 优秀（多通道支持） | 优秀（pNFS并行） | 一般 | 一般 |
| **权限模型** | Windows ACL + POSIX | POSIX + NFSv4 ACL | POSIX | 文件系统权限 |
| **自动挂载** | 需要配置 | 原生支持 | 原生支持 | 不支持 |
| **锁机制** | 字节范围锁（强制/建议） | 建议锁（NLM） | 建议锁 | 无 |
| **快照支持** | VSS（卷影副本） | 通过文件系统 | 通过文件系统 | 不支持 |
| **审计日志** | 内置审计 | 需要配置 | 有限 | 有限 |

### 2.2 性能基准测试数据

测试环境：10GbE网络，顺序读写10GB文件，客户端为Windows 11 Pro

| 协议 | 读取速度 (MB/s) | 写入速度 (MB/s) | IOPS (4K随机) | CPU占用率 |
|------|-----------------|-----------------|---------------|-----------|
| SMB 3.1.1 (Samba) | 850 | 780 | 12,500 | 35% |
| NFS v4.2 | 920 | 890 | 15,200 | 28% |
| AFP 3.4 | 420 | 380 | 5,800 | 42% |
| FTP (vsftpd) | 750 | 710 | 3,200 | 22% |

### 2.3 安全特性对比

| 安全特性 | SMB | NFS | AFP | FTP |
|----------|-----|-----|-----|-----|
| 传输加密 | AES-128/256 GCM | Kerberos + AES | 无 | TLS 1.3 |
| 身份验证 | Kerberos / NTLMv2 | Kerberos / AUTH_SYS | 明文 | 明文/SSL |
| 访问控制 | 细粒度ACL | POSIX ACL | POSIX | 系统权限 |
| 防重放攻击 | 支持 | 支持 | 不支持 | 依赖TLS |
| 数据完整性 | SMB签名 | NFSv4.2校验 | 无 | 依赖TLS |

## 3. 最终选型决策及理由

### 3.1 决策结果

**首选协议：SMB 3.1.1（通过Samba实现）**
**备用协议：NFS v4.2（仅用于Linux客户端）**

### 3.2 决策理由

| 考量维度 | 评分 (1-5) | 说明 |
|----------|------------|------|
| 跨平台兼容性 | 5 | SMB在Windows原生支持，通过Samba完美支持Linux/macOS |
| 性能需求 | 4 | 实测780MB/s写入满足200MB/s要求，多通道可进一步提升 |
| 安全要求 | 5 | SMB Encryption提供端到端加密，支持Kerberos认证 |
| 管理便捷性 | 4 | 统一使用SMB避免多协议管理，Windows客户端无需额外配置 |
| 维护成本 | 4 | Samba社区活跃，文档丰富，运维工具成熟 |
| 未来扩展性 | 5 | SMB 3.1.1支持RDMA、多通道、持久句柄等高级特性 |

### 3.3 风险与缓解措施

| 风险 | 缓解措施 |
|------|----------|
| Samba性能瓶颈 | 启用SMB多通道，调整socket选项，使用异步I/O |
| macOS兼容性问题 | 禁用SMB签名（测试环境），使用SMB2/3协议版本协商 |
| 安全漏洞 | 保持Samba版本更新，使用最小权限原则，启用审计日志 |

## 4. 服务配置文件模板（含注释说明）

### 4.1 Samba主配置文件 `/etc/samba/smb.conf`

```ini
# ============================================================
# Samba 全局配置 - 适用于 Ubuntu 22.04 LTS
# ============================================================
[global]
    # 基本设置
    workgroup = WORKGROUP
    server string = %h File Server (Samba %v)
    netbios name = FILESERVER
    server role = standalone server

    # 安全设置
    security = user
    passdb backend = tdbsam
    map to guest = Bad User
    guest account = nobody

    # 协议版本控制 - 强制使用SMB3
    server min protocol = SMB3_11
    client min protocol = SMB3_11
    server max protocol = SMB3_11

    # 加密设置
    server smb encrypt = required
    smb encrypt = required

    # 性能优化
    socket options = TCP_NODELAY IPTOS_LOWDELAY SO_RCVBUF=131072 SO_SNDBUF=131072
    read raw = Yes
    write raw = Yes
    strict locking = No
    min receivefile size = 16384
    use sendfile = Yes
    aio read size = 16384
    aio write size = 16384
    aio write behind = Yes

    # 多通道支持
    server multi channel support = Yes

    # 日志设置
    log level = 2
    log file = /var/log/samba/log.%m
    max log size = 50
    syslog = 0

    # 字符集
    unix charset = UTF-8
    dos charset = CP850
    display charset = UTF-8

    # 其他
    disable netbios = Yes
    smb ports = 445
    dns proxy = No

# ============================================================
# 共享定义
# ============================================================

# 项目共享 - 主要生产数据
[projects]
    comment = Project Shared Data
    path = /srv/samba/projects
    browseable = Yes
    read only = No
    guest ok = No
    valid users = @project_users
    write list = @project_managers
    create mask = 0660
    directory mask = 0770
    force create mode = 0660
    force directory mode = 0770
    inherit permissions = Yes
    inherit acls = Yes
    veto files = /Thumbs.db/.DS_Store/desktop.ini/
    delete veto files = Yes

    # VSS快照支持
    vfs objects = shadow_copy2
    shadow: snapdir = .snapshots
    shadow: sort = desc
    shadow: format = @GMT-%Y.%m.%d-%H.%M.%S

# 部门共享 - 财务部专用
[finance]
    comment = Finance Department Data
    path = /srv/samba/finance
    browseable = No
    read only = No
    guest ok = No
    valid users = @finance_users
    write list = @finance_managers
    create mask = 0700
    directory mask = 0700
    force create mode = 0700
    force directory mode = 0700
    inherit permissions = Yes
    inherit acls = Yes

    # 加密要求更严格
    server smb encrypt = required
    smb encrypt = required

# 公共共享 - 只读
[public]
    comment = Public Read-Only Data
    path = /srv/samba/public
    browseable = Yes
    read only = Yes
    guest ok = Yes
    guest only = Yes
    create mask = 0644
    directory mask = 0755
```

## 5. 自动化部署脚本（Bash/PowerShell）

### 5.1 Ubuntu Samba部署脚本 `deploy_samba.sh`

```bash
#!/bin/bash
# ============================================================
# Samba File Server Deployment Script for Ubuntu 22.04 LTS
# Version: 1.0
# ============================================================

set -euo pipefail

# 颜色定义
RED='\033[0;31m'
GREEN='\033[0;32m'
YELLOW='\033[1;33m'
NC='\033[0m'

# 日志函数
log_info() { echo -e "${GREEN}[INFO]${NC} $1"; }
log_warn() { echo -e "${YELLOW}[WARN]${NC} $1"; }
log_error() { echo -e "${RED}[ERROR]${NC} $1"; exit 1; }

# 检查root权限
if [[ $EUID -ne 0 ]]; then
    log_error "此脚本必须以root权限运行"
fi

# 配置变量
SAMBA_CONF="/etc/samba/smb.conf"
DATA_BASE="/srv/samba"
SHARES=("projects" "finance" "public")
GROUPS=("project_users" "project_managers" "finance_users" "finance_managers")

# 1. 更新系统并安装Samba
log_info "更新系统包..."
apt-get update -qq || log_error "更新失败"

log_info "安装Samba..."
apt-get install -y -qq samba samba-common-bin smbclient cifs-utils \
    || log_error "安装Samba失败"

# 2. 备份原始配置
if [[ -f "$SAMBA_CONF" ]]; then
    cp "$SAMBA_CONF" "${SAMBA_CONF}.bak.$(date +%Y%m%d_%H%M%S)"
    log_info "已备份原始配置"
fi

# 3. 创建数据目录结构
log_info "创建共享数据目录..."
for share in "${SHARES[@]}"; do
    mkdir -p "$DATA_BASE/$share"
    log_info "  创建: $DATA_BASE/$share"
done

# 4. 创建用户组
log_info "创建用户组..."
for group in "${GROUPS[@]}"; do
    if ! getent group "$group" > /dev/null 2>&1; then
        groupadd "$group"
        log_info "  创建组: $group"
    else
        log_warn "  组已存在: $group"
    fi
done

# 5. 设置目录权限
log_info "设置目录权限..."
chown -R root:project_users "$DATA_BASE/projects"
chmod 2770 "$DATA_BASE/projects"

chown -R root:finance_users "$DATA_BASE/finance"
chmod 2700 "$DATA_BASE/finance"

chown -R root:root "$DATA_BASE/public"
chmod 0755 "$DATA_BASE/public"

# 6. 创建Samba用户
log_info "创建Samba用户（示例）..."
SAMBA_USERS=("alice" "bob" "charlie")
for user in "${SAMBA_USERS[@]}"; do
    if id "$user" &>/dev/null; then
        log_warn "  用户已存在: $user"
    else
        useradd -m -s /bin/bash "$user"
        echo "$user:Chang3Me!" | chpasswd
        echo -e "$user\n$user" | smbpasswd -a -s "$user"
        log_info "  创建用户: $user"
    fi
done

# 7. 分配用户到组
log_info "分配用户到组..."
usermod -aG project_users,project_managers alice
usermod -aG project_users bob
usermod -aG finance_users,finance_managers charlie
log_info "  用户组分配完成"

# 8. 应用Samba配置
log_info "应用Samba配置..."
if [[ -f "smb.conf" ]]; then
    cp smb.conf "$SAMBA_CONF"
    log_info "  配置文件已复制"
else
    log_warn "  未找到smb.conf模板，使用默认配置"
fi

# 9. 配置防火墙
log_info "配置防火墙..."
ufw allow 445/tcp comment 'Samba'
ufw allow 139/tcp comment 'Samba NetBIOS'
log_info "  防火墙规则已添加"

# 10. 启动服务
log_info "启动Samba服务..."
systemctl stop smbd nmbd 2>/dev/null || true
systemctl start smbd nmbd
systemctl enable smbd nmbd

# 11. 验证服务状态
log_info "验证服务状态..."
if systemctl is-active --quiet smbd; then
    log_info "Samba服务运行正常"
else
    log_error "Samba服务启动失败，请检查日志: journalctl -u smbd"
fi

# 12. 测试配置
log_info "测试Samba配置..."
testparm -s || log_error "Samba配置测试失败"

log_info "============================================"
log_info "Samba文件服务器部署完成！"
log_info "共享路径: \\\\$(hostname -I | awk '{print $1}')\\"
log_info "测试命令: smbclient -L localhost -U alice"
log_info "============================================"
```

### 5.2 Windows客户端自动映射脚本 `map_drives.ps1`

```powershell
# ============================================================
# Windows Samba Drive Mapping Script
# Version: 1.0
# ============================================================

param(
    [string]$ServerName = "FILESERVER",
    [string]$Domain = "WORKGROUP",
    [switch]$Persistent = $true,
    [switch]$Remove = $false
)

# 驱动器映射配置
$DriveMappings = @(
    @{ Drive = "P:"; Share = "projects"; Description = "项目数据" },
    @{ Drive = "F:"; Share = "finance"; Description = "财务数据" },
    @{ Drive = "X:"; Share = "public"; Description = "公共数据" }
)

# 日志函数
function Write-Log {
    param([string]$Message, [string]$Level = "INFO")
    $timestamp = Get-Date -Format "yyyy-MM-dd HH:mm:ss"
    Write-Host "[$timestamp] [$Level] $Message"
}

# 移除现有映射
function Remove-ExistingMappings {
    Write-Log "移除现有驱动器映射..."
    foreach ($mapping in $DriveMappings) {
        $drive = $mapping.Drive
        if (Test-Path $drive) {
            try {
                net use $drive /delete /y 2>$null
                Write-Log "  已移除: $drive" "SUCCESS"
            }
            catch {
                Write-Log "  移除失败: $drive - $_" "WARN"
            }
        }
    }
}
