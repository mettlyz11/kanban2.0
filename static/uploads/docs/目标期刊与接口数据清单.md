## 3. 技术参数与访问限制

### 3.1 认证机制详述

| 认证类型 | 适用期刊 | 凭证获取方式 | 凭证有效期 | 刷新机制 |
|----------|----------|--------------|------------|----------|
| API Key (Header) | Nature, Nature Comms, TPAMI, Adv. Materials | 出版社开发者门户注册 | 1年（自动续期需重新申请） | 手动替换 |
| API Key (Query) | NEJM, PRL, PRD | 申请表单审核 | 2年 | 邮件通知续期 |
| OAuth 2.0 | Science, Science Robotics | 开发者账号+应用注册 | Access Token: 1h, Refresh Token: 30天 | 自动刷新（需存储Refresh Token） |
| API Key + InstToken | Cell, The Lancet | Elsevier API注册+机构IP认证 | Key: 1年, Token: 动态 | Token通过IP自动验证 |
| 无认证（公开） | PNAS, NAR, MNRAS, CVPR | 无需凭证 | N/A | N/A |

### 3.2 调用频率限制与错误处理

| API/Feed | 基础限制 | 突发限制 | 429错误处理 | 重试策略 |
|----------|----------|----------|-------------|----------|
| Springer Nature API | 10 req/s | 20 req/s (burst 2s) | 指数退避：1s→2s→4s→8s，最多5次 | 使用`Retry-After`头 |
| Elsevier API | 20 req/s | 50 req/s (burst 5s) | 指数退避：2s→4s→8s，最多3次 | 使用`X-RateLimit-Reset`头 |
| IEEE Xplore API | 10 req/s | 30 req/s (burst 3s) | 线性退避：5s等待，最多3次 | 使用`x-ratelimit-reset`头 |
| APS Harvest API | 5 req/s | 10 req/s (burst 2s) | 指数退避：1s→2s→4s，最多5次 | 使用`Retry-After`头 |
| Science OAuth API | 100 req/h | 10 req/min | 等待至下一小时，最多2次 | 检查`X-RateLimit-Reset`头 |
| Wiley TDM API | 5 req/s | 10 req/s (burst 2s) | 指数退避：2s→4s→8s，最多3次 | 使用`Retry-After`头 |
| Crossref API | 50 req/s | 100 req/s (burst 2s) | 指数退避：1s→2s→4s，最多10次 | 推荐使用`mailto`参数提高配额 |
| DBLP API | 10 req/s | 20 req/s (burst 2s) | 线性退避：3s等待，最多5次 | 无特殊头，需手动控制 |
| RSS Feed | 1 req/30s | 1 req/10s | 等待60s后重试，最多2次 | 使用`If-Modified-Since`头减少请求 |
