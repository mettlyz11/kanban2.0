# 调研溯源文档

## 一、调研范围界定与方法论说明

### 1.1 调研背景与目标

本次调研旨在全面梳理XX集团公司采购管理现有业务流程，输出完整、准确的业务流程清单，为后续流程优化与系统建设提供基础依据。调研覆盖总部及三家区域分公司（华东、华南、华北），重点聚焦采购申请、供应商管理、合同签订、订单执行、验收付款五大核心环节。

**调研周期**：2024年1月15日至2024年2月28日（共计6周）

**核心目标**：
- 输出标准化业务流程清单（含流程图、操作说明、表单模板）
- 识别流程瓶颈与风险点（不少于15处）
- 收集业务方改进建议（不少于20条）

### 1.2 调研方法论与工具

采用“四维调研法”确保数据全面性与真实性：

| 调研维度 | 具体方法 | 工具/模板 | 产出物 |
|---------|---------|-----------|--------|
| 制度文档分析 | 文档审阅与内容提取 | 制度文档编码表 | 制度条款对照表 |

| 现场观察 | 工作日跟岗记录 | 观察记录表 | 流程差异分析表 |

## 二、关键人员访谈纪要摘要

### 2.1 采购部经理访谈摘要

**受访人**：张XX（华东分公司采购部经理，从业18年）
**访谈日期**：2024年1月22日

**现状描述**：
“目前采购流程主要依赖纸质审批单流转，从需求提交到采购订单生成平均需要7个工作日。紧急采购走特批通道，但缺乏统一标准，去年紧急采购占比达到23%，严重影响了采购计划性。”

**核心痛点**：
1. 审批节点过多（平均8个审批节点），且部分节点存在重复审核
2. 紧急采购缺乏量化标准，导致“紧急”变成常态
3. 采购需求变更频繁（月均变更率12%），但变更流程不清晰

**期望流程**：
- 建立分级审批机制：常规采购（≤5万元）简化至3个节点
- 紧急采购设置明确触发条件（如生产停工风险、客户交期违约风险）
- 需求变更需关联原采购申请单，保留完整变更轨迹

### 2.2 采购专员访谈摘要

**受访人**：李XX（华南分公司采购专员，从业4年）
**访谈日期**：2024年1月25日

**现状描述**：
“每天要处理约15-20个采购申请单，其中约30%的申请单信息不完整，需要反复沟通补充。供应商报价比对主要靠Excel手工操作，容易出错且效率低。”

**核心痛点**：
1. 采购申请单缺乏标准化模板，字段填写随意
2. 供应商报价比对无系统支撑，历史价格查询困难
3. 采购订单生成后，验收环节缺少系统联动，需要人工催办

**期望流程**：
- 采购申请单强制校验必填字段（物料编码、规格参数、期望到货日期等）
- 建立供应商报价数据库，支持自动比价与历史价格对比
- 实现采购订单-验收单-发票三单匹配系统自动校验

### 2.3 业务需求部门代表访谈摘要

**受访人**：王XX（生产部设备主管，从业12年）
**访谈日期**：2024年1月28日

**现状描述**：
“设备维修备件采购经常出现到货不及时情况。上月有3次因为采购周期长导致设备停机，每次损失约5万元产能。我们提需求时已经标注了‘紧急’，但采购部反馈系统里没有紧急标识。”

**核心痛点**：
1. 需求部门与采购部对“紧急”定义不一致
2. 采购进度无法实时查询，只能电话催问
3. 到货验收标准不明确，部分备件到货后与需求不符

**期望流程**：
- 建立采购进度可视化看板，实时展示各环节状态
- 明确紧急采购等级（L1-L3）及对应响应时限
- 验收标准在采购申请阶段即明确，并纳入合同条款

### 2.4 财务部审核人员访谈摘要

**受访人**：陈XX（集团财务部应付会计主管，从业9年）
**访谈日期**：2024年2月1日

**现状描述**：
“每月处理约300笔采购付款申请，其中约15%存在单据不一致问题。最常见的是发票金额与订单金额不符、验收单日期晚于发票日期。”

**核心痛点**：
1. 三单匹配（订单、验收单、发票）依赖人工核对
2. 付款审批流程中缺少预算占用校验
3. 供应商对账周期长（平均15天），影响账期管理

**期望流程**：
- 实现系统自动三单匹配，异常单据自动标记并推送处理
- 付款前自动校验预算余额，超预算需触发追加流程
- 支持电子对账，缩短对账周期至3个工作日内

### 3.2 制度与系统数据对照分析

**关键发现1：制度规定的审批时限与实际执行差异**

制度规定：“常规采购审批时限不超过3个工作日”
系统数据统计（2023年7月-2024年1月）：
- 审批时长≤3工作日：占比42%
- 审批时长3-5工作日：占比31%
- 审批时长5-10工作日：占比19%
- 审批时长>10工作日：占比8%

**分析**：审批时限达标率不足50%，主要瓶颈在部门负责人审批环节（平均耗时1.8天）和财务审核环节（平均耗时1.5天）。

**关键发现2：供应商准入流程执行偏差**

制度规定：“新供应商准入需经过资质审核、现场考察、样品测试、商务谈判四个环节”
系统数据统计：
- 2023年新增供应商87家
- 完成全部四个环节的：29家（33%）
- 仅完成资质审核的：41家（47%）
- 无完整准入记录的：17家（20%）

**分析**：供应商准入流程执行严重不足，存在合规风险。

**关键发现3：合同归档及时性**

制度规定：“合同签署后3个工作日内完成归档”
系统数据统计：
- 3日内归档：占比52%
- 3-7日归档：占比28%
- 7-30日归档：占比15%
- 超过30日归档：占比5%

**分析**：归档及时性有待提升，长期未归档合同存在法律风险。

### 3.3 流程差异深度分析

**采购申请环节**：
- 制度规定：需求部门填写标准采购申请单，经部门负责人审批后提交采购部
- 实际执行：约35%的申请单使用非标准格式，15%的申请单缺少必要字段
- 根因分析：标准模板未嵌入业务系统，员工习惯使用Excel自制表单

**供应商选择环节**：
- 制度规定：单项采购金额≥10万元需进行三家以上比价
- 实际执行：比价执行率78%，但比价记录完整性仅52%
- 根因分析：缺乏比价系统支撑，比价过程依赖人工留存

**验收环节**：
- 制度规定：到货后3个工作日内完成验收
- 实际执行：平均验收周期5.2个工作日
- 根因分析：验收标准不明确，验收人员与采购人员沟通不畅
