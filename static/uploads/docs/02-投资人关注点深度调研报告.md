## 一、2026年硬科技投资人决策框架最新变化

### 1.1 宏观趋势：资本"两极化"集中

2026年开年，AI融资呈现极端分化：
- **基础模型层**: 17家美国初创吸金超百亿美元，头部效应显著
- **垂直应用层**: 能快速落地产生收入的AI应用公司受追捧
- **中间层**: 纯技术平台、无清晰商业模式的公司融资困难

### 1.2 硬科技投资六大新标准

| 排名 | 新标准 | 旧标准 | 变化说明 |
|------|--------|--------|----------|
| 1 | **收入验证** | 技术领先 | 从"技术好"到"能赚钱" |
| 2 | **单位经济模型** | 市场空间 | 从"市场大"到"每单赚" |
| 3 | **客户付费意愿** | 专利数量 | 从"有专利"到"愿付费" |
| 4 | **团队产业背景** | 学术背景 | 从"科学家"到"企业家" |
| 5 | **落地速度** | 技术深度 | 从"深"到"快" |
| 6 | **护城河可持续性** | 先发优势 | 从"先"到"牢" |

### 1.3 2026年投资决策时间轴变化

```
2024年前典型流程:          2026年典型流程:
┌─────────┐                ┌─────────┐
│  初筛   │ 2周            │  初筛   │ 3天
├─────────┤                ├─────────┤
│  尽调   │ 2-3月          │  快速尽调│ 2-4周
├─────────┤                ├─────────┤
│  IC审批 │ 1月            │  决策    │ 1-2周
├─────────┤                ├─────────┤
│  交割   │ 1月            │  交割    │ 1-2周
└─────────┘                └─────────┘
总计: 4-6月                 总计: 6-10周
```

**关键变化**: 决策加速，但标准更严。投资人用更短时间做更深入的商业验证。

## 二、AI材料公司尽调核心指标清单

### 2.1 技术壁垒（权重30%）

| 指标 | 权重 | 优秀标准 | 和光智成自评 |
|------|------|----------|-------------|
| 核心算法独特性 | 40% | 自研算法，非开源 wrapper | ⭐⭐⭐⭐ |
| 数据壁垒 | 30% | 独家材料数据库/合作 | ⭐⭐⭐ |
| 专利布局 | 20% | 10+发明专利，覆盖核心路径 | ⭐⭐⭐⭐ |
| 算力/基础设施 | 10% | 自有算力或稳定云资源 | ⭐⭐⭐ |

**尽调问题示例**:
- "你们的AI模型与通用大模型+材料数据库的区别是什么？"
- "如果OpenAI/Google进入这个领域，你们的防御策略是什么？"
- "核心算法的准确率/效率相比传统方法提升多少？有第三方验证吗？"

### 2.2 商业化能力（权重35%）

| 指标 | 权重 | 优秀标准 | 和光智成自评 |
|------|------|----------|-------------|
| 收入规模 | 25% | 年营收>1000万 | ⭐⭐ |
| 客户质量 | 25% | 行业头部客户付费 | ⭐⭐⭐ |
| 合同/POC | 20% | 3+付费POC或年度合同 | ⭐⭐⭐ |
| 商业模式清晰度 | 20% | SaaS/授权/服务路径明确 | ⭐⭐⭐ |
| 客单价/续约率 | 10% | 客单价>50万，续约率>80% | ⭐⭐ |

**尽调问题示例**:
- "目前收入构成中，一次性项目 vs  recurring收入比例？"
- "从POC到正式采购的平均转化周期和转化率？"
- "客户的预算来源是研发经费还是生产预算？"

### 2.3 团队完整性（权重20%）

| 指标 | 权重 | 优秀标准 | 和光智成自评 |
|------|------|----------|-------------|
| 创始人背景 | 30% | 学术+产业复合，连续创业优先 | ⭐⭐⭐⭐ |
| CTO/技术负责人 | 25% | 顶级AI+材料交叉背景 | ⭐⭐⭐⭐ |
| 商业化负责人 | 25% | 有成功销售/BD经验 | ⭐⭐ |
| 团队完整性 | 20% | 技术+产品+销售铁三角 | ⭐⭐⭐ |

**尽调问题示例**:
- "创始人全职投入还是兼职？股权如何分配？"
- "商业化负责人是否有成功从0到1的经验？"
- "核心团队在一起工作多久？有无竞业限制？"

### 2.4 护城河与竞争格局（权重15%）

## 四、成功融资案例BP关键要素拆解

### 4.1 深势科技 B+轮案例

| 要素 | 内容 |
|------|------|
| **融资额** | 数亿人民币 |
| **估值** | ~30亿人民币 |
| **核心亮点** | AI for Science平台化、药物研发+材料双赛道 |
| **BP结构** | 问题→解决方案→技术验证→商业模式→团队→财务预测 |
| **关键数据** | 合作药企数量、计算任务量、学术论文数 |

### 4.2 晶泰科技 IPO案例

| 要素 | 内容 |
|------|------|
| **上市估值** | 港股上市，市值波动 |
| **核心亮点** | 从药物发现扩展到材料、农业 |
| **收入结构** | 药物发现服务(60%) + 智能自动化(40%) |
| **关键数据** | 客户数量、项目成功率、收入增长曲线 |

### 4.3 成功BP的12个必备模块

```
1. 封面: 一句话定位 + Logo + 融资信息
2. 问题: 行业痛点，用数据说话
3. 解决方案: 产品/服务如何解决问题
4. 技术: 核心壁垒，避免过度技术细节
5. 市场: TAM/SAM/SOM，增长驱动力
6. 商业模式: 怎么赚钱，单位经济模型
7. 竞争: 竞争格局，差异化优势
8.  traction: 收入/客户/POC，一切能证明进展的数据
9. 团队: 核心成员背景，为什么是你们
10. 财务: 3-5年预测，关键假设
11. 融资用途: 钱怎么花，里程碑
12. 愿景: 长期价值，退出路径
```

### 4.4 BP常见致命错误

| 错误 | 后果 | 改进建议 |
|------|------|----------|
| 技术细节过多 | 投资人看不懂，失去兴趣 | 用"类比+数据"代替公式 |
| 市场只讲TAM | 显得不接地气 | 聚焦SAM，讲清楚第一步怎么切 |
| 团队只有学术背景 | 商业化能力存疑 | 强调产业顾问/合作方 |
| 财务预测过于乐观 | 可信度下降 | 分场景预测，标注关键假设 |
| 回避竞争 | 显得不成熟 | 坦诚竞争，强调差异化 |
