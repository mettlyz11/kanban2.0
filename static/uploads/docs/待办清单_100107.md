### 二、执行检查命令（复制即用）

**Linux系统执行以下命令，保存输出：**

```bash
# 1. 系统基础信息
uname -a > sysinfo.txt
uptime >> sysinfo.txt

# 2. 资源使用（关键）
df -h > disk_usage.txt
free -h > memory.txt
top -bn1 | head -20 > cpu_top.txt

# 3. 服务状态
systemctl list-units --failed > failed_services.txt 2>/dev/null || service --status-all > services.txt

# 4. 网络状态
ss -tulnp > network.txt 2>/dev/null || netstat -tulnp > network.txt 2>/dev/null
ip addr >> network.txt

# 5. 日志异常（最近24小时）
journalctl --since "24 hours ago" -p err > errors.log 2>/dev/null || grep -i "error\|fail\|critical" /var/log/syslog | tail -100 > errors.log

# 6. 安全更新
# Ubuntu/Debian: apt list --upgradable > updates.txt
# RHEL/CentOS: yum check-update > updates.txt 2>/dev/null

# 7. 负载历史
cat /proc/loadavg > load.txt
```
