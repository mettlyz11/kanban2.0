# 过渡态寻找算法对比矩阵

## 1. 对比维度定义

### 1.1 计算成本 (Computational Cost)
- **定义**：完成一次过渡态搜索所需的平均能量与梯度计算次数
- **量化指标**：每步迭代的PES评估次数 × 收敛所需迭代次数
- **等级划分**：
  - 极低：<50次能量计算
  - 低：50-200次
  - 中：200-500次
  - 高：500-1000次
  - 极高：>1000次

### 1.2 初猜依赖性 (Initial Guess Dependency)
- **定义**：算法对初始结构质量的敏感程度
- **量化指标**：初始RMSD与收敛成功率的相关系数
- **等级划分**：
  - 低：可接受任意合理结构（RMSD < 2.0 Å）
  - 中：需合理近似（RMSD < 1.0 Å）
  - 高：需接近真实TS（RMSD < 0.5 Å）
  - 极高：需精确初始Hessian

### 1.3 路径连续性 (Path Continuity)
- **定义**：算法是否提供反应路径的完整信息
- **等级划分**：
  - 完整：输出IRC/MEP全路径
  - 部分：输出路径片段
  - 无：仅输出TS结构

### 1.4 并行扩展性 (Parallel Scalability)
- **定义**：算法在多核/多节点环境下的加速效率
- **量化指标**：Speedup = T(1)/T(N)，理想线性为N
- **等级划分**：
  - 优：>0.8线性加速
  - 良：0.5-0.8
  - 中：0.2-0.5
  - 差：<0.2

### 1.5 虚频验证可靠性 (Imaginary Frequency Verification Reliability)
- **定义**：算法对TS鞍点特征的确认能力
- **等级划分**：
  - 高：自动Hessian计算+虚频确认
  - 中：有限差分验证
  - 低：无内置验证

### 2.1 经典算法详细特性

**QST2/3 (Synchronous Transit)**
- **收敛特征**：采用二次同步跃迁方法，沿反应物-产物连线插值
- **典型迭代次数**：30-80步
- **失败模式**：反应路径弯曲度>60°时易失败
- **内存需求**：低(<1GB)
- **适用理论级别**：HF, DFT, MP2

**Eigenvector Following (EF)**
- **收敛特征**：沿Hessian最小本征方向步进
- **典型迭代次数**：20-50步
- **Hessian更新**：需精确初始Hessian，后续BFGS更新
- **步长控制**：Trust radius方法，典型值0.1-0.5 Bohr
- **适用理论级别**：高精度DFT, CCSD(T)

**CI-NEB (Climbing Image NEB)**
- **图像数量影响**：N=8-32，每增加1图像增加~15%计算量
- **收敛标准**：最大力<0.02 eV/Å，爬坡图像力<0.01 eV/Å
- **弹簧常数**：k=5.0 eV/Å²（典型值）
- **适用理论级别**：DFT, 力场

| **AutoTS** | 低-中(100-300次) | 极低(仅需分子式) | 部分 | 中(0.4-0.6) | 高(自动) | 极高 | AutoTS, XTB |

### 3.1 现代算法详细特性

**GSM (Growing String Method)**
- **核心机制**：从反应物端逐步生长路径，自动插值
- **典型参数**：初始节点数=3，最大节点数=20
- **收敛判据**：路径RMS梯度<0.001 Hartree/Bohr
- **优势场景**：多步反应、未知机理
- **计算示例**：C2H6+H→C2H5+H2，30节点收敛于45步

**AutoTS**
- **工作流**：构象搜索→初猜生成→TS优化→IRC验证
- **成功率**：>85% (对<20原子体系)
- **典型耗时**：10原子体系约2小时(DFT)
- **输出**：TS结构+IRC路径+能量剖面

**Bayesian Optimization TS**
- **核心思想**：高斯过程代理模型，主动学习
- **采样策略**：Expected Improvement (EI) + Upper Confidence Bound (UCB)
- **初始采样**：10-20个随机点
- **收敛保证**：概率性收敛，需50-100次PES评估

**NN PES-based Search**
- **训练要求**：>1000个PES点
- **推理速度**：<1ms/结构
- **精度**：RMSE < 0.5 kcal/mol (足够训练数据)
- **部署成本**：高(需预训练)，但使用成本极低

### 5.5 调优示例脚本

```python
# CI-NEB 收敛判据调优示例 (ASE接口)
from ase.io import read
from ase.neb import NEB
from ase.optimize import BFGS
from ase.calculators.vasp import Vasp

# 初始化反应物和产物
initial = read('initial.xyz')
final = read('final.xyz')

# 创建NEB路径
images = [initial.copy() for _ in range(12)]
for i, img in enumerate(images):
    img.set_calculator(Vasp(xc='PBE', encut=400, kpts=(3,3,1)))

neb = NEB(images, k=5.0, climb=True)  # 弹簧常数k=5.0
neb.interpolate(method='idpp')  # 使用IDPP插值

# 优化器设置
optimizer = BFGS(neb, trajectory='neb.traj')
optimizer.run(fmax=0.02)  # 最大力收敛判据

# 检查收敛
forces = images[6].get_forces()  # 爬坡图像
print(f"Climbing image max force: {np.max(np.linalg.norm(forces, axis=1)):.3f} eV/Å")
```

### 5.6 自动化参数调整策略

**自适应步长算法**：
```python
def adaptive_step_size(current_grad, prev_grad, step, 
                       factor_inc=1.2, factor_dec=0.5,
                       max_step=0.5, min_step=0.01):
    """
    基于梯度变化的自适应步长
    """
    grad_ratio = np.linalg.norm(current_grad) / np.linalg.norm(prev_grad)
    
    if grad_ratio > 1.5:  # 梯度增大，减小步长
        step = max(step * factor_dec, min_step)
    elif grad_ratio < 0.5:  # 梯度减小，增大步长
        step = min(step * factor_inc, max_step)
    
    return step

# 使用示例
step = 0.1
prev_grad = np.random.randn(3, 10)
for iteration in range(100):
    current_grad = calculate_gradient()  # 实际计算
    step = adaptive_step_size(current_grad, prev_grad, step)
    update_structure(step)
    prev_grad = current_grad
```

```
1. 体系大小?
   ├─ <50原子 → 2
   └─ ≥50原子 → 3

2. 精度需求?
   ├─ 高精度 → EF/QST3
   └─ 高通量 → AutoTS/GSM

3. 路径信息需求?
   ├─ 需要 → CI-NEB/GSM
   └─ 不需要 → Dimer/L-BFGS TS

   ├─ 充足 → 并行CI-NEB
   └─ 有限 → Dimer
```
