## 1. 重复性任务定义与边界划定

### 1.1 核心定义

重复性任务是指在一定时间周期内，按照固定或高度相似的流程、规则和操作步骤，由同一个人或同一岗位反复执行的业务活动。这类任务具有**可预测性**、**标准化**和**低认知负荷**三大核心特征。

**科学界定标准（三要素模型）：**

| 要素 | 定义 | 量化阈值 |
|------|------|----------|
| 频次要素 | 在固定周期内出现次数 | 月频次≥4次（即周均≥1次） |
| 流程要素 | 操作步骤的标准化程度 | 步骤相似度≥80%（基于Levenshtein距离） |
| 产出要素 | 输出结果的同质性 | 产出物变异系数≤15% |

### 1.2 边界排除规则

以下三类工作**不属于**重复性任务范畴：

**一次性任务（排除标准）：**
- 生命周期≤1次/年的活动（如：年度预算编制、组织架构调整）
- 项目型交付任务（如：客户定制化方案设计、系统迁移实施）
- 判断依据：任务出现频次<4次/年，且无固定模板复用

**强创意类工作（排除标准）：**
- 需要原创性思维的任务（如：广告创意策划、产品原型设计）
- 产出结果不可预测，每次执行都需要重新构思
- 判断依据：任务执行过程中非结构化决策占比>60%

**异常处理类工作（部分排除）：**
- 仅排除完全依赖个人经验的非标准化异常处理
- 保留可规则化的异常处理（如：密码重置、账户冻结解封）

### 1.3 边界划定的操作流程

```
步骤1：收集岗位职责清单（至少3个月周期）
步骤2：对每项任务进行频次统计
步骤3：抽取5次执行记录，计算步骤相似度
步骤4：评估任务产出物的一致性
步骤5：对照排除规则进行过滤
步骤6：输出候选重复性任务清单
```

import cv2
import numpy as np
from collections import Counter

def analyze_screen_recording(video_path, output_dir):
    """
    分析操作录屏，提取重复性操作模式
    
    Parameters:
    -----------
    video_path : str
        录屏视频文件路径
    output_dir : str
        输出目录
    """
    cap = cv2.VideoCapture(video_path)
    fps = cap.get(cv2.CAP_PROP_FPS)
    
    mouse_clicks = []
    page_transitions = []
    frame_count = 0
    
    while cap.isOpened():
        ret, frame = cap.read()
        if not ret:
            break
            
        # 每30帧分析一次（约1秒间隔）
        if frame_count % 30 == 0:
            # 检测鼠标位置（基于颜色识别或模板匹配）
            mouse_pos = detect_mouse_position(frame)
            if mouse_pos:
                mouse_clicks.append(mouse_pos)
            
            # 检测页面变化（基于帧差法）
            if frame_count > 0:
                diff = cv2.absdiff(prev_frame, frame)
                change_ratio = np.sum(diff > 30) / diff.size
                if change_ratio > 0.3:  # 页面变化超过30%
                    page_transitions.append(frame_count / fps)
            
            prev_frame = frame
        
        frame_count += 1
    
    cap.release()
    
    # 分析鼠标点击热点
    click_hotspots = Counter(mouse_clicks)
    print(f"检测到 {len(click_hotspots)} 个操作热点区域")
    
    # 分析页面切换规律
    if len(page_transitions) > 0:
        intervals = np.diff(page_transitions)
        print(f"页面切换平均间隔: {np.mean(intervals):.2f}秒")
        print(f"页面切换间隔标准差: {np.std(intervals):.2f}秒")
    
    return {
        'click_hotspots': click_hotspots,
        'page_transitions': page_transitions,
        'total_duration': frame_count / fps
    }

def detect_mouse_position(frame):
    """
    检测鼠标在画面中的位置
    基于鼠标指针的特定颜色或形状特征
    """
    # 转换为HSV色彩空间
    hsv = cv2.cvtColor(frame, cv2.COLOR_BGR2HSV)
    
    # 鼠标指针颜色范围（白色/浅色）
    lower_white = np.array([0, 0, 200])
    upper_white = np.array([180, 30, 255])
    
    mask = cv2.inRange(hsv, lower_white, upper_white)
    
    # 查找轮廓
    contours, _ = cv2.findContours(mask, cv2.RETR_EXTERNAL, cv2.CHAIN_APPROX_SIMPLE)
    
    if contours:
        # 取最大轮廓作为鼠标位置
        largest = max(contours, key=cv2.contourArea)
        M = cv2.moments(largest)
        if M['m00'] > 0:
            cx = int(M['m10'] / M['m00'])
            cy = int(M['m01'] / M['m00'])
            return (cx, cy)
    
    return None
```

## 3. 量化判定标准

### 3.1 执行频次评分（F-Score）

**计算公式：**
```
F-Score = min(实际频次 / 基准频次, 1.0) × 权重系数

其中：
- 基准频次 = 4次/月（周均1次）
- 权重系数 = 1.0（日频次）/ 0.8（周频次）/ 0.6（月频次）
```

**分级标准：**

| F-Score范围 | 频次等级 | 判定 |
|-------------|----------|------|
| 0.8 - 1.0 | 高频 | 明确重复性 |
| 0.5 - 0.8 | 中频 | 可能重复性 |
| 0.0 - 0.5 | 低频 | 非重复性 |

### 3.2 单次耗时评分（T-Score）

**计算公式：**
```
T-Score = 1 - (实际耗时 - 最小耗时) / (最大耗时 - 最小耗时)

其中：
- 取该任务最近20次执行记录
- 最小耗时 = 20次记录中的最小值
- 最大耗时 = 20次记录中的最大值
```

**判定标准：**
- T-Score > 0.7：耗时稳定，重复性高
- T-Score 0.3-0.7：耗时波动中等
- T-Score < 0.3：耗时波动大，重复性低

### 3.3 规则固化度评分（R-Score）

**规则固化度评估矩阵：**

| 评估维度 | 权重 | 评分标准（1-5分） |
|----------|------|-------------------|
| 操作步骤标准化程度 | 0.3 | 1=完全依赖个人经验, 5=有精确操作手册 |
| 决策点占比 | 0.3 | 1=每个步骤都需要判断, 5=完全无需判断 |
| 输入数据源固定性 | 0.2 | 1=数据源不固定, 5=固定单一数据源 |
| 输出格式标准化 | 0.2 | 1=自由格式, 5=固定模板 |

**计算公式：**
```
R-Score = Σ(维度评分 × 权重) / 5
```

### 3.4 异常处理率评分（E-Score）

**计算公式：**
```
E-Score = 1 - (异常处理次数 / 总执行次数)

其中：
- 异常处理次数 = 需要人工干预或非标准流程处理的次数
- 总执行次数 = 统计周期内的总执行次数
```

**判定标准：**
- E-Score > 0.95：异常率极低，适合自动化
- E-Score 0.85-0.95：异常率较低，可考虑自动化
- E-Score < 0.85：异常率较高，需先标准化

### 3.5 综合判定模型

**最终重复性指数（RPI）：**

```
RPI = F-Score × 0.25 + T-Score × 0.25 + R-Score × 0.30 + E-Score × 0.20
```

**判定阈值：**

| RPI范围 | 判定结果 | 建议行动 |
|---------|----------|----------|
| ≥ 0.80 | 高重复性 | 纳入自动化优先清单 |
| 0.60 - 0.80 | 中重复性 | 进一步分析后考虑 |
| < 0.60 | 低重复性 | 暂不纳入自动化范围 |

**综合判定代码实现：**

```python
import numpy as np
import pandas as pd

class RepetitivenessClassifier:
    """
    重复性任务综合判定分类器
    """
    
    def __init__(self):
        self.weights = {
            'frequency': 0.25,
            'duration': 0.25,
            'rule_codification': 0.30,
            'exception_rate': 0.20
        }
    
    def calculate_frequency_score(self, task_data):
        """
        计算频次评分
        
        Parameters:
        -----------
        task_data : dict
            包含 'execution_records' 列表，每个记录有 'timestamp' 字段
        """
        records = pd.DataFrame(task_data['execution_records'])
        records['month'] = pd.to_datetime(records['timestamp']).dt.month
        
        # 按月统计执行次数
        monthly_counts = records.groupby('month').size()
        avg_monthly = monthly_counts.mean()
        
        # 计算频次等级
        if avg_monthly >= 20:  # 日均1次
            weight = 1.0
        elif avg_monthly >= 4:  # 周均1次
            weight = 0.8
        else:  # 月均不足1次
            weight = 0.6
        
        f_score = min(avg_monthly / 4, 1.0) * weight
        return min(f_score, 1.0)
    
    def calculate_duration_score(self, task_data):
        """
        计算耗时评分
        """
        durations = [r['duration_minutes'] for r in task_data['execution_records'] 
                    if 'duration_minutes' in r]
        
        if len(durations) < 5:
            return 0.5  # 数据不足时返回中等值
        
        durations = np.array(durations)
        min_dur = durations.min()
        max_dur = durations.max()
        
        if max_dur == min_dur:
            return 1.0
        
        #
