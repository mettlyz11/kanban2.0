### 5.2 截词符使用指南

#### 5.2.1 截词符类型说明
| 截词符 | 名称 | 作用 | 示例 |
|--------|------|------|------|
| * | 无限截词符 | 匹配任意数量的字符（包括0个） | comput* → computer, computing, computation |
| ? | 有限截词符 | 匹配单个字符 | wom?n → woman, women |
| $ | 可选截词符 | 匹配0或1个字符 | colo$r → color, colour |

#### 5.2.2 推荐截词位置表
| 词根 | 截词符 | 扩展结果 | 适用数据库 |
|------|--------|----------|------------|
| diagnos* | * | diagnosis, diagnostic, diagnostics, diagnose, diagnosing | 所有 |
| comput* | * | computer, computing, computation, computational | 所有 |
| classif* | * | classification, classify, classifying, classifier | 所有 |
| segment* | * | segmentation, segment, segmenting, segmental | 所有 |
| detect* | * | detection, detect, detecting, detector, detectable | 所有 |
| predict* | * | prediction, predict, predicting, predictive, predictability | 所有 |
| optimi* | * | optimization, optimize, optimizing, optimal | 所有 |
| tumor? | ? | tumor, tumour | 英式/美式 |
| analy* | * | analysis, analyze, analyse, analyzing, analytical | 所有 |

#### 5.2.3 截词符使用注意事项
1. **避免过度截词**：过短的词根可能导致大量无关结果，如`a*`会产生天文数字的结果
2. **数据库差异**：不同数据库对截词符支持不同（PubMed使用*，Web of Science使用*，Scopus使用*或?）
3. **性能影响**：截词符可能降低检索速度，建议在关键位置使用
4. **组合使用**：可同时使用多个截词符，如`p?diatr*`同时匹配英式/美式拼写
