# 创建家庭活动日历共享文档：操作手册

## 一、平台特性对比与家庭场景选型建议

### 1.1 主流平台核心特性对比

| 特性维度 | 飞书日历 | 腾讯文档（在线表格/日历） | Notion（Database日历视图） | Google日历 |
|---------|---------|------------------------|--------------------------|-----------|
| **免费额度** | 个人版免费，企业版需付费 | 个人版免费，企业版需付费 | 个人版免费，团队版$10/月 | 个人版免费，Workspace需付费 |
| **日历视图** | 日/周/月视图，支持甘特图 | 仅月视图（表格可自定义） | 日/周/月/年视图，支持时间轴 | 日/周/月/年/日程视图 |
| **共享协作** | 支持链接分享、部门共享 | 支持链接分享、指定成员共享 | 支持链接分享、Workspace共享 | 支持链接分享、指定邮箱共享 |
| **权限分级** | 管理员/编辑者/查看者 | 管理员/编辑者/查看者/评论者 | 完全控制/编辑/评论/查看 | 管理员/编辑者/查看者/空闲查看者 |
| **移动端同步** | iOS/Android原生App | 微信小程序+App | iOS/Android原生App | iOS/Android原生App |
| **模板支持** | 内置活动模板库 | 无内置日历模板，需手动创建 | 海量社区模板（含家庭日历） | 无内置模板，但支持导入iCal |
| **家庭成员友好度** | 中（需注册飞书账号） | 高（微信扫码即可） | 低（需注册Notion账号） | 中（需Google账号，但普及率高） |
| **通知提醒** | App推送+邮件 | 微信服务通知+邮件 | App推送+邮件+浏览器通知 | App推送+邮件+短信（部分区域） |

### 1.2 家庭场景选型建议

**推荐方案：**
- **技术门槛最低方案**：腾讯文档（在线表格）+ 微信通知。适合家庭成员中老年人较多、不熟悉新App的家庭。通过微信小程序即可访问，无需额外注册。
- **功能最全面方案**：Notion。适合年轻家庭、希望同时管理待办事项、购物清单、活动计划的用户。日历视图可与其他数据库关联。
- **同步最稳定方案**：Google日历。适合家庭成员已普遍使用Google服务的家庭，支持跨平台同步（iOS/Android/Web）。
- **国内综合最优方案**：飞书日历。适合希望使用国内服务、需要企业级协作功能的家庭。支持文档、日历、待办一体化。

**本手册将以飞书日历为主要演示平台**，同时提供其他平台的快速指引。

## 二、文档/日历创建与模板导入流程

### 2.1 飞书日历创建步骤

**步骤1：登录飞书**
- 访问 [feishu.cn](https://feishu.cn) 或下载飞书App
- 使用手机号注册个人账号（无需企业认证）
- 登录后点击左侧导航栏的“日历”图标

**步骤2：创建家庭日历**
1. 在日历页面左侧，点击“新建日历”按钮（+号）
2. 选择“创建新日历”
3. 输入日历名称：例如“王小明家庭活动日历”
4. 选择颜色（建议使用家庭主题色，如蓝色）
5. 点击“创建”

**步骤3：导入模板（可选）**
飞书提供内置活动模板，可快速导入：
1. 在日历页面，点击右上角“设置”齿轮图标
2. 选择“模板管理”
3. 在模板库中搜索“家庭”或“活动”
4. 选择“家庭活动计划表”模板
5. 点击“应用模板”，系统会自动创建示例活动（如“每周家庭会议”、“生日提醒”等）
6. 根据需要修改模板中的活动名称、时间和重复规则

**模板示例数据：**

| 活动名称 | 日期 | 时间 | 重复规则 | 备注 |
|---------|------|------|---------|------|
| 家庭周会 | 每周日 | 20:00-21:00 | 每周重复 | 讨论下周计划 |
| 妈妈生日 | 2025-03-15 | 全天 | 每年重复 | 准备礼物 |
| 孩子家长会 | 2025-04-10 | 14:00-16:00 | 不重复 | 带笔记本 |
| 家庭清洁日 | 每月第一个周六 | 09:00-12:00 | 每月重复 | 分工表见文档 |
| 暑假旅行 | 2025-07-15至07-22 | 全天 | 每年重复 | 预算5000元 |

### 2.2 其他平台快速创建指引

**腾讯文档（在线表格）：**
1. 访问 [docs.qq.com](https://docs.qq.com)
2. 点击“新建” → “在线表格”
3. 输入列标题：日期、时间、活动名称、负责人、备注
4. 使用“条件格式”高亮今日活动（设置规则：=TODAY()）
5. 通过“插入” → “图表”创建时间线图

**Notion：**
1. 访问 [notion.so](https://notion.so)
2. 创建新页面，选择“Database” → “Calendar”
3. 添加属性：日期（Date）、标签（Select）、负责人（Person）、状态（Status）
4. 从社区复制模板：[Family Calendar Template](https://www.notion.so/templates/family-calendar)
5. 修改模板中的示例数据

**Google日历：**
1. 访问 [calendar.google.com](https://calendar.google.com)
2. 点击左侧“其他日历”旁的“+” → “创建新日历”
3. 输入名称“家庭活动日历”
4. 可选：导入iCal文件（从其他平台导出）

## 三、权限分级配置（管理员/编辑者/查看者）

### 3.1 飞书日历权限配置

**权限级别定义：**
- **管理员**：完全控制，可修改日历设置、删除日历、管理成员权限
- **编辑者**：可创建、修改、删除日历中的活动
- **查看者**：只能查看活动，无法修改

**配置步骤：**
1. 在日历列表中找到“家庭活动日历”
2. 鼠标悬停在日历名称上，点击右侧出现的“...”菜单
3. 选择“设置与分享”
4. 在“权限设置”区域，点击“添加成员”
5. 输入家庭成员飞书账号（手机号或邮箱）
6. 在权限下拉菜单中选择：
   - 爸爸 → 管理员
   - 妈妈 → 管理员
   - 孩子（12岁以上） → 编辑者
   - 孩子（12岁以下） → 查看者
   - 爷爷奶奶 → 查看者
7. 点击“确认”

**高级配置：**
- **公开链接分享**：开启后生成公开链接，无需登录即可查看（仅查看权限）
- **限制编辑范围**：勾选“仅允许编辑者修改自己的活动”
- **通知设置**：为不同成员设置活动提醒（默认15分钟前）

### 3.2 其他平台权限配置

**腾讯文档：**
- 权限级别：仅查看、可评论、可编辑
- 配置：文档右上角“分享” → “指定人” → 输入微信/QQ → 选择权限
- 特殊：支持“仅查看”权限下开启“允许查看者下载”

**Notion：**
- 权限级别：完全访问、可编辑、可评论、仅查看
- 配置：页面右上角“Share” → “Invite” → 输入邮箱 → 选择权限
- 特殊：支持“Guest”权限（限时访问）

**Google日历：**
- 权限级别：管理员、编辑者、查看者、空闲查看者（仅看忙/闲状态）
- 配置：日历设置 → “与特定人员共享” → 输入邮箱 → 选择权限
- 特殊：可生成公开日历链接（仅查看）

## 四、成员邀请链接生成与通知设置

### 4.1 飞书日历邀请流程

**方法一：直接添加成员（推荐）**
1. 进入日历设置 → “权限设置”
2. 点击“添加成员”
3. 输入家庭成员飞书账号（支持批量添加，用逗号分隔）
4. 系统自动发送飞书消息通知

**方法二：生成邀请链接**
1. 在日历设置中，开启“公开链接分享”
2. 点击“复制链接”
3. 通过微信/短信发送给家庭成员
4. 成员点击链接后，选择“加入日历”

**通知设置：**
- **默认提醒**：活动开始前15分钟发送飞书App推送
- **自定义提醒**：编辑活动时，在“提醒”选项中选择：
  - 时间：活动开始前5/10/15/30分钟或1/2/24小时
  - 方式：App推送、邮件、短信（需绑定）
- **每日摘要**：开启后，每天早8点发送当日活动汇总

### 4.2 多平台通知配置

| 平台 | 通知方式 | 配置路径 | 备注 |
|------|---------|---------|------|
| 飞书 | App推送+邮件 | 设置→通知→日历通知 | 可设置静音时段 |
| 腾讯文档 | 微信服务通知 | 文档→分享→开启通知 | 需关注腾讯文档公众号 |
| Notion | App推送+邮件+浏览器 | 设置→通知→日历提醒 | 可设置不同设备通知 |
| Google日历 | App推送+邮件+短信 | 设置→通知→添加通知 | 短信仅限部分国家 |

**最佳实践：**
- 为所有家庭成员设置统一的默认提醒时间（如15分钟前）
- 重要活动（如家长会、医疗预约）设置双提醒（1天前+15分钟前）
- 为孩子开启“家长通知”功能（活动修改时自动通知家长）

## 五、移动端同步与常见问题排查

### 5.1 移动端同步配置

**飞书App同步（iOS/Android）：**
1. 下载并登录飞书App
2. 点击底部“日历”标签
3. 确保“家庭活动日历”已显示在日历列表中
4. 开启“同步到手机系统日历”（设置→日历→同步到系统日历）
5. 在手机系统日历中查看家庭活动

**跨平台同步方案：**
- **方案A**：使用CalDAV协议（飞书→Google日历）
  - 飞书日历设置 → 导出CalDAV链接
  - Google日历 → 其他日历 → 从URL添加 → 粘贴链接
- **方案B**：使用iCal导出（飞书→Apple日历）
  - 飞书日历设置 → 导出为iCal文件
  - Apple日历 → 文件 → 导入 → 选择iCal文件

### 5.2 常见问题排查

| 问题 | 可能原因 | 解决方案 |
|------|---------|---------|
| 成员无法看到日历 | 权限未正确配置 | 检查成员权限是否为“查看者”及以上 |
| 活动未同步到手机 | 同步开关未开启 | 在App设置中开启“同步到系统日历” |
| 通知未收到 | 通知权限被关闭 | 在手机设置中开启飞书通知权限 |
| 编辑冲突 | 多人同时修改同一活动 | 飞书会提示冲突，手动选择保留版本 |
| 邀请链接失效 | 链接过期（默认7天） | 重新生成链接或直接添加成员 |
| 日历显示乱码 | 时区设置不一致 | 检查所有成员的时区设置（建议统一为UTC+8） |
| 无法删除活动 | 权限不足（查看者） | 联系管理员提升权限 |
| 模板导入失败 | 网络问题或模板已更新 | 重新尝试导入，或手动创建活动 |

### 5.3 故障排除高级技巧

**排查步骤：**
1. **确认网络连接**：检查所有设备是否正常联网
2. **检查账号状态**：确保所有家庭成员已登录飞书账号
3. **验证日历可见性**：在日历列表中确认“家庭活动日历”未被隐藏（左侧勾选状态）
4. **测试权限**：让一个管理员创建一个测试活动，查看其他成员是否能正常查看
5. **查看日志**：在飞书设置→帮助与反馈→查看操作日志，定位问题

**数据恢复：**
- 误删活动：在飞书日历的“回收站”中找回（保留30天）
- 误删日历：联系飞书客服恢复（需提供日历ID）
- 批量导出备份：在日历设置中导出为CSV或iCal格式，每月备份一次
