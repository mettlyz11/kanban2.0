## 四、演练中发现的问题与修复
### 问题1：mysqldump 认证插件异常
- 现象：`mysqldump` 无法加载 `mysql_native_password.so`；
- 影响：标准 MySQL 逻辑导出失败；
- 处理：在备份执行器中加入自动 fallback 机制，切换到 Python 级核心表导出，避免整条链路中断；
- 结论：灾备方案对本机 MySQL 客户端缺陷具备容错能力。

### 问题2：初版验证脚本字符串拼接错误
- 现象：验证脚本中的 f-string 引号嵌套不正确；
- 处理：改为先生成 `summary` 变量，再写入 markdown 行；
- 结果：验证脚本可稳定执行。

### 问题3：恢复脚本环境变量导出顺序问题
- 现象：`MANIFEST` 环境变量在 Python 子进程前未显式导出；
- 处理：将 `export MANIFEST` 前置；
- 结果：恢复脚本能够正确读取 manifest 并完成恢复材料生成。
