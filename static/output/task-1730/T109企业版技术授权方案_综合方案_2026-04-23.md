## 一、T109当前可授权能力边界

### 1.1 核心技术能力全景

T109是和光智成自主研发的**AI+计算化学**平台，核心技术壁垒覆盖以下领域：

| 能力模块 | 技术描述 | 成熟度 | 可授权状态 |
|----------|----------|--------|------------|
| **过渡态AI预测** | 基于ML的过渡态（TS）几何结构直接预测，跳过传统NEB/IRC计算流程 | 生产就绪 | ✅ 核心授权项 |
| **Hermes子代理系统** | ML驱动的自主过渡态寻找子代理，支持72小时无人值守运行 | 生产验证通过（SDS验证） | ✅ 核心授权项 |
| **多基组计算优化** | 自动化基组选择与计算精度-效率平衡 | 生产就绪 | ✅ 可授权 |
| **反应路径搜索** | 自动反应网络探索与路径优化 | 生产就绪 | ✅ 可授权 |
| **AI全自动化实验室技术** | 实验流程全自动化（结构测试全流程），北航重点实验室联合研发 | 联合研发中 | ⚠️ 联合授权（需北航同意） |
| **文献计量与知识管理** | 自动文献下载、筛选、笔记整理到Obsidian | 运行中 | ✅ 可授权 |
| **SDS自驱动系统** | 72小时无人值守验证通过，异常自愈率~100% | 生产级就绪 | ✅ 企业定制版独有 |
| **知识大脑（Graph RAG）** | 3阶段检索管道（向量粗筛→图路径扩展→语义排序），30个核心概念+55个关系 | 运行中 | ✅ 企业定制版独有 |

### 1.2 不可授权范围（红线）

| 范围 | 原因 |
|------|------|
| 和光智成核心商业数据与融资信息 | 商业机密 |
| 未发表的核心算法源代码 | 知识产权保护，计划写入JCTC/Nature MI论文 |
| 北航联合研发未公开成果 | 知识产权归属未完全清晰 |
| Hermes子代理的完整训练权重 | 核心竞争力，仅提供API/模型调用 |

### 1.3 交付形态

T109企业版可通过以下形态交付：
- **SaaS云服务**：和光智成托管，客户通过Web/API使用
- **私有化部署**：部署到客户自有服务器（需额外费用）
- **混合模式**：核心计算在和光云端，敏感数据本地处理
- **技术授权**：授权客户在自有系统中集成T109能力（API/SDK）

## 七、风险边界

### 7.1 技术风险

| 风险 | 影响 | 应对措施 |
|------|------|----------|
| AI预测精度不满足工业级要求 | 客户流失 | 明确精度边界，提供传统计算方法兜底 |
| 大规模并发导致系统不稳定 | SLA违约 | 逐步放量，设置并发上限 |
| 数据安全/泄露 | 法律风险+品牌损害 | 私有化部署选项，加密传输与存储 |
| 核心算法被逆向工程 | 知识产权损失 | API交付为主，私有化交付加密模型 |

### 7.2 商业风险

| 风险 | 影响 | 应对措施 |
|------|------|----------|
| 定价过高导致客户拒绝 | 收入不达标 | 提供POC免费试用验证价值，灵活议价 |
| 定价过低导致利润不足 | 亏损 | 严格成本核算，设置最低价格红线 |
| 竞品（如Schrödinger/Materials Studio）低价竞争 | 市场份额被侵蚀 | 突出AI加速差异化，不拼价格拼价值 |
| 客户付费意愿不足 | 转化率低 | 先学术后工业，先小规模后大规模 |
| 融资节奏与收入不匹配 | 现金流压力 | 技术授权收入作为中期补充，不依赖为主要收入 |

### 7.3 法律与合规风险

| 风险 | 影响 | 应对措施 |
|------|------|----------|
| 北航联合研发成果授权不清 | 知识产权纠纷 | 与北航明确知识产权划分 |
| 军工客户涉密要求 | 合规风险 | 建立涉密项目隔离机制 |
| 数据跨境（澳门/海外客户） | 合规风险 | 遵守数据出境安全评估办法 |
| 论文发表与技术保密冲突 | 核心算法泄露 | 论文发表前进行保密审查 |

### 7.4 不可触碰的红线

1. **核心算法源代码绝不开放**，仅提供API/编译后的模型
2. **不与竞品（Schrödinger等）直接对比测试**，除非客户主动要求
3. **不承诺超出技术能力的精度或速度指标**
4. **不在未签NDA的情况下展示客户数据或案例**
5. **不接受排他性授权条款**（限制和其他客户合作）
