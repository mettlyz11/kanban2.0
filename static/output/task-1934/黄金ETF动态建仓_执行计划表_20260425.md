## 三、产品交易细则

### 3.1 BAR（贝莱德黄金ETF）
- 代码：BAR
- 交易所：NYSE Arca
- 每单位对应：约1/100盎司黄金
- 当前价格：约$38.5
- 最小交易单位：1股
- 流动性：日均$3.2亿成交量，小额交易无忧

### 3.2 IAU（iShares黄金ETF）
- 代码：IAU
- 交易所：NYSE Arca
- 每单位对应：约1/100盎司黄金
- 当前价格：约$38.5
- 最小交易单位：1股
- 流动性：日均$12亿成交量，适合较大额交易

### 3.3 交易优化建议
- 单笔交易<5万美元：可市价单直接成交
- 单笔交易5-20万美元：拆分为3-5笔限价单
- 单笔交易>20万美元：使用算法交易或跨多个交易日执行
- 最佳交易时段：美股开盘后1小时-收盘前1小时

## 六、应急处理流程

### 6.1 快速下跌应急（单日下跌>3%）
1. **暂停所有买入计划**
2. **检查下跌原因**：是基本面变化还是技术性调整？
3. **若为技术性调整**：等待企稳后按原计划执行
4. **若为基本面变化（如降息预期取消）**：重新评估策略，考虑减仓
5. **触及止损线（回撤>18%）**：立即减仓50%

### 6.2 快速上涨应急（单日上涨>3%）
1. **不追高买入**
2. **检查是否有基本面重大利好**
3. **若为短期情绪推动**：等待回调
4. **若趋势确认**：按第四批计划执行，不额外加仓

### 6.3 流动性应急
- 若BAR流动性不足：临时切换为IAU交易
- 保持至少50%仓位在高流动性产品
- 极端情况下可使用GLD作为流动性备份
