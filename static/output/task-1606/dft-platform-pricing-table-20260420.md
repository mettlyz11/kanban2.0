## 定价体系概述

### 设计原则

| 原则 | 说明 |
|------|------|
| **3级阶梯定价** | 入门级→专业级→企业级，逐级递增，降低决策门槛 |
| **价值定价** | 按"客户节省的研发成本"定价，而非"计算资源成本" |
| **对标定价** | 对标Schrödinger/VASP，定价为其25-40% |
| **混合计费** | 年费订阅 + 按量计费补充 + 项目制服务，灵活适配 |
