## 附录B: 演示PPT设计规范

### B.1 视觉风格

| 元素 | 规范 |
|------|------|
| **主色** | 深蓝 (#1a237e) — 科技感、专业感 |
| **辅色** | 亮蓝 (#42a5f5) — 高亮/强调 |
| **强调色** | 橙色 (#ff9800) — CTA/关键数据 |
| **背景** | 白色或浅灰 — 干净简洁 |
| **字体** | 标题: 思源黑体 Bold / 正文: 思源黑体 Regular |
| **图标** | Material Design 风格线性图标 |

### B.2 每页设计原则

| 原则 | 说明 |
|------|------|
| 一观点 | 每页只传达一个核心观点 |
| 少文字 | 每页≤6行，每行≤15字 |
| 多图表 | 用图表替代文字描述 |
| 数据优先 | 用具体数字代替定性描述 |
| 对比强烈 | 竞品对比用红/绿色直观区分 |
