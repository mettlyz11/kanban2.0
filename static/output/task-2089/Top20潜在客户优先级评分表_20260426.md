**基本信息：**
- 成立时间：1998年
- 上市代码：600309.SH
- 员工数量：约18000人
- 2024年营收：约1850亿元
- 研发投入：约55亿元（占比约3%）

**数字化现状：**
- 2019年启动工业互联网平台建设
- 2023年发布"数字万华"战略
- 现有系统：SAP ERP、MES、LIMS、PLM等
- 正在推进：智慧研发平台、数字孪生工厂

**核心需求：**
1. 聚氨酯配方AI优化（MDI、TDI等）
2. 新材料研发周期缩短（POE、尼龙12等）
3. 工艺参数实时优化与能耗降低
4. 研发知识管理与专家经验固化

**决策链条：**
- 最终决策人：董事长/总裁
- 技术选型：CIO + 中央研究院院长
- 项目执行：数字科技部 + 各事业部研发负责人

**联系方式线索：**
- 总机：0535-3033000
- 数字科技部总经理：公开演讲场合可接触
- 中央研究院院长：行业学术会议常客
- 总部地址：山东省烟台市芝罘区幸福南路7号

通过"中国聚氨酯工业协会"或"化工学会"举办的会议建立初步联系，提出"MDI配方优化"POC方案，以研发效率提升30%为目标，3个月验证期。
