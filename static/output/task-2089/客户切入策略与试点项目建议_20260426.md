## 一、总体切入策略框架

### 1.1 "三步走"切入战略

```
【第一步：单点突破】
    ↓
  选择1-2个具体痛点做POC
  周期：1-3个月
  预算：30-100万元
  目标：建立信任，验证效果
    ↓
【第二步：模块推广】
    ↓
  将成功POC扩展到多个产品线/工厂
  周期：3-9个月
  预算：100-300万元
  目标：形成部门级应用，建立标杆案例
    ↓
【第三步：平台合作】
    ↓
  建设企业级AI研发平台
  周期：9-24个月
  预算：500-2000万元
  目标：成为战略合作伙伴，深度绑定
```

## 二、首批试点项目详细方案（5个）

### 试点项目1：万华化学 - 聚氨酯配方AI优化

#### 项目背景
- 万华是全球MDI龙头，市占率超30%
- 聚氨酯配方复杂，影响因素超过500个
- 当前研发主要依赖"试错法"，新品开发周期12-18个月
- 每年研发投入超50亿元，优化空间巨大

#### 项目目标（SMART原则）
| 指标 | 目标值 | 计算方式 |
|-----|-------|---------|
| 研发效率提升 | ≥30% | (优化后实验次数 - 优化前)/优化前 |
| 配方性能提升 | ≥5% | 核心性能指标对比 |
| 研发成本降低 | ≥20% | 单配方研发成本对比 |
| 项目周期 | 3个月 | POC验证周期 |

#### 项目范围
- **聚焦品类**：聚合MDI（产品代码：PM200）
- **数据范围**：近3年历史实验数据，约5000组实验
- **功能范围**：配方推荐 + 性能预测 + 实验设计优化
- **部署方式**：私有化部署，数据不出域

#### 项目预算
| 科目 | 金额（万元） | 说明 |
|-----|------------|------|
| 数据清洗与治理 | 40 | 数据标准化、特征工程 |
| AI模型开发与训练 | 60 | 推荐模型、预测模型开发 |
| 系统开发与部署 | 50 | Web界面、API接口、部署实施 |
| 3个月运行维护 | 20 | 模型迭代、技术支持 |
| **合计** | **170** | 含3个月POC验证期 |

#### 成功标准与验收
1. 配方推荐命中率≥60%（推荐的前10个配方中有6个性能达标）
2. 新配方研发周期从平均15个月缩短至10个月以内
3. 研发人员满意度评分≥4.0/5.0
4. 系统稳定运行率≥99.5%

#### 推进时间表
| 时间节点 | 里程碑 | 交付物 |
|---------|-------|-------|
| 第1周 | 项目启动会 | 项目章程、需求规格说明书 |
| 第2-4周 | 数据获取与清洗 | 数据集、数据质量报告 |
| 第5-8周 | 模型开发与训练 | 模型原型、性能测试报告 |
| 第9-10周 | 系统开发与部署 | 完整系统、用户手册 |
| 第11-12周 | 试运行与优化 | 试运行报告、优化后的模型 |
| 第13周 | 项目验收 | 验收报告、总结文档 |

#### 关键风险与应对
| 风险 | 可能性 | 影响 | 应对措施 |
|-----|--------|------|---------|
| 数据质量差 | 高 | 严重 | 1. 配置专职数据工程师<br>2. 建立数据质量评估机制<br>3. 必要时补充新实验数据 |
| 客户配合度不够 | 中 | 严重 | 1. 找内部发起人（研发负责人）<br>2. 建立周例会机制<br>3. 设置里程碑奖励机制 |
| 模型效果不达预期 | 中 | 高 | 1. 设置"效果对赌"条款<br>2. 分阶段验收，及时调整<br>3. 准备备选技术方案 |

- 现有LIMS系统已积累大量数据，但未充分利用

#### 项目目标
| 指标 | 目标值 |
|-----|-------|
| 新品开发周期 | 缩短40%（从10个月→6个月） |
| 实验数量 | 减少50% |
| 配方性能匹配度 | ≥80% |
| 知识沉淀率 | 提升100% |

#### 项目范围
- **聚焦产品**：锂电池电解液（六氟磷酸锂体系）
- **功能模块**：
  1. 配方智能推荐引擎
  2. 性能预测模型（电导率、氧化电位、低温性能等）
  3. 实验设计优化（DOE）
  4. 研发知识图谱
- **用户规模**：约100名研发人员使用

#### 项目预算
| 科目 | 金额（万元） |

| 需求调研与方案设计 | 20 |

| 部署与培训 | 20 |

#### 差异化优势
1. **新能源行业Know-how**：团队有锂电材料研发背景
2. **快速迭代能力**：采用敏捷开发，每2周交付一个版本
3. **电池企业资源**：可对接宁德时代等下游客户需求
4. **成本优势**：相比海外同类产品，价格低50%以上

#### 推进关键

### 试点项目4：恒力石化 - PTA工艺参数优化系统

#### 项目背景
- 恒力石化PTA产能全球第一，年产能超1000万吨
- PTA是聚酯产业链关键环节，利润空间受成本影响大
- PTA工艺氧化反应器参数复杂，人工调优空间有限
- 恒力处于快速扩张期，对数字化投入大、决策快

#### 项目目标
| 指标 | 目标值 |
|-----|-------|
| PTA产品收率提升 | ≥0.3% |
| 对二甲苯（PX）单耗降低 | ≥2kg/吨PTA |
| 能耗降低 | ≥3% |
| 优等品率提升 | ≥1% |

#### 项目价值估算（单套装置）
- 年产能：250万吨PTA
- PX单耗降低2kg/吨 → 年节省PX 5000吨 → 价值约4000万元
- 能耗降低3% → 年节省约500万元
- 优等品率提升1% → 年增收约1000万元
- **单套装置年化收益：约5500万元**
- 恒力有4套PTA装置，总潜力超2亿元/年

#### 项目预算与周期
- 单套装置预算：180万元
- 实施周期：4个月
- 投资回收期：<1个月

#### 推进关键
- 恒力董事长对"降本增效"极其敏感，ROI是核心
- PTA是恒力核心业务，工艺部门话语权大
- 建议先做1套装置POC，验证后快速复制到其他装置
- 可采用"基础费用+效益分成"模式（如收取年度节省额的10%）

### 试点项目5：巴斯夫中国 - 可持续材料联合研发

#### 项目背景
- 巴斯夫是全球化工领导者，"可持续发展"是核心战略
- 中国市场占巴斯夫亚太区40%，是最重要增长极
- 巴斯夫全球有统一数字化平台，但中国市场有本地化需求
- 中国"双碳"政策对产品碳足迹要求越来越高

- 不做"系统供应商"，而是"创新合作伙伴"
- 聚焦巴斯夫全球平台覆盖不到的中国特色需求
- 以联合研发项目形式切入，避免与巴斯夫全球供应商竞争

#### 项目方向
1. **中国市场特色产品的配方优化**（如适应中国煤制烯烃原料）
2. **产品碳足迹AI核算工具**（符合中国"双碳"政策要求）
3. **中国供应商材料性能预测模型**（本地化供应链）

#### 项目预算
- 联合研发项目：150-300万元/项目
- 周期：6-12个月
- 后续：可扩展到亚太区其他国家

#### 推进关键
- 巴斯夫对供应商资质要求极高，需要"耐心培育"
- 找对部门：亚太区创新部 > 数字化部 > IT部门
- 建议先参加巴斯夫供应商创新日，展示技术能力
- 与巴斯夫风险投资部门（BASF Venture）接触，寻求战略合作可能

## 三、分行业切入打法

### 3.1 炼化行业（中石化、中石油、恒力、荣盛）

#### 行业特点
- 产能规模大，单套装置产值超百亿
- 工艺成熟，优化空间看似小但绝对值大
- 安全与稳定是首要考虑，创新相对保守
- 决策链条长，合规要求高

#### 核心切入点排序
1. ⭐⭐⭐⭐⭐ **工艺参数优化**（收率提升0.1%即价值千万）
2. ⭐⭐⭐⭐⭐ **设备故障预警**（非计划停车损失巨大）
3. ⭐⭐⭐⭐☆ **能耗优化**（双碳政策驱动）
4. ⭐⭐⭐☆☆ **安全风险预警**（政策强制要求）
5. ⭐⭐☆☆☆ **催化剂研发**（长期价值大但周期长）

#### 销售话术要点
```
"我们的AI优化系统已在某炼厂催化装置验证，
帮助客户提升收率0.5%，年化收益超1500万元，
投资回收期不到2个月。

系统采用私有化部署，数据不出厂，

我们可以先做单装置POC验证，
效果达标后再付费，风险您完全可控。"

#### 典型客户决策路径
```
车间主任提出需求 → 生产副总同意 → 信息部选型 → 集团招标 → 项目实施
      ↓                    ↓                    ↓
  看重"效果可量化"   看重"风险可控"    看重"合规性与价格"

## 四、投标与商务策略

### 4.1 投标文件核心要点

#### 技术标重点突出
1. **化工行业Know-how**：展示团队化工背景，而非纯IT公司
2. **标杆案例**：同行业成功案例是最佳说服力
3. **效果量化**：每个功能点都要有ROI计算
4. **数据安全**：强调私有化部署、数据加密、等保认证
5. **实施方法论**：展示成熟的项目管理体系

#### 商务标策略
| 项目类型 | 报价策略 | 付款方式 |
|---------|---------|---------|
| **POC项目** | 成本价甚至免费 | 验收后一次性付款 |
| **标杆项目** | 适中报价，预留打折空间 | 3-3-3-1（预付款30%） |
| **通用项目** | 标准化报价 | 按里程碑付款 |
| **战略项目** | 低价切入，看重后续价值 | 灵活的商务条款 |

### 4.2 创新商业模式

#### 模式1：效果对赌模式
```
基础服务费 + 效果分成

例：工艺优化项目
- 基础费用：50万元（覆盖成本）
- 效果分成：年度效益的10%，连续收取3年
- 保底条款：如年化效益低于500万元，不收取分成

对客户：零风险，不达目标不付费
对我们：优质项目可获得超额回报
```

#### 模式2：SaaS订阅模式
```
适合标准化程度高的产品

- 订阅费：10-30万元/年/模块
- 按使用人数收费：5000元/人/年
- 按计算量收费：按API调用次数计费

优势：收入可预测，客户粘性高，持续迭代
```

#### 模式3：联合研发模式

## 六、成功关键要素总结

### 6.1 产品层面
1. ✅ **行业Know-how是核心壁垒**：纯AI公司不懂化工，纯化工公司不懂AI，交叉领域是我们的机会
2. ✅ **效果必须可量化**：化工客户极其务实，不能用"提升效率"这种空话，必须算清楚具体收益
3. ✅ **数据安全是底线**：私有化部署、数据不出域、等保认证是标配

### 6.2 销售层面
1. ✅ **找对人**：研发/工艺部门 > 业务部门 > IT部门，找到真正的痛点所有者
2. ✅ **算对账**：用ROI说话，让客户觉得"这不是花钱，是投资"
3. ✅ **用巧劲**：从POC切入，小步快跑，用效果建立信任
4. ✅ **讲故事**：同行案例是最好的说服力，"XX用了之后怎么样"

### 6.3 交付层面
1. ✅ **首战必胜**：第一个项目必须做好，标杆效应价值千万
2. ✅ **快速交付**：POC控制在3个月内，让客户快速看到效果
3. ✅ **持续服务**：化工客户粘性高，做好服务后续订单自然来

化工行业圈子很小，口碑传播比什么都重要。
把每一个客户都做成标杆，业务自然越做越顺。
