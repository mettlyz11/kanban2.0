## 二、Hermes子代理能力设计

### 2.1 核心定位：过渡态搜索策略专家

#### 能力层级架构
```
Hermes子代理
├── 策略层：搜索策略选择与优化
├── 执行层：NEB/QST2/QST3算法调度
├── 判断层：TS验证与质量评估
├── 交互层：人工介入决策支持
```

### 2.2 具体功能模块设计

#### 模块1：智能算法选择器
- **输入**: 反应类型、反应物/产物结构、计算资源
- **输出**: 最优搜索算法（NEB/QST2/QST3/ML直接预测）
- **决策逻辑**: 
  - 简单反应 → QST2 + ML初始猜测
  - 复杂反应 → NEB-ci + 逐步优化
  - 催化反应 → QST3 + 活性位点约束

#### 模块2：ML初始猜测生成器
- 基于GNN的TS几何预測
- 多模型集成（减少偏差）
- 置信度评估与阈值判断

#### 模块3：自动化优化工作流
- 初始结构生成 → 粗优化 → 精确优化 → 频率验证
- 失败自动重试（更换算法/调整参数）
- 计算资源动态调度

#### 模块4：人工介入触发机制
- 连续3次失败自动请求人工
- TS结构异常（虚频≠1）报警
- 能量异常（>50 kcal/mol）预警

## 三、训练数据准备策略

### 3.1 公开数据集整合

| 数据集 | 规模 | 特点 | 优先级 |
|--------|------|------|--------|
| **QM9-TS** | ~10k | 小分子气相，高质量DFT | ★★★★★ |
| **SPCREACT2** | ~5k | 有机反应，多样性好 | ★★★★☆ |
| **ReactDB** | ~3k | 催化反应，稀缺 | ★★★★★ |
| **TS-Benchmark** | ~2k | 标准测试集 | ★★★☆☆ |
| **Materials Project TS** | ~8k | 固体表面反应 | ★★★☆☆ |

**预计总量**: ~28k高质量TS结构

### 3.2 T109自有计算数据

#### 数据生成计划
1. **第一阶段（1-2月）**: 500个有机反应DFT计算
2. **第二阶段（3-4月）**: 300个催化反应计算
3. **第三阶段（5-6月）**: 200个液相反应计算

**数据标准**:
- 理论级别: B3LYP-D3/def2-SVP（粗优化）
- 验证级别: M06-2X/def2-TZVP（精确优化）
- 频率验证: 必须有且仅有1个虚频
- IRC验证: 连接反应物与产物

### 3.3 数据增强策略
- 构象扰动（±0.1Å键长，±5°键角）
- 同位素取代
- 溶剂效应隐式建模
- 预计数据扩增5-10倍
