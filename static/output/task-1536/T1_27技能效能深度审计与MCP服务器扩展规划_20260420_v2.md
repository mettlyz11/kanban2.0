## 第三章：系统性问题诊断

### 3.1 🔴 严重问题（P0-需立即修复）

#### 问题1: 记忆向量索引完全失效
```
症状: 184个记忆文件chunks均报告 "without vector embeddings — sqlite-vec unavailable"
影响: memory_search 降级为纯文本搜索，Graph RAG检索管道失效
根因: sqlite-vec Python包未安装
修复: pip install sqlite-vec 或安装带向量扩展的SQLite
预估影响: 记忆检索质量下降60%+
```

#### 问题2: Telegram命令超载截断
```
症状: 108-112个命令配置 vs Telegram bot 100个命令限制
影响: 8-12个命令被截断，用户无法通过Telegram调用
根因: 技能+插件命令总数超出限制
修复: 禁用原生命令(channels.telegram.commands.native: false)或减少技能数量
```

#### 问题3: Composio MCP连接持续失败
```
症状: 43次连接失败，7个MCP工具无法使用
影响: Composio集成的第三方服务全部不可用
根因: composio.dev MCP endpoint 不可达或认证问题
修复: 检查API Key有效性，或降级为CLI模式
```

### 3.2 ⚠️ 中等问题（P1-需本周解决）

#### 问题4: qqbot WebSocket持续断开
```
症状: qqbot通道持续Token刷新失败
影响: QQ通信不稳定
根因: QQ开放平台Token过期或网络问题
```

#### 问题5: 图像尺寸校验失败
```
症状: 多次"image length and width do not meet model restrictions"错误
影响: 图像生成任务失败
根因: 模型对图像尺寸有特定要求（height:1200或width限制）
```

#### 问题6: 技能冗余度25%
```
症状: 81个技能中约20个功能重叠或极少使用
影响: 增加Telegram命令数，增大上下文加载负担
修复: 合并/禁用低频重叠技能
```
