## 一、系统定位与愿景

### 1.1 核心定位
**Pepi = 化学领域的数字员工，而非仅仅数字人**
- 数字人 = 交互展示、情感表达、形象呈现
- 数字员工 = 实际工作执行、任务自动化、决策辅助
- **化学领域垂直聚焦**：面向材料科学、计算化学、药物研发的专业AI助手

### 1.2 愿景目标
成为化学科研人员的"第二大脑"和"虚拟实验员"，实现：
- 80%的重复性科研工作自动化
- 文献理解与知识提取效率提升10倍
- 计算化学任务提交门槛降低到自然语言
- 实验设计与数据分析的智能辅助

## 二、三层能力体系定义

### L1 交互层 - 数字人体验（基础层）
**核心能力**：自然语言对话 + 情感表达 + 数字人形象

| 能力模块 | 具体功能 | 技术实现 |
|---------|---------|---------|
| 多模态对话 | 语音/文字输入、上下文理解、多轮对话 | LLM + ASR + TTS |
| 情感表达 | 面部表情、语气变化、肢体语言 | 数字人引擎 + 情感化TTS |
| 形象呈现 | 2D/3D数字人形象、场景切换、动作驱动 | Live2D/Unity + 动作捕捉 |
| 唤醒交互 | 语音唤醒、视线追踪、主动交互 | 唤醒词检测 + VLM |

**验收标准**：
- 对话响应延迟 < 500ms
- 语音识别准确率 > 95%
- 自然语言理解准确率 > 90%
- 数字人画面帧率 > 30fps

---

### L2 操作层 - 工具执行（核心层）
**核心能力**：浏览器自动化 + Office操作 + 化学软件调用

| 能力模块 | 具体功能 | 技术实现 |
|---------|---------|---------|
| 浏览器自动化 | 文献检索、数据爬取、表单填写、网页交互 | Playwright/Puppeteer + MCP |
| Office操作 | Word编辑、Excel数据处理、PPT生成、邮件撰写 | Office JS + Python自动化 |
| 化学软件接口 | Gaussian提交、ORCA计算、VMD可视化、Materials Studio操作 | CLI调用 + 脚本封装 |
| 文件系统操作 | 目录管理、文件读写、格式转换、备份同步 | OS API + 云存储接口 |
| 数据库操作 | 文献入库、数据查询、结果保存、知识图谱构建 | SQL + Vector DB |

**化学领域特殊能力**：
1. **3D分子结构可视化**：支持SMILES转3D、构象搜索、对齐比对
2. **计算化学任务提交**：自然语言描述 → 输入文件生成 → 任务调度 → 结果解析
3. **文献管理自动化**：PDF批量下载、元数据提取、参考文献格式化
4. **实验记录整理**：实验数据自动录入、图表生成、报告撰写

**验收标准**：
- 浏览器操作成功率 > 95%
- Gaussian任务提交成功率 > 90%
- Office文档生成准确率 > 95%
- 单任务执行时间 < 5分钟（简单任务）

---

### L3 思考层 - 智能决策（高级层）
**核心能力**：文献理解 + 实验设计 + 数据分析

| 能力模块 | 具体功能 | 技术实现 |
|---------|---------|---------|
| 文献深度理解 | 全文语义理解、方法提取、结论总结、知识图谱构建 | RAG + 化学领域微调VLM |
| 实验智能设计 | 反应路径推荐、条件优化、风险评估、成本估算 | 化学知识库 + LLM推理 |
| 数据分析挖掘 | 谱图解析、趋势分析、异常检测、相关性发现 | ML模型 + 统计分析 |
| 论文写作辅助 | 摘要生成、段落润色、引用推荐、审稿意见回复 | LLM + 学术语料微调 |
| 课题方向探索 | 研究热点分析、空白领域发现、跨领域联想、创新点挖掘 | 文献计量 + 知识图谱推理 |

**化学领域深度能力**：
1. **反应机理推理**：基于文献和量子化学计算的机理推演
2. **材料性能预测**：基于结构的性能预测、分子设计优化
3. **文献矛盾分析**：识别不同文献中的结论冲突、提供验证建议
4. **课题可行性评估**：综合文献、技术、成本、时间的全面评估

**验收标准**：
- 文献摘要准确率 > 85%（专家评估）
- 实验设计合理性 > 80%（专家评估）
- 数据分析结论有效性 > 85%
- 写作辅助采纳率 > 70%

## 三、技术栈选型

### 3.1 核心技术架构
```
┌─────────────────────────────────────────────────────────────┐
│                    用户交互层 (L1)                            │
│  数字人形象 ◆ 语音交互 ◆ 文字对话 ◆ 情感表达                  │
├─────────────────────────────────────────────────────────────┤
│                    任务编排层                                 │
│  任务分解 ◆ 工具选择 ◆ 执行调度 ◆ 错误处理 ◆ 结果汇总         │
├─────────────────────────────────────────────────────────────┤
│                    能力执行层 (L2)                            │
│  浏览器自动化 ◆ Office操作 ◆ 化学软件 ◆ 文件系统 ◆ 数据库      │
├─────────────────────────────────────────────────────────────┤
│                    智能思考层 (L3)                            │
│  文献理解 ◆ 实验设计 ◆ 数据分析 ◆ 写作辅助 ◆ 课题探索         │
├─────────────────────────────────────────────────────────────┤
│                    基础模型层                                 │
│  LLM大脑 ◆ VLM视觉 ◆ TTS语音 ◆ ASR语音 ◆ Embedding向量       │
└─────────────────────────────────────────────────────────────┘
```

### 3.2 具体技术选型

| 技术领域 | 选型方案 | 选型理由 |
|---------|---------|---------|
| **LLM大脑** | DeepSeek V3 / Qwen 3.6 / Kimi K2.6 | 中文能力强、长文本支持、代码能力优秀 |
| **VLM视觉** | Qwen-VL / GPT-4o / Claude 3.5 Opus | 图像理解强、支持图表/谱图解析 |
| **语音合成** | 豆包TTS / ElevenLabs / 阿里云语音 | 中文自然度高、情感化表达 |
| **语音识别** | 讯飞ASR / OpenAI Whisper | 准确率高、专业术语适配 |
| **数字人引擎** | Live2D / Unity / 即构数字人 | 开发效率高、效果逼真 |
| **浏览器自动化** | Playwright + Browser-use | 稳定性好、AI驱动能力强 |
| **工具调用框架** | MCP (Model Context Protocol) | 标准协议、生态丰富 |
| **化学计算接口** | ASE + PySCF + RDKit | 开源免费、Python生态完善 |
| **向量数据库** | Milvus / ChromaDB | 性能优秀、相似度检索能力强 |
| **任务编排** | LangGraph / AutoGen | 多Agent协作、复杂任务分解 |

### 3.3 化学领域专用工具链
- **分子处理**: RDKit, OpenBabel, PyMol
- **量化计算**: Gaussian, ORCA, VASP, LAMMPS (封装调用)
- **文献处理**: CrossRef API, Semantic Scholar API, ChemReader
- **数据分析**: Pandas, NumPy, Matplotlib, Plotly (化学专用图表)
- **知识图谱**: Neo4j (化学反应网络、材料关系图谱)

## 五、与T109（计算化学平台）集成方案

### 5.1 集成定位
**Pepi = T109的自然语言用户界面**
- 用户无需学习T109的复杂操作
- 通过自然语言描述计算需求
- Pepi自动转换为T109可执行的任务

### 5.2 集成架构
```
用户自然语言请求
    ↓
Pepi语义理解与任务分解
    ↓
T109 API调用（任务提交）
    ↓
计算节点执行（Gaussian/ORCA/VASP）
    ↓
Pepi结果解析与可视化
    ↓
自然语言回答 + 图表 + 分子结构
```

### 5.3 集成功能清单
1. **计算任务提交**：自然语言 → 输入参数 → T109任务创建
2. **任务状态查询**：进度跟踪、剩余时间预估、异常告警
3. **结果可视化**：能量曲线、分子轨迹、谱图绘制
4. **报告生成**：自动整理计算结果、生成分析报告
5. **历史管理**：计算记录查询、数据对比、知识积累
