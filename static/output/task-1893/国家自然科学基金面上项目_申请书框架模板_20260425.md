### 1.3 四大创新点设计

#### ✨ 创新点1：Hermes子代理过渡态主动学习框架【方法创新】
- 突破传统"初猜-优化"模式，实现端到端过渡态几何结构直接预测
- 主动学习策略将训练数据需求降低70%
- 预测精度达到DFT级别(MAE < 0.1 Å)

#### ✨ 创新点2：电子结构感知的能垒预测模型【理论创新】
- 提取3D电子密度分布作为关键描述符(而非简单几何特征)
- 物理约束的ML模型保证能垒预测误差 < 1 kcal/mol
- 可解释AI揭示"结构-能垒"构效关系本质

#### ✨ 创新点3：丁二烯氢氰化反应的MLFF构建【应用创新】
- 首个针对工业氢氰化反应的专用机器学习力场
- 实现纳秒级配体解离动力学模拟
- 揭示Ni-P配体协同效应的微观机制

#### ✨ 创新点4：从TS预测到催化剂设计的全闭环【集成创新】
- 构建"过渡态预测→能垒排序→虚拟筛选→实验验证"完整链条
- 催化设计周期从6个月缩短至1周
- T109平台实现全自动无人干预

#### 1.1 项目的立项依据 (约4000字)

**1.1.1 研究意义**
- 催化反应精准设计是化学科学的核心挑战(第一段)
- 过渡态是催化活性/选择性的决定性瓶颈(第二段)
- AI为过渡态预测带来范式变革机遇(第三段)
- 面向国家尼龙66产业卡脖子需求(丁二烯氢氰化案例)(第四段)
- 北航在该领域的独特积累和优势(第五段)

**1.1.2 国内外研究现状及发展动态分析**
```
▌板块1：传统过渡态搜索方法的局限
  - DFT过渡态搜索：人工初猜→迭代优化→频率验证(2-4周/反应)
  - 全自动TS搜索：GSN、AutoTS、ReaCAT等(依赖反应模板)
  - 核心瓶颈：复杂反应成功率<30%，无法实现高通量

▌板块2：机器学习在催化领域的进展
  - 描述符工程：火山图、d带中心、BEP关系(传统路线)
  - MLFF浪潮：ANI、MACE、NequIP等通用力场(精度仍待提升)
  - 最新突破：MIT Science 2024 - ML直接预测TS几何结构

▌板块3：氢氰化反应机理研究现状
  - 经典机理：Tolman 1970s提出的Ni催化循环
  - 最新进展：DFT揭示配体效应的电子根源
  - 遗留问题：全周期动力学、副反应控制、配体设计理论

▌板块4：本项目的切入点
  - 现有AI方法缺乏物理可解释性
  - 氢氰化等工业反应缺乏专用ML模型
  - 从TS预测到催化剂设计的闭环尚未形成
```

**1.2.1 研究目标**
```
总体目标：
  建立基于AI的过渡金属催化反应过渡态预测方法体系，
  实现丁二烯氢氰化催化剂的精准逆向设计，
  为工业催化反应的理性设计提供新范式。

具体目标：
  (1) 构建1000+规模的Ni催化反应过渡态数据库
  (2) 开发Hermes过渡态预测模型，成功率≥90%
  (3) 构建氢氰化专用MLFF，实现纳秒级动力学模拟
  (4) 设计并实验验证3-5个高性能氢氰化催化剂
  (5) 发表JCR一区论文8-10篇，申请发明专利3-5项
```

**1.2.2 研究内容 (四大模块)**

**研究内容一：过渡态电子结构特征提取与数据库构建**
- 计算方法：DLPNO-CCSD(T)基准 + DFT(PBE0/def2-SVP)批量计算
- 反应体系：Ni/Pd/Fe催化的氢氰化、氢甲酰化、C-C偶联
- 数据库：反应名称→反应物→产物→TS几何→能垒→电子密度特征
- 规模：1000+过渡态结构，含50+配体变体
- 特色：3D电子密度体素化存储，而非简单SMILES字符串

**研究内容二：Hermes主动学习过渡态预测模型**
```
技术路线：
  初始数据集(100个已计算TS)
       ↓
  特征提取(几何+电子+拓扑)
       ↓
  GNN/Transformer模型训练
       ↓
  不确定性估计(蒙特卡洛dropout)
       ↓
  高不确定性样本选择 → DFT验证
       ↓
  模型增量更新(主动学习闭环)
       ↓
  收敛(MAE < 0.1 Å, 能垒误差 < 1 kcal/mol)
```
- 创新：子代理并行架构，每个子代理专精一类反应
- 可解释性：SHAP值分析揭示关键结构特征

**研究内容三：丁二烯氢氰化专用MLFF构建**
- 训练集构建：5000+ snapshots from AIMD + normal mode sampling
- 力场选择：MACE或NequIP (equivariant GNN)
- 验证：能量守恒、力误差、过渡态重现
- 应用：10 ns MD模拟Ni-DPPB催化循环的完整动力学
- 突破：首次在原子层面观察配体解离与再结合动态过程

**研究内容四：催化剂逆向设计平台与实验验证**
- 生成模型：VAE/GAN生成新型配体结构
- 筛选漏斗：粗筛(Hermes TS预测)→精筛(DFT)→实验验证
- 实验体系：Ni盐+新型配体，丁二烯氢氰化反应
- 评价指标：转化率、选择性、TON、稳定性
- 目标：线性/支化比 > 50:1，TON > 1000

**1.2.3 拟解决的关键科学问题**
```
K1: 决定过渡金属催化反应能垒的本质电子结构特征是什么？
    → 突破：超越d带中心，建立3D电子密度描述符体系

K2: 如何在保证量子精度的同时，实现过渡态的毫秒级预测？
    → 突破：物理约束ML + 主动学习，精度=DFT，速度=10^6×

K3: 如何从过渡态预测反推最优催化剂结构？
    → 突破：TS结构→配体参数→可合成分子的逆映射算法
```
