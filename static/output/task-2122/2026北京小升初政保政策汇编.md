# 2026年北京小升初政保政策汇编

**编制日期：2026年4月**

---

## 一、政保政策概述

### 1.1 政保定义
政保全称"政策保障协调入学"，是具备特定条件或资格的单位为内部员工提供的升学福利。政保并非一成不变，单位资格可能年度调整，家长需及时关注单位政策动态。

### 1.2 政保类型分类
| 类型 | 适用范围 | 覆盖人群 | 统筹层级 |
|------|----------|----------|----------|
| **大政保** | 全区统筹 | 高层次人才子女、中央及市级机关单位子女 | 全区范围统筹安排 |
| **小政保** | 学区内对口 | 区属单位职工子女、学区内企业人才 | 所在学区内安排入学 |

### 1.3 2026年政策趋势
- **政保名额持续压缩**：西城区政保名额从2021年约5500人（"应保尽保"）逐步压缩，2025年预估降至4000人以内，2026年预计进一步缩至3200-3800人
- **多校划片深化**：政保生可能被分配到同一教育集团内的不同校区
- **人才专项通道扩容**：高层次人才引进子女政策保障力度加大
- **阳光招生推进**：纪检监察部门全程参与监督，流程更透明规范

## 二、北京市级政保政策框架

### 2.1 核心政策依据
《北京市教育委员会关于2025年义务教育阶段入学工作的意见》
- 坚持区级为主、免试就近入学
- 小学入学坚持以登记入学为主，单校划片和多校划片相结合
- 小升初采取免试、按志愿派位录取方式

### 2.2 按本市户籍对待人群
1. 区台办认定的台胞子女
2. 区侨务部门认定的华侨子女
3. 国家或北京市博士后管理部门认定的在京在站博士后研究人员子女
4. 符合随军进京落户条件正在办理随军手续的现役军人子女
5. 父母一方为本市户籍或持有《北京市工作居住证》的适龄儿童少年

### 2.3 优先照顾对象
- 残疾儿童少年同等条件下在服务范围内就近就便优先入学
- **烈士子女、台籍学生、华侨子女、现役军人子女、全国劳动模范子女**按有关规定在同等条件下给予照顾
- 区级以上引进人才子女按户籍所在地、家庭实际居住地等划定服务片区，按有关规定办理

### 2.4 2026年新增政策亮点
1. **多孩子女长幼随学**：坚持自愿申请、公平公正、就近就便原则，保障多孩子女同校就读
2. **一网通办深化**：义务教育入学服务平台接入"京通"市级统一身份认证，简化办理流程
3. **学位供给扩容**：2025年新增2万余个中小学学位，2026年继续保持学位增长态势
4. **集团化办学深化**：全市集团化办学覆盖率达70%，学区制管理覆盖率达90%

## 三、海淀区政保政策详解

### 3.1 政保资格获取
- **申报主体**：由所在单位统一申报，个人无法单独申请
- **审核机构**：海淀区教委统一审核
- **名额性质**：政保生不占用普通招生名额，单独列编
- **申报时限**：需在每年4月底前完成申报备案，逾期无法补办
- **特殊要求**：军队等特殊单位需提供《军人子女教育优待证明》等完整材料

### 3.2 政保流程时间线
| 时间节点 | 关键事项 | 操作要点 |
|----------|----------|----------|
| **3-4月** | 单位政保资格审核 | 与单位人事部门确认资格，准备材料 |
| **4月** | 发布政策，提交材料 | 提交户口本、单位证明等材料 |
| **5月底-6月初** | 填报"一派"志愿 | 冲击"六小强"等优质学校的黄金时机 |
| **6月中下旬** | 一派摇号结果公布 | 未中签则启动政保录取程序 |
| **6月下旬** | 政保统筹分配 | 按学区或全区统筹安排入学 |

### 3.3 志愿填报规则
- 政保生需填报**1-3所意向学校**（2024年部分单位志愿数增至5个且需满额填报）
- 最终由区教委根据学位情况和政策要求进行统筹分配
- 无法保证被第一志愿录取
- 若政保单位与学校有定向合作协议，录取概率大幅提高

### 3.4 重点学校政保情况
| 学校 | 2024年政保生占比 | 主要来源单位 | 备注 |
|------|------------------|--------------|------|
| **人大附中** | ≈10% | 中央及市级机关在海淀相关单位 | 教育、科技领域单位优先 |
| **北大附中** | ≈8% | 高校、科研院所在海淀分支机构 | 北大系统资源倾斜 |
| **清华附中** | ≈7% | 与清华大学合作紧密单位、军队系统 | 注重创新能力培养 |
| **中关村三小万柳部** | ≈6% | 海淀区重点企业、科研机构 | 九年一贯，直升比例高 |
| **首师大附中** | ≈5% | 市级文化艺术、教育科研单位 | 艺术素养特色 |
| **一零一中学** | - | 海淀区属国有企业、事业单位 | 强调综合素质提升 |

### 3.5 2025年一派招生变化
- **总规模扩大**：公办登记入学（一派）总计划达8655人，较2024年增加465人
- **公办寄宿扩招**：寄宿学校从6所增至8所，招生790人，增加140人
- **全区派位学校扩容**：从10所增加到13所，新增一零一双榆树校区、上地实验学校、十一晋元中学、清华附属实验学校
- **清华附中系扩招显著**：9所学校共招生970人，增加180人

## 四、朝阳区政保政策详解

### 4.1 入学方式体系
朝阳区实行多途径入学，政保生与普通生共享以下入学途径：

1. **就近分配入学**
   - 全区范围内公办初中校就近登记入学
   - 单校划片入学（九年一贯制对口接收）
   - 多校划片入学（按统筹分配服务片填报志愿）

2. **公办寄宿学校入学**
   - 全区范围内公办寄宿学校自愿申请
   - 电脑随机派位录取，公证处监督

3. **民办学校入学**
   - 与公办学校同步报名、同步录取、同步注册学籍
   - 报名人数超计划实行电脑随机派位

### 4.2 政保生特殊政策
- **区级以上引进人才子女**：按户籍所在地、家庭实际居住地等划定服务片区，按有关规定办理
- **特殊照顾对象**：烈士、华侨、现役军人、全国劳动模范子女及台籍学生在同等条件下给予照顾
- **人才专项通道**：朝阳区重点企业、高新技术企业人才子女可申请专项政策保障

### 4.3 北京四中朝阳学校政保情况
- 北京四中朝阳学校作为优质教育资源，接收部分政保生
- 主要面向朝阳区属重点单位、教育系统内部职工子女
- 通过全区派位和学区统筹相结合方式安排入学

### 4.4 八十中学政保情况
- 八十中学作为朝阳区龙头校，政保生比例相对较高
- 面向朝阳区政府机关、重点企事业单位职工子女
- 设有专项人才子女通道（如CBD企业人才、科技创新人才等）

## 五、人才子女专项通道政策

### 5.1 高层次人才认定范围
1. **国家级人才计划入选者**："千人计划""万人计划"等国家级人才项目入选者
2. **市级高层次人才**：北京市"海聚工程""高创计划"入选者
3. **中关村高端领军人才**：中关村国家自主创新示范区认定的高端领军人才
4. **区县级重点人才**：各区认定的优秀企业家、科技创新领军人才等
5. **博士后研究人员**：国家或北京市博士后管理部门认定的在京在站博士后

### 5.2 人才子女入学待遇
- 按本市户籍对待，入学方式与本市户籍学生相同
- 可申请跨学区统筹安排，不受房产、户籍严格限制
- 部分区设立人才子女专项招生计划，定向分配优质学位
- 博士后研究人员子女享受政策保障入学待遇

### 5.3 2026年人才政策新动向
- **中关村科学城人才政策升级**：加大对科技创新企业人才子女教育保障力度
- **"三城一区"联动**：中关村科学城、怀柔科学城、未来科学城、亦庄经开区探索教育资源共享机制
- **企业人才评价自主权**：重点高新技术企业可自主推荐人才子女享受政保待遇

## 六、"四个严禁"政策红线

### 6.1 严禁事项
1. **严禁以考试成绩和各类竞赛证书、培训竞赛成绩、考级证明等作为招生依据**
2. **严禁以面试、评测、接收简历等形式选拔学生**
3. **严禁学校和校外培训机构以培训班、校园开放日、夏令营等形式提前招生、选拔学生**
4. **严禁任何学校以实验班、特色班、国际部、国际课程班等名义招生**

### 6.2 违规后果
- 对违反"四个严禁"要求、违规"掐尖招生"行为坚决严肃查处
- 纪检监察部门全程参与监督义务教育入学工作
- 违规学校将被通报批评、削减招生计划、追究相关人员责任
