## 📱 使用说明

1. **每日记录**：早晨起床后5分钟内完成，通过快捷指令输入
2. **数据同步**：Apple Watch数据自动同步到健康App
3. **周复盘**：每周日晚上完成，花15-20分钟
4. **月度总结**：每月最后一天完成
5. **文件存储**：所有记录保存在Notion数据库或本地Markdown文件

**建议：** 每周日晚将本周数据可视化（用快捷指令生成图表），直观看到进步！
