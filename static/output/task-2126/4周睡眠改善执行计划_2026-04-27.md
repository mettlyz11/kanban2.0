# 4周递进式睡眠改善执行计划

> **目标用户**：创业者/高压职场人士  
> **核心目标**：建立稳定23:00入睡、6:30起床的睡眠节律  
> **理论基础**：90分钟睡眠周期对齐法 + 冷黑房技术 + AI监测

---

## 第一周：建立基础（适应期）

**主题**：锚定起床时间，建立睡眠仪式感

### 每日执行清单
- [ ] **6:30 固定起床**（无论前一晚几点睡，周末也执行）
- [ ] 起床后立即拉开窗帘/开灯，接受光照5分钟
- [ ] 22:00 开启"睡前1小时仪式"
- [ ] 22:30 手机开启夜览模式+灰度屏幕
- [ ] 22:45 进行5分钟呼吸冥想（4-7-8呼吸法）
- [ ] **23:00 上床入睡**（目标7.5小时 = 5个睡眠周期）

### 环境调整
- [ ] 购买遮光窗帘或睡眠眼罩
- [ ] 空调设定18-20°C
- [ ] 移除卧室所有发光电子设备
- [ ] 准备床头 journaling 笔记本

### 周目标
- 起床时间达标率 ≥ 90%（7天中至少6天6:30起）
- 入睡时间达标率 ≥ 70%（7天中至少5天23:00前）
- 不追求完美，允许有2天过渡期

---

## 第二周：优化质量（深化期）

**主题**：提升深度睡眠比例，建立咖啡因戒律

### 新增执行项
- [ ] **14:00后完全禁咖啡因**（咖啡、茶、可乐、巧克力）
- [ ] 睡前2小时停止所有屏幕使用（改用Kindle或纸质书）
- [ ] 晚餐与入睡间隔 ≥ 3小时
- [ ] 睡前1小时温水泡脚（10分钟，40-42°C）
- [ ] 开始记录每日"日间精力评分"（1-10分）

### 数据追踪
- 每日查看Apple Health睡眠数据
- 关注核心指标：
  - 睡眠效率（目标 > 80%）
  - 深度睡眠时长（目标 > 1.5小时）
  - 夜间觉醒次数（目标 < 2次）

### 周目标
- 入睡时间达标率 ≥ 85%
- 日间精力评分均值 ≥ 6分
- 咖啡因戒律执行率 100%

---

## 第三周：巩固节律（稳定期）

**主题**：固化生物钟，引入午睡优化

### 新增执行项
- [ ] **13:00-13:30 能量盹**（设闹钟26分钟，NASA protocol）
- [ ] 每周3次轻度运动（快走/瑜伽），但睡前3小时不运动
- [ ] 睡前 journaling：写下3件感恩的事 + 明日1个优先任务
- [ ] 周末也保持6:30起床（允许±30分钟弹性）

### 数据优化
- 睡眠效率目标 > 85%
- 深度睡眠比例目标 > 20%
- HRV（心率变异性）呈上升趋势
- 日间精力评分均值 ≥ 7分

### 本周重点
- 观察连续7天固定作息后的身体变化
- 记录入睡是否更快、晨醒是否更自然
- 注意下午是否不再需要咖啡提神

## 第四周：长期维持（固化期）

**主题**：建立终身睡眠系统，制定个人睡眠守则

### 本周任务
- [ ] 完成4周完整数据复盘（见复盘模板）
- [ ] 总结个人最有效的3个睡眠"杠杆动作"
- [ ] 制定《个人睡眠守则》（打印贴床头）
- [ ] 配置Shortcuts自动化（见iPhone配置方案）
- [ ] 设定"睡眠债"追踪机制

### 4周验收标准
| 指标 | 初始基线 | 第4周目标 |
|------|---------|----------|
| 平均入睡时间 | — | 23:00 ± 15分钟 |
| 平均起床时间 | — | 6:30 ± 15分钟 |
| 睡眠效率 | — | > 85% |
| 日间精力评分 | — | ≥ 7.5分 |
| 入睡潜伏期 | — | < 15分钟 |
| 夜间觉醒次数 | — | ≤ 1次 |

### 睡眠守则模板（示例）
```
我的睡眠守则
1. 无论何事，23:00是我和床的约定时间
```

## 特殊场景应对

### 跨时区出差
- 提前3天开始按目的地时间调整
- 飞行日：按目的地时间决定睡/不睡
- 到达目的地后立即接受当地光照

### 高强度工作日晚
- 若必须22:00后工作：使用蓝光过滤眼镜
- 紧急任务：设硬截止23:30，损失1个周期好过全乱
- 次日不补觉，坚持6:30起，晚上会自然早睡

### 社交聚餐
- 提前告知朋友你的睡眠计划（社交支持很重要）
- 晚餐选清淡选项，避免酒精
- 设定22:30的"优雅离场"闹钟
