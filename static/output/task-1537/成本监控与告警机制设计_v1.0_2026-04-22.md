## 🎯 设计目标

建立一套**主动式、分层级、可自愈**的成本监控与告警体系，实现：
- 🔍 **全链路可观测**：Token消耗从哪里来，到哪里去
- 🚨 **异常主动发现**：在成本失控前发出告警
- 🤖 **自动优化执行**：告警触发后自动执行优化策略
- 📊 **成本ROI分析**：量化每一分钱的产出价值

### 1.2 成本计算公式

```
单次调用成本 = (input_tokens × input_price / 1,000,000) 
             + (output_tokens × output_price / 1,000,000)

任务总成本 = Σ(子任务单次调用成本)

日成本 = Σ(当日所有任务总成本)
```

## 🎯 三、预算与阈值体系

### 3.1 三级预算体系

| 预算级别 | 周期 | 推荐值 | 说明 |
|---------|------|--------|------|
| **L1 日预算** | 每日 | $5.00 | 日常运行基准 |
| **L2 周预算** | 每周 | $25.00 | 中期波动控制 |
| **L3 月预算** | 每月 | $100.00 | 长期成本控制 |

### 3.2 告警阈值矩阵

| 告警级别 | 触发条件 | 严重程度 | 自动动作 |
|---------|---------|---------|---------|
| **🟡 L1 警告** | 日预算使用 &gt; 60%<br>小时环比增长 &gt; 50%<br>单任务 &gt; $0.50 | 警告 | 生成优化报告<br>记录上下文 |
| **🟠 L2 告警** | 日预算使用 &gt; 85%<br>日环比增长 &gt; 100%<br>单任务 &gt; $2.00 | 告警 | 非关键任务降级<br>Research节流50% |
| **🔴 L3 紧急** | 日预算超支 100%<br>2小时增长 &gt; 300%<br>单任务 &gt; $5.00 | 紧急 | 暂停全部Research<br>只保留核心调度<br>通知人工介入 |

### 3.3 异常检测规则

**静态阈值检测：**
- 单次调用Token > 10万
- 单小时调用 > 100次
- 模型错误率 > 20%

**趋势异常检测（Z-score）：**
```
Z = (当前值 - 历史均值) / 历史标准差

Z > 2.0 → 疑似异常
Z > 3.0 → 确认异常
```

## 🤖 五、自动优化与自愈

### 5.1 优化策略执行矩阵

| 策略 | 触发条件 | 执行动作 | 回滚条件 |
|-----|---------|---------|---------|
| **模型降级** | L2告警触发 | Research→deepseek<br>通用→免费模型 | L1解除后1小时 |
| **Research节流** | L2告警触发 | Research并发-50%<br>缓存TTL×2 | L1解除后2小时 |
| **暂停非核心** | L3告警触发 | 暂停全部Research<br>只保留调度器 | 人工确认恢复 |
| **上下文压缩** | 单任务&gt;50K Token | 历史对话摘要化<br>截断到10轮 | 持续生效 |
| **缓存复用** | 常态化 | 相同Query复用结果<br>TTL: 24小时 | 持续生效 |

### 5.2 智能模型路由

**路由决策树：**
```
任务开始
    ↓
判断任务类型
    ├─ 代码任务 → huoshanCoding/ark-code-latest
    ├─ Research → 预算充足?
    │   ├─ Yes → moonshot/kimi-k2.6
    │   └─ No → deepseek/deepseek-chat
    ├─ 摘要/分类 → dmxapi/kimi-k2.5-free (免费)
    └─ 通用对话 → alicodingplan/qwen3.6-plus
```

### 5.3 自愈验证流程

```
告警触发 → 执行优化动作
    ↓
等待 15 分钟
    ↓
检查指标是否改善?
    ├─ Yes → 记录成功, 持续观察
    └─ No → 升级告警级别, 执行更强措施
```

### 6.1 每日成本报告

**内容结构：**
1. 📊 **今日概览**：总消耗、预算占比、环比变化
2. 💰 **按模型分布**：各模型消耗占比饼图

4. 🎯 **异常检测**：异常点标注与分析
5. 💡 **优化建议**：可优化点与预估节省
6. 📅 **明日预测**：基于趋势的成本预测

**发送时间：** 每日 23:00  
**发送渠道：** CoCo #daily-reports 频道

### 6.2 月度成本分析

**内容结构：**
1. 📈 **月度趋势**：30天成本曲线
2. 🎯 **ROI分析**：$投入 vs 任务产出
3. 🏆 **模型性价比**：各模型成功率/成本比
4. ⚠️ **异常回顾**：本月重大告警复盘
5. 📋 **下月预算**：建议预算与分配
6. 🚀 **优化路线图**：下月优化重点

### 6.3 任务ROI模型

**ROI计算公式：**
```
任务ROI = (任务价值分数 × 完成质量) / 任务成本

任务价值分数 = 
  战略相关性(0-5) + 
  紧迫性(0-5) + 
  成果可复用性(0-5)
```

**ROI分级：**
- **高ROI (>10):** 优先保障预算
- **中ROI (3-10):** 正常执行
- **低ROI (<3):** 评估必要性，考虑降级或取消
