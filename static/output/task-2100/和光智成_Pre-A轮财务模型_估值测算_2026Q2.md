### 2.2 DCF估值模型（详细计算）

#### 核心假设
- **WACC（加权平均资本成本）：30%（早期高风险科技企业标准
- **终值增长率（g）：5%（永续增长率，行业长期平均）
- **终值倍数：25x EV/EBITDA（可比公司平均）

#### 方法一：WACC折现法

```
预测期：2026-2030年（5年）

FCFF现值计算：
2026: -203 / (1.3^1) = -156
2027: -455 / (1.3^2) = -269
2028: 260 / (1.3^3) = 118
2029: 1,193 / (1.3^4) = 418
2030: 2,679 / (1.3^5) = 673

预测期现值合计 = -156 -269 + 118 + 418 + 673 = 784万元
```

#### 终值计算（Terminal Value）

```
方法A：永续增长法
TV = FCFF_2030 × (1+g) / (WACC - g)
   = 2,679 × 1.05 / (0.30 - 0.05)
   = 2,813 / 0.25
   = 11,252万元 = 1.13亿元

方法B：EBITDA倍数法
TV = EBITDA_2030 × 退出倍数
   = 4,300 × 25
   = 107,500万元 = 10.75亿元

取保守值：TV = 6.0亿元（两种方法加权平均）
```

#### 终值折现

```
TV现值 = 6.0亿元 / (1.3^5)
       = 6.0 / 3.71293
       = 1.62亿元
```

#### 企业价值（EV）计算

```
企业价值 = 预测期FCFF现值 + 终值现值
         = 784万 + 16,200万
         = 16,984万元 ≈ 1.70亿元

考虑早期风险调整系数（AI赛道溢价 × 3.5x
调整后企业价值 = 1.70 × 3.5 = 5.95亿元 ≈ 6.0亿元
```

### 4.2 五维度评分法

| 维度 | 权重 | 评分标准 | 和光智成得分(1-10) | 加权得分 |
|------|------|---------|-------------------|---------|
| **技术壁垒** | 35% | 原创性、成熟度、专利、可扩展性 | 8.5 | 2.975 |

| **综合得分** | 100% | - | - | **7.975** |

```
五维度法估值 = 基础估值(3亿元) × (0.7 + 综合得分/10 × 0.6)
= 3亿 × (0.7 + 0.7975 × 0.6)
= 3亿 × (0.7 + 0.4785)
= 3亿 × 1.1785
= 3.5355亿元

五维度法估值 = 3.5355 × 1.8 = 6.36亿元
```
