## 案例一：新能源电池电解液添加剂筛选

### 客户画像
| 维度 | 内容 |
|------|------|
| **行业** | 新能源电池 |
| **客户类型** | Tier 1电池材料企业 |

客户需开发下一代高电压（>4.5V）锂离子电池电解液体系，核心挑战是找到能同时满足高压稳定性、低温性能、阻燃性的新型添加剂。传统高通量筛选周期长、成本高。

| 阶段 | 方法 | Helight技术栈 |

| Phase 1 | AI分子设计生成3000+候选分子 | Helight生成式分子设计引擎 |
| Phase 2 | 过渡态计算筛选稳定性 | Helight过渡态计算核心 |
| Phase 3 | 自动化实验验证Top 50候选 | XuanLab无水无氧自动化平台 |
| Phase 4 | 湿实验闭环验证Top 5 | DeepChem平台迭代 |

### 核心指标

| 指标 | 传统方法 | Helight方法 | 提升 |
|------|---------|------------|------|
| 项目周期 | 10-12个月 | 6-8周 | **缩短80%** |
| 候选分子数 | 200-500（人工筛选）| 3000+（AI生成）| **6倍+** |
| 实验验证数 | 100-200 | 50（AI预筛选后）| **减少75%** |
| 成功率 | 15% | 85%+（AI预测准确率） | **5.7倍** |
| 总成本 | 500-800万 | 150-200万 | **降低60-75%** |

### 业务价值

| 价值维度 | 量化评估 |
|---------|---------|
| **时间价值** | 产品上市提前8-10个月，在竞争激烈的电池市场中抢占专利先机 |
| **成本节约** | 直接实验成本降低60%+，人力投入降低80% |
| **技术突破** | 发现2种新型添加剂分子，实现4.5V稳定循环500次+ |
| **知识产权** | 申请3项核心专利（添加剂分子结构+合成方法） |

## 案例二：高性能催化剂工业级优化

### 客户画像
| 维度 | 内容 |
|------|------|
| **行业** | 化学工业/催化剂 |
| **客户类型** | Tier 2精细化工企业 |
| **决策者** | CTO / 工艺部门负责人 |
| **痛点** | 现有催化剂选择性不足（75%），副产物占比高导致纯化成本飙升 |
| **预算** | 100-300万/年 |

### 项目背景
客户核心产品（医药中间体）使用的钯催化体系选择性仅75%，大量副产物导致后续纯化成本占总生产成本40%。尝试了6个月传统优化但突破有限。

### 技术方案
| 阶段 | 方法 | Helight技术栈 |
|------|------|--------------|
| Phase 1 | 现有催化机理分析 | Helight过渡态计算+反应路径分析 |
| Phase 2 | 配体库AI优化生成1000+候选 | 生成式分子设计（配体空间搜索） |
| Phase 3 | TOP 20候选自动化验证 | XuanLab无水无氧条件模拟 |
| Phase 4 | 优化配方放大验证 | DeepChem工艺优化 |

### 核心指标

| 指标 | 优化前 | 优化后 | 提升 |
|------|--------|--------|------|
| 选择性 | 75% | 94% | **+19pp** |
| 转化率 | 88% | 97% | **+9pp** |
| 副产物比例 | 25% | 6% | **降低76%** |
| 纯化成本占比 | 40% | 12% | **降低70%** |
| 总收率 | 66% | 91% | **+25pp** |

### 业务价值

| 价值维度 | 量化评估 |
|---------|---------|
| **降本** | 纯化成本降低70%，整体生产成本降低35% |
| **增产** | 有效产能（合格产品）提升38% |
| **环保** | 副产物废弃物减少76%，符合ESG合规要求 |
| **ROI计算** | 投入200万→年化节约800-1200万（纯化成本+原料节省） |

### 技术亮点
Helight的过渡态计算能力帮助识别了反应中关键的速率决定步骤，这是竞品（Schrödinger/深势科技）普遍未覆盖的能力。

### 客户画像
| 维度 | 内容 |

客户需开发一种新型耐高温（>350°C）结构粘合剂，同时满足轻量化（密度<1.2g/cm³）、高粘结强度（>15MPa）、良好加工性（可注塑或3D打印）三大矛盾性能要求。

| 阶段 | 方法 | Helight技术栈 |
|------|------|--------------|
| Phase 1 | 多目标优化模型建立 | AI分子设计+物理约束模型 |
| Phase 2 | 配方参数空间搜索 | 生成式设计生成2000+配方组合 |
| Phase 3 | TOP 20配方快速验证 | XuanLab自动化合成与表征 |
| Phase 4 | 最佳3个配方放大测试 | 工艺参数优化 |

### 核心指标

| 指标 | 初始配方 | 优化后配方 | 提升 |
|------|---------|-----------|------|
| 耐温性 | 300°C | 380°C | **+80°C** |
| 粘结强度 | 8MPa | 18MPa | **2.25倍** |
| 密度 | 1.35g/cm³ | 1.15g/cm³ | **降低15%** |
| 加工性指数 (MFR) | 不满足 | 满足注塑要求 | **✅ 达成** |
| 配方迭代次数 | 15轮（传统） | 3轮（AI驱动） | **降低80%** |

### 亮点

| Phase 4 | 工艺参数微调 | DeepChem闭环迭代 |

### 核心指标

| 指标 | 优化前 | 优化后 | 提升 |

## 案例五：绿色化学工艺路线设计

### 客户画像
| 维度 | 内容 |
|------|------|
| **行业** | 医药/精细化工 |
| **客户类型** | Tier 1跨国药企中国研发中心 |
| **决策者** | 工艺化学负责人 |
| **痛点** | 现有工艺使用有毒溶剂（DMF/二氯甲烷），面临ESG合规压力，需开发绿色替代路线 |
| **预算** | 200-500万/项目 |

### 项目背景
客户核心药物中间体生产使用大量二氯甲烷和DMF，排放超标面临环保处罚。目标是在6个月内找到替代溶剂方案，同时保持或提升产率和纯度。

### 技术方案
| 阶段 | 方法 | Helight技术栈 |
|------|------|--------------|
| Phase 1 | 现有工艺全路径碳足迹/毒性分析 | AI多维度工艺评估 |
| Phase 2 | 绿色溶剂替代方案AI筛选 | 生成式设计+溶剂数据库匹配 |
| Phase 3 | 新工艺路径自动化验证 | XuanLab条件优化 |
| Phase 4 | 最佳方案工艺放大验证 | DeepChem放大参数预测 |

### 核心指标

| 指标 | 原工艺 | 新工艺 | 提升 |
|------|--------|--------|------|
| 溶剂毒性等级 | 高（DMF/CH₂Cl₂） | 低（绿色溶剂） | **✅ 合规** |
| 碳足迹 (kg CO₂/kg产品) | 45 | 18 | **降低60%** |
| 产率 | 82% | 91% | **+9pp** |
| 溶剂回收率 | 60% | 95% | **+35pp** |
| 工艺步骤数 | 7步 | 5步 | **减少29%** |
| E因子 (废弃物/产品) | 38 | 8 | **降低79%** |

### 业务价值

| 价值维度 | 量化评估 |
|---------|---------|
| **合规避险** | 避免环保处罚风险（预计500万+/年） |
| **ESG提升** | 碳足迹降低60%，符合全球ESG评级要求 |
| **成本降低** | 溶剂采购+废弃物处理成本降低55% |
| **ROI计算** | 投入300万→年化节约600-800万（合规成本+溶剂+废弃物处理） |

### 亮点
绿色化学路线设计是AI+材料科学的高价值应用方向。Helight的生成式设计能力超越了传统"已有溶剂替换"的思维局限，发现了全新的反应路径。
