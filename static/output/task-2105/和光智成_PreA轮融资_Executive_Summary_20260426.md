## 一、公司概览

**和光智成 (Helight)** 是中国领先的 **AI驱动材料发现与自动化实验平台**，依托北航联合实验室的学术权威与技术积累，为材料企业和研究机构提供端到端的新材料研发解决方案。

| 核心指标 | 详情 |
|---------|------|
| **成立时间** | 2025年 |
| **总部** | 北京 |
| **核心定位** | 北航背书的AI材料发现与自动化实验一体化平台 |
| **技术壁垒** | AI建模 + 自动化实验 + 北航专属材料数据库 |
| **学术资质** | 北航联合实验室 + 北京市重点实验室 |
| **创始人** | 刘宇宙博士（北航化学学院教授，AI材料科学专家） |

---

## 二、投资亮点

### 🔥 赛道爆发：AI材料科学是2026年最热赛道
- **Periodic Labs**：7个月估值从$13亿→$70亿（翻7倍），a16z+Nvidia领投
- **XtalPi**：2025年营收8.03亿RMB（+201% YoY），港交所上市，市值$60亿
- **全球市场**：AI材料发现市场2026年$25亿，CAGR 26.4%，2035年$200亿+
- **中国市场**：CAGR 31.2%（全球第一），2034年生成式AI材料市场$117亿

### 🎓 学术壁垒：北航独家背书，不可复制
- **北航-和光智成AI材料合成联合实验室**（已通过北航联席办公会）
- **空天动力结构强度智能试验技术与仪器北京市重点实验室**（联合申请中）
- **人工智能全自动化实验室关键共性技术北京市重点实验室**（已获批）
- **刘宇宙博士**：北航化学学院教授，和光智成创始人，AI材料科学领域领军人物

### 🔄 双引擎模式：材料 + 药物协同，TAM最大化
- 区别于XtalPi（仅药物）和Periodic Labs（仅材料）
- **材料赛道**：电池材料、半导体材料、航空航天材料、催化剂
- **药物赛道**：利用相同AI技术栈拓展药物发现（XtalPi已验证的市场）
- 双赛道协同效应 = 更大市场空间 + 更低研发成本 + 更高估值上限

### 🤖 技术闭环：干实验 + 湿实验一体化
- AI分子建模与预测（干实验）
- 自动化实验平台（湿实验）
- 数据闭环：实验数据反馈优化AI模型
- 新材料研发周期：5年 → 1-2年（缩短75%）
- 研发成功率：30% → 90%（提升3倍）
