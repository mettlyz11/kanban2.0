## 七、执行建议

### 7.1 天使轮投资执行路线图

```
Phase 1: 渠道建设 (1-2月)
├── 加入3-5个高质量投资社群
├── 与2-3家垂直FA建立联系
├── 拜访深圳/北京天使母基金
└── 参加Demo China等路演活动

Phase 2: 项目 sourcing (持续)
├── 每周审查10+个项目BP
├── 重点关注高校/中科院转化项目
├── 跟踪YC/奇绩创坛毕业项目
└── 通过FA获取独家项目

Phase 3: 尽调与决策 (2-4周/项目)
├── 技术尽调：聘请学术顾问
├── 市场尽调：访谈潜在客户
├── 法律尽调：关注IP归属
└── 估值谈判：参考可比交易

Phase 4: 投后管理 (持续)
├── 每季度跟踪被投项目
├── 协助对接产业资源
├── 为下一轮融资铺路
└── 建立个人投资品牌
```
