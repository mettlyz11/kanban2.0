## 六、投资人关注问题清单

### 技术类（必问）
1. 你们的AI模型与传统计算材料学方法有什么本质区别？
2. 模型准确率如何？如何通过湿实验验证？
3. 数据来源是什么？如何保证数据质量？
4. 核心技术团队背景？是否全职？
5. 专利布局情况？技术壁垒在哪里？

### 商业类（重点）
1. 客户付费意愿调研情况？客单价预期？
2. 标杆客户案例进展？签约时间节点？
3. 商业模式SaaS vs 项目制 vs 分成，各自占比规划？
4. 2026-2028年营收预测？盈亏平衡点？
5. 销售团队搭建计划？获客成本？

### 竞争类（关键）
1. 与材科源图、开物纪智能等竞品的差异化？
2. 国际巨头（Citrine、Materials Zone）进入中国怎么办？
3. 如果华为/腾讯下场做这个赛道，你们如何应对？
4. 先发优势能维持多久？后来者的追赶壁垒是什么？

### 团队类（基础）
1. 创始人全职投入吗？股权结构如何？
2. 核心成员是否有竞业限制？
3. 股权激励计划？核心人才保留机制？
4. 顾问团队构成？是否有行业泰斗背书？

### 融资类（收尾）
1. 本轮融资额度、估值、资金用途？
2. 下一轮融资里程碑？预计何时启动？
3. 退出路径规划？IPO时间预期？
4. 战略投资人引入计划？是否接受产业资本？
