# 深云智合 × 和光智成 项目协同方案

## 任务信息
- **看板任务ID**: #945
- **批次**: #5687
- **协同机会**: AI材料合成技术共享
- **制定时间**: 2026年4月17日

---

## 一、协同背景与目标

### 1.1 协同背景
深云智合（DeepChem）与和光智成（Helight）作为刘宇宙教授创立的两家AI驱动材料科学公司，在AI材料合成领域具有显著的技术重叠和互补性：

| 维度 | 深云智合 (DeepChem) | 和光智成 (Helight) |
|------|---------------------|-------------------|
| **核心定位** | 分子设计与合成平台 | AI分子智能平台 |
| **技术重点** | 合成路径预测、反应条件优化 | 分子性质预测、智能筛选 |
| **应用场景** | 药物中间体、功能材料 | 航空航天材料、新能源材料 |
| **北航合作** | 联合实验室建设 | 3个联合实验室（含2个北京市重点实验室） |

### 1.2 协同目标
- **短期（1-3个月）**：建立沟通机制，完成技术盘点
- **中期（3-6个月）**：实现核心AI模型/算法共享
- **长期（6-12个月）**：形成协同研发能力，共同申报重大项目

## 二、跨项目沟通机制

### 2.1 组织架构
```
┌─────────────────────────────────────────────────────────────┐
│                    协同领导小组                              │
│              （刘宇宙教授 + 双方CTO/技术负责人）              │
└──────────────────────────┬──────────────────────────────────┘
                           │
           ┌───────────────┼───────────────┐
           ▼               ▼               ▼
    ┌────────────┐  ┌────────────┐  ┌────────────┐
    │ 技术协调组  │  │ 资源共享组  │  │ 项目推进组  │
    │（算法/模型）│  │（数据/算力）│  │（落地执行）│
    └────────────┘  └────────────┘  └────────────┘
```

### 2.2 沟通机制

| 会议类型 | 频率 | 参与人员 | 主要内容 |
|----------|------|----------|----------|
| **战略对齐会** | 每月1次 | 领导小组 | 方向确认、重大事项决策 |
| **技术研讨会** | 双周1次 | 技术协调组 | 技术进展、共享方案讨论 |
| **资源协调会** | 按需 | 资源共享组 | 算力/数据/设备调度 |
| **项目进度会** | 每周1次 | 项目推进组 | 任务跟踪、问题解决 |

### 2.3 协作工具与流程
- **项目管理**: 统一使用看板系统 (Server 1)
- **文档协作**: 飞书文档/Notion
- **代码共享**: 私有Git仓库 (内部搭建)
- **即时沟通**: 飞书群组 + 定期视频会议

## 三、可共享资源识别

### 3.1 AI技术资源

#### 3.1.1 可共享算法/模型
| 技术领域 | 深云智合 | 和光智成 | 共享方式 | 优先级 |
|----------|----------|----------|----------|--------|
| **分子表示学习** | 图神经网络架构 | Transformer分子编码器 | 模型权重 + 训练代码 | ⭐⭐⭐⭐⭐ |
| **反应预测** | 合成路径预测模型 | 反应条件优化模型 | API接口 + 预训练模型 | ⭐⭐⭐⭐⭐ |
| **性质预测** | 理化性质预测 | 多任务学习框架 | 共享训练框架 | ⭐⭐⭐⭐ |
| **数据增强** | 分子生成模型 | 虚拟筛选流程 | 开源共享 | ⭐⭐⭐ |

| 数据类型 | 深云智合 | 和光智成 | 共享策略 |

## 五、风险与应对措施

| 风险类型 | 风险描述 | 应对措施 |
|----------|----------|----------|
| **知识产权** | 技术共享涉及IP归属 | 签署详细的IP共享协议，明确边界 |

| **优先级冲突** | 各自业务优先级不同 | 战略对齐会定期调整，灵活安排 |
