### 1.2 行业标杆对比

| 平台 | 核心能力 | 开源 | A股支持 | AI集成 | 适合度 |
|------|----------|------|---------|--------|--------|
| **Microsoft Qlib** | 全量AI量化流水线 | ✅ 是 | ✅ 沪深300 | LGBM/DNN/RL | ⭐⭐⭐⭐⭐ |
| **OpenBB** | 金融数据聚合+终端 | ✅ 是 | ⚠️ 有限 | MCP Agent集成 | ⭐⭐⭐⭐ |
| **QuantConnect** | 云回测+实盘交易 | ❌ 部分 | ✅ | Mia AI助手 | ⭐⭐⭐ |
| **vn.py** | 国内量化交易框架 | ✅ 是 | ✅ | ⚠️ 弱 | ⭐⭐⭐ |
| **Backtrader** | Python回测框架 | ✅ 是 | ⚠️ 需适配 | ❌ | ⭐⭐ |

### 1.3 核心结论

**推荐双引擎架构：Qlib(AI研究) + OpenBB(数据聚合)**

- Qlib负责AI因子挖掘→模型训练→回测→组合优化
- OpenBB负责全球金融数据获取+宏观经济数据+另类数据
- 现有AkShare/Tushare作为A股数据补充

## 四、关键技术选型决策

### 4.1 为什么选Qlib？

| 优势 | 说明 |
|------|------|
| **微软背书** | Microsoft Research出品，持续维护 |
| **全链路** | 数据处理→因子→模型→回测→组合→执行 |
| **AI原生** | 内置LGBM/MLP/GRU/ALSTM等15+模型 |
| **A股支持** | 内置CSI300/CSI500数据集 |
| **RD-Agent集成** | 自动化R&D流程，AI自动生成策略 |
| **社区活跃** | GitHub 13k+ stars |

### 4.2 为什么选OpenBB？

| 优势 | 说明 |
|------|------|
| **数据聚合** | 100+数据源统一接口 |
| **开源免费** | MIT许可证，无使用限制 |
| **MCP集成** | 2026年支持AI Agent直接调用 |
| **Python SDK** | 与Qlib完美配合 |
| **全球覆盖** | 股票/债券/ETF/加密货币/宏观 |

### 4.3 不选其他平台的理由

| 平台 | 不选理由 |
|------|----------|
| vn.py | 侧重交易执行，AI能力弱 |
| Backtrader | 维护放缓，无AI原生支持 |
| QuantConnect | 云依赖，数据出隐私顾虑 |
| Zipline | 已停止维护（QuantConnect接手但方向不同） |
