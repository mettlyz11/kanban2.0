#### 2.2.4 预申请书模板框架（2000字）

```
【标题】（建议≤30字，突出原创性和颠覆性）

1. 原创学术思想（~500字）
   - 当前材料发现范式的根本性局限是什么？
   - 你的原创思想如何从本质上突破这些局限？
   - 为什么这个想法是"非共识"的？

2. 科学性依据（~500字）
   - 理论基础：大模型/ML在分子表征中的数学原理
   - 初步证据：已有数据/预实验支持
   - 可行性分析：为什么现在可以做？

3. 潜在影响力（~500字）
   - 对材料科学领域的变革意义
   - 对产业应用的影响（和光智成商业价值）
   - 国际学术竞争力提升

4. 研究方案概要（~500字）
   - 研究目标（1句话）
   - 关键科学问题（2-3个）
   - 技术路线（流程图/关键步骤）
   - 预期成果（论文/专利/软件/平台）
```
