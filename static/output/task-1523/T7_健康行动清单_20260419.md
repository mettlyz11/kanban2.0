# T7 健康行动清单（可执行版）

> **生成日期**: 2026-04-19
> **使用说明**: 勾选完成项，每周回顾

---

## 📅 每日行动清单

### 早晨（起床后30分钟）
- [ ] 起床后喝水500ml
- [ ] 10分钟正念冥想（Waking Up / 潮汐）
- [ ] 记录睡眠评分（Apple Watch / Oura）
- [ ] 记录晨起静息心率

### 上午（工作时段）
- [ ] 90分钟工作后站立/走动5分钟
- [ ] 午餐前记录饮食（薄荷健康）
- [ ] 上午11点前完成当日最难任务（利用高能时段）

### 下午（工作时段）
- [ ] 午饭后散步15分钟（或拉伸）
- [ ] 下午3点补充水分
- [ ] 下午2点后不摄入咖啡因

### 晚间（下班后）
- [ ] 运动30分钟（力量/有氧/灵活性轮换）
- [ ] 记录当日情绪（Daylio，1分钟）
- [ ] 晚餐后不再进食（至少睡前3小时）
- [ ] 睡前1小时关闭工作屏幕
- [ ] 卧室温度调至18-20°C
- [ ] 固定时间入睡（建议23:00-23:30）

---

## 📅 每周行动清单

### 运动计划
- [ ] 力量训练 × 3次（周一/三/五）
- [ ] 有氧运动 × 2次（周二/四）
- [ ] 灵活性/拉伸 × 2次（周六/日）
- [ ] 周回顾：查看运动完成率

### 营养管理
- [ ] 周日规划本周工作餐（减少决策负担）
- [ ] 每周至少5天记录饮食
- [ ] 补充剂按计划服用

### 心理健康
- [ ] 至少5天冥想（≥10分钟/天）
- [ ] 1次深度放松（按摩/桑拿/户外/阅读）
- [ ] 1次与家人/朋友深度交流（≥30分钟）

### 工作-健康协同
- [ ] 检查日程安排是否匹配能量曲线
- [ ] 确保每周有1个"无会议半天"（用于深度工作+恢复）
- [ ] 周末至少半天完全脱离工作

## 🚨 红线规则（绝对遵守）

| 规则 | 说明 |
|------|------|
| 不熬夜 | 最晚0:30入睡（特殊情况除外） |
| 不跳过体检 | 年度体检不可取消 |
| 不连续3天不运动 | 即使再忙，每天10分钟 |
| 不忽略身体信号 | 持续不适→立即就医 |
| 不以健康换工作 | 没有健康，一切归零 |
