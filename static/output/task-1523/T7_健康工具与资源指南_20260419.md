## 一、可穿戴设备

### 1.1 Apple Watch（已有设备 - 立即利用）
- **功能**: 心率/HRV/血氧/睡眠追踪/运动记录
- **配合App**: AutoSleep（睡眠分析）、HRV4Training（恢复监测）
- **成本**: 已有设备，AutoSleep ~$7
- **优势**: 与iPhone/iPad/Mac生态无缝整合

### 1.2 Oura Ring Gen 3（推荐购买）
- **功能**: 睡眠阶段/体温/HRV/活动追踪
- **价格**: 戒指~$299 + 会员$5.99/月
- **优势**: 睡眠追踪精度行业领先，佩戴舒适不影响睡眠
- **购买渠道**: 官网 / 亚马逊

### 1.3 WHOOP 4.0（可选）
- **功能**: 恢复评分/strain/睡眠/HRV
- **价格**: 免费硬件 + 会员$30/月
- **优势**: 恢复评分算法最成熟，运动员首选
- **vs Oura**: WHOOP偏运动恢复，Oura偏睡眠健康

### 1.4 连续血糖监测（CGM，可选）
- **产品**: 雅培FreeStyle Libre / Dexcom G7
- **功能**: 实时血糖追踪，了解饮食对血糖影响
- **价格**: ~$100-300/月
- **适用**: 关注代谢健康/减脂/能量管理

## 三、体检服务

### 3.1 北京推荐体检机构
| 机构 | 价格区间 | 特点 |
|------|----------|------|
| 爱康国宾 | 2000-8000元 | 全国连锁，标准化 |
| 美年大健康 | 1500-6000元 | 网点最多 |
| 和睦家 | 5000-15000元 | 国际医疗标准 |
| 北航校医院 | 基础免费 | 基础检查方便 |

### 3.2 建议年度体检项目
```
必做项目：
✅ 血常规 + 尿常规
✅ 生化全套（肝功/肾功/血糖/血脂/尿酸）
✅ 甲状腺功能（TSH, FT3, FT4）
✅ 心电图
✅ 胸片/低剂量CT
✅ 腹部超声
✅ 肿瘤标志物（CEA, AFP, CA19-9, PSA等）

推荐加做：
✅ 维生素D, B12, 铁蛋白
✅ 糖化血红蛋白
✅ 颈动脉超声
✅ 骨密度（35岁后）
✅ 眼底检查
```

## 五、专业服务

### 5.1 私人教练
- **推荐场景**: 运动基础薄弱或动作不规范
- **价格**: 北京 300-800元/课时
- **选择标准**: 认证资质(NSCA/ACE) + 沟通风格匹配
- **替代方案**: 线上教练（Keep教练 / 小红书健身博主）

### 5.2 营养师咨询
- **推荐场景**: 有特殊饮食需求或体检异常
- **价格**: 北京 300-1000元/次
- **线上替代**: 薄荷健康VIP营养师

### 5.3 心理咨询
- **推荐场景**: 持续压力/焦虑/情绪问题
- **价格**: 北京 500-1500元/次
- **线上平台**: 壹心理 / 简单心理
- **AI辅助**: Woebot (英文AI CBT)
