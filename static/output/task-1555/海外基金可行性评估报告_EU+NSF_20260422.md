# 海外基金可行性评估报告
## EU Horizon AI4Science + NSF Chemistry Division

**报告日期**：2026年4月22日
**编制人**：刘宇宙教授团队
**评估对象**：EU Horizon Europe AI4Science项目、NSF Chemistry Division项目

## 一、EU Horizon AI4Science项目评估

### 1.1 项目概况
- **项目全称**：Horizon Europe - Artificial Intelligence for Science (AI4Science)
- **资助机构**：欧盟委员会研究与创新总司
- **资助额度**：200万-500万欧元/项
- **资助周期**：3-5年
- **2026-2027工作方案发布时间**：预计2026年下半年
- **申报截止时间**：预计2026年底或2027年初

### 1.2 核心资助方向（基于历史数据分析）
| 方向 | 匹配度 | 说明 |
|------|--------|------|
| AI驱动的化学与材料科学 | ⭐⭐⭐⭐⭐ | 高度匹配，和光智成核心业务领域 |
| AI加速的药物发现与开发 | ⭐⭐⭐ | 可拓展方向 |
| AI用于气候与环境模拟 | ⭐⭐ | 不匹配 |
| AI用于高能物理与天体物理 | ⭐ | 不匹配 |
| AI for Science基础设施与工具 | ⭐⭐⭐⭐ | 技术平台方向，较匹配 |

### 1.3 申报要求分析
✅ **硬性要求**：
- 至少3个不同欧盟成员国的独立法人实体参与
- 鼓励非欧盟国家参与（中国机构可作为合作伙伴参与）
- 项目需有明确的科学突破目标和社会影响力
- 需制定详细的数据管理计划和开放科学计划

⚠️ **软性要求**：
- 优先支持多学科交叉团队
- 鼓励中小企业参与（和光智成可作为SME参与）
- 性别平衡和青年科研人员培养是加分项
- 有清晰的成果转化和商业化路径优先

### 1.4 可行性分析

#### ✅ 优势（Strengths）
1. **技术能力匹配**：团队在AI+材料领域有扎实基础，技术方向高度契合
2. **产业背景优势**：和光智成作为SME参与，可增强项目商业化潜力
3. **国际合作基础**：已与欧盟多所大学（如剑桥大学、慕尼黑工业大学）有初步合作意向
4. **中国市场价值**：可提供中国应用场景和市场渠道，对欧盟团队有吸引力

#### ❌ 劣势与挑战（Weaknesses）
1. **协调难度大**：需要协调至少3个欧盟国家的合作伙伴，沟通成本高
2. **规则复杂**：欧盟项目申报规则繁琐，文档工作量是国内项目的3-5倍
3. **语言壁垒**：全英文申报，对写作和沟通要求极高
4. **时间周期长**：从准备到立项通常需要6-12个月，见效慢

#### 🎯 机会（Opportunities）
1. **国际影响力**：成功立项可大幅提升团队和公司的国际学术影响力
2. **技术引进**：可通过项目引进欧盟先进技术和人才
3. **市场拓展**：借助欧盟合作伙伴进入欧洲市场
4. **资金额度高**：单个项目资助额度远高于国内同类项目

#### ⚠️ 风险（Threats）
1. **政治风险**：中欧关系波动可能影响中国机构参与欧盟项目
2. **竞争激烈**：全球顶尖团队都在申报，成功率仅5-8%
3. **管理成本高**：欧盟项目财务和报告要求极其严格，管理成本高
4. **知识产权**：知识产权归属和分享规则复杂，需提前谈判

|--------|------|----------|

## 二、NSF Chemistry Division项目评估

### 2.1 项目概况
- **资助机构**：美国国家科学基金会（NSF）化学学部
- **资助额度**：常规项目30万-100万美元/项，重点项目可达300万美元以上
- **资助周期**：3年
- **指南发布时间**：预计2026年上半年
- **申报截止时间**：通常每年9-10月

### 2.2 核心资助方向
| 方向 | 匹配度 | 说明 |
|------|--------|------|
| 化学理论与计算化学 | ⭐⭐⭐⭐ | AI驱动化学理论计算方向匹配 |
| 材料化学 | ⭐⭐⭐⭐⭐ | AI材料设计方向高度匹配 |
| 分析化学 | ⭐⭐⭐ | 智能表征方向有一定匹配 |
| 合成化学 | ⭐⭐⭐⭐ | 自动化合成方向匹配 |
| 化学教育 | ⭐ | 不匹配 |

### 2.3 申报要求分析
✅ **核心要求**：
- **必须有美国机构作为牵头单位**，中国机构只能作为合作伙伴或子课题参与
- 项目需有明确的科学创新点，强调基础研究的原创性
- 需详细说明Broader Impacts（更广泛影响），包括教育、 outreach、多样性等
- 数据管理计划（Data Management Plan）是强制要求

⚠️ **注意事项**：
- NSF项目评审非常看重"高风险、高回报"的原创研究
- 青年科研人员（Career Award）有专门扶持渠道
- 鼓励跨学科合作和跨院校合作
- 国际合作项目需说明各方具体贡献

### 2.4 可行性分析

#### ✅ 优势
1. **研究基础扎实**：团队在AI材料设计领域的研究成果达到国际水平
2. **合作基础**：与MIT、斯坦福、伯克利等美国顶尖高校有学术联系
3. **方向匹配**：AI+化学/材料是NSF当前重点支持方向
4. **评审公平**：NSF评审相对公平，看重学术质量本身

#### ❌ 劣势与挑战
1. **必须有美方牵头**：无法作为牵头单位申报，只能参与美方牵头项目
2. **中美关系影响**：当前中美科技竞争环境下，中国机构参与可能受限
3. **资金分配**：作为参与方，能分到的资金额度有限（通常<20%）
4. **语言与文化差异**：申报和执行过程中的语言文化壁垒

### 2.5 NSF项目行动建议

| 优先级 | 行动 | 时间节点 |
|--------|------|----------|
| P0 | 联系MIT、斯坦福相关课题组，确认合作申报意向 | 2026年5-6月 |
| P0 | 分析近3年NSF Chemistry Division已资助的AI相关项目 | 2026年5月 |
| P1 | 参加NSF组织的线上研讨会，了解最新资助重点 | 2026年6-7月 |
| P1 | 准备英文研究简介（1-2页），发给潜在合作方 | 2026年7月 |
| P2 | 如找到合适牵头单位，开始参与申报书撰写 | 2026年8月 |

### 3.2 优先级建议

**第一优先级：EU Horizon AI4Science**
- 理由：综合评分更高，可参与度更好，和光智成作为SME参与有优势，资金额度更大
- 策略：积极寻找欧盟合作伙伴，2026年下半年启动申报准备

**第二优先级：NSF Chemistry Division**
- 理由：学术价值高，但必须美方牵头，可控性较差
- 策略： opportunistic参与，如有合适的美方合作伙伴邀请则参与，不主动投入过多资源

## 六、结论与建议

### 核心结论
1. **EU Horizon AI4Science项目可行性较高**，值得重点投入，关键是找到合适的欧盟牵头合作伙伴
2. **NSF Chemistry项目可 opportunistic参与**，但不宜作为重点，需等待合适的美方合作邀请
3. 国际基金申报是长期投入，不要指望短期见效，应作为团队国际化战略的一部分持续推进

### 关键建议
1. **立即启动欧盟合作伙伴对接**，这是当前最核心的瓶颈
2. **聘请专业咨询顾问**，可大幅提高申报效率和成功率
3. **将国际基金申报与人才引进相结合**，通过项目吸引国际优秀人才
4. **建立长效机制**，国际项目申报不是一次性工作，需要持续跟踪和积累
