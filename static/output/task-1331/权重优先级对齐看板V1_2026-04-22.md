# 权重-优先级对齐看板 V1.0

- 任务编号：1331
- 日期：2026-04-22

## 一、看板用途

用于每日追踪T1/T2是否真正获得与其战略权重相匹配的执行优先级和时间投入，及时识别优先级倒挂、资源偏航与阻塞积压。

## 二、核心指标

- T1完成率
- T2完成率
- T1 Avg_Priority
- T2 Avg_Priority
- T1投入时长(h)
- T2投入时长(h)
- T1新增/完成/阻塞数
- T2新增/完成/阻塞数
- 阻塞清零率
- 跨节点响应时长(h)
- 权重执行偏差率(%)

## 三、计算规则

### 1. 执行优先级
`执行优先级 = 基础优先级 × 0.5 + 目标权重归一化系数 × 0.5`

### 2. 权重执行偏差率
`权重执行偏差率 = (目标权重归一化值 - 实际Avg_Priority) / 目标权重归一化值 × 100%`

### 3. 阻塞清零率
`阻塞清零率 = 已清零阻塞项 / 本周期阻塞总项 × 100%`

## 四、阈值定义

- 绿色：Avg_Priority ≥ 9.2
- 黄色：9.0 ≤ Avg_Priority < 9.2
- 红色：Avg_Priority < 9.0
- 严重偏航：连续2天红色，或72小时无关键里程碑推进

## 七、异常处理规则

1. 任一目标Avg_Priority跌破9.0，次日必须减少非核心事项。
2. 连续两天低于9.0，立即召开15分钟纠偏会。
3. 若投入时长占比低于60%，优先清理会议和碎片任务。
4. 若阻塞项超48小时未清零，必须升级处理。

## 八、使用说明

- 每日收盘更新一次。
- 每72小时输出一次Sprint Review摘要。
- 双周结束生成瀑布图、热力图、ROI分析与关键结论。
