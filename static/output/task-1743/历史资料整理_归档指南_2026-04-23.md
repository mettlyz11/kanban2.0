## 五、工具使用指南

### 5.1 iCloud 共享相册操作
1. 打开「照片」App → 点击「相册」标签
2. 点击「+」→「新建共享相册」
3. 命名并添加家庭成员
4. 选择照片 → 点击分享按钮 →「添加到共享相册」
5. 添加描述文字

### 5.2 Apple 备忘录使用
1. 每个成员一个专属文件夹
2. 按「YYYY-MM-DD 主题」命名每条备忘录
3. 支持插入照片、手绘、扫描文档
4. 可通过搜索快速定位

### 5.3 本地文件系统操作
```bash
# 目录结构示例
家庭成长记录/
├── 01-照片视频库/
│   └── 2026/
│       └── Q1-第一季度/
│           ├── 2026-01-15_寒假第一天/
│           ├── 2026-01-28_春节准备/
│           └── 2026-02-10_春节庆祝/
├── 02-成长日志/
│   ├── 女儿成长记录/
│   └── 儿子成长记录/
└── 03-里程碑与奖项/
    ├── 女儿奖项.md
    └── 儿子奖项.md
```
