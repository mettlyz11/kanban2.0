## 二、韧性评估模型 - 算法细节

### 2.1 特征提取器 (PyTorch实现)

```python
class ResilienceFeatureExtractor(nn.Module):
    def __init__(self):
        super().__init__()
        # 时序特征提取
        self.temporal_encoder = TemporalConvNet(
            num_inputs=12,  # 12维生理指标
            num_channels=[64, 128, 64],
            kernel_size=3
        )
        # 注意力机制
        self.attention = nn.MultiheadAttention(64, num_heads=4)
        # 输出层
        self.classifier = nn.Sequential(
            nn.Linear(64, 32),
            nn.ReLU(),
            nn.Dropout(0.3),
            nn.Linear(32, 4)  # 4维度韧性评分
        )
    
    def forward(self, x):
        features = self.temporal_encoder(x)
        attended, _ = self.attention(features, features, features)
        return self.classifier(attended.mean(dim=1))
```

### 2.2 校准阈值

| 韧性等级 | 总分范围 | 行动建议 |
|---------|---------|---------|
| 优秀 | 85-100 | 维持现状，每月随访 |

| 较差 | 40-54 | 强化干预 + 医生咨询 |

def generate_intervention(user_profile, resilience_score, anomalies):
    recommendations = []

    if resilience_score['cardio'] < 60:

## 四、预算优化 - 数学模型

### 4.1 成本效益分析 (CEA)

```
增量成本效果比 (ICER) = (干预方案成本 - 基线成本) / (QALY干预 - QALY基线)

其中 QALY (质量调整生命年) = 生命年 × 健康效用值
```

### 4.2 保险选择优化模型

```python
def optimize_insurance_plan(user_risk, plans, budget_constraint):
    # 使用线性规划求解最优方案
    c = [-plan['expected_value'] for plan in plans]
    A = [[plan['premium'] for plan in plans]]
    b = [budget_constraint]
    
    result = linprog(c, A_ub=A, b_ub=b, method='highs')
    return plans[result.x.argmax()]
```
