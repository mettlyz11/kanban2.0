# 3个月心血管风险降低干预执行计划
## 总目标
3个月内将核心指标调整至正常范围，心血管风险降低30%以上，建立长期健康管理习惯。

---
### 第1个月：基础习惯建立期
核心目标：建立规律作息、运动和饮食基础
1. **作息调整**：每日23:30前入睡，保证7小时睡眠，逐步取消凌晨1点后工作安排
2. **运动干预**：每周3次中等强度有氧运动（快走/慢跑/游泳，每次45分钟），每日步数≥8000步
3. **饮食调整**：减少高油高盐摄入，每日摄入蔬菜≥500g，水果≥200g，戒烟限酒（每日酒精摄入<25g）
4. **压力管理**：每日10分钟冥想，每周安排1次半天完全脱离工作的休息时间
5. **指标监测**：每日完整记录所有核心指标，完成首次基线体检

---
### 第2个月：强化干预期
核心目标：优化干预方案，指标逐步达标
1. **运动升级**：每周增加1次力量训练（核心肌群训练，每次30分钟），有氧运动提升到每次1小时
2. **饮食优化**：控制碳水化合物摄入，增加Omega-3脂肪酸摄入（深海鱼/坚果），每日饮水量≥2L
3. **压力管理**：每周增加1次兴趣爱好活动（打球/摄影/徒步等），降低工作压力水平
4. **指标监测**：完成1次中期指标复查，对比基线数据调整干预方案

---
### 第3个月：习惯固化期
核心目标：固化健康习惯，指标稳定达标
1. 所有干预动作固化为日常习惯，无需刻意坚持
2. 完成全套心血管复查，评估干预效果
3. 制定长期健康管理方案，维持干预成果
4. 建立每月1次的健康复盘机制，长期追踪

---
## 禁忌事项
1. 避免连续熬夜、连续高强度工作超过10天
2. 避免高负荷运动后立即喝冰水、吹冷风
3. 避免情绪剧烈波动（大喜大悲、暴怒）
4. 避免自行服用心血管相关保健药品，需遵医嘱
