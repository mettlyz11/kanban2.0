## 通用就餐策略

### 外卖点餐指南

#### ✅ 推荐选择
1. **轻食沙拉** - 备注：多加蛋白质，少酱或酱分开
2. **日式定食** - 备注：少饭，多选烤鱼/煮肉
3. **潮汕牛肉火锅** - 多选牛肉和蔬菜，少主食
4. **烤鱼** - 选清江鱼/鲈鱼，配菜多要蔬菜
5. **蒸菜馆** - 清蒸鱼+蒸蔬菜，健康首选

#### ❌ 尽量避免
- 炸鸡汉堡类
- 麻辣香锅（油太多）
- 披萨（高碳水高脂肪）
- 奶茶甜品

### 出差应急策略

1. **早餐:** 酒店自助优先选鸡蛋+酸奶+水果，避开糕点
2. **午餐:** 优先选择有蒸菜/烤鱼的餐厅
3. **晚餐:** 清淡为主，避免应酬暴饮暴食
4. **应急:** 随身携带蛋白棒/坚果，避免过度饥饿

### 假期/周末策略

1. 早餐保持规律（不要因为周末不吃）
2. 午餐可以相对丰盛（但不要吃到撑）
3. 晚餐清淡，补偿午餐的丰盛
4. 安排1次"放纵餐"（但仅此1次）
