## 二、每日热量与宏量营养素计算

### 2.1 基础代谢率 (BMR)

使用Mifflin-St Jeor公式（最准确的现代公式）：

```
男性BMR = 10×体重(kg) + 6.25×身高(cm) - 5×年龄 + 5

假设年龄40岁：
BMR = 10×75.5 + 6.25×175 - 5×40 + 5
    = 755 + 1093.75 - 200 + 5
    = 1,653.75 千卡/天
```

### 2.2 总能量消耗 (TDEE)

**活动系数选择:** 1.55（中度活跃 - 教授工作+日常运动+每日1万步）

```
TDEE = BMR × 活动系数
     = 1,653.75 × 1.55
     ≈ 2,563 千卡/天
```

### 2.3 减脂期热量目标

**策略:** 温和热量赤字（300-500千卡/天），可持续不反弹

| 场景 | 每日热量 | 预期减重速度 | 适用期 |
|------|---------|-------------|--------|
| **维持期** | 2,560 kcal | 体重稳定 | 体重达标后 |
| **温和减脂** | **2,200 kcal** | 0.3-0.5 kg/周 | 第1-8周 ✅ |
| **快速减脂** | 2,000 kcal | 0.5-0.8 kg/周 | 不推荐 |

> ✅ **推荐方案:** 每日2,200千卡，预计3个月减至72kg（BMI=23.5）

### 2.4 宏量营养素分配 (IIFYM法)

| 营养素 | 比例 | 每公斤体重 | 每日克数 | 热量占比 |
|--------|------|----------|---------|---------|
| **蛋白质** | 高 | 2.0 g/kg | **150 g** | 27% |
| **碳水化合物** | 中 | 3.0 g/kg | **225 g** | 41% |
| **脂肪** | 低 | 0.8 g/kg | **60 g** | 32% |
| **合计** | - | - | - | **2,220 kcal** |

**蛋白质策略详解:**
- 2.0g/kg体重 = 充足的肌肉保护
- 每餐30-40g蛋白质 = 最大化肌肉蛋白合成
- 优质蛋白来源：鸡蛋、鸡胸肉、鱼虾、豆制品、乳清蛋白

**碳水化合物策略:**
- 运动前后集中摄入（运动前1小时，运动后30分钟内）
- 优先选择低GI碳水：燕麦、糙米、红薯、全麦面包
- 避免精制碳水：白米、白面、含糖饮料

**脂肪策略:**
- 优先不饱和脂肪：橄榄油、牛油果、坚果、深海鱼
- 每日至少摄入必需脂肪酸（Omega-3）
- 避免反式脂肪和过量饱和脂肪

## 三、营养优先级与饮食原则

### 3.1 10条核心饮食原则

1. **蛋白质优先** - 每餐先吃蛋白质，确保饱腹感和肌肉保护
2. **蔬菜管够** - 每餐至少200g蔬菜，热量低营养密度高
3. **碳水定时** - 碳水集中在运动前后，其余时间低碳
4. **饮水充足** - 每日2.5-3L水（约8-10杯），饭前喝1杯
5. **三餐规律** - 固定时间吃饭，避免过度饥饿导致暴饮暴食
6. **慢吃咀嚼** - 每口咀嚼20次，用餐时间≥20分钟
7. **8分饱停止** - 感知到"不饿"就停，不要吃到"撑"
8. **加工越少越好** - 天然食物 > 加工食品 > 快餐外卖
9. **允许适度放纵** - 每周1顿"欺骗餐"，避免心理压力
10. **记录复盘** - 每周记录1-2天饮食，持续优化

### 3.2 食物红黑榜

#### ✅ 绿灯食物（随便吃）
- 蔬菜类：西兰花、菠菜、生菜、黄瓜、番茄、芹菜、蘑菇
- 蛋白质：鸡蛋、鸡胸肉、鱼虾、瘦牛肉、豆腐、无糖酸奶
- 健康脂肪：牛油果、坚果（少量）、橄榄油、亚麻籽油

#### 🟡 黄灯食物（适量吃）
- 主食：燕麦、糙米、红薯、玉米、全麦面包、藜麦
- 水果：苹果、香蕉、蓝莓、橙子（每日≤2份）
- 豆类：黑豆、红豆、鹰嘴豆

#### 🔴 红灯食物（尽量不吃）
- 含糖饮料：可乐、果汁、奶茶、运动饮料（无糖除外）
- 精制碳水：白面包、蛋糕、饼干、油条
- 油炸食品：炸鸡、薯条、油条
- 加工肉：香肠、培根、午餐肉

## 五、常见问题与解决方案

### Q1: 工作忙没时间做饭怎么办？
**A:** 预制餐策略
- 周末集中备餐：每周日花2小时准备3-5天的主食和蛋白质
- 便捷蛋白质：煮鸡蛋、即食鸡胸肉、蛋白棒、无糖酸奶
- 便捷蔬菜：沙拉菜、预切蔬菜、微波炉蒸蔬菜
- 外卖选择：沙拉、轻食、日式定食（备注少饭少油）

### Q2: 社交聚餐不可避免怎么办？
**A:** 灵活调整策略
- 聚餐前：先吃点蛋白质+蔬菜垫底，避免过度饥饿
- 聚餐中：优先吃蛋白质和蔬菜，少吃主食和油炸
- 聚餐后：下一餐减少热量，当天增加运动
- 聚餐频率：控制在每周≤1次，不连续两天

### Q3: 平台期体重不动怎么办？
**A:** 三板斧突破
1. 增加热量赤字：再减100-200千卡/天
2. 增加运动消耗：每日多走2000步或增加20分钟运动
3. 碳水循环：高碳日+低碳日交替，打破代谢适应

### Q4: 饥饿感太强坚持不下去怎么办？
**A:** 饱腹感优化
- 增加蛋白质比例（提高到2.2g/kg）
- 增加膳食纤维（多吃蔬菜、蘑菇、木耳）
- 多喝水（饭前1杯，每天≥2.5L）
- 分餐：3正餐+2小加餐，避免长时间空腹
