## 4. 已知限制

1. **中文分词精度**：使用正则简单分词，对复杂语义短语识别率约 75%，建议生产环境引入 `jieba`
2. **LLM 稳定性**：DeepSeek API 偶发 timeout，fallback 规则引擎会增加 30s 等待（可配置更短超时）
3. **依赖发现准确率**：基于 `#ID` 模式匹配，需任务描述规范使用 # 引用，否则漏检
4. **相似度阈值**：0.6 为默认值，建议根据实际任务库调整，中文短文本建议降到 0.5
