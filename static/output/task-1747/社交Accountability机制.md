# 🤝 社交 Accountability 机制

**建立日期**: 2026-04-23  
**核心原则**: 通过社交承诺增加运动执行的约束力和动力

---

## 📌 机制设计

### 1. 运动报备伙伴（至少1-2人）

**选择标准**:
- 关系较好的朋友/同事
- 对方也有运动习惯或健康意识
- 不会敷衍你的报备，会认真回应

**建议报备对象**（请自行选定）:
- 对象1: _______（关系：_______）
- 对象2: _______（关系：_______）

### 2. 报备方式

| 报备类型 | 频率 | 内容 | 渠道 |
|---------|------|------|------|
| 每周报备 | 每周日 | 本周运动完成情况 + 下周计划 | 微信消息 |
| 月度通报 | 每月1日 | 月度总结 + 体测数据 | 微信消息/当面 |
| 打卡分享 | 每次运动后 | "今天跑了XX分钟" + 截图 | 朋友圈/私信 |

### 3. 报备模板（微信消息）

**每周报备消息**:
```
🏃 本周运动报备（W{周次}）
✅ 有氧跑步：X/X次
✅ 力量训练：X/X次  
✅ 拉伸：X/7天
📊 完成率：XX%
💪 身体感受：[1-5分]
📝 下周目标：继续坚持/调整计划

请监督我！🫡
```

**月度通报消息**:
```
📊 月度运动总结（{月份}月）
📈 月均完成率：XX%
⚖️ 体重：XX kg（较上月 ±X kg）
📏 体脂率：XX%（较上月 ±X%）
🎯 下月目标：[具体目标]

感谢监督，继续加油！💪
```

### 4. Accountability 升级机制

如果连续2周未完成目标，触发以下升级：

1. **Level 1**: 向报备伙伴发送"自我检讨"消息，说明原因和改进计划
2. **Level 2**: 请报备伙伴在下周运动日发消息提醒你
3. **Level 3**: 如果伙伴愿意，可以约定一起运动（线上/线下同步）

### 5. 社群打卡（可选）

- 加入运动打卡微信群/小组
- 每日/每周在群内打卡
- 群体压力 > 一对一压力
