# 和光智成 - 6个月商业化路线图

## 时间范围：2026年5月 - 2026年10月

---

## 一、总体目标

> **6个月内完成LumiDFT MVP上线，获取首批10+付费客户，实现月收入¥50,000+，为A轮融资建立产品-市场契合(PMF)证据。**

```

 │          │          │          │          │          │
 ▼          ▼          ▼          ▼          ▼          ▼
```

## 二、阶段详细规划

### Phase 1: 开发冲刺期（5月1日 - 5月31日）

**目标：** 完成LumiDFT V1.0 MVP开发

#### 2.1.1 技术交付

| 周次 | 交付内容 | 负责人 | 验收标准 |
|------|---------|--------|---------|
| W1-W2 | 计算引擎层 | 算法团队 | NEB/CI-NEB跑通3个基准测试 |
| W1-W2 | 任务调度系统 | 后端团队 | 支持100+并发队列 |
| W2-W3 | Web前端（提交+结果） | 前端团队 | Figma设计稿还原度>90% |
| W2-W3 | 用户/计费系统 | 后端团队 | 注册/登录/支付完整 |
| W3-W4 | 集成测试 | QA | 核心流程10个用例100%通过 |
| W4 | 性能优化 + Bug修复 | 全团队 | 小任务<4h完成 |

#### 2.1.2 运营准备

| 事项 | 交付物 | 负责人 |
|------|--------|--------|
| 品牌物料 | Logo/官网/产品手册 | 市场 |
| 帮助中心 | 10篇教程文档 + 3个视频 | 产品 |
| 定价页面 | 官网定价页 + 合同模板 | 销售 |
| 客服体系 | 企业微信/帮助台配置 | 运营 |

#### 2.1.3 关键风险
- **风险1：计算精度不达标** → 预案：与高校合作验证，预留2周调参时间
- **风险2：云资源成本超支** → 预案：与阿里云/华为云谈学术折扣

### Phase 2: MVP发布期（6月1日 - 6月15日）

**目标：** 产品正式上线，启动种子用户计划

#### 2.2.1 发布活动

| 日期 | 活动 | 目标 |
|------|------|------|
| 6月1日 | 内部发布（员工+亲友） | 找Bug，收反馈 |
| 6月8日 | 定向邀请（50个目标用户） | 种子用户激活 |
| 6月15日 | 公开上线 | 开始自然流量 |

#### 2.2.2 种子用户计划

**招募标准：**
- 企业：材料企业R&D负责人，有DFT需求但缺能力
- 高校：材料/化学课题组，有经费且急需计算资源

**激励方案：**
- 免费试用200核时 + 1对1培训
- 成为"创始客户"，Logo展示+终身9折
- 直接反馈通道（与CEO/CTO定期沟通）

**目标：** 招募30个种子用户，其中10个转化为付费

---

### Phase 3: 获客启动期（6月16日 - 7月31日）

**目标：** 验证获客渠道，获取首批付费客户

#### 2.3.1 多渠道获客策略

| 渠道 | 策略 | 预算 | 目标 |
|------|------|------|------|
| **学术会议** | 材料/化学会议展位+演讲 | ¥50,000 | 200个Leads |
| **内容营销** | 知乎/公众号技术文章 | ¥10,000 | 500个注册用户 |
| **社群运营** | 材料计算微信群/QQ群 | ¥0 | 100个活跃用户 |
| **直销BD** | 定向拜访TOP50材料企业 | ¥20,000 | 20个企业试用 |
| **高校合作** | 与5所高校签框架协议 | ¥0 | 5个学术版客户 |

#### 2.3.2 销售流程设计

```
Leads → 试用注册 → 产品演示(可选) → 方案报价 → 签约付费 → 客户成功
  │        │            │              │          │          │
  会议   自动邮件    30min在线     标准报价单   电子合同   月度回访
  内容   新手引导    讲解          定制方案    对公付款   使用报告
```

#### 2.3.3 7月目标
- 注册用户：200+
- 活跃试用：50+
- 付费客户：5+
- 月收入：¥25,000+

### Phase 4: 产品迭代期（8月1日 - 8月31日）

**目标：** 基于客户反馈迭代产品，提升留存

#### 2.4.1 功能迭代（V1.1）

| 优先级 | 功能 | 需求来源 |
|--------|------|---------|
| P0 | 光谱计算模块（IR/Raman） | 客户反馈#1 |
| P0 | API接口开放 | 大客户要求 |
| P1 | 团队权限管理 | 企业客户要求 |
| P1 | 钉钉/企微集成 | 国内企业习惯 |
| P2 | 计算结果对比工具 | 用户建议 |

#### 2.4.2 客户成功体系

| 客户层级 | 服务策略 | 负责人 |
|---------|---------|--------|
| 战略客户（年付>20万） | 专属CSM + 月度业务回顾 | 客户成功总监 |
| 重要客户（年付5-20万） | 季度健康检查 + 培训 | 客户成功经理 |
| 标准客户（年付<5万） | 自动化邮件 + 帮助中心 | 自动+客服 |

#### 2.4.3 8月目标
- 付费客户：8+
- 月收入：¥40,000+
- NPS：>30

### Phase 5: 规模获客期（9月1日 - 9月30日）

**目标：** 规模化获客，冲刺10+付费客户

#### 2.5.1 加速策略

| 策略 | 具体动作 | 预期效果 |
|------|---------|---------|
| **案例包装** | 发布3个客户成功案例 | 提升转化率 |

#### 2.5.2 销售团队扩充

- 招聘1名Inside Sales（电话/线上销售）
- 招聘1名Field Sales（大客户拜访）
- 创始人继续参与TOP10客户销售

#### 2.5.3 9月目标
- 付费客户：12+
- 月收入：¥60,000+
- 获客成本(CAC)：<¥3,000
