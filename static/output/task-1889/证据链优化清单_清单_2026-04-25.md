# 证据链优化清单

## A. 商业秘密成立要件补强
- [ ] 列出涉案商业秘密清单，拆分为3-7个“秘密单元”并编号
- [ ] 对每个秘密单元说明：内容、价值、非公知性、载体位置、形成时间
- [ ] 准备“秘密点边界说明”，避免使用“整体技术”“全部资料”等模糊表述

## B. 保密措施证据
### 1. 制度层
- [ ] 保密制度/员工手册/研发资料管理制度
- [ ] 制度发布日期、版本号、适用范围
- [ ] 制度送达、签收或宣贯记录

### 2. 身份层
- [ ] 劳动合同中的保密条款
- [ ] 专项保密协议/NDA
- [ ] 竞业限制协议（如有）
- [ ] 岗位职责说明、涉密岗位说明

### 3. 控制层
- [ ] 文件密级标识、水印、编号示例
- [ ] 网盘/代码仓/服务器访问权限截图
- [ ] 下载审批、打印审批、导出限制记录
- [ ] 门禁、实验室、纸质文件领用登记

### 4. 执行层
- [ ] 保密培训签到、课件、考试记录
- [ ] 日常抽查或违规提醒记录
- [ ] 离职交接单、设备回收单、账号停用记录
- [ ] 离职后保密承诺书（如有）

## C. 侵权比对与接触路径
- [ ] 制作《实质相同比对矩阵》
- [ ] 制作《接触条件与时间线表》
- [ ] 固定邮件、微信、钉钉、网盘分享、下载日志
- [ ] 固定U盘接入、异常导出、集中打印、离职前高频访问记录
- [ ] 固定被告加入竞争主体/开展相关业务的时间点

## D. 抗辩预判
- [ ] 准备“非公知信息”说明，排除行业常识抗辩
- [ ] 准备“独立研发不成立”反驳框架
- [ ] 准备“合法来源不明”反驳框架
- [ ] 准备“形式化保密”专项回应材料

## E. 程序性选择
- [ ] 内部先完成《商业秘密合规审计报告》底稿
- [ ] 评估是否对法院提交审计报告正式版
- [ ] 先不急于申请技术鉴定，待秘密点和比对矩阵固定后再决定
- [ ] 如日志/平台数据掌握不足，考虑申请调查令或证据保全

## F. 庭前展示材料
- [ ] 一页案件总图
- [ ] 一页秘密点目录
- [ ] 一页保密措施执行证据表
- [ ] 一页接触路径时间线
- [ ] 一页反驳独立研发/公知信息意见
