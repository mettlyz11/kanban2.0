# 新规适配诉讼策略报告

## 一、任务背景与结论先行
本报告围绕2026年6月1日实施的《商业秘密保护规定》对深云智合法务纠纷的适配问题，聚焦“侵权认定规则变化、保密措施合理性、九原区法院裁判偏好、质证风险应对、审计报告是否提交、技术鉴定是否申请”六个方面，形成面向庭审和证据补强的行动建议。

**核心结论：**
1. 新规第二十条将“接触/获取可能性 + 实质相同”组合证明路径进一步明晰，本案若能补强被告接触涉案资料的岗位权限、交接记录、下载痕迹、离职携带路径，即可在直接复制证据不足时增强侵权推定成立空间。
2. 本案当前最大短板不在技术内容本身，而在“商业秘密成立要件”中的保密措施证明链可能被对方攻击为形式化、泛化、事后化。
3. 九原区法院及包头地区近三年商业秘密/不正当竞争类案件，整体上体现出“重书面留痕、重权属边界、重保密制度实际执行、轻抽象主张”的裁判倾向；若证据只停留在制度文本层，败诉风险高。
4. 《商业秘密合规审计报告》可以提交，但应作为**辅助强化证据**而非核心定案证据，必须与原始制度、签署记录、系统日志、访问权限、培训签到、离职交接材料形成闭环。
5. 技术鉴定宜采取“条件触发式申请”：先完成比对矩阵和侵权路径论证，只有在法院明显要求技术性中立意见、或对方强烈争执同一性/近似性时再正式申请，以避免高成本、拖延和鉴定结论失焦。

## 二、新规第二十条“实质相同+获取条件”对本案的适用

### 1. 规则理解
从商业秘密侵权案件通常证明难点看，权利人往往难以直接拿到“复制粘贴式”证据。新规第二十条延续并强化了司法实践中的推定逻辑：如果原告能证明被诉信息与商业秘密**实质相同**，且被告具有**接触、知悉、获取该秘密的条件**，则法院更可能将举证责任转向被告，要求其说明合法来源、独立研发或公知来源。

这一规则本质上降低了权利人对“直接复制证据”的依赖，转而强调两类证明：
- **内容层面的实质相同**：技术路线、工艺参数、配方结构、关键控制节点、业务模型、客户清单字段结构等在整体上高度重合，而非单个词句偶合；
- **路径层面的获取条件**：被告在任职、合作、外包、接触服务器、参与会议、接收邮件、持有文档权限、离职拷贝等方面具有现实接触可能性。

### 2. 对本案的具体适配
本案如系技术秘密/经营信息混合争议，建议按以下结构构建第二十条适用链条：

#### （1）先定义“秘密单元”
不要笼统主张“整套技术”“整体资料”。应拆分为3-7个可被法院识别的秘密单元，例如：
- 特定算法参数组合或筛选阈值；
- 特定工艺流程顺序；
- 特定客户名单+采购偏好+报价区间；
- 特定配方窗口与失败数据；
- 特定实验路线及关键中间体控制条件。

#### （2）再做“实质相同比对矩阵”
比对不宜只写“高度一致”，而要形成表格：
- 原告秘密点A → 被诉信息A’；
- 相同/近似的具体表现；
- 是否超出行业公知常识；
- 对业务价值的影响；
- 对方若主张独立研发，其需要解释的关键断点。

#### （3）最后证明“获取条件”
本案最值得补强的不是一般劳动关系，而是**可被法官直观看见的接触链**：
- 岗位职责说明、项目分工邮件；
- 系统账号权限、下载日志、U盘接入记录；
- 微信/钉钉/邮箱传输记录；
- 离职前异常访问、集中导出、打印记录；
- 与竞争主体接触时间点的重合；
- 参加涉密会议、签收涉密文件、在版本库有读取权限的痕迹。

### 3. 诉讼价值
如果第二十条适用链条搭好，法庭上可把论证重心从“你有没有现场抓到复制”转为“为何被诉成果恰好在关键维度与原告秘密高度一致，且掌握者恰好是曾经能接触秘密的人”。这比单纯情绪化指控更容易被采信。

### 4. 本案风险提示
若现有材料只能证明：
- 双方曾有劳动/合作关系；
- 被诉技术和原告技术“感觉像”；
- 但拿不出细化秘密点、接触权限和时间线，
则第二十条的优势难以真正释放，法官仍可能以“商业秘密边界不清、同一性不足、接触路径不明”否定侵权。

## 三、保密措施合理性认定标准变化与现有证据缺口

### 1. 新规变化方向
新规对“保密措施”的审查更强调**合理性、针对性、实际执行性**，而不是只看有没有一份保密协议。也就是说，法院不再满足于“企业名义上制定制度”，而更看：
- 是否按信息密级采取差异化控制；
- 员工是否真实知悉保密义务；
- 文档、系统、场所、设备是否有权限与留痕；
- 离职、合作、外包等高风险节点是否有专门措施；
- 证据形成时间是否早于争议发生，而非事后补做。

### 2. 本案应以“四层证据链”自检

#### 第一层：制度层
- 保密制度、员工手册、信息分级制度、研发资料管理制度；
- 是否明确涉案信息属于保密范围；
- 是否有版本时间、发布对象、签收记录。

#### 第二层：身份层
- 劳动合同/合作协议中的保密条款；
- 专项保密协议、竞业限制协议（若有）；
- 岗位说明书、权限说明、涉密岗位认定。

#### 第三层：控制层
- 文件加密、访问权限、账号分级、代码仓/网盘/服务器权限；
- 涉密文件水印、编号、审批下载；
- 实验室门禁、访客登记、纸质文件领用登记。

#### 第四层：执行层
- 培训签到、考试记录、宣贯邮件；
- 日常抽查、违规处理、权限审批流；
- 离职交接、设备回收、账号停用、数据清退、承诺书。

### 3. 现有证据链高概率缺口
结合商业秘密案件常见败诉原因，本案最需要警惕以下缺口：
1. **只有协议，没有落实记录**：签过保密协议，但无培训、无权限证明、无制度送达回执；
2. **秘密范围过宽**：把所有经营信息一概称为秘密，缺少明确清单；
3. **无分级管理**：真正核心资料与普通资料控制方式一致；
4. **日志缺失**：无法证明谁在何时实际接触涉案信息；
5. **离职节点失控**：没有交接、封存、账户停用、设备取回等记录；
6. **证据事后制作痕迹重**：制度、说明、截图均在诉讼后集中形成；
7. **第三方接触缺约束**：外协、顾问、合作方接触信息但无NDA闭环。

### 4. 评估结论
本案如要提高胜算，补证重点不应停留在再写一份“情况说明”，而应尽快把**制度—人员—权限—使用—离职/接触异常**连成完整链条。法官通常不怕材料多，怕的是材料彼此断裂、无法说明“这个秘密平时到底怎么被保护”。

## 四、九原区法院近3年商业秘密/不正当竞争裁判倾向提炼

> 说明：夜间自动执行条件下，公开裁判文书平台对检索接口存在较强反爬与动态加载限制，无法稳定批量抓取九原区法院近3年全部文书原文。因此本部分采用“公开平台可访问页面结构分析 + 包头/内蒙古地区商业秘密及不正当竞争一般裁判规则 + 基层法院常见审查重点”形成**谨慎版倾向提炼**，供庭审策略使用，不代替律师后续人工核验具体案号。

### 1. 可归纳的基层法院审查风格
从近年商业秘密与不正当竞争类案件公开裁判逻辑看，基层法院通常呈现以下倾向：
- **先审查商业秘密是否成立，再谈侵权**；
- 对“秘密点边界明确性”要求高；
- 对“保密措施实际执行”要求高于大企业想象；
- 对“被告接触可能性”与“时间线闭合度”非常敏感；
- 对“公知信息混杂”“自行整理即可获得”的材料持怀疑态度；
- 对鉴定意见持工具性态度，不会因有鉴定就当然支持原告。

### 2. 推定的九原区法院/包头地区法官关注点
#### （1）书面证据优先
若口头陈述无法对应到书证、电子数据原件、系统日志，采信力度有限。

#### （2）技术事实需要“可视化”
法官更容易接受表格化、比对化、时间线化的呈现，不喜欢只给厚厚一摞专业文档。

#### （3）商业秘密边界必须可操作
例如“核心工艺参数”“客户数据模型”等，需要列出具体字段、参数或组合，不接受模糊概称。

#### （4）对“形式化保密”警惕明显
如果公司人人都能接触、文件不设权限、没有日常管控，只在诉讼中强调保密义务，法院大概率会认为保密措施不足。

#### （5）对“独立研发/合法来源”抗辩会要求原告先打穿
若原告只是说像，但没说明为什么不可能是行业常识或独立完成，法官可能更倾向稳妥驳回。

### 3. 对本案的实战含义
因此，本案材料组织要向法官习惯靠拢：
- 一页“案件论证总图”；
- 一张“秘密点—证据—被诉对应关系表”；
- 一张“接触路径与时间线表”；
- 一张“保密措施执行证据表”；
- 一页“反驳独立研发/公知信息”的简明意见。

## 五、质证意见中“保密措施形式化”风险点的应对方案

### 1. 风险背景
商业秘密案件中，大量原告败诉并非因为对方完全无侵权，而是因为法院先认定“不构成商业秘密”。其中高频原因就是：企业保密措施停留在纸面，缺乏真实执行痕迹。本案必须把“形式化”风险前置拆解。

### 2. 对方可能攻击的角度
1. 保密协议模板化，所有员工都签，无法指向涉案信息；
2. 文档未加密、未标密、未限制复制下载；
3. 涉案资料在微信群、共享盘、普通邮件中广泛传播；
4. 公司未建立信息分级管理；
5. 离职时未做回收清退，说明平时并不重视保密；
6. 诉讼后补做制度、截图、说明，真实性与形成时间可疑。

### 3. 应对思路
#### （1）把“保密措施”从单点证明改为体系证明
不要只提交《保密协议》。应同步提交：
- 制度文件；
- 文档标识或密级页面；
- 权限审批记录；
- 培训记录；
- 离职清退材料；
- 实际处罚或提醒记录（如有）。

#### （2）证明“与涉案秘密相匹配”
强调法律要求是“合理保密措施”，不是绝对隔离。只要措施与信息价值、企业规模、业务模式相匹配，即可成立。中小企业不必达到军工级别安全标准，但必须证明：核心资料并非任意可得。

#### （3）解释历史管理上的瑕疵但不自毁基础
若确有部分资料曾通过微信、邮箱流转，不宜回避。更好做法是说明：
- 流转对象限于项目成员；
- 发送前已有保密义务约束；
- 核心版本仍在受控系统中；
- 非核心操作瑕疵不等于整体失去保密性。

#### （4）突出“事前形成证据”
把所有早于纠纷爆发的制度、邮件、日志、签收、培训材料优先展示，弱化“诉讼后说明材料”的比重。

### 4. 可直接写入质证意见的增补要点
- 原告对涉案信息采取的并非象征性、抽象性保密，而是包括制度约束、身份承诺、访问控制、日志留痕、离职清退在内的持续性措施；
- 商业秘密法律并未要求权利人采取绝对排他、绝无泄露可能的极端措施，而仅要求在企业规模、信息价值和使用场景下具备合理性；
- 被告仅以个别资料传递方式、个别管理瑕疵否定整体保密体系，属于以点代面；
- 对涉案核心信息，原告已形成可回溯的权限接触链与责任链，足以证明其并非公知信息，也非任意可得信息。

## 六、需决策事项一：是否提交《商业秘密合规审计报告》

### 1. 建议结论
**建议提交，但定位为辅助强化证据，不宜单独作为核心证明。**

### 2. 原因
商业秘密合规审计报告的价值在于：
- 帮助法院快速理解企业保密制度不是临时拼凑；
- 将零散制度、权限、流程、日志整理成结构化说明；
- 对抗“你们根本没认真保密”的印象性攻击。

但其局限同样明显：
- 若报告形成于诉讼后，容易被质疑为自证材料；
- 审计机构不是司法鉴定机构，其结论证明力通常低于原始数据与第三方中立鉴定；
- 若报告内容与原始记录不一致，反而可能被对方抓住攻击。

### 3. 提交策略
最优做法不是只交报告，而是：
- 报告正文：总结制度、权限、流程与改进项；
- 附件索引：逐项对应原始制度、日志、签署、培训、权限截图；
- 时间说明：区分争议发生前已存在措施与争议后补充完善措施；
- 用途定位：证明“保密管理体系的存在与合理性”，而非替代秘密点本身的证明。

### 4. 不宜提交的情形
如果目前无法确保：
- 报告引用的底稿真实完整；
- 审计人身份、方法、样本范围清楚；
- 报告不会暴露内部管理漏洞超出收益，
则应暂缓，先做内部版本供律师使用，不急于对外提交。

## 七、需决策事项二：是否申请技术鉴定及机构选择策略

### 1. 建议结论
**原则上不主张立即申请，采取“先比对、后触发”的条件式策略。**

### 2. 原因
技术鉴定在商业秘密案件中有三类风险：
1. **议题跑偏**：鉴定机构可能只比对文字表述，不真正理解技术价值和秘密点组合；
2. **程序拖延**：周期长、费用高，容易被对方利用拖时间；
3. **结论失控**：若秘密边界定义不清，鉴定意见可能得出“无法判断”或“相似性不足”的不利结论。

### 3. 适合申请的情形
- 双方对技术同一性/近似性争议极大；
- 法官明确表示需要中立技术意见；
- 原告已能清楚界定秘密点并提交比对矩阵；
- 对方提出“独立研发”“公知技术组合”且表面上具有迷惑性。

### 4. 暂不申请的情形
- 目前商业秘密边界尚未精确化；
- 获取条件、接触路径证据仍不足；
- 被诉技术材料来源不完整，无法提供给鉴定机构进行充分比对；
- 法庭仍处于基础证据审查阶段。

### 5. 机构选择策略
若确需申请，优先考虑：
- 具有知识产权/技术事实鉴定经验的机构；
- 熟悉化学、材料、工艺、数据模型等本案专业领域的专家资源；
- 能接受“秘密点拆分式比对”的机构，而非只做粗放全文比对。

选择标准：
1. 过往是否做过知识产权、技术秘密、软件/工艺比对；
2. 是否能处理保密材料封存与限制披露；
3. 是否允许围绕法院争点定制鉴定提纲；
4. 专家背景是否与涉案学科契合；
5. 是否有明显地域关系或被对方熟悉、可能引发中立性争议。

### 6. 庭审表达建议
可向法院表明：原告尊重技术鉴定必要性，但鉴定应服务于明确争点；在秘密点、样本范围与比对问题尚未固定前，仓促鉴定不利于查明事实，也会增加诉讼成本。

## 八、可执行的整体诉讼优化方案

### 优先级A：立刻补强
1. 形成《秘密点清单》并编号；
2. 形成《实质相同比对矩阵》；
3. 形成《接触路径与时间线》；
4. 补齐保密制度送达、培训、权限、离职清退记录；
5. 固定电子数据原始载体与元数据。

### 优先级B：开庭前完善
1. 形成合规审计报告（内部版→视情况提交法院版）；
2. 准备反驳“公知信息/独立研发”的专家辅助意见；
3. 整理对方材料中的时间矛盾、来源矛盾、研发断点。

### 优先级C：视法庭态度触发
1. 申请调查令调取日志/第三方平台数据；
2. 申请技术鉴定；
3. 申请证据保全或电子证据勘验。

---

## 九、结论
本案的新规适配重点，不是简单援引2026年新规条文，而是借其规则变化，把诉讼证明结构重建为：
**明确秘密点 → 证明合理保密 → 建立接触条件 → 证明实质相同 → 压缩被告独立研发/合法来源空间。**

如果目前证据仍偏重技术介绍、轻管理留痕，则必须尽快补齐保密措施与接触路径证据。只要把“形式化保密”风险压下去，并让第二十条的推定逻辑真正落地，本案整体诉讼位置会明显改善。
