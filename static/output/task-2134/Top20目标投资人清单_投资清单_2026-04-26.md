## 投资机构筛选标准

### 核心筛选维度
1. **方向匹配度**：有AI for Science、材料科学、硬科技投资历史
2. **阶段匹配**：早期投资（种子/A轮）能力
3. **中国布局**：在中国有办公室和团队
4. **资源价值**：能提供产业资源、后续融资支持
5. **品牌背书**：机构品牌能提升下一轮融资吸引力

### 优先级分类
- **S级**：战略级重点，必投的顶级机构，有明确的该领域投资案例
- **A级**：重点跟进，有相关领域投资记录，资源价值高
- **B级**：备选跟进，有硬科技布局，阶段匹配

## 融资执行路线图

### 第一阶段：准备期（第1-2周）
1. 完善中英文BP版本
2. 准备财务模型
3. 整理技术Demo材料
4. 梳理引荐人脉

### 第二阶段：预热期（第3-4周）
1. 联系天使投资人和行业专家获取背书
2. 参加2-3个AI/硬科技峰会
3. 通过校友网络初步接触3-5家VC
4. 收集反馈，迭代BP

### 第三阶段：集中对接期（第5-8周）
1. S级6家机构集中对接
2. A级8家机构同步推进
3. 每周安排3-5次深度沟通
4. 安排技术Demo和客户拜访

### 第四阶段：Term Sheet谈判（第9-12周）
1. 目标拿到3-5份TS
2. 选择领投方（优先红杉或a16z）
3. 确定跟投方组合（2-3家）
4. 估值谈判（目标2-3亿人民币）

### 第五阶段：交割（第13-16周）
1. 尽职调查
2. 法律文件签署
3. 资金到位
4. 投后对接启动

## 关键成功要素

### 1. 叙事一致性
- 所有材料保持一致核心信息
- 中英文版本逻辑统一
- 团队成员口径一致
