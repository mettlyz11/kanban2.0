- 30%-40%：75-84分 (晶瑞86, 江丰87, 雅克85, 彤程88)
- 20%-30%：65-74分 (有研75, 瑞联74, 强力72)

### 2. 毛利率评分 (权重20%)

基于2026年Q1毛利率评分：
- >50%：90-100分 (安集95)
- 45%-50%：85-89分 (华海94, 瑞联92, 南大91)
- 40%-45%：75-84分 (鼎龙88, 彤程86, 雅克84, 上海新阳81)
- 35%-40%：65-74分 (晶瑞77, 江丰77)

### 3. 研发投入评分 (权重15%)

### 4. 估值水平评分 (权重15%)

## 核心结论

1. **CMP抛光材料赛道整体评分最高**，受益AI芯片产能扩张，国产替代加速，推荐鼎龙股份、安集科技、华海诚科

2. **光刻胶赛道分化明显**，具备全产业链布局和高端产品量产能力的龙头公司评分较高，推荐鼎龙股份、彤程新材、晶瑞电材

3. **湿电子化学品赛道受益半导体产能扩张**，G5级产品国产化空间大，推荐晶瑞电材、江化微

4. **估值与成长匹配度是关键**，高成长但估值合理的标的具备更好的投资性价比
