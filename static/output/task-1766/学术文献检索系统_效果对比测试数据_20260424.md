### 1.2 评估指标定义

| 指标 | 公式 | 含义 |
|------|------|------|
| **准确率 (Precision)** | TP / (TP + FP) | 检索结果中相关文档的比例 |
| **召回率 (Recall)** | TP / (TP + FN) | 检索到的相关文档占全部相关文档的比例 |
| **F1分数** | 2 * P * R / (P + R) | 准确率和召回率的调和平均 |
| **MRR** | 1/mean(rank_i) | 第一个相关结果的排名倒数的平均值 |
| **NDCG@k** | DCG@k / IDCG@k | 前k个结果的归一化折损累计增益 |

其中:
- TP = True Positive (正确检出的相关文档)
- FP = False Positive (误检的不相关文档)
- FN = False Negative (漏检的相关文档)
