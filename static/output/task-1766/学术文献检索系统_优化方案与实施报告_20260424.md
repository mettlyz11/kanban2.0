## 一、现状分析

### 1.1 当前系统架构

现有学术文献检索系统由以下模块组成：

| 模块 | 数据源 | 功能 | 问题 |

| 问题类型 | 具体表现 | 影响 |

| 关键词匹配策略简单 | 仅精确字符串匹配 | 误检率高(30-40%) |

| 缺少智能后处理 | 无摘要、无自动分类 | 信息过载 |

## 二、优化方案设计

### 2.1 检索算法优化

#### 方案1: 多层级检索策略

```
第一层级: 精确匹配 (高准确率)
  ├── 标题精确匹配
  ├── DOI/作者精确匹配
  └── 期刊卷期精确匹配

第二层级: 语义扩展匹配 (高召回率)
  ├── 同义词扩展 (WordNet + 领域词表)
  ├── 术语变体识别 (缩写、全称、中英文对照)
  └── 相关概念扩展 (知识图谱关联)

第三层级: 模糊匹配 (兜底)
  ├── 编辑距离匹配 (Levenshtein)
  ├── n-gram 字符匹配
  └── 向量相似度匹配 (Sentence-BERT)
```

#### 方案2: 混合排序算法

**排序权重公式:**
```
最终得分 = 
  0.40 * 标题匹配度 + 
  0.25 * 摘要匹配度 + 
  0.15 * 引用次数归一化 + 
  0.10 * 期刊影响因子归一化 + 
  0.10 * 发表时间衰减因子
```

### 2.2 关键词匹配策略优化

#### 中英文术语映射表构建

构建材料科学领域的双语术语映射：

| 中文术语 | 英文术语 | 缩写 | 相关术语 |
|----------|----------|------|----------|
| 密度泛函理论 | Density Functional Theory | DFT | 第一性原理、从头算 |
| 分子动力学 | Molecular Dynamics | MD | MD模拟、动力学模拟 |
| 金属有机框架 | Metal-Organic Framework | MOF | 配位聚合物、多孔材料 |
| 图神经网络 | Graph Neural Network | GNN | 图卷积网络、GCN |
| 多尺度模拟 | Multiscale Simulation | - | 多尺度建模、跨尺度 |

#### 查询重写规则

1. **缩写扩展**: "GNN" → "图神经网络 OR Graph Neural Network OR GCN"
2. **中英文混合**: "MOF 吸附" → "(MOF OR 金属有机框架) AND (吸附 OR adsorption)"
3. **概念扩展**: "催化剂" → "催化剂 OR 催化材料 OR 助催化剂"
4. **拼写纠错**: Levenshtein 距离 ≤ 2 时自动纠错

### 2.3 AI智能摘要和分类功能

#### 智能摘要功能设计

**摘要层级:**
1. **超简短摘要** (100字以内): 一句话概括论文核心贡献
2. **标准摘要** (300-500字): 研究背景、方法、结果、结论
3. **深度摘要** (1000字+): 详细方法描述、实验设计、数据讨论

**实现技术:**
- 使用 DeepSeek / Qwen 大模型
- Prompt 工程: 针对学术论文优化的提示词模板
- 结构化输出: JSON 格式便于后续处理

#### 智能分类功能设计

**分类维度:**
1. **研究领域**: 计算化学、材料科学、生物信息学、物理学等
2. **研究方法**: DFT、MD、GNN、蒙特卡洛等
3. **应用方向**: 催化、能源、生物、环境等
4. **数据类型**: 计算、实验、综述

**分类算法:**
- 零样本分类 (Zero-shot classification)
- 关键词规则匹配 (兜底)
- 置信度评分 (可配置阈值)

### 3.1 检索算法实现

```python
class AcademicSearchOptimizer:
    def __init__(self):
        self.term_mapper = TermMapper()
        self.query_rewriter = QueryRewriter()
        self.semantic_matcher = SemanticMatcher()
        
    def search(self, query: str, sources: List[str] = None) -> SearchResult:
        # 1. 查询预处理
        cleaned_query = self.preprocess(query)
        
        # 2. 查询重写和扩展
        expanded_queries = self.query_rewriter.expand(cleaned_query)
        
        # 3. 多源并行检索
        raw_results = self.parallel_search(expanded_queries, sources)
        
        # 4. 去重与合并
        deduplicated = self.deduplicate(raw_results)
        
        # 5. 相关性评分与排序
        ranked = self.rank_results(deduplicated, cleaned_query)
        
        # 6. AI后处理 (摘要+分类)
        enriched = self.enrich_with_ai(ranked)
        
        return SearchResult(
            query=query,
            expanded_queries=expanded_queries,
            total_count=len(enriched),
            results=enriched
        )
```

### 3.2 误检过滤机制

```python
class FalsePositiveFilter:
    def filter(self, results: List[Paper], query: str) -> List[Paper]:
        filtered = []
        for paper in results:
            score = self.calculate_relevance(paper, query)
            if score >= self.threshold:
                paper.relevance_score = score
                filtered.append(paper)
        return sorted(filtered, key=lambda x: x.relevance_score, reverse=True)
    
    def calculate_relevance(self, paper: Paper, query: str) -> float:
        scores = []
        
        # 标题匹配度 (BM25)
        title_score = self.bm25_score(paper.title, query)
        scores.append(('title', title_score, 0.4))
        
        # 摘要匹配度 (BM25)
        abstract_score = self.bm25_score(paper.abstract, query)
        scores.append(('abstract', abstract_score, 0.3))
        
        # 语义相似度 (Sentence-BERT)
        semantic_score = self.semantic_similarity(
            f"{paper.title} {paper.abstract}", query
        )
        scores.append(('semantic', semantic_score, 0.3))
        
        # 加权求和
        total_score = sum(score * weight for _, score, weight in scores)
        return total_score
```

class AISummarizer:

    def summarize(self, paper: Paper, level: str = "standard") -> dict:

        prompt = prompt.format(
            title=paper.title,

        )
        
        response = self.call_llm(prompt, max_tokens)

### 4.2 评估指标

- **准确率 (Precision)**: 检索结果中相关文档的比例
- **召回率 (Recall)**: 检索到的相关文档占全部相关文档的比例
- **F1分数**: 准确率和召回率的调和平均
- **MRR (Mean Reciprocal Rank)**: 第一个相关结果的排名倒数的平均值
- **NDCG@10**: 前10个结果的归一化折损累计增益
