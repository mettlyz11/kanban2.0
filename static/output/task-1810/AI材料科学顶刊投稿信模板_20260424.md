## 投稿信写作要点

### 1. 黄金结构（300-500字）

```
第1段：核心贡献一句话概括
第2段：3-5个主要发现，每个一句话
第3段：为什么选择这个期刊（精准匹配期刊定位）
第4段：标准声明（原创性、利益冲突等）
```

### 2. 关键加分项

✅ **使用期刊关键词**：
- Advanced Materials → "significant advance"
- ACS Nano → "fundamental understanding" "structure-property relationships"
- Nature Materials → "paradigm shift" "broad implications"

✅ **量化指标**：
- 性能提升百分比
- 效率提升倍数
- 数据集大小
- 验证样本数

✅ **链接附加资源**：
- GitHub 代码库
- Figshare 数据集
- 视频摘要
- 预印本链接

### 3. 绝对避免的错误

❌ 不要重复摘要内容
❌ 不要过度谦虚（"we hope" → "we demonstrate"）
❌ 不要泛泛而谈（"很重要" → "提升XX%"）
❌ 不要写错编辑名字
❌ 不要超过一页

### 4. 期刊定位速查

| 期刊 | 核心价值主张 | 投稿信关键词 |
|-----|-------------|-------------|
| **Advanced Materials** | 应用性能优先 | significant advance, superior performance, application potential |
| **ACS Nano** | 基础科学优先 | fundamental understanding, mechanistic insight, nanoscale phenomena |
| **Nature Materials** | 范式转变 | paradigm shift, transformative, broad implications |
| **Nature Energy** | 能源影响 | energy storage/conversion, practical impact, device performance |
| **Nano Letters** | 快速创新 | novel, rapid communication, timely findings |
