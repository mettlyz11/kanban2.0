## 🔬 必检项目清单

### 基础体检
- [ ] 身高、体重、BMI、体脂率
- [ ] 血压、心率
- [ ] 视力、眼压、眼底
- [ ] 听力检测
- [ ] 口腔检查

### 血液检查
- [ ] 全血细胞计数（CBC）
- [ ] 肝肾功能
- [ ] 血脂四项（胆固醇、甘油三酯、HDL、LDL）
- [ ] 空腹血糖 + 糖化血红蛋白（HbA1c）
- [ ] 甲状腺功能（TSH、FT3、FT4）
- [ ] 维生素D、B12、铁蛋白
- [ ] 尿酸

### 🔴 肿瘤标志物（重点）
- [ ] CEA（癌胚抗原）
- [ ] AFP（甲胎蛋白）- 肝癌
- [ ] CA19-9 - 胰腺癌/消化道
- [ ] CA125 - 卵巢癌
- [ ] PSA（男性前列腺特异抗原）
- [ ] CYFRA21-1 - 肺癌
- [ ] CA72-4 - 胃癌

### 🧬 基因检测（年度一次）
- [ ] 肿瘤易感基因筛查（如BRCA1/2等）
- [ ] 药物代谢基因检测（指导用药）
- [ ] 推荐机构：华大基因 / 燃石医学 / 泛生子
- [ ] 预算: 3000-8000元

### 影像学检查
- [ ] 胸部低剂量CT（肺癌筛查）
- [ ] 腹部B超（肝胆脾胰肾）
- [ ] 甲状腺B超
- [ ] 颈动脉B超
- [ ] 心脏彩超
- [ ] 骨密度检测（DEXA）
- [ ] 胃肠镜（建议每2-3年一次）

### 其他专项检查
- [ ] 心电图（静息）
- [ ] 24小时动态心电图（Holter）- 高压人群推荐
- [ ] 肺功能检测
- [ ] 前列腺B超
- [ ] 精液分析（可选）

## 📅 体检预约时间表

| 步骤 | 时间 | 行动 |
|------|------|------|
| T-30天 | 3月中旬 | 确定体检机构，电话预约 |
| T-14天 | 3月底 | 确认体检日期和套餐 |
| T-3天 | 体检前3天 | 清淡饮食，避免剧烈运动 |
| T-1天 | 体检前1天 | 晚8点后禁食，可少量饮水 |
| T日 | 体检当天 | 空腹前往，穿宽松衣物 |
| T+7天 | 体检后1周 | 获取报告 |
| T+14天 | 体检后2周 | 预约医生解读报告 |

## 💡 创业者特别注意事项

1. **心脑血管风险**: 长期高压工作增加心血管负担，重点关注血压、血脂、心电图
2. **睡眠障碍筛查**: 建议做睡眠监测（PSG），排查睡眠呼吸暂停
3. **压力激素**: 可加测皮质醇（Cortisol）水平
4. **心理健康**: 年度心理评估不容忽视
