# 儿子小升初暑假学习衔接计划（2026年）

## 一、初中学习要求评估（政保路径适配）
1. **数学**：需提前掌握代数基础（有理数、整式运算、一元一次方程）、几何入门（线与角、三角形基础），政保路径要求初中入学后期中/期末数学排名需稳定在年级前30%，提前铺垫可降低开学后适应压力。
2. **英语**：需掌握初中核心词汇1500个，搭建基础语法体系（时态、简单从句入门），具备初级阅读和写作能力，应对初中英语难度相较小学的跨越式提升。
3. **物理**：初中二年级正式开课，暑假提前做趣味启蒙，了解力、热、光、电基础概念，培养学科兴趣，降低后续学习门槛。

## 二、7周学习计划安排（每天2.5小时，兼顾放松）
| 周次 | 学习内容 | 时间分配 |
|------|----------|----------|
| 第1周 | 适应阶段：数学有理数概念+运算、英语小学词汇复盘+初中核心词汇前200个、物理趣味启蒙实验1个 | 数学1h、英语1h、物理0.5h |
| 第2-3周 | 数学：整式运算、一元一次方程解法练习；英语：词汇累计到800个、三大基础时态学习；物理：力与运动核心概念学习 | 数学1h、英语1h、物理0.5h |
| 第4周 | 中期调整周：学习任务减半，安排2次户外出游，复盘前3周学习内容查漏补缺 | 每天1.5h学习 |
| 第5-6周 | 数学：几何线与角、三角形基础；英语：词汇累计到1500个、简单从句入门；物理：热、光、电基础概念学习 | 数学1h、英语1h、物理0.5h |
| 第7周 | 收尾验收周：整体复习所有内容，完成基础测试题，预留2天完全放松调整状态迎接开学 | 每天2h学习 |

## 三、教辅与在线课程推荐
1. 数学：《5年中考3年模拟 七年级数学上册》、B站李永乐初中数学入门系列课
2. 英语：《新东方初中词汇词根+联想记忆法（乱序版）》、猿辅导初中英语语法入门课
3. 物理：《这就是物理》科普漫画、抖音趣味物理实验系列短视频

## 四、家庭时间平衡安排
1. 学习时间固定为每天上午9:00-11:30，下午和晚上预留完整时间陪伴女儿进行国际教育相关学习与活动，避免双娃学习时间冲突。
2. 每周安排2次户外运动、1次家庭集体活动，保证孩子充足放松时间，避免学习压力过大。
