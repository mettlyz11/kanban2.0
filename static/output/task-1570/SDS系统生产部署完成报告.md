## 🚀 系统架构

### 组件关系图

```
┌─────────────────────────────────────────────────────────────┐
│                    看板数据库 (MySQL)                         │
│                    (tasks, projects, goals)                   │
└─────────────────────────────────────────────────────────────┘
                              ▲
                              │
┌─────────────┐     ┌─────────────┐     ┌─────────────┐
│ 任务分析器   │────▶│ 任务生成器   │────▶│ 子代理调度器 │
│ (TaskAnalyzer)    │ (AutoTaskGen)    │(SubagentSched)│
└─────────────┘     └─────────────┘     └─────────────┘
       │                   │                   │
       │                   ▼                   │
       │          ┌─────────────────┐          │
       └─────────▶│ SDS 主控制器    │◀─────────┘
                  │ (SDSController) │
                  └─────────────────┘
                           │
           ┌───────────────┼───────────────┐
           ▼               ▼               ▼
    ┌───────────┐   ┌───────────┐   ┌───────────┐
    │ 72h监控   │   │ 仪表盘     │   │ 安全护栏   │
    │ 系统      │   │ 生成器     │   │ 系统      │
    └───────────┘   └───────────┘   └───────────┘
```

### 数据流

1. **任务分析器** 扫描数据库 → 识别停滞任务、项目缺口、质量问题
2. **分析结果** 输入到 **任务生成器** → 自动创建新看板任务
3. **子代理调度器** 监控任务队列 → 分发到可用子代理槽位
4. **72h监控系统** 持续监控所有组件 → 异常检测与自愈
5. **仪表盘生成器** 收集所有指标 → 生成可视化HTML报告
6. **安全护栏** 拦截所有高危操作 → 审计记录+自动备份
