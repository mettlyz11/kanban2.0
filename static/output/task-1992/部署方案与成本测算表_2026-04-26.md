## 2. 详细部署方案

### 2.1 阶段1: 本地验证环境

**硬件要求**

| 组件 | 最低配置 | 推荐配置 | 当前状态 |
|------|---------|---------|---------|
| CPU | Apple Silicon M1 | Apple Silicon M4 Pro | ✅ M4 Pro |
| 内存 | 16GB | 32GB | ✅ 36GB |
| 存储 | 256GB SSD | 512GB SSD | ✅ 512GB+ |
| 网络 | 100Mbps | 1Gbps | ✅ 1Gbps |

**软件部署清单**

```yaml
# docker-compose.local.yml
version: '3.8'
services:
  openclaw-gateway:
    image: openclaw/gateway:2026.4.15
    ports:
      - "18789:18789"
    volumes:
      - ~/.openclaw:/config
    environment:
      - OPENCLAW_MODE=local
      - DB_HOST=postgres
    
  langgraph-runtime:
    image: langgraph/runtime:latest
    ports:
      - "8000:8000"
    environment:
      - OPENAI_API_KEY=${OPENAI_API_KEY}
      - ANTHROPIC_API_KEY=${ANTHROPIC_API_KEY}
    volumes:
      - ./workflows:/app/workflows
      
  mcp-servers:
    image: mcp/servers-bundle:latest
    environment:
      - MCP_FILESYSTEM_ROOT=/data
    volumes:
      - ./data:/data
      
  postgres:
    image: postgres:16-alpine
    environment:
      - POSTGRES_USER=agent
      - POSTGRES_PASSWORD=${DB_PASSWORD}
      - POSTGRES_DB=agent_db
    volumes:
      - postgres_data:/var/lib/postgresql/data
    ports:
      - "5432:5432"
      
  redis:
    image: redis:7-alpine
    ports:
      - "6379:6379"
      
  milvus-standalone:
    image: milvusdb/milvus:v2.4.0
    ports:
      - "19530:19530"
    volumes:
      - milvus_data:/var/lib/milvus

volumes:
  postgres_data:
  milvus_data:
```

**部署步骤**

```bash
# 1. 准备环境
mkdir -p ~/agent-infra && cd ~/agent-infra

# 2. 创建数据目录
mkdir -p data/{documents,logs,cache}

# 3. 配置环境变量
cat > .env << EOF
DB_PASSWORD=$(openssl rand -base64 32)
OPENAI_API_KEY=sk-...
ANTHROPIC_API_KEY=sk-ant-...
ALIYUN_API_KEY=sk-...
MOONSHOT_API_KEY=sk-...
DEEPSEEK_API_KEY=sk-...
EOF

# 4. 启动服务
docker-compose -f docker-compose.local.yml up -d

# 5. 验证部署
curl http://localhost:18789/health
curl http://localhost:8000/health
```
