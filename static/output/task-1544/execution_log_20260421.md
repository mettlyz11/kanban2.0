- **问题**: 天使轮已基本确定，是否需要立即签FA？
- **解决方案**: 分阶段FA策略

  - Phase 2 (5/15-6/15): 评估后选择性签约
  - Phase 3 (6/15后): FA主导Pre-A轮

- **问题**: 缺乏直接触达Nvidia Ventures/Lux Capital的渠道
- **解决方案**: 多路径触达策略

  - 路径2: 通过全球FA覆盖
  - 路径3: 通过北航国际合作渠道
  - 路径4: 通过产业合作方引荐
