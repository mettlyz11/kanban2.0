# 社情民意信息 Word 版制作说明

由于无法直接生成 .docx 文件，请按以下步骤手动转换：

## 转换步骤

1. **打开 Word 文档**
   - 新建空白 Word 文档
   - 或从 `Files/T6_社会参与与统战工作/` 中查找是否有模板

2. **复制正文内容**
   - 打开 `output/task-1611/01-社情民意信息_完善终稿.md`
   - 复制正文内容（从标题到联系方式）
   - 粘贴到 Word 文档

3. **格式调整**

   ### 标题格式
   - 标题：黑体，二号，居中
   - 报送单位/报送人/日期：仿宋，小三，右对齐

   ### 正文格式
   - 一级标题（一、二、三）：黑体，三号
   - 二级标题（一是/建议一）：楷体，小三，加粗
   - 正文：仿宋，三号
   - 行距：固定值28磅
   - 页边距：上3.7cm，下3.5cm，左2.8cm，右2.6cm

4. **页眉页脚**
   - 页眉：致公党北京市委会社情民意信息
   - 页脚：页码居中

5. **保存**
   - 文件名：`关于加快AI驱动新材料研发中试平台建设的建议_刘宇宙_20260420.docx`
   - 同时保存 PDF 版本备用

## 致公党格式参考

根据致公党北京市委网站信息，社情民意信息一般要求：
- 字数：800-2000字
- 格式：Word 文档
- 报送：电子版 + 纸质版（如需）

## 建议

如不确定具体格式要求，建议：
1. 先联系致公党市委参政议政部确认格式
2. 或参考之前成功提交的社情民意信息格式
3. 保持简洁专业，内容重于形式
