## 一、核心目标期刊投稿指南

### 1. ACS Macromolecules / ACS Applied Polymer Materials
#### 1.1 期刊基本信息
- **类型**: ACS Publications，高质量聚合物科学期刊
- **IF**: 5.1~6.8
- **特别版**: "AI for Polymer Science and Technology"专刊
- **截止日期**: 2026年12月31日

#### 1.2 投稿要求精要
- **论文类型**: Letter（4页）/ Article（通常8-12页）/ Communication（快报）
- **图表标准**: 高分辨率（≥300 dpi），TIFF/EPS格式优先
- **参考文献**: ACS格式，通常50-80条
- **数据共享**: 鼓励在ACS期刊的Data Share平台提交原始数据
- **Supplementary Information**: 实验细节、完整谱图、AI模型参数

#### 1.3 AI材料论文写作框架

```
标题结构: 
"[方法] for [目标]: [核心成果]"
例: "Machine Learning-Guided Design of α-Diimine Nickel Catalysts 
     for Controlled Ethylene Polymerization"

摘要 (250词):
1. 问题背景 (2-3句)
2. 研究空白 (1-2句) 
3. 本文方法 (2-3句) ← AI/ML方法重点突出
4. 核心结果 (3-4句)
5. 意义影响 (1-2句)

正文结构:
├── Introduction (约600-800词)
│   ├── 领域重要性与研究背景
│   ├── 现有方法局限性（引出AI的必要性）
│   ├── 本文工作的创新点（明确贡献声明）
│   └── 论文结构简介
├── Results and Discussion (约2500-3500词)
│   ├── 数据集构建与描述符选择
│   ├── AI/ML模型构建与验证
│   ├── 预测结果与实验验证
│   ├── 关键结构-活性关系揭示
│   └── 与已报道催化剂的对比
├── Conclusions (约200-300词)
├── Experimental Section / Computational Methods
└── Supplementary Information
```

#### 1.4 关键写作要点（AI材料论文特有）
- **透明度**: 必须提供完整的模型架构、超参数、训练/验证集划分
- **基准测试**: 与传统方法（DFT计算）对比显示AI优势
- **可复现性**: 代码/数据集链接（GitHub/Zenodo）
- **化学合理性**: AI预测结果需有化学机理解释，避免"黑盒"批评
- **失败案例**: 诚实讨论模型局限性，提升审稿人信任

### 2. Journal of Materials Chemistry A (RSC)
#### 2.1 期刊基本信息
- **IF**: 11.9（RSC旗舰材料期刊）
- **特别版**: 单原子催化专刊，截止2026年9月11日
- **发表周期**: ~70天（审稿+修改+接受）

#### 2.2 RSC论文格式要求
- **通讯**: ≤4000词 + 3图/表（Communications类型）
- **全文**: 无严格字数限制，但建议6000-8000词（Articles类型）
- **图表**: RGB色彩模式；图例字号≥6pt
- **参考文献**: RSC格式（上标数字）
- **Graph abstract**: 必须，200×200像素，用于目录展示

#### 2.3 单原子催化主题论文框架

```
推荐研究角度（结合团队优势）:
"AI辅助单原子过渡金属催化剂设计用于可持续聚烯烃合成"

关键要素:
✓ 单原子/准单原子金属（Ni/Fe/Co）主题契合专刊
✓ 可持续性（绿色催化、低能耗）
✓ AI预测位点优化（加分项）
✓ 性能突破（TOF > 已报道最高值的X倍）
```

### 3. JCIM - Machine Learning in Materials Science
#### 3.1 期刊定位
- **特点**: 方法学导向，重视数据集贡献和算法创新
- **适合论文类型**: 方法论文、基准研究、数据库论文

#### 3.2 JCIM AI论文写作框架

```
论文类型1: 数据集论文
"A Curated Dataset of [X] Transition Metal Catalysts for 
 Machine Learning Benchmarking"
- 贡献: 开放数据集 + 基准模型
- 优势: 被引率高，长期影响力大

论文类型2: 方法论文
"[算法名]: A [方法描述] for Predicting Catalytic Activity 
 in Olefin Polymerization"
- 需要: 新算法或显著改进的方法
- 验证: 交叉验证 + 留出测试集 + 外部验证

论文类型3: 应用论文
"Machine Learning-Guided Virtual Screening of α-Diimine 
 Metal Complexes for Selective Ethylene Polymerization"
- 适合: 现阶段团队条件（实验验证+AI）
```

## 二、通用AI材料论文写作原则

### 2.1 标题策略
| 类型 | 示例 | 适用场景 |
|------|------|---------|
| 方法导向 | "Deep Learning-Accelerated Discovery of..." | 算法创新时 |
| 应用导向 | "AI-Guided Design of...for Enhanced..." | 实验验证时 |
| 数据导向 | "A High-Throughput Dataset of...for ML Benchmarking" | 数据集贡献 |
| 问题导向 | "Overcoming the Synthesis-Property Gap via AI-Driven..." | 解决领域难题时 |

### 2.2 摘要写作模板（AI材料论文专用）

```
[背景] [领域]中[具体问题]是一个重要挑战。
[现状] 传统方法[局限性]，无法实现[目标]。
[创新] 本文提出[方法名]，结合[实验/计算数据]，
       通过[AI技术]实现[目标]。
[结果] 模型在[测试集]上达到[定量指标]（R²=X, MAE=Y）。
       基于模型预测，我们设计并合成了[X]种新催化剂/材料，
       其[性能指标]比现有最佳值提升[N]倍/百分比。
[意义] 该方法为[领域]提供了可扩展的AI辅助设计范式，
       有望加速[应用场景]的材料开发。
```

### 2.3 必备图表清单（AI材料论文）

| 图表 | 内容 | 必要性 |
|------|------|-------|
| 研究示意图 | 整体工作流（数据→AI→实验验证） | 必须 |
| 数据集分析 | 特征分布、相关性热图 | 必须 |
| 模型验证 | 预测vs实验散点图（R²图） | 必须 |
| 特征重要性 | SHAP值或特征贡献图 | 强烈建议 |
| 化学解释 | 关键结构特征可视化 | 必须 |
| 实验验证 | 新候选材料的实验结果 | 必须 |

## 四、常见审稿意见预案

| 常见审稿意见 | 预防措施 |
|------------|---------|
| "AI模型是黑盒，缺乏化学解释" | 预先加入SHAP分析章节 |
| "数据集太小，结论不可靠" | N>100条数据；使用交叉验证；报告不确定度 |
| "没有独立验证集" | 预留20%外部测试集，不参与训练 |
| "合成方法没有创新性" | 强调AI辅助发现逻辑的创新性 |
| "与已知工作相比没有突破" | 加强Introduction中的差异化定位 |
| "计算描述符选择不合理" | 引用文献支持描述符选择逻辑 |
