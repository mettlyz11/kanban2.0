## 二、关键指标计算逻辑

### 2.1 身体活动指标

#### 每日步数目标达成率
```
目标达成率 = 实际步数 / 目标步数 * 100%

目标步数基准：
- 基础目标：8000步/天
- 活跃目标：10000步/天
- 专业目标：12000步/天
```

#### 活动能量消耗 (TEE)
```
TEE = BMR × 活动系数

其中：
BMR(男) = 88.362 + (13.397 × 体重kg) + (4.799 × 身高cm) - (5.677 × 年龄)
BMR(女) = 447.593 + (9.247 × 体重kg) + (3.098 × 身高cm) - (4.330 × 年龄)

活动系数：
- 久坐：1.2
- 轻度活动：1.375
- 中度活动：1.55
- 高度活动：1.725
- 极高活动：1.9
```

#### 心率区间计算
```
最大心率 (MHR) = 220 - 年龄

区间1 (恢复区): 50-60% MHR  → 放松恢复
区间2 (燃脂区): 60-70% MHR  → 脂肪燃烧
区间3 (有氧区): 70-80% MHR  → 心肺训练
区间4 (无氧区): 80-90% MHR  → 耐力提升
区间5 (极限区): 90-100% MHR → 峰值训练
```

### 2.2 睡眠质量指标

#### 睡眠效率
```
睡眠效率 = (总睡眠时长 / 在床上的时间) × 100%

评价标准：
- 优秀：≥ 90%
- 良好：85-89%
- 一般：80-84%
- 较差：< 80%
```

#### 睡眠结构比例参考值
```
深睡占比：15-25% 总睡眠时长
REM占比：20-25% 总睡眠时长
浅睡占比：50-60% 总睡眠时长

深睡最佳时长：90-120分钟/晚
REM最佳时长：90-120分钟/晚
```

#### 睡眠规律性评分
```
入睡时间标准差 = 最近7天入睡时间的标准差(分钟)
起床时间标准差 = 最近7天起床时间的标准差(分钟)

规律性评分 = 100 - min(60, (入睡时间标准差 + 起床时间标准差) / 2)

评分等级：
- 优秀：≥ 90分 (差异 < 20分钟)
- 良好：80-89分 (差异 20-40分钟)
- 一般：70-79分 (差异 40-60分钟)
- 较差：< 70分 (差异 > 60分钟)
```

### 2.3 心血管健康指标

#### 静息心率趋势
```
正常范围：60-80 bpm
优秀运动员：40-60 bpm

静息心率异常检测：
  若连续3天 > 基线值 + 10 bpm
  则标记为异常升高（可能疲劳、生病、压力大）
```

#### 心率变异性 (HRV)
```
SDNN (全部窦性心搏RR间期标准差)
  正常：100-150 ms
  良好：> 150 ms
  需关注：< 100 ms

HRV趋势分析：
  连续下降 → 疲劳累积、压力增大
  连续上升 → 恢复良好
```

### 2.4 恢复与压力指标

#### 恢复分数
```
恢复分数 = f(HRV, 静息心率变化, 睡眠质量, 前一天活动量)

权重分配：
  HRV趋势：35%
  睡眠质量：30%
  静息心率：20%
  活动恢复平衡：15%

评分等级：
  90-100：恢复极佳
  70-89：恢复良好
  50-69：恢复一般
  30-49：恢复较差
  0-29：严重疲劳
```

## 三、睡眠质量评分模型

### 3.1 多维度评分体系

睡眠质量综合评分采用100分制，从以下6个维度加权计算：

| 维度 | 权重 | 评分依据 | 满分条件 |
|------|------|---------|---------|
| **总睡眠时长** | 25% | 7-9小时为最佳 | 480分钟 = 100分 |
| **睡眠效率** | 20% | 入睡后醒来时间占比 | ≥ 90% = 100分 |
| **深睡比例** | 20% | 深睡占总睡眠比例 | 20% = 100分 |
| **REM比例** | 15% | REM占总睡眠比例 | 22% = 100分 |
| **入睡潜伏期** | 10% | 关灯到入睡时间 | 15分钟 = 100分 |
| **夜间觉醒** | 10% | 醒来次数和时长 | 0-1次 = 100分 |

### 3.2 评分计算公式

```python
def calculate_sleep_score(sleep_data):
    """
    计算睡眠质量综合评分
    """
    score = 0
    
    # 1. 总睡眠时长 (满分25分)
    optimal_duration = 480  # 8小时
    duration_diff = abs(sleep_data['total_duration'] - optimal_duration)
    duration_score = max(0, 25 - (duration_diff / 60) * 2)
    score += duration_score
    
    # 2. 睡眠效率 (满分20分)
    efficiency = sleep_data['sleep_efficiency']
    if efficiency >= 90:
        efficiency_score = 20
    else:
        efficiency_score = 20 * (efficiency / 90)
    score += efficiency_score
    
    # 3. 深睡比例 (满分20分)
    deep_ratio = sleep_data['deep_duration'] / sleep_data['total_duration']
    optimal_deep = 0.20
    deep_diff = abs(deep_ratio - optimal_deep)
    deep_score = max(0, 20 - deep_diff * 100)
    score += deep_score
    
    # 4. REM比例 (满分15分)
    rem_ratio = sleep_data['rem_duration'] / sleep_data['total_duration']
    optimal_rem = 0.22
    rem_diff = abs(rem_ratio - optimal_rem)
    rem_score = max(0, 15 - rem_diff * 80)
    score += rem_score
    
    # 5. 入睡潜伏期 (满分10分)
    latency = sleep_data['sleep_latency']
    if latency <= 15:
        latency_score = 10
    elif latency <= 30:
        latency_score = 8
    elif latency <= 45:
        latency_score = 5
    else:
        latency_score = max(0, 10 - (latency - 45) / 5)
    score += latency_score
    
    # 6. 夜间觉醒 (满分10分)
    awakenings = sleep_data['awakenings_count']
    if awakenings <= 1:
        awakening_score = 10
    else:
        awakening_score = max(0, 10 - (awakenings - 1) * 1.5)
    score += awakening_score
    
    return round(score, 1)
```

### 3.3 评分等级定义

| 分数区间 | 等级 | 评价 | 建议 |
|----------|------|------|------|
| **90-100** | A | 睡眠质量极佳 | 保持当前作息 |
| **80-89** | B | 睡眠质量良好 | 微调整即可 |
| **70-79** | C | 睡眠质量一般 | 需要改善 |
| **60-69** | D | 睡眠质量较差 | 重点关注 |
| **< 60** | F | 睡眠质量很差 | 建议就医咨询 |

## 四、运动效果评估模型

### 4.1 训练负荷 (Training Load)

```
急性训练负荷 (Acute Load) = 运动时长 × 强度系数

强度系数：
  极低强度：1.0
  低强度：1.5
  中等强度：2.0
  高强度：3.0
  极限强度：4.0

慢性训练负荷 (Chronic Load) = 最近7天急性负荷的移动平均值

训练压力平衡 (CTL/ATL Ratio) = 慢性负荷 / 急性负荷
  > 1.5：恢复过度
  0.8-1.5：最佳平衡
  < 0.8：过度训练风险
```

### 4.2 运动效果多维评分

| 维度 | 权重 | 计算公式 |
|------|------|---------|
| **有氧效果** | 30% | 基于心率区间停留时间 |
| **力量效果** | 25% | 基于力量训练类型和组次 |
| **卡路里消耗** | 15% | 实际消耗 / 目标消耗 |
| **心率表现** | 15% | 最大心率恢复速率 |
| **持续时间** | 15% | 运动时长评分 |

### 4.3 训练适应性评估

```
适应性指数 = (静息HR改善 + HRV改善 + 运动表现提升) / 3

评估周期：4-8周

结果解读：
  > 10%：适应良好，训练有效
  0-10%：适应中，可调整训练计划
  < 0：过度训练或恢复不足
```

## 五、综合健康评分模型

### 5.1 H-Score 健康评分体系

```
H-Score = 睡眠评分 × 0.35 
        + 活动评分 × 0.30 
        + 心血管评分 × 0.20 
        + 恢复评分 × 0.15

各子项均为0-100分，最终H-Score范围：0-100分
```

### 5.2 健康等级标准

| H-Score | 健康等级 | 颜色标识 |
|---------|----------|----------|
| 90-100 | 优秀 | 🟢 |
| 80-89 | 良好 | 🟢 |
| 70-79 | 一般 | 🟡 |
| 60-69 | 需关注 | 🟠 |
| < 60 | 需改善 | 🔴 |
