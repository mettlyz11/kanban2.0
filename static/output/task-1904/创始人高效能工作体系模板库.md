# 创始人高效能工作体系模板库

> **核心理念**：创始人时间是最稀缺资源。通过系统化时间管理、会议效率提升、助理协作优化和精力管理机制，实现个人产出最大化。

---

## 一、每周时间块规划模板

### 原则
- **深度工作** = 无干扰、高认知负荷任务（战略思考、重要决策、复杂沟通）
- **浅度工作** = 行政事务、邮件处理、 routine决策
- **保护性时间** = 运动、家庭、休息（不可侵犯）

### 深度工作时间保护规则

```
✅ DO:
- 关闭所有通知（Slack、微信、邮件）
- 使用番茄工作法：50分钟专注 + 10分钟休息
- 提前告知助理：非紧急勿打扰
- 准备深度工作清单（前一晚列出）

❌ DON'T:
- 在深度工作时段查看手机
- 允许临时会议插入
- 处理非紧急邮件
- 在办公桌前进食（保持环境纯净）
```

### 2.4 创始人"会议精简原则"

| 会议类型 | 最大时长 | 必要参与者 | 替代方案 |
|---------|---------|-----------|---------|
| 日常同步 | 15分钟 | 直接相关人员 | 异步文档更新 |
| 决策会议 | 50分钟 | 决策者+关键影响者 | 预决策+确认 |
| 头脑风暴 | 90分钟 | 4-6人 | 异步头脑风暴+汇总 |
| 1:1会议 | 30分钟 | 创始人+下属 | 每两周1次，非每周 |
| 外部会议 | 25分钟 | 创始人+必要人员 | 助理预筛选 |

**会议密度上限**：每天不超过4个会议，每周深度工作≥20小时

## 三、助理协作流程优化SOP

### 3.1 邮件筛选与处理SOP

```markdown
## 创始人邮件分类标准

### A级 - 创始人必须亲自处理（立即通知）
- 董事会/投资人邮件
- 法律/合规相关
- 关键客户/合作伙伴高层邮件
- 紧急危机事件

### B级 - 创始人需要知晓但可延后（日报汇总）
- 部门负责人汇报
- 重要项目进展
- 媒体采访邀请
- 行业活动邀请

### C级 - 助理可代为处理（无需汇报）
- 一般商务合作
- 会议邀约筛选（非必要婉拒）
- 行政事务
- 垃圾邮件清理

### 处理流程
1. 助理每2小时检查一次邮件
2. A级：立即转发+短信/微信提醒
3. B级：每日17:00发送汇总摘要
4. C级：助理直接回复或归档
```

### 3.2 日程管理SOP

```markdown
## 日程管理规则

### 预约原则
- 周一上午不安排外部会议（战略思考时间）
- 周五下午不安排重要决策会议
- 每天保留1个"缓冲时段"（30-60分钟）应对突发
- 出差前后各留半天恢复/准备时间

### 日程变更权限
- 创始人发起的变更：助理直接执行
- 外部请求变更：助理确认创始人后回复
- 取消会议：需提前24小时通知

### 日程提醒
- 提前15分钟：推送会议提醒
- 提前1小时：检查会议材料是否准备
- 提前1天：确认参会人员
```

### 3.3 差旅安排SOP

### 出发当天

- [ ] 实时航班/交通信息监控
- [ ] 目的地接待确认

### 差旅后
- [ ] 发票收集整理
- [ ] 差旅费用报销
- [ ] 会议后续跟进清单

### 4.2 精力管理机制

#### 每日精力管理
```markdown
### 晨间启动（起床后1小时）
- [ ] 7-8小时睡眠（查看睡眠APP数据）
- [ ] 15-30分钟运动（有氧或力量）
- [ ] 营养早餐（蛋白质+复合碳水+水果）
- [ ] 10分钟冥想/正念

### 日间节奏
- 09:00-12:00：处理最重要/最困难任务（认知巅峰）
- 12:00-13:30：午餐+短暂休息（避免碳水过量）
- 13:30-15:00：会议/协作（午后低谷，适合互动）
- 15:00-17:00：第二波深度工作（如有必要）
- 17:00-18:00：邮件/行政（认知需求低）

### 晚间恢复
- [ ] 18:00后不再处理紧急工作（除非危机）
- [ ] 家庭时间全身心投入（不查看工作手机）
- [ ] 21:00后数字宵禁启动
- [ ] 22:30前上床，保证7-8小时睡眠
```

#### 周度精力恢复
```markdown
### 周五下午：行政清理
- 清空收件箱（Inbox Zero）
- 更新下周日程
- 完成所有待审批事项

### 周六：完全脱离工作
- 不查看工作邮件/消息
- 家庭活动/社交
- 个人兴趣爱好

### 周日：准备与充电
- 上午：休闲/运动
- 下午：下周规划（30分钟）
- 晚上：阅读/放松，早睡
```
