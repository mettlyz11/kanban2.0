# 📚 看板系统任务模板库

**创建时间：** 2026-04-25  
**版本：** v1.0  
**用途：** 从源头提升任务质量，确保任务描述完整、验收标准明确

---

## 📋 任务质量标准（100分制）

| 维度 | 分值 | 达标要求 |
|------|------|---------|
| 标题清晰度 | 10分 | 明确目标 + 动词 + 范围 |
| 描述完整性 | 20分 | ≥200字，背景+目标+范围明确 |
| 验收标准 | 25分 | 3-5条可量化checklist |
| 任务拆解 | 20分 | 拆分为3-7个可执行步骤 |
| 时间预估 | 15分 | 明确预估时长 + 截止日期 |
| 战略关联 | 10分 | 关联T1-T7战略目标 |

## 🎯 模板分类

### 模板1：调研分析类（子代理执行）

**适用场景：** 市场调研、趋势分析、竞品分析、数据收集

```markdown
## 任务标题
【目标代码】: 领域 - 具体研究主题 + 产出物名称

## 任务描述（≥200字）
【背景】为什么要做这个调研？当前存在什么问题或机会？
【目标】希望通过调研解决什么问题？达到什么效果？
【范围】需要覆盖哪些维度？(行业/时间/地域/对象)
【数据源】建议参考哪些数据源？(数据库/网站/报告)

## 验收标准（可量化）
✅ 产出完整调研报告，≥3000字
✅ 包含至少5个案例分析
✅ 数据来源标注清晰，可追溯
✅ 包含3-5条可落地的行动建议
✅ 附件上传：调研报告.md + 数据.xlsx

## 任务拆解
1. 文献/数据收集（预计2小时）
2. 竞品/案例分析（预计3小时）
3. 报告撰写与结构化（预计3小时）
4. 数据验证与建议提炼（预计1小时）
5. 格式整理与附件上传（预计0.5小时）

## 时间预估
总时长：9.5小时
建议完成时间：7天内

## 战略关联
T?: 战略目标名称
```

### 模板2：方案设计类（子代理执行）

**适用场景：** 方案设计、计划书、策略制定

```markdown
## 任务标题
【目标代码】: 领域 - 具体方案名称 + 版本号

## 任务描述（≥200字）
【背景】方案解决什么痛点？针对什么场景？
【目标】方案需要达到什么效果？支持什么决策？
【受众】方案给谁看？决策人是谁？
【约束】有什么预算/时间/资源限制？

## 验收标准（可量化）
✅ 完整方案文档，≥2500字
✅ 包含明确的执行路径图（时间轴）
✅ 包含成本/预算测算表
✅ 包含风险评估与应对措施（至少3条）
✅ 包含3个备选方案对比（优劣势分析）

## 任务拆解
1. 需求分析与框架设计（预计1.5小时）
2. 方案主体撰写（预计4小时）
3. 成本测算与风险评估（预计2小时）
4. 备选方案对比分析（预计1.5小时）
5. 格式优化与图表制作（预计1小时）

## 时间预估
总时长：10小时
建议完成时间：7天内

## 战略关联
T?: 战略目标名称
```

### 模板3：合作跟进类（人工执行）

**适用场景：** 人脉拓展、合作跟进、会议安排、沟通协调

```markdown
## 任务标题
【目标代码】: 合作方名称 - 合作事项跟进

## 任务描述（≥200字）
【合作方背景】对方是什么机构？核心优势是什么？
【合作基础】之前有什么接触？共同利益点是什么？
【当前状态】进展到哪一步？最近一次沟通是什么时候？
【下一步目标】本次跟进希望达成什么结果？
【关键人物】对接人姓名、职位、联系方式

## 验收标准（可量化）
✅ 完成至少1次有效沟通（电话/见面/微信）
✅ 形成书面沟通纪要，≥300字
✅ 明确下一步行动计划和时间节点
✅ 识别出2-3个潜在合作切入点
✅ 更新人脉档案信息

## 任务拆解
1. 背景资料准备与历史沟通回顾（预计0.5小时）
2. 联系对方确认沟通时间（预计0.5小时）
3. 执行沟通（预计1小时）
4. 撰写沟通纪要与行动清单（预计0.5小时）
5. 更新CRM/人脉档案（预计0.5小时）

## 时间预估
总时长：3小时
建议完成时间：3天内

## 战略关联
T?: 战略目标名称
```

## ✅ 使用指南

### 新建任务时：
1. 根据任务类型选择对应模板
2. 复制模板内容到任务描述
3. 填充具体信息（不要留空）
4. 确保验收标准可量化、可验证
5. 关联正确的战略目标

### 任务审核时：
- 描述 < 200字 → 驳回补充
- 无验收checklist → 驳回补充
- 无时间预估 → 驳回补充
- 无战略关联 → 驳回补充
