# 深云智合/硅研新材 调解谈判策略手册

> **编制日期**: 2026年4月30日
> **适用案件**: 包头市九原区公司僵局案件
> **使用对象**: 刘宇宙先生及律师团队
> **保密级别**: 内部机密

---

## 一、谈判总体战略

### 1.1 核心原则

> **"以打促谈、以谈促和、以和促退"**

- **以打促谈**: 利用公司解散诉讼的压力，迫使对方回到谈判桌
- **以谈促和**: 在诉讼过程中保持调解通道，争取有利条件
- **以和促退**: 最终目标是实现有序退出，而非消灭公司

### 1.2 战略定位

刘宇宙先生在本案中的核心诉求是**有序退出并获得合理对价**，而非摧毁公司。这一立场在谈判中应始终明确传达：

- ✅ "我愿意退出，但需要公平的价格和保障"
- ❌ 避免表达"就是要搞垮公司"的情绪化诉求
- ✅ 强调"公司存续对双方都有利，只是我需要退出"

### 1.3 谈判目标层级

| 层级 | 目标 | 条件 |
|------|------|------|
| **最优目标** | 股权回购，一次性支付，按净资产评估价+资金补偿 | 对方有充足资金+愿意和解 |
| **满意目标** | 股权回购/减资，分期支付，有担保保障 | 对方愿意但资金紧张 |
| **可接受目标** | 减资退出，分3-5期支付，大股东连带担保 | 对方仅愿部分退让 |
| **底线目标** | 确保不低于实缴出资额+资金占用利息退出 | 最低保障 |

## 二、调解谈判路线图

### 阶段一：诉前准备（第1-4周）

#### 目标：穷尽内部救济，建立证据基础

| 任务 | 具体内容 | 负责人 | 期限 |
|------|---------|--------|------|
| 书面沟通 | 向控股股东发出正式书面函件，提出股权回购/转让意向 | 律师 | 第1周 |
| 知情权行使 | 要求查阅公司财务报表、会计账簿、会议记录等 | 律师 | 第1-2周 |
| 第三方调解 | 联系包头市工商联/行业协会，请求组织调解 | 刘宇宙/律师 | 第2-3周 |
| 证据保全 | 收集所有沟通记录、函件往来、调解记录 | 律师 | 全程 |
| 财务调查 | 通过公开渠道调查公司资产、债务、涉诉情况 | 律师 | 第2-4周 |

#### 关键输出
- 书面沟通记录（函件+回复）
- 第三方调解记录（即使失败也是证据）
- 公司财务和资产调查报告

### 阶段二：提起诉讼，施压谈判（第5-8周）

#### 目标：以公司解散之诉制造压力，启动法院调解

| 任务 | 具体内容 | 负责人 | 期限 |
|------|---------|--------|------|
| 提起诉讼 | 向包头九原区法院提交公司解散诉状 | 律师 | 第5周 |
| 诉状要点 | 重点陈述：股东会机制失灵、已穷尽内部救济、继续存续将导致重大损失 | 律师 | 第5周 |
| 法院调解 | 配合法院组织的调解程序，展示合作态度 | 律师 | 第6-8周 |
| 方案提出 | 在调解中正式提出股权回购方案 | 律师 | 第6-7周 |

#### 诉状核心论点
1. **主体资格**: 刘宇宙持有XX%股权，满足10%以上要求
2. **经营管理严重困难**: 股东会长期未召开、无法形成有效决议
3. **重大损失**: 投资目的无法实现、股东权利被架空
4. **穷尽救济**: 已尝试书面沟通、知情权、第三方调解均未果

### 阶段三：深入谈判，促成方案（第9-12周）

#### 目标：在法院调解框架下达成具体方案

| 任务 | 具体内容 | 负责人 | 期限 |
|------|---------|--------|------|
| 方案评估 | 评估对方回应，确定最优谈判方案 | 刘宇宙+律师 | 第9周 |
| 价格谈判 | 就股权定价机制进行谈判 | 双方律师 | 第9-10周 |
| 支付安排 | 就支付方式、期限、担保进行谈判 | 双方律师 | 第10-11周 |
| 协议起草 | 起草调解协议和股权回购/减资协议 | 律师 | 第11-12周 |
| 法院确认 | 将调解协议提交法院，申请出具民事调解书 | 律师 | 第12周 |

### 阶段四：执行与撤诉（第13-16周）

#### 目标：履行协议，正式结案

| 任务 | 具体内容 | 负责人 | 期限 |
|------|---------|--------|------|
| 首期付款 | 按协议收到首期款 | - | 第13周 |
| 工商变更 | 办理股权变更/减资登记 | 双方 | 第13-14周 |
| 申请撤诉 | 向法院申请撤诉 | 律师 | 第14周 |
| 后续款项 | 按约收取剩余款项 | - | 按协议约定 |

## 三、调解协议模板框架

### 3.1 股权回购调解协议（模板）

```
民事调解协议

甲方（回购方）：[控股股东姓名/公司名称]
乙方（退出方）：刘宇宙
丙方（目标公司）：深云智合/硅研新材[全称]

鉴于：
1. 丙方系依法设立的有限责任公司，注册资本人民币XXX万元
2. 甲方持有丙方XX%股权，乙方持有丙方XX%股权
3. 丙方股东会长期未能有效运作，公司治理陷入僵局
4. 乙方已向XX人民法院提起公司解散诉讼（案号：XXX）
5. 经法院主持调解，三方自愿达成如下协议：

第一条 股权回购
1.1 甲方同意以人民币XXX万元的价格回购乙方持有的丙方XX%股权
1.2 定价依据：[选择以下之一]
    (a) 经[审计机构名称]审计的丙方截至[基准日]的净资产，乘以乙方持股比例
    (b) 经[评估机构名称]评估的乙方股权价值
    (c) 三方协商确定的价格

第二条 支付安排
2.1 甲方分[三]期支付回购款：
    第一期：本协议生效之日起[10]个工作日内，支付总价的[30]%，计XXX万元
    第二期：股权工商变更完成后[30]日内，支付总价的[40]%，计XXX万元
    第三期：工商变更完成后[12]个月内，支付总价的[30]%，计XXX万元

2.2 第三期付款保障：
    (a) 甲方应在本协议签署后[15]个工作日内向乙方提供等额银行保函
    (b) 或将等值[房产/有价证券]质押给乙方
    (c) 或甲方实际控制人提供个人连带责任保证

2.3 逾期付款违约责任：
    甲方逾期付款的，应按日万分之[五]的标准向乙方支付违约金

第三条 工商变更
3.1 甲方支付首期款后[30]个工作日内，三方应共同办理股权变更工商登记
3.2 工商变更完成后，乙方不再享有丙方股东权利，不承担股东义务

第四条 撤诉
4.1 本协议生效且首期款到账后[5]个工作日内，乙方应向XX人民法院申请撤诉
4.2 丙方应承担本案诉讼费用

第五条 其他
5.1 本协议一式[五]份，三方各执[一]份，交法院[二]份
5.2 本协议自三方签字（盖章）之日起生效
5.3 本协议项下争议由XX人民法院管辖

甲方（签字/盖章）：         日期：
乙方（签字）：               日期：
丙方（盖章）：               日期：
```

### 3.2 减资调解协议（模板要点）

与股权回购协议类似，主要差异在于：
- 回购方改为"丙方（目标公司）"
- 资金来源为公司可分配资金
- 增加债权人保护条款（公告、清偿、担保）
- 增加大股东对减资后债务的连带责任承诺

## 四、对方可能提出的反方案及应对策略

### 4.1 反方案一：拒绝一切方案，坚持公司不解散

**对方论点**: "公司经营状况良好，不存在经营管理严重困难，不符合解散条件"

**应对策略**:
1. 展示已穷尽内部救济的证据（书面沟通记录、调解记录）
2. 强调"经营管理严重困难"的核心是治理失灵，而非经营亏损（引用指导案例8号）
3. 指出"继续存续会使股东利益受到重大损失"——投资目的无法实现、股东权利被架空
4. 提供公司长期未召开股东会、无法形成有效决议的证据

### 4.2 反方案二：同意回购但大幅压低价格

**对方论点**: "公司已停止运营，资产贬值严重，股权价值很低"

**应对策略**:
1. 坚持第三方独立评估，不接受对方单方定价
2. 引用《公司法》第89条"合理价格"的规定
3. 主张资金占用补偿（按LPR利率计算）
4. 准备反制：如价格差距过大，坚持推进解散诉讼

### 4.3 反方案三：同意回购但拒绝分期付款担保

**对方论点**: "公司/个人信用良好，无需提供担保"

**应对策略**:
1. 强调担保是行业标准做法，不是不信任
2. 提供中卫酒店案等成功案例中分期支付+担保的先例
3. 退让方案：可降低担保金额（如只担保尾款部分的150%）
4. 底线：无任何担保的分期付款不接受

### 4.4 反方案四：要求刘宇宙承担公司债务

**对方论点**: "公司存在债务，刘宇宙应按比例承担"

**应对策略**:
1. 明确区分股东责任（以出资额为限）和公司债务
2. 如采用股权回购，回购价格已体现公司净值（含负债）
3. 如采用减资退出，债权人保护程序由公司负责
4. 要求对方提供完整的债务清单和债权人同意文件

### 4.5 反方案五：拖延战术（管辖权异议、申请鉴定等）

**对方策略**: 通过程序性事项拖延诉讼进程

**应对策略**:
1. 提前准备应对管辖权异议的法律意见
2. 对鉴定申请：同意但要求明确鉴定范围和期限
3. 同时保持调解通道，不将谈判与诉讼对立
4. 向法官说明拖延行为的消极影响

### 4.6 反方案六：提出公司分立但故意设置不合理条件

**对方策略**: 表面同意分立，但将优质资产全部留给自己

**应对策略**:
1. 要求第三方机构对资产进行独立评估
2. 坚持"同比例分割"原则（各50%净资产）
3. 如资产不可等值分割，主张差额现金补偿
4. 将分立方案作为谈判筹码，推动对方在回购方案上让步

## 五、谈判话术要点

### 5.1 开场话术

> "我们提起诉讼的目的不是要搞垮公司，而是要找到一个对双方都公平的退出方案。公司存续对大家都有好处，只是我需要拿回我的投资。我们希望通过法院调解，找到一个双方都能接受的方案。"

### 5.2 价格谈判话术

> "我理解你对价格的顾虑，但股权的价值应该由独立的第三方评估来确定，而不是任何一方说了算。我们可以共同委托一家双方都认可的审计机构，这样对双方都公平。"

### 5.3 付款安排话术

> "我理解一次性支付有压力，分期支付也可以接受，但分期需要有基本的保障。这不是不信任，而是标准的商业做法。中卫那个案例就是分期支付+担保，最后双方都很满意。"

### 5.4 施压话术（适度使用）

> "解散诉讼对双方都没有好处，公司一旦解散清算，资产打折变现，谁也拿不到多少钱。但如果我们能在调解中达成一致，公司可以继续存续，你也能保留控制权，我也能公平退出，这是双赢。"

### 5.5 底线话术

> "我可以做出让步，但底线是我的投资本金和合理的资金补偿不能少。这是我最基本的诉求，如果连这都达不到，那我只能坚持把诉讼进行到底。"

## 六、关键风险提示

| 风险 | 概率 | 影响 | 应对措施 |
|------|------|------|---------|
| 对方拒绝调解 | 中 | 高 | 继续诉讼程序，等待法院判决 |
| 价格分歧过大 | 高 | 中 | 引入第三方评估，以评估结果为准 |
| 分期付款违约 | 中 | 高 | 必须设置担保，保函/质押/连带保证 |
| 诉讼周期过长 | 中 | 中 | 积极推动调解，避免一审二审全流程 |
| 公司资产被转移 | 低 | 极高 | 申请财产保全，冻结公司主要账户 |
| 对方提起反诉 | 中 | 中 | 提前评估反诉可能性，准备应对预案 |

## 七、成功调解案例参考（谈判中可引用）

1. **包头某评估公司案**（判例9）：包头中院一审解散，内蒙高院二审通过多次调解促成股权回购，双方握手言和
   - 谈判话术："包头本地就有类似案例，二审法院调解成功，股权回购，双方都好"

2. **中卫某酒店公司案**（判例10）：二审法官联动多案统筹，达成股权收购+分期支付+关联案件一并解决
   - 谈判话术："分期支付是有先例的，中卫那个案例就是分期支付，最后全部关联案件都解决了"

3. **重庆某实业公司案**（判例11）：兄弟关系10余年纠纷，通过抓阄+存续分立+股权置换彻底化解
   - 谈判话术："如果实在分不拢，分立也是一个选项，重庆法院用抓阄的方式解决了10年的纠纷"

4. **湖北谷城县案**（判例12）：存续式和解，修订章程+股权转让退出
   - 谈判话术："法院现在最鼓励的就是'存续式和解'，公司不解散，一方有序退出"
