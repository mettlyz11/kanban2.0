## 一、清单使用说明

### 1.1 本草案局限性声明

本资源清单为基于公开可获取的碎片化信息生成的**示范性文件**，旨在为执行团队提供标准化分类框架、字段模板及数据填充范例。**重要声明如下：**

- **数据来源限制：** 所有条目内容均来自公开报道、政府白皮书、企业年报、学术期刊及国际组织数据库，未包含任何涉密、内部专有或商业敏感信息。
- **字段完整性：** 示范条目中的“联系方式”“我方参与主体详细名录”“内部价值评估”等字段已做脱敏处理，标注为`[待补充]`或使用占位符。
- **时效性：** 部分协议签署时间、项目状态为截至2025年6月的公开信息，需由执行者根据内部最新动态更新。
- **法律效力：** 本清单不构成任何法律意义上的承诺或协议，仅供内部工作参考。

### 1.2 替换指引

执行团队在使用本清单时，请遵循以下步骤：

1. **替换数据：** 将示范条目中的公开信息替换为内部真实合作数据（包括但不限于：协议全文、内部审批记录、项目进度报告）。
2. **补充字段：** 完善“联系方式”“价值评估维度”等需内部确认的字段。
3. **分类调整：** 根据本单位实际业务范围，增删“资源分类总览”中的行业领域标签。
4. **保密处理：** 对涉及国家秘密、商业秘密或敏感政治关系的条目，按《保密法》及内部规定进行脱敏或单列管理。
5. **版本控制：** 每次更新后应更新版本号及修改记录，确保追溯性。

## 四、字段模板

### 4.1 标准字段定义表

| 字段名称 | 数据类型 | 必填 | 填写说明与示例 |
| :--- | :--- | :---: | :--- |
| **合作方信息** | 文本 | 是 | 外方全称（中英文）、国别、机构性质（政府/企业/学术） |
| **协议类型** | 枚举 | 是 | 可选值：MOU、JV Agreement、Offtake Agreement、特许经营、联合研究协议、框架协议等 |
| **签署时间** | 日期 | 是 | 格式：YYYY年MM月；如为长期框架，注明首次签署时间 |
| **当前状态** | 枚举 | 是 | 可选值：意向阶段、谈判中、已签署、执行中、已完成、终止/搁置 |
| **我方参与主体** | 文本 | 是 | 具体到子公司、部门或团队；如涉密，注明“内部备案号：[XXX]” |
| **价值评估维度** | 文本 | 否 | 用量化指标（金额、产量、人数、专利数等）和定性描述（战略意义、风险等级） |
| **联系方式** | 文本 | 否 | 内部联系人姓名、电话、邮箱；可填写“内部通讯录编号：[XXX]” |

### 4.2 扩展字段（可选）

对于重要或复杂的合作项目，建议增加以下字段：

- **法律管辖：** 适用法律（如：瑞士法、中国法）
- **争议解决机制：** 仲裁机构（如：ICC、SIAC、CIETAC）
- **保密等级：** 内部公开、部门密级、公司机密、国家秘密
- **关联项目：** 与清单中其他条目的联动关系（如：某矿产项目为某电池厂供料）
- **风险评估：** 政治风险、合规风险、技术风险、财务风险（高/中/低）
