## 一、调研目标界定

### 1.1 业务问题拆解框架

调研目标必须从具体业务问题出发，使用**问题树分解法**进行系统拆解。以下为标准化拆解模板：

```
业务问题：为什么Q3季度新产品上市后，首月转化率仅为预期的45%？

一级拆解：
├─ 客户认知问题：目标客户是否知道该产品？
├─ 客户匹配问题：产品是否满足目标客户的核心需求？
├─ 客户决策问题：什么因素阻碍了购买决策？
└─ 竞争替代问题：客户选择了什么替代方案？

二级拆解（以"客户匹配问题"为例）：
├─ 需求识别：客户当前使用什么方案解决该问题？
├─ 痛点排序：客户最在意的三个痛点是什么？
├─ 价值感知：客户对产品核心价值点的理解程度？
└─ 价格敏感：客户对价格区间的接受范围？
```

### 1.2 假设设定模板

每个拆解节点必须生成可验证的假设，使用以下格式：

| 假设编号 | 假设内容 | 验证方法 | 验证标准 |
|----------|----------|----------|----------|
| H1 | 目标客户中60%以上使用Excel管理客户信息 | 问卷调查+行为数据 | 问卷回答+产品埋点 |
| H2 | 客户最痛点是"数据同步困难"，而非"功能不足" | 深度访谈 | 5/10位受访者主动提及 |
| H3 | 价格是阻碍转化的首要因素（占比>40%） | A/B测试+问卷 | 不同定价版本转化率对比 |

### 3.2 样本量计算公式

**定量调研样本量计算：**

```
n = (Z² × p × (1-p)) / E²

其中：
n = 所需样本量
Z = 置信水平对应的Z值（95%置信度取1.96）
p = 预期比例（取0.5可得最大样本量）
E = 允许误差（通常取5% = 0.05）

示例计算：
n = (1.96² × 0.5 × 0.5) / 0.05²
n = (3.8416 × 0.25) / 0.0025
n = 0.9604 / 0.0025
n = 384.16 ≈ 385人
```

**定性调研样本量决策标准：**
- 同质群体：8-12人达到信息饱和
- 异质群体：15-20人
- 复杂B2B决策：每类决策角色3-5人

## 四、数据采集执行清单

### 4.1 问卷设计原则与检查清单

**问卷设计黄金法则：**
1. **单一维度原则**：每个问题只测量一个概念
2. **避免引导性**：不使用"难道你不认为..."等句式
3. **选项互斥且穷尽**：所有选项不重叠且覆盖所有可能
4. **从易到难排序**：人口统计信息放在最后
5. **控制问卷长度**：5分钟以内完成，不超过15题

**问卷检查清单：**

```
□ 明确告知调研目的和预计用时
□ 隐私保护声明：数据仅用于研究，不涉及个人身份信息
□ 逻辑跳转设置正确（如：选择"否"则跳过后续相关问题）
□ 量表一致性：同一维度使用相同量表（如全部5点李克特量表）
□ 反向题设置：至少2道反向题检测随意作答
□ 开放题不超过2道，放在最后
□ 预测试：邀请5人进行认知测试，检查理解偏差
```

### 5.2 定量数据分群算法

**K-means聚类执行代码（Python实现）：**

```python
import pandas as pd
import numpy as np
from sklearn.cluster import KMeans
from sklearn.preprocessing import StandardScaler
import matplotlib.pyplot as plt

# 加载数据（示例数据）
data = pd.DataFrame({
    'age': [25, 35, 45, 28, 32, 50, 22, 38, 42, 30],
    'income': [5000, 12000, 15000, 6000, 10000, 18000, 4000, 11000, 14000, 8000],
    'purchase_frequency': [1, 3, 2, 2, 4, 1, 1, 3, 2, 2],
    'satisfaction_score': [3, 4, 5, 4, 3, 5, 2, 4, 5, 3]
})

# 数据标准化
scaler = StandardScaler()
scaled_data = scaler.fit_transform(data)

# 确定最佳K值（肘部法则）
inertias = []
for k in range(1, 8):
    kmeans = KMeans(n_clusters=k, random_state=42)
    kmeans.fit(scaled_data)
    inertias.append(kmeans.inertia_)

plt.plot(range(1, 8), inertias, marker='o')
plt.xlabel('Number of clusters (K)')
plt.ylabel('Inertia')
plt.title('Elbow Method for Optimal K')
plt.show()

# 执行聚类（假设最优K=3）
kmeans = KMeans(n_clusters=3, random_state=42)
data['cluster'] = kmeans.fit_predict(scaled_data)

# 输出聚类结果
cluster_summary = data.groupby('cluster').agg({
    'age': 'mean',
    'income': 'mean',
    'purchase_frequency': 'mean',
    'satisfaction_score': 'mean',
    'cluster': 'count'
}).rename(columns={'cluster': 'count'})

print("聚类结果摘要：")
print(cluster_summary)

# 保存结果
data.to_csv('customer_segments.csv', index=False)
```

### 5.3 画像验证方法

**画像验证三角模型：**

```
验证维度1：数据一致性
- 方法：将画像特征与行为数据交叉验证
- 示例：画像显示"价格敏感型"，对应行为数据应显示：
  * 多次查看价格页面
  * 使用优惠券频率高于平均
  * 在促销期间购买比例高

验证维度2：客户自述一致性
- 方法：同一客户在不同时间、不同场景的回答一致性
- 示例：问卷中回答"非常满意"，但开放式问题中抱怨服务差

验证维度3：专家评审
- 方法：邀请3位行业专家对画像进行评审
- 评分标准：
  * 准确性（1-5分）：与专家经验是否一致
  * 可操作性（1-5分）：能否指导营销决策
  * 完整性（1-5分）：是否覆盖关键维度
```

## 六、常见陷阱与质量管控

### 6.1 偏差识别与应对策略

| 偏差类型 | 识别方法 | 预防措施 | 纠正方法 |
|----------|----------|----------|----------|
| 幸存者偏差 | 只调研了现有客户，未包括流失客户 | 明确纳入流失客户群体 | 补充流失客户调研 |
| 社会期许偏差 | 敏感问题回答过于正面 | 使用随机响应技术 | 匿名化处理+设置反向题 |
| 回忆偏差 | "上个月购买了几次？"回答模糊 | 缩短回忆周期（"最近一次"） | 交叉验证行为数据 |
| 确认偏差 | 分析师只关注支持假设的数据 | 设立"魔鬼代言人"角色 | 强制寻找反例数据 |
| 抽样偏差 | 样本不能代表总体 | 进行代表性检验 | 加权调整或补充样本 |

### 6.2 数据清洗标准流程

**数据清洗检查清单（Python实现）：**

```python
import pandas as pd
import numpy as np

def data_cleaning_pipeline(df):
    """
    标准数据清洗流程
    """
    cleaning_log = []
    
    # 1. 删除完全重复记录
    initial_count = len(df)
    df = df.drop_duplicates()
    cleaning_log.append(f"删除重复记录：{initial_count - len(df)}条")
    
    # 2. 处理缺失值
    missing_threshold = 0.5  # 缺失50%以上则删除该变量
    df = df.dropna(thresh=len(df) * (1 - missing_threshold), axis=1)
    
    # 3. 处理异常值（使用IQR方法）
    numeric_cols = df.select_dtypes(include=[np.number]).columns
    for col in numeric_cols:
        Q1 = df[col].quantile(0.25)
        Q3 = df[col].quantile(0.75)
        IQR = Q3 - Q1
        lower_bound = Q1 - 1.5 * IQR
        upper_bound = Q3 + 1.5 * IQR
        outliers = df[(df[col] < lower_bound) | (df[col] > upper_bound)]
        if len(outliers) > 0:
            cleaning_log.append(f"列'{col}'发现{len(outliers)}个异常值")
            # 用中位数替换异常值
            median_val = df[col].median()
            df.loc[(df[col] < lower_bound) | (df[col] > upper_bound), col] = median_val
    
    # 4. 检查逻辑一致性
    # 示例：年龄不能小于0
    if 'age' in df.columns:
        invalid_age = df[df['age'] < 0]
        if len(invalid_age) > 0:
            cleaning_log.append(f"发现{len(invalid_age)}个无效年龄值")
            df.loc[df['age'] < 0, 'age'] = np.nan
    
    # 5. 检查答题时间（问卷调研）
    if 'response_time' in df.columns:
        fast_respondents = df[df['response_time'] < 60]  # 小于60秒
        if len(fast_respondents) > 0:
            cleaning_log.append(f"发现{len(fast_respondents)}个快速作答样本")
            df = df[df['response_time'] >= 60]
    
    print("数据清洗完成：")
    for log in cleaning_log:
        print(f"- {log}")
    
    return df

# 使用示例
cleaned_data = data_cleaning_pipeline(raw_data)
```
