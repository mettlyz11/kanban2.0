# 顶尖理工大学申请准备路线图 (IB体系)
## 一、目标院校IB成绩要求
| 院校 | 理工专业最低IB要求 | 推荐分数 | 特殊要求 |
|------|---------------------|----------|----------|
| 牛津大学 | 38-40分 | ≥42分 | HL科目3门7/7/6，数学/物理HL必须7分 |
| 剑桥大学 | 40-42分 | ≥43分 | HL科目3门7/7/7，数学AA/物理HL强制7分 |
| 帝国理工学院 | 38-40分 | ≥41分 | HL理科科目必须7分 |
| MIT | 无最低要求 | ≥43分 | 需提交SAT/ACT+AP补充，HL数学/物理7分 |
| 斯坦福大学 | 无最低要求 | ≥42分 | 看重科研和竞赛背景，IB HL成绩7分优先 |
| 加州理工学院 | 无最低要求 | ≥43分 | 数学/物理/化学HL必须7分，竞赛奖项优先 |

## 二、课外活动规划（按学年）
| 学年 | 核心活动 |
|------|----------|
| G10 | 参加物理/数学竞赛入门（AMC10/Physics Bowl），进入学校科研社团 |
| G11 | 完成1项个人科研项目（物理/化学/AI相关），参加高阶竞赛（AMC12/BPhO/UKChO），暑假参加顶尖大学夏校（牛津夏校/斯坦福夏校/Ross数学营） |
| G12 | 发表科研成果（如有），完成竞赛奖项积累，准备申请文书 |

## 三、推荐信准备路径
1. **推荐人人选**：
   - 1封：物理HL授课老师（最好是IB阅卷人，了解学生学术能力）
   - 1封：数学AA HL授课老师
   - 1封：科研项目导师（大学教授/竞赛教练，展示课外学术能力）
2. **培养路径**：
   - 课堂积极参与，多问专业问题，让老师熟悉学生特点
   - 提前12个月和推荐人沟通，提供详细的活动/成绩清单，帮助推荐人写出有细节的推荐信
   - 申请季前2个月提醒推荐人提交，避免错过截止日期

## 四、申请时间线
- G11下：确定目标院校清单，准备文书素材
- G12上：9月提交牛津/剑桥申请，10月提交UCAS英国申请，11月提交美国EA/ED申请，1月提交美国RD申请
- G12下：2-4月收offer，确定入读院校
