## 2. 标签映射与自动化/半自动化打标流程

### 2.1 标签体系设计原则

- **粒度级别**：分为三级粒度
  - L1（粗粒度）：业务域（如“客户服务”、“产品开发”）
  - L2（中粒度）：主题域（如“故障处理”、“需求管理”）
  - L3（细粒度）：概念单元（如“网络连接失败”、“API超时”）
- **覆盖范围**：L1覆盖100%数据，L2覆盖≥80%，L3覆盖≥60%
- **互斥性**：同一粒度级别标签互斥，不同粒度可共存

### 2.2 标签映射表生成

使用以下Python脚本从现有数据中自动生成标签映射建议：

```python
import pandas as pd
from sklearn.feature_extraction.text import TfidfVectorizer
from sklearn.cluster import KMeans
import json

def generate_label_mapping(data_path, output_path):
    """
    基于现有数据生成标签映射建议
    :param data_path: 数据文件路径（CSV格式，包含text和existing_label列）
    :param output_path: 映射表输出路径
    """
    # 加载数据
    df = pd.read_csv(data_path)
    texts = df['text'].tolist()
    existing_labels = df['existing_label'].tolist()
    
    # TF-IDF向量化
    vectorizer = TfidfVectorizer(max_features=1000, stop_words='english')
    X = vectorizer.fit_transform(texts)
    
    # 聚类分析（假设分为10个主题簇）
    kmeans = KMeans(n_clusters=10, random_state=42)
    cluster_labels = kmeans.fit_predict(X)
    
    # 构建映射关系
    mapping = {}
    for i, (cluster, existing) in enumerate(zip(cluster_labels, existing_labels)):
        cluster_str = f"L2_Cluster_{cluster}"
        if cluster_str not in mapping:
            mapping[cluster_str] = {
                "existing_labels": [],
                "sample_texts": []
            }
        if existing not in mapping[cluster_str]["existing_labels"]:
            mapping[cluster_str]["existing_labels"].append(existing)
        if len(mapping[cluster_str]["sample_texts"]) < 3:
            mapping[cluster_str]["sample_texts"].append(texts[i][:100])
    
    # 输出映射表
    output = {
        "mapping_rules": [],
        "coverage_statistics": {
            "total_records": len(df),
            "mapped_records": len(cluster_labels),
            "mapping_rate": len(cluster_labels) / len(df)
        }
    }
    
    for cluster, info in mapping.items():
        output["mapping_rules"].append({
            "new_label": cluster,
            "mapped_from": info["existing_labels"],
            "sample_texts": info["sample_texts"],
            "recommended_action": "auto" if len(info["existing_labels"]) > 1 else "manual_review"
        })
    
    with open(output_path, 'w', encoding='utf-8') as f:
        json.dump(output, f, ensure_ascii=False, indent=2)
    
    print(f"标签映射表已生成至：{output_path}")
    return output

# 执行示例
generate_label_mapping("data/training_data.csv", "output/label_mapping.json")
```

### 2.3 自动化打标流程（基于规则+AI混合）

```python
import re
import requests
import json

class AutoLabeler:
    def __init__(self, rules_path, ai_api_url, confidence_threshold=0.7):
        with open(rules_path, 'r', encoding='utf-8') as f:
            self.rules = json.load(f)
        self.ai_api_url = ai_api_url
        self.confidence_threshold = confidence_threshold
    
    def rule_based_label(self, text):
        """基于正则规则的快速打标"""
        labels = []
        for rule in self.rules["regex_rules"]:
            if re.search(rule["pattern"], text, re.IGNORECASE):
                labels.append(rule["label"])
        return labels
    
    def ai_based_label(self, text):
        """调用AI模型进行语义打标"""
        payload = {
            "text": text,
            "model": "knowledge-classifier-v2",
            "return_confidence": True
        }
        try:
            response = requests.post(self.ai_api_url, json=payload, timeout=5)
            if response.status_code == 200:
                result = response.json()
                # 只返回置信度高于阈值的标签
                return [
                    label for label, conf in result["labels"].items()
                    if conf >= self.confidence_threshold
                ]
        except Exception as e:
            print(f"AI打标失败：{e}")
        return []
    
    def hybrid_label(self, text):
        """混合打标：规则优先，AI补充"""
        rule_labels = self.rule_based_label(text)
        ai_labels = self.ai_based_label(text)
        
        # 合并标签，规则结果具有最高优先级
        final_labels = list(set(rule_labels + [l for l in ai_labels if l not in rule_labels]))
        return final_labels

# 配置示例
labeler = AutoLabeler(
    rules_path="config/label_rules.json",
    ai_api_url="http://10.0.0.1:8000/api/classify",
    confidence_threshold=0.75
)

# 批量打标示例
sample_texts = [
    "用户报告网络连接失败，无法访问公司VPN",
    "需要申请新的开发服务器，配置要求：32GB内存，4核CPU"
]
for text in sample_texts:
    labels = labeler.hybrid_label(text)
    print(f"文本：{text[:30]}... 标签：{labels}")
```

#### 4.1.1 评审角色与职责

| 角色 | 职责 | 人数 | 资质要求 |
|------|------|------|----------|
| 标注员 | 对低置信度数据进行标签标注 | 5人 | 熟悉业务领域，通过标注测试 |
| 审核员 | 对标注结果进行抽样审核 | 2人 | 3年以上业务经验 |

#### 4.1.2 评审SOP

```
1. 标注员登录标注平台
2. 系统分配待标注数据（每次20条）
3. 标注员阅读数据内容，从标准标签库中选择标签
4. 系统记录标注时间、标签、置信度
5. 审核员每日抽取10%已标注数据进行复核
6. 若审核通过率<95%，标注员需重新培训
7. 每周召开标注质量会议，讨论争议案例
8. 领域专家每月评审新出现的标签需求
```

### 4.2 业务场景微调SOP

#### 4.2.1 场景识别与优先级

```python
# 场景优先级评分模型
def calculate_scenario_priority(scenario_data):
    """
    计算业务场景优先级
    :param scenario_data: dict, 包含以下字段：
        - query_volume: 月查询量
        - user_satisfaction: 当前用户满意度(0-1)
        - business_impact: 业务影响评分(0-10)
        - implementation_cost: 实施成本(人天)
    """
    score = (
        scenario_data['query_volume'] * 0.3 +
        (1 - scenario_data['user_satisfaction']) * 0.3 +
        scenario_data['business_impact'] * 0.3 -
        scenario_data['implementation_cost'] * 0.1
    )
    return score

# 示例场景
scenarios = [
    {"name": "客服工单分类", "query_volume": 50000, "user_satisfaction": 0.6, "business_impact": 8, "implementation_cost": 20},
    {"name": "内部知识检索", "query_volume": 20000, "user_satisfaction": 0.7, "business_impact": 6, "implementation_cost": 15},
    {"name": "产品文档导航", "query_volume": 10000, "user_satisfaction": 0.8, "business_impact": 5, "implementation_cost": 10}
]

for s in scenarios:
    s['priority_score'] = calculate_scenario_priority(s)
    
# 按优先级排序
sorted_scenarios = sorted(scenarios, key=lambda x: x['priority_score'], reverse=True)
print("场景优先级排序：")
for s in sorted_scenarios:
    print(f"{s['name']}: {s['priority_score']:.2f}")
```

#### 4.2.2 微调操作步骤

```
1. 收集场景数据（至少1000条带标签样本）
2. 分割数据集：训练70%、验证15%、测试15%
3. 基于新场景数据微调分类模型
4. 评估指标：准确率≥85%，召回率≥80%
5. 对比微调前后在旧数据上的性能下降（目标：下降<5%）
6. 通过A/B测试验证场景效果提升
7. 灰度发布新模型，监控异常
8. 全量部署并更新知识库索引
```

## 5. 常见实施问题排查与质量验收标准

### 5.1 常见问题排查表

| 问题现象 | 可能原因 | 排查步骤 | 解决方案 |
|----------|----------|----------|----------|
| 标签覆盖率低 | 标签体系设计过细 | 1. 检查L3标签覆盖率<br>2. 分析未覆盖数据特征 | 合并相似标签，或扩展标签库 |
| 打标准确率低 | 训练数据不足或不平衡 | 1. 分析混淆矩阵<br>2. 检查各类别样本数 | 增加欠采样类别数据，或使用过采样技术 |
| API响应超时 | 索引性能不足 | 1. 检查索引分片数量<br>2. 监控CPU和内存使用 | 增加索引分片，优化查询语句 |

| 模型迭代后性能下降 | 新数据分布偏移 | 1. 对比新旧数据分布<br>2. 检查模型收敛情况 | 回滚至上一版本，增加数据验证步骤 |
