#### 3. 实用建议

- **批量下载**：优先使用Unpaywall API（合法且稳定）配合CrossRef API解析DOI，然后批量抓取OA PDF。
- **法律合规**：避免使用Sci-Hub或LibGen进行系统性抓取，仅作个人应急。
- **自动化脚本**：可基于以下伪代码构建：
  ```python
  import requests
  def get_oa_pdf(doi, email):
      url = f"https://api.unpaywall.org/v2/{doi}?email={email}"
      r = requests.get(url)
      if r.status_code == 200 and r.json().get('is_oa'):
          pdf_url = r.json()['best_oa_location']['url_for_pdf']
          return requests.get(pdf_url).content
      return None
  ```
