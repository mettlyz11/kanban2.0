## 📋 系统概述

SDS（自我驱动系统）是一个全自动无人值守的看板任务管理和执行系统，能够：

1. **自动发现任务缺口** - 分析活跃项目、停滞任务、质量问题
2. **智能创建看板任务** - 根据分析结果自动生成高质量任务
3. **子代理调度执行** - 智能槽位管理，自动分发任务
4. **结果验证回收** - 自动验证完成质量，标记不合格任务
5. **72小时无人值守** - 自动监控，异常检测，自愈机制
6. **安全护栏保护** - 风险分级，自动备份，审计日志，一键回滚

## 🛡️ 安全护栏

### 风险分级
| 级别 | 处理方式 |
|------|---------|
| SAFE | 自动批准执行 |
| LOW | 自动批准，记录日志 |
| MEDIUM | 记录警告，执行 |
| HIGH | 暂停执行，需要人工审批 |
| CRITICAL | 禁止执行，记录告警 |

### 禁止操作
- ❌ DROP TABLE, DROP DATABASE
- ❌ rm -rf /, shutdown, reboot
- ❌ 修改Server 1 (47.93.184.128)
- ❌ 重启Gateway服务
- ❌ 执行macOS系统更新

### 回滚机制
- 每次高危操作前自动创建备份点
- 操作失败自动回滚到备份点
- 支持手动回滚到任意历史版本

## 📞 故障排查

### 常见问题

1. **任务没有自动生成**
   - 检查任务分析器日志: `logs/sds-task-analyzer.log`
   - 确认有活跃项目缺少任务
   - 检查数据库连接是否正常

2. **任务状态没有更新**
   - 检查调度器日志: `logs/sds-subagent-scheduler.log`
   - 确认子代理执行完成后调用了验证接口
   - 检查数据库写权限

3. **仪表盘没有更新**
   - 检查仪表盘日志: `logs/sds-dashboard.log`
   - 确认输出目录有写权限
   - 检查浏览器缓存

4. **高风险操作被拒绝**
   - 查看审计日志: `logs/sds-audit-log.jsonl`
   - 确认操作是否在禁止列表中
   - 需要人工审批的操作请联系管理员
