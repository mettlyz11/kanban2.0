## 第一章：总则与核心使用原则

### 1.1 文件性质与适用范围

本《家庭活动日历共享文档协同规范》（以下简称“本规范”）旨在为家庭成员共同维护的共享日历提供标准化操作指南。本规范适用于所有拥有日历访问权限的家庭成员，包括但不限于：父母、子女、同住亲属及其他经授权的外部家庭成员（如保姆、家庭教师等）。

### 1.2 核心使用原则

#### 1.2.1 及时性原则

所有家庭成员应在获知活动信息后的 **2小时** 内完成日历录入。对于紧急变更（如临时加班、突发就医等），应在决策做出后 **30分钟内** 更新日历。

**示例场景**：
- 小明被通知周五下午3点有家长会，必须在通知到达后2小时内录入日历
- 妈妈临时接到加班通知需要取消原定的家庭晚餐，必须在确认加班后30分钟内更新

#### 1.2.2 准确性原则

日历中的每一条活动记录必须包含以下 **最低信息要求**：

| 字段 | 必填 | 格式要求 | 示例 |
|------|------|----------|------|
| 活动名称 | 是 | 简明扼要，不超过20字 | “小明家长会” |
| 日期 | 是 | YYYY-MM-DD | 2024-09-15 |
| 开始时间 | 是 | HH:MM（24小时制） | 15:00 |
| 结束时间 | 是 | HH:MM（24小时制） | 16:30 |
| 地点 | 是 | 详细地址或常用简称 | “学校3楼会议室”或“家” |
| 参与者 | 是 | 列出所有相关家庭成员 | “爸爸、小明” |
| 备注 | 否 | 补充信息，不超过100字 | “需带成绩单” |

**禁止行为**：
- 使用模糊时间（如“下午”、“晚上”）
- 使用不确定地点（如“某餐厅”、“学校附近”）
- 遗漏关键参与者

#### 1.2.3 共识性原则

任何涉及 **3名及以上家庭成员** 的活动，必须在录入前获得所有相关成员的 **口头或书面确认**。对于可能影响家庭整体安排的活动（如家庭旅行、装修施工等），需经 **2/3以上家庭成员** 同意后方可录入。

**共识确认流程**：
1. 发起人提出活动草案（时间、地点、内容）
2. 通过家庭群聊或当面沟通征求意见
3. 获得必要数量的确认回复
4. 录入日历并标注“已确认”

## 第二章：信息录入与修改规范

### 2.1 活动录入提前量

| 活动类型 | 最小提前量 | 建议提前量 | 备注 |
|----------|------------|------------|------|
| 个人日常活动 | 2小时 | 1天 | 如个人健身、阅读时间 |
| 家庭共同活动 | 24小时 | 3天 | 如家庭晚餐、电影之夜 |
| 重要家庭活动 | 3天 | 7天 | 如生日聚会、家庭旅行 |
| 外部预约 | 按预约要求 | 预约当天 | 如医院挂号、维修上门 |

**违规处理**：连续3次未达到最小提前量的成员，将被暂时限制编辑权限，需参加一次家庭会议后方可恢复。

### 2.2 冲突处理机制

#### 2.2.1 自动冲突检测

日历系统将在录入时自动检测以下冲突类型：
- **时间冲突**：同一时间段内，同一家庭成员被安排在两处活动
- **资源冲突**：同一时间段内，家庭共用资源（如车辆、客厅）被重复预定
- **优先级冲突**：低优先级活动与高优先级活动重叠

#### 2.2.2 冲突解决优先级

当检测到冲突时，按以下优先级顺序处理：

1. **健康医疗类活动**（最高优先级）
   - 例：医院预约、急诊、体检
2. **教育学习类活动**
   - 例：学校活动、考试、培训课程
3. **工作商务类活动**
   - 例：重要会议、出差、客户接待
4. **家庭共同活动**
   - 例：家庭聚餐、集体出游
5. **个人休闲类活动**（最低优先级）
   - 例：个人娱乐、社交聚会

#### 2.2.3 冲突协商流程

1. 系统标记冲突并通知相关成员
2. 相关成员在 **4小时内** 进行沟通协商
3. 协商结果由优先级较高的活动保留，低优先级活动调整
4. 若无法达成一致，由 **家庭管理员**（通常为父母之一）最终裁定
5. 裁定结果更新至日历，并在备注中说明协商过程

### 2.3 修改与取消规范

- **取消活动**：必须提前 **12小时** 通知所有参与者，并在日历中删除或标记为“已取消”
- **修改时间**：必须提前 **6小时** 通知，并在日历中更新，同时保留原时间记录供参考
- **临时变更**：突发情况（如生病、紧急工作）可在活动开始前1小时修改，但需在备注中说明原因

## 第三章：权限管理与隐私边界设置

### 3.1 权限分级体系

| 权限等级 | 成员类型 | 可执行操作 | 备注 |
|----------|----------|------------|------|
| L3-管理员 | 父母 | 全部权限：创建/修改/删除任何活动、管理成员权限、查看所有隐私活动 | 建议2人 |
| L2-普通成员 | 子女（12岁以上） | 创建/修改/删除个人活动及参与的家庭活动、查看所有非隐私活动 | 可申请提升权限 |
| L1-受限成员 | 子女（12岁以下） | 仅可查看日历、由管理员代为录入活动 | 可申请临时编辑权限 |
| L0-访客 | 外部授权人员 | 仅可查看指定活动（如保姆查看接送安排） | 需管理员单独授权 |

### 3.2 隐私边界设置

#### 3.2.1 隐私活动定义

以下活动类型建议标记为“隐私”：
- 个人医疗信息（如心理咨询、特定科室就诊）
- 个人社交活动（如约会、朋友聚会成员不详）
- 个人工作/学习敏感信息（如面试、成绩公布）
- 其他成员明确要求保密的活动

#### 3.2.2 隐私活动处理规则

1. **标记方式**：在活动名称前添加 `[隐私]` 标签，如 `[隐私] 心理咨询 15:00-16:00`
2. **可见范围**：
   - 管理员（L3）：可见活动时间及备注“隐私活动”，不可见具体内容
   - 活动本人：完全可见
   - 其他成员：仅可见活动时间段被占用，不可见任何详情
3. **隐私活动数量限制**：每人每月隐私活动不超过 **5项**，超出需管理员审批
4. **隐私活动审核**：管理员每季度进行一次隐私活动合理性审查

#### 3.2.3 外部人员访问控制

- 访客账号必须由管理员创建，且设置 **有效期**（建议最长30天）
- 访客仅能查看与其相关的活动（如保姆仅看接送相关日程）
- 访客不得查看隐私活动
- 访客权限到期后自动失效，需重新申请

### 3.3 权限变更流程

1. 成员填写《权限变更申请表》（电子版或纸质版）
2. 提交至家庭管理员
3. 管理员在 **48小时内** 审核并回复
4. 变更结果在家庭群组公示
5. 每次权限变更需在日历的“系统日志”中记录

## 第四章：定期维护与数据清理机制

### 4.1 维护周期与责任人

| 维护类型 | 频率 | 责任人 | 具体内容 |
|----------|------|--------|----------|
| 日常检查 | 每日 | 当日值班成员 | 检查是否有过期未处理的活动 |
| 周度清理 | 每周日 | 管理员 | 清理已过期活动，归档重要活动 |
| 月度审查 | 每月1日 | 全体成员 | 审查隐私活动合理性，更新成员权限 |
| 季度大清理 | 每季度末 | 管理员 | 彻底清理数据，备份年度重要活动 |
| 年度归档 | 每年1月 | 管理员 | 创建年度活动总结报告 |

### 4.2 数据清理规则

#### 4.2.1 自动清理策略

- **已过去7天**的活动：自动从主日历视图隐藏，移入“历史记录”分区
- **已过去30天**的活动：自动删除（除标记为“重要”的活动外）
- **标记为“重要”** 的活动：保留至年度归档时手动处理

#### 4.2.2 手动清理规范

**周度清理流程**：
1. 打开“过期活动”视图
2. 逐条确认活动是否已执行
3. 已执行且无保留价值：删除
4. 已执行但需保留：标记为“重要”，添加备注说明保留原因
5. 未执行但已过期：分析原因，记录在家庭会议纪要中

**季度大清理流程**：
1. 导出当前季度所有活动数据（CSV格式）
2. 按家庭成员分类统计活动数量
3. 生成《季度家庭活动分析报告》
4. 删除90天前的非重要活动
5. 将重要活动移入“年度档案”文件夹

### 4.3 数据备份策略

| 备份类型 | 频率 | 存储位置 | 保留期限 |
|----------|------|----------|----------|
| 自动备份 | 每日 | 云端（Google Drive/OneDrive） | 30天 |
| 手动备份 | 每周 | 本地硬盘 + 云端 | 90天 |
| 年度归档 | 每年 | 外部硬盘 + 云端长期存储 | 永久 |

## 第五章：家庭反馈与规则迭代流程

### 5.1 反馈收集机制

#### 5.1.1 日常反馈渠道

- **家庭群聊**：随时提出意见，使用 `#日历反馈` 标签
- **月度会议**：每月第一个星期日晚上8点，作为固定议程
- **匿名反馈箱**：在家庭公共区域设置实体信箱，或使用在线匿名表单

#### 5.1.2 反馈内容分类

| 分类 | 示例 | 处理时限 |
|------|------|----------|
| 技术问题 | 日历同步失败、系统报错 | 24小时内响应 |
| 规则漏洞 | 某项规则不适用当前情况 | 7天内讨论 |
| 体验建议 | 希望增加新功能、简化流程 | 14天内评估 |
| 争议申诉 | 对冲突处理结果不满 | 48小时内复议 |

### 5.2 规则迭代流程

#### 5.2.1 常规迭代（月度）

1. **收集阶段**（每月1-7日）：通过各渠道收集反馈
2. **整理阶段**（每月8-10日）：管理员整理反馈，形成《规则修改提案》
3. **讨论阶段**（每月第一个周日）：家庭会议讨论提案
4. **表决阶段**：2/3以上家庭成员同意即通过
5. **公示阶段**：通过后3天内更新本规范文档，并在家庭群组公示
6. **生效阶段**：公示后第7天正式生效

#### 5.2.2 紧急迭代（非常规）

当出现以下情况时，可启动紧急迭代：
- 发现重大安全隐患（如隐私泄露风险）
- 系统重大更新导致规则不适用
- 家庭结构重大变化（如新成员加入、成员迁出）

**紧急迭代流程**：
1. 管理员在 **2小时内** 发布临时规则
2. 在 **24小时内** 召开紧急家庭会议
3. 会议后 **48小时内** 确定正式规则
4. 立即生效，并在所有渠道公告

### 5.3 规则版本管理

- 每次迭代后更新本规范文档版本号
- 保留所有历史版本，存储在“规范历史”文件夹中
- 版本变更记录需包含：变更日期、变更内容、表决结果、反对意见摘要

## 第六章：违规处理与激励机制

### 6.1 违规分级与处理

| 违规等级 | 违规行为示例 | 处理措施 |
|----------|--------------|----------|
| 轻度违规 | 录入信息不完整、忘记标注参与者 | 口头提醒，家庭群组@当事人 |
| 中度违规 | 连续3次未达到提前量、未按流程取消活动 | 暂停编辑权限3天，需完成规则学习 |
| 重度违规 | 擅自查看他人隐私活动、恶意篡改日历 | 暂停全部权限7天，召开家庭会议检讨 |
| 严重违规 | 泄露家庭隐私信息、破坏日历系统 | 永久限制权限，重新评估成员资格 |

### 6.2 激励机制

| 奖励类型 | 条件 | 奖励内容 |
|----------|------|----------|
| 月度之星 | 当月无违规，且主动维护日历3次以上 | 获得一次“活动决策权”（可指定一次家庭活动） |
| 季度贡献奖 | 提出有效建议被采纳，或帮助他人解决日历问题 | 获得家庭活动预算额外额度50元 |
| 年度模范 | 全年表现优秀，被评为最遵守规范的成员 | 获得“家庭日历管理员”称号，参与规则制定 |

## 附录B：常见问题解答（FAQ）

**Q1: 如果忘记录入活动怎么办？**
A: 发现忘记后立即补录，并在备注中说明原因。若造成其他成员不便，需当面道歉。

**Q2: 隐私活动被他人看到怎么办？**
A: 立即截图留存证据，报告管理员。管理员将调查并依据违规处理条款执行。

**Q3: 家庭成员外出旅行，如何维护日历？**
A: 旅行前需提前规划并录入所有活动。旅行期间由管理员代管，旅行归来后补录未记录的活动。

**Q4: 新成员加入家庭，如何授予权限？**
A: 新成员需先学习本规范，参加一次家庭会议，然后由管理员创建账号并分配权限。
