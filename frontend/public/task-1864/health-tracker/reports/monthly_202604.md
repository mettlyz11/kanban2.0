# 量化自我健康监测系统 - 技术方案

## 1. 系统概述

基于 Apple Watch 传感器数据，搭建个人健康数据量化系统，实现数据驱动的健康管理。

## 2. 系统架构

```
┌─────────────────────────────────────────────────────────────┐
│                        数据采集层                             │
│  Apple Watch → HealthKit Export → XML/模拟数据               │
└──────────────────────┬──────────────────────────────────────┘
                       │
┌──────────────────────▼──────────────────────────────────────┐
│                        数据处理层                             │
│  Python 引擎: 数据解析 → 健康评分算法 → 异常检测              │
│  评分维度: 运动30% + 睡眠30% + 心率20% + 精力20%             │
└──────────────────────┬──────────────────────────────────────┘
                       │
┌──────────────────────▼──────────────────────────────────────┐
│                        数据存储层                             │
│  InfluxDB 时序数据库 (HTTP API, Bucket: health_data)         │
│  测量值: health_metrics (原始指标) + health_scores (评分)    │
└──────────────────────┬──────────────────────────────────────┘
                       │
┌──────────────────────▼──────────────────────────────────────┐
│                        可视化层                               │
│  Grafana Dashboard: 10个面板，覆盖评分/步数/睡眠/心率趋势     │
│  企业微信: 每日简报推送 + 异常预警                            │
└─────────────────────────────────────────────────────────────┘
```

## 3. 核心算法

### 3.1 健康评分公式

```
总评分 = 运动×0.3 + 睡眠×0.3 + 心率×0.2 + 精力×0.2

运动评分 = (步数达成率×0.6 + 卡路里达成率×0.4) × 100
睡眠评分 = 基础分(时长) + 深度睡眠比例加成
心率评分 = 100 - |静息心率-65| × 2 (最佳区间 55-75)
精力评分 = 心率储备×0.6 + 站立时间×0.4
```

### 3.2 异常预警规则

| 优先级 | 规则 | 阈值 |
|--------|------|------|
| 🔴 高 | 睡眠不足 | < 5小时 |
| 🟡 中 | 静息心率偏高 | 持续 > 80 bpm |
| 🟢 低 | 静息心率偏低 | < 50 bpm |

| 任务调度 | cron | - |

## 5. 部署步骤

1. **环境准备**: 安装 Python3、Docker Desktop
2. **依赖安装**: `pip install -r requirements.txt`
3. **基础设施**: `docker-compose up -d` (InfluxDB + Grafana)
4. **配置系统**: 复制 `config.yaml` → `config.local.yaml`，填入 Token
5. **数据导出**: iPhone 导出健康数据 XML，或启用模拟模式
6. **运行测试**: `python main.py sync`
7. **配置定时任务**: crontab 设置每日/周/月执行
