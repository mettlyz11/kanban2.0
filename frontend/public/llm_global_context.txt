/** 3. 系统架构全貌 **/
=== SDS 自我驱动系统 (sds1/) ===
  llm_client.py      — 统一 LLM 调用入口，含 call_llm() 模型路由+轮值+上下文注入
  modules/           — 核心模块
    subagent_scheduler — 子代理调度 + 失败分析
    task_analyzer       — 任务分解分析
    auto_evaluator      — 自动质量评估
    failure_attribution — 失败归因诊断
    quality_scorer      — 质量评分
    progress_estimator  — 进度预估
    llm_auditor         — LLM 审计
    model_tracker       — 模型效果追踪（含 eval）
    pending_triage      — 待办分层评分
    actor_llm           — 扮演者对话引擎

=== SDS 自进化系统 (sds_evolution/) ===
  evolution_daemon.py  — 主 daemon，每周期循环（probe→brainstorm→apply→verify→learn）
  evolib/applier.py    — 代码自动应用（probe + 按模型 budget 塞文件 + no_rotate）
  evolib/brainstorm_strategies/ — 多策略脑暴（base.py + probe 流）
  evolib/multi_model_voter.py  — 多模型投票选最优方案
  evolib/healer.py     — 错误自动修复
  evolib/auto_evaluator.py — 改进效果自动评估
  evolib/learner.py    — 长期经验学习器
  进化 DB: data/evolution.db (SQLite, 7K+ 改进记录)

=== OpenClaw Gateway (本地) ===
  管理所有 LLM 调用路由、fallback 链、轮值、token 追踪
  9 个 Provider / 64+ 模型
  Skills: 50+ 技能（actor、代码、搜索、工具调用等）
  数据: ~/.openclaw/openclaw.json（配置）/ .env（密钥）

=== 看板系统（阿里云 47.93.184.128） ===
  前端: https://kanbanyun.com (React + TypeScript + vite)
  后端: gunicorn:8086 / koa:8888 / nginx:443
