# 顶尖理工大学申请准备路线图

## 一、英美顶尖大学IB成绩要求

### 1.1 英国G5理工专业要求

| 大学 | 专业 | IB要求 | HL要求 |
|------|------|--------|---------|
| **牛津大学 | 工程/物理/CS | 40-42 | 776-777 |
| **剑桥大学** | 工程/自然科学 | 40-42 | 776，部分专业STEP |
| **帝国理工** | 工程/CS | 38-40 | 766 |
| **伦敦政经** | 数学/统计 | 38-39 | 766 |
| **UCL** | 工程/CS | 36-39 | 766 |

**英国申请关键：**
- 强烈建议考STEP/MAT考试（牛津/剑桥/帝国理工）
- PS（个人陈述）学术深度是关键
- 提前1年申请（UCAS 10月15日截止）
- 面试准备：牛津剑桥的面试是决定性的

## 二、课外活动规划（G10-G12）

### 2.1 科研项目规划

#### G10（探索期）
- **校内：** 科学节/科创比赛
- **目标：** 找到兴趣方向（物理/化学/CS）
- **产出：** 1-2个小型实验报告

#### G11（深度期）
- **优先选择1-2个方向深度参与：
  1. **大学实验室项目：** 联系北航/清华等高校教授进实验室
  2. **线上科研：** 如Pioneer、CIS等项目
  3. **独立研究：** EE延伸，可发表

#### G12（成果期）
- 论文发表/专利申请/竞赛获奖

### 2.2 竞赛规划

| 类别 | 推荐竞赛 | 时间 |
|------|---------|------|
| **数学** | AMC 12/AIME | G10-G11 |
| **物理** | 物理碗/BPhO | G11 |
| **计算机** | USACO/CCC | G10-G11 |
| **科创** | 丘成桐中学科学奖 | G11 |
| **商赛** | FBLA/DECA 可选 |

**竞赛策略：**
- 深度优先，1-2项拿奖 >> 5-6项参与
- 越早开始越好，G11是黄金期
- 组队参加，互相促进

### 2.3 暑期学校规划

#### G10暑假
- 国内：清华暑校/各大高校夏令营
- 目标：体验大学学习生活

#### G11暑假（关键）
- **顶尖夏校申请：
  - 数学：ROSS，PROMYS，SUMaC
  - 理工：MIT RSI，SSP，SSTP
  - 英国：牛津剑桥夏校
- **备选：大学学分夏校

## 三、推荐信规划

### 3.1 推荐人人选标准

| 推荐人 | 推荐人身份 | 推荐重点 |
|--------|-----------|---------|
| **主推荐人1 | 数学HL老师 | 学术能力、逻辑思维 |
| **主推荐人2 | 物理HL老师 | 实验能力、科研潜力 |
| **补充推荐人 | 科研导师/竞赛教练 | 具体项目经历 |

### 3.2 与推荐人建立关系时间线

**G10：
- 课堂积极参与
- 课后主动问问题
- 让老师记住你

**G11上学期：
- 保持良好课堂表现
- 主动分享学习进展
- 确定EE导师确认

**G11下学期结束：
- 跟老师明确请老师写推荐信
- 提供详细给老师详细个人简历
- 9月前完成

## 四、申请时间线总览

### G10（基础年
```
9-1月：适应IB，确定兴趣方向
2-6月：参加校内活动，开始竞赛准备
暑假：夏校/科研探索
```

### G11（关键年）
```
9-1月：确定选课，开始深度科研
2-6月：竞赛集中参赛，EE选题
暑假：夏校/EE初稿/考试准备
```

### G12（申请年）
```
9月：EE终稿，推荐信，开始文书
10月：英国UCAS提交
11月：牛津剑桥面试准备
12-1月：美国申请截止
2-3月：录取结果
```
