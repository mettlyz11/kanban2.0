# 2026年北京小升初升学路径设计与时间规划

**适用对象**：儿子，海淀区某小学六年级，成绩中上等，有科技特长
**家庭背景**：父亲为国家级高新技术企业高管，符合人才子女政保条件
**目标层级**：冲击市重点→稳健区重点→保底优质校

---

## 路径一：冲刺路径·冲击顶流市重点

### 🎯 目标学校
**中国人民大学附属中学（海淀六小强之首）**

### 🔍 路径可行性分析
| 评估维度 | 现状 | 得分 | 备注 |
|----------|------|------|------|
| **政保资格** | 高新技术企业高管+人才认定 | 8/10 | 符合2026年人才子女专项通道 |
| **学习成绩** | 班级前15%，数学优势明显 | 7/10 | 达到人大附分班考基础要求 |
| **特长获奖** | 科技类市二等奖 | 6/10 | 有一定竞争力但不够突出 |
| **家庭资源** | 企业纳税大户，中关村重点企业 | 8/10 | 企业层面有加分 |
| **综合评分** | - | **7.3/10** | 有希望但需精心准备 |

### 📅 详细时间规划表（2026年4月-9月）

#### 第一阶段：准备期（4月26日-5月10日）**[关键！仅剩15天]**
| 日期 | 任务 | 责任人 | 完成标志 | 优先级 |
|------|------|--------|----------|--------|
| 4.26-4.28 | 联系单位人事部，确认政保申报流程 | 父亲 | 获取申报须知和材料清单 | ⭐⭐⭐⭐⭐ |
| 4.28-4.30 | 准备企业资质证明：高新技术企业证书、纳税证明 | 父亲+企业行政 | 加盖公章的复印件 | ⭐⭐⭐⭐⭐ |
| 4.29-5.1 | 准备个人材料：任职证明、社保记录、人才引进证明 | 父亲 | 所有材料齐全 | ⭐⭐⭐⭐⭐ |
| 5.1-5.3 | 向中关村管委会申请"高端人才"认定 | 父亲 | 提交认定申请 | ⭐⭐⭐⭐⭐ |
| 5.2-5.5 | 孩子简历制作：突出科技特长和获奖经历 | 母亲 | 完成3页精美简历 | ⭐⭐⭐⭐ |
| 5.4-5.10 | 所有材料复核、打印、装订成册 | 全家 | 材料册一式3份 | ⭐⭐⭐⭐⭐ |

#### 第二阶段：申报期（5月11日-5月31日）
| 日期 | 任务 | 关键节点 |
|------|------|----------|
| 5.11-5.15 | 政保材料正式提交至区教委 | 取得接收回执 |
| 5.15-5.20 | 关注教委官网公示信息，如有问题及时补正 | 材料审核通过 |
| 5.20-5.25 | 一派志愿填报：第一志愿人大附 | 志愿确认签字 |
| 5.25-5.31 | 与同企业成功家长交流，了解最新动态 | 建立信息渠道 |

#### 第三阶段：等待与冲刺（6月1日-6月30日）
| 日期 | 任务 | 备选方案 |
|------|------|----------|
| 6.1-6.10 | 一派摇号等待期，同时准备分班考 | 启动人大附校园开放日 |
| 6.10左右 | 一派摇号结果公布 | ✅ 中签→庆祝，❌ 未中→政保启动 |
| 6.10-6.20 | 未中签则政保通道启动，密切跟进 | 与教委保持电话联系 |
| 6.20-6.30 | 政保录取结果公布，接收录取通知 | 如人大附未录→转路径二 |

#### 第四阶段：入学准备（7月-9月）
| 时间 | 任务 |
|------|------|
| 7月 | 分班考冲刺：数学/语文/英语三科强化 |
| 8月 | 新初一预习，参加学校夏令营 |
| 8月底 | 报到、家长会、军训 |
| 9月1日 | 正式入学 |

### ⚠️ 风险控制
1. **风险A**：政保名额被更高优先级占用 → **应对**：第二志愿填101中学作为备选
2. **风险B**：人才认定不通过 → **应对**：转企业共建通道，降低预期目标
3. **风险C**：一派中签但分班考失利 → **应对**：提前3个月启动分班考培训

### 💰 成本预算
| 项目 | 预估费用 | 说明 |
|------|----------|------|
| 材料制作打印 | 200元 | 简历、证明材料装订 |
| 人才认定 | 0元 | 政府免费服务 |
| 分班考培训 | 8000-15000元 | 可选，2个月集训 |
| 其他杂费 | 500元 | 交通、咨询等 |
| **总计** | **约1-2万元** | 政保本身无直接费用 |

## 路径二：稳健路径·优质区重点

### 🎯 目标学校
**北京101中学 / 首师大附中（任选其一）**

### 🔍 路径可行性分析
| 评估维度 | 现状 | 得分 | 备注 |
|----------|------|------|------|
| **政保资格** | 高新技术企业高管 | 9/10 | 区重点对企业政保更友好 |
| **学习成绩** | 中上等 | 8/10 | 完全符合学校要求 |
| **学区距离** | 101中学距离家3公里 | 9/10 | 就近统筹概率高 |
| **竞争烈度** | 比人大附低约40% | 8/10 | 名额相对充足 |
| **综合评分** | - | **8.5/10** | 成功率很高，属于稳健选择 |

### 📅 详细时间规划表
#### 第一阶段：铺垫期（现在-5月）
| 任务 | 具体内容 | 时间节点 |
|------|----------|----------|
| 政保申报 | 同路径一，材料完整提交 | 5月15日前 |
| 志愿填报 | 第一志愿人大附，第二志愿101中学 | 5月25日前 |
| 信息收集 | 联系101中学招生办，了解企业政保情况 | 5月底前 |
| 提前沟通 | 通过企业HR与学校建立联系 | 5月底前 |

#### 第二阶段：执行期（6月）
| 时间 | 关键动作 |
|------|----------|
| 6月上旬 | 一派未中签后，主动向教委表达101中学意愿 |
| 6月中旬 | 如人大附未录，跟进教委统筹进度 |
| 6月下旬 | 确认录取，领取通知书 |

#### 第三阶段：备选方案（如政保统筹不理想）
| 触发条件 | 转进路径 |
|----------|----------|
| 6月20日仍无消息 | 启动公办寄宿/民办校通道 |

### ✅ 路径优势分析
✅ **成功率高**：85%以上成功概率，属于可控范围
✅ **学校优质**：101/首师附都是海淀六小强，教学质量有保障
✅ **压力适中**：家长孩子心理压力都较小
