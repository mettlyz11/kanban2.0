## 重点监控关键词

1. `"九原区" + "区长" / "书记" / "领导班子"` — 官员动态
2. `"九原区" + "营商环境" / "投资" / "合作"` — 政策变化
3. `"九原区" + "诉讼" / "违约" / "纠纷"` — 案件相关

5. `"包头" + "优化营商环境条例"` — 立法进展
