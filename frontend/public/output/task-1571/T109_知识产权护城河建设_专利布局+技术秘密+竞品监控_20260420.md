## 一、执行摘要

T109作为**基于Web的量子化学计算平台**，其核心差异化在于**过渡态AI预测 + 自动化工作流 + Web协作平台**。本方案从三大维度构建知识产权护城河：

| 维度 | 核心策略 | 关键指标 |
|------|---------|---------|
| **专利布局** | 12项专利提案 → 聚焦3项优先申请 + 9项防御布局 | 2026Q2提交≥3项发明 |
| **技术秘密** | 核心算法/训练数据/模型权重以商业秘密保护 | 建立分级保密制度 |
| **竞品监控** | 月度监控Schrödinger/晶泰科技/Citrine/Dassault等8家竞品 | 月报+预警机制 |

**护城河定位**: T109不在分子模拟通用平台（Schrödinger/BIOVIA）或AI制药终端（晶泰科技）赛道竞争，而在**过渡态计算自动化工具层**建立专利壁垒。

## 四、技术秘密保护方案

### 4.1 技术秘密 vs 专利的选择矩阵

| 技术要素 | 保护方式 | 理由 |
|---------|---------|------|
| **AI模型权重** | 🔒 技术秘密 | 公开后易被复制，无法通过专利充分保护 |
| **训练数据集** | 🔒 技术秘密 | 数据集本身是核心资产，公开将丧失竞争优势 |
| **TS构型预测算法框架** | 📋 专利 + 🔒 技术秘密 | 公开方法框架（专利），隐藏具体实现细节（技术秘密） |
| **调度算法核心逻辑** | 📋 专利 | 算法流程适合专利保护，便于维权 |
| **Web平台源代码** | 🔒 技术秘密 + 软著 | 源代码本身适合技术秘密，同时申请软件著作权 |
| **用户交互设计** | 🎨 外观设计专利 | UI/UX可考虑外观设计保护 |
| **PSI4输出解析规则库** | 🔒 技术秘密 | 规则库是长期积累的know-how |

### 4.2 分级保密制度

| 级别 | 内容 | 知悉范围 | 保护措施 |
|------|------|---------|---------|
| **绝密** | 模型权重、训练数据、核心算法参数 | 仅创始人+核心开发者(≤3人) | 加密存储+访问日志+签署NDA |
| **机密** | 调度算法实现、解析规则库、系统架构设计 | 开发团队(≤5人) | 内部Git私有仓库+代码审查 |
| **内部** | 一般功能代码、用户文档、测试数据 | 全体员工 | 标准员工保密协议 |
| **公开** | 已公开专利、产品文档、营销材料 | 任何人 | 专利公开审查后释放 |

### 4.3 技术秘密保护工具矩阵

| 工具/措施 | 用途 | 成本 | 优先级 |
|-----------|------|------|--------|
| **NDA **(竞业限制协议) | 员工/合作方保密 | ~0.5万/份 | ★★★★★ |
| **代码加密存储** | Git LFS + GPG加密 | 免费-低成本 | ★★★★★ |
| **访问日志审计** | 谁在何时访问了什么 | 低成本 | ★★★★ |
| **软件著作权登记** | 保护源代码表达 | ~0.3万/项 | ★★★★ |
| **商业秘密备案** | 地方知识产权局备案 | 免费 | ★★★ |
| **竞业限制补偿** | 核心员工离职后限制 | ~月薪30%/月 | ★★★★ |

### 5.2 竞品专利关键发现

#### Schrödinger
- 截至2024年1月: **~12项待审美国专利 + 100+项化合物专利**
- 战略方向: 将资源从软件许可转向**专利药物发现项目**（自研管线授权）
- 核心优势: 物理基础计算 + ML增强（FEP自由能计算行业领先）
- **对T109的启示**: Schrödinger正在从"卖铲人"转向"淘金者"，其过渡态相关专利多集中在分子模拟层面，不涉及Web自动化工作流——这正是T109的机会窗口

#### 晶泰科技 (XtalPi)
- 港交所"18C第一股"，AI+机器人药物发现领导者
- 与辉瑞、礼来(2.5亿美元)等顶级药企深度合作
- **核心优势**: 量子物理 + AI + 自动化机器人三位一体
- **对T109的威胁**: 晶泰在量子计算+AI方向布局激进，但其重心在药物发现端到端，不涉及独立的过渡态计算工具——差异化空间充足

#### Citrine Informatics
- 5项专利，核心专利:"预测性材料开发度量"
- 专注生成式AI for materials + chemicals
- **对T109的启示**: Citrine关注材料数据基础设施，与T109的量子化学计算工具层不直接竞争

#### 国工智能
- 关键专利: CN118016177B "基于二聚体算法的化学反应过渡态分析方法及装置"
- **对T109的直接威胁**: 这是过渡态搜索领域最相关的中国专利
- **应对策略**: 在专利申请中明确区分——国工智能聚焦"二聚体算法"，T109聚焦"AI辅助预测+Web自动化工作流"
