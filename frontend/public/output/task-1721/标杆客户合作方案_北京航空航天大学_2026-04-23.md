# 和光智成 × 北京航空航天大学化学学院
## 标杆客户战略合作方案

---

### 一、合作背景

北京航空航天大学化学学院在材料科学领域拥有国内顶尖的研究实力和丰富的应用场景，涵盖高分子材料、纳米材料、能源材料等多个前沿方向。和光智成作为AI+材料科学的商业化平台，其AI材料研发辅助系统在配方优化、性能预测、文献分析等方面具有显著技术优势。双方合作将实现"AI赋能科研"的示范效应，打造行业标杆案例。

### 二、合作目标

1. **技术验证**：在北航化学学院实际科研场景中验证和光智成AI系统的准确性和实用性
2. **成果共建**：联合产出高质量学术论文和发明专利，提升双方学术影响力
3. **品牌背书**：通过顶级学府合作案例，建立和光智成的行业公信力和市场信任度
4. **产品迭代**：基于北航真实使用反馈，持续优化产品功能和用户体验

### 三、合作内容

#### 3.1 免费全功能平台授权
- 授权期限：1年（自协议签署之日起）
- 授权范围：和光智成平台全部功能模块，包括但不限于：
  - AI材料配方优化引擎
  - 文献智能检索与分析系统
  - 材料性能预测模型
  - 实验数据管理与可视化
  - 定制化模型训练接口
- 用户配额：支持30名教师及研究生同时使用

#### 3.2 联合技术支持
- 和光智成指派2名高级技术工程师作为专属技术顾问
- 每月定期技术支持会议（线上）
- 优先响应通道：工作时间内2小时响应
- 定制化需求开发：每学期最多2个定制化功能需求

#### 3.3 联合科研合作
- **论文合作**：联合在Materials Science领域顶级期刊（Nature Materials、Advanced Materials等）发表2-3篇高水平论文
- **专利申请**：联合申请2-3项AI+材料科学相关发明专利
- **项目申报**：联合申报国家自然科学基金、重点研发计划等科研项目

#### 3.4 人才培养
- 和光智成每年提供2-3个实习/就业岗位给北航化学学院优秀研究生
- 联合举办"AI+材料科学"专题研讨会或workshop（每年至少1次）
- 和光智成技术专家可作为北航客座讲师参与相关课程

### 四、双方权利与义务

#### 4.1 和光智成
- 提供免费平台使用权限及技术支持
- 保证系统稳定性和数据安全
- 有权在经北航同意后将合作成果用于市场推广
- 承诺不泄露北航未公开的科研数据

#### 4.2 北航化学学院
- 积极使用和光智成平台并反馈使用意见
- 在联合发表的论文和专利中标注和光智成的贡献
- 授权和光智成使用合作案例进行市场推广（需事先审核宣传内容）
- 配合完成case study所需的信息采集和确认

### 五、成果归属

| 成果类型 | 归属原则 |
|---------|---------|
| 学术论文 | 双方共同署名，第一作者归属实际完成方 |
| 发明专利 | 双方共同申请，权属比例另行约定 |
| 平台改进 | 基于北航使用反馈产生的平台改进归和光智成所有 |
| 科研数据 | 北航产生的原始数据归北航所有 |

### 六、宣传推广

- 和光智成可在官网、宣传材料中使用"北航化学学院战略合作伙伴"标识
- 联合发布新闻稿，经双方审核后对外发布
- 北航授权和光智成在营销活动中使用合作logo
- 所有宣传内容需经双方书面确认后方可发布
