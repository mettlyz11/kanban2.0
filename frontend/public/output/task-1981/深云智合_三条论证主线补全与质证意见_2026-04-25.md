### 二、需补强的核心证据

#### 证据A: 公章管理沟通记录（微信）
**取证要求**:
1. 从原始手机导出完整对话
2. 标注关键节点：首次要求→拒绝→再次要求→再次拒绝→上报董事会
3. 公证保全 + SHA256哈希
4. 制作《微信聊天记录证据说明》（含身份确认、时间线、关键截图）

**证明目的**: 证明公司管理层多次、明确要求刘瑞交出公章，刘瑞始终拒绝，问题系个人行为而非公司管理失职。

#### 证据B: 深原科创其他董事证言
**取证要求**:
1. 联系深原科创其他董事会成员
2. 书面证言：是否知晓刘瑞不配合公章管理的情况
3. 是否参与过要求刘瑞移交公章的讨论

**证明目的**: 通过第三方证人印证刘瑞不服从管理的事实。

#### 证据C: 刘瑞行为时间线
**取证要求**:
1. 从现有证据中提取所有与刘瑞相关的行为记录
2. 按时间排列：任命→首次不服从→公章争夺→九原区介入→股权变更

**证明目的**: 展示刘瑞个人行为的时间轨迹，证明公司一直在试图管理而非放任。

```
质证意见 — 主线一

审判长、审判员：

证据[00015]第二次董事会决议明确记载刘瑞担任内蒙古深原科创董事长的任
命经过北京深云智合董事会正式决议，任命程序合法合规。

证据[00409]《印章、证照、介绍信管理标准XHJ30110017》证明公司建立了
完善的印章管理制度，管理规范有据可查。

三、公司多次要求刘瑞履行管理义务
（补强证据A：微信聊天记录）证明公司管理层从[首次要求日期]开始，先后
[次数]次明确要求刘瑞交出公章、配合管理，刘瑞始终拒绝。

四、问题根源在于刘瑞个人不服从管理
（补强证据B：董事证言）深原科创其他董事[姓名]出具证言，证实刘瑞在
任职期间多次不配合公司管理决策，问题完全系个人行为。

五、公司层面持续在履职
证据[00197]表决事项决议证明，即使刘瑞不配合，北京深云智合仍通过董
事会层面持续处理协议解除及转股事宜，从未放弃管理职责。

综上，刘瑞问题系其个人不服从管理造成，北京深云智合已尽到合理管理
职责。原告/被告以"公司管理失职"为由主张我方承担全部责任，缺乏事实
和法律依据，请求法庭不予支持。
```

### 三、质证意见（针对九原区"资金已到位/项目正常"主张）

```
质证意见 — 主线三

审判长、审判员：

针对原告/被告关于"资金已按约定拨付、项目正常推进"的主张，我方质证如下：

一、股权变更程序异常
证据[00103]显示，九原区通过8%股权转让获得深原科创董事席位。该股权

刘瑞已经实际管理项目的情况下介入公司治理的。

二、资金流向存在重大疑点
证据[00085]3000万资金到账情况说明和证据[00169]银行回单证明，部分资
金确实到账。但（补强证据G：资金流向图）将显示，资金并未完全按照合
作协议约定的路径进入北京深云智合账户，存在被截留或挪用的重大疑点。

（补强证据I）2025年1月9日投资款转换协议将进一步证明，资金转换流程
绕开了北京深云智合的正常审批程序。

三、刘瑞与九原区存在非正常沟通渠道
（补强证据H）将证明刘瑞在担任深原科创董事长期间，与九原区相关领导
存在绕过北京深云智合的直接沟通，沟通内容涉及资金拨付、项目决策、
人事安排等本应由北京深云智合统一管理的事项。

四、九原区通过股权安排干预项目运营
证据[00244]九原区会议纪要（2025.8.12）证明，九原区深度参与了项目
管理决策，这与合作协议约定的管理架构不符。

综上，刘瑞与九原区之间存在不当关联，通过股权变更、资金截留、绕开
审批等方式，绕开正常流程获取国家资源。请求法庭对此予以重视。
```

## 六、庭审注意事项

1. **先确认法庭争点**: 开庭后首先确认法庭归纳的争议焦点，确保三条主线对准争点
2. **证据编号一致性**: 庭审中所有证据引用必须使用v163统一编号体系
3. **时间线优先**: 所有论证先讲时间线，再讲具体内容，便于法官理解
4. **不主动暴露短板**: 如评审结论尚未取得，不主动提及，仅在对方质疑时回应
5. **重点攻击资金流向**: 这是九原区最难辩护的部分，集中火力于此
6. **保留后续权利**: 庭审中如对方提交新证据，当庭声明"庭后提交书面质证意见"
