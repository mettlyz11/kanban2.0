## 2. 四大场景标准化工作流

### 2.1 科研写作场景

**标准工作流：**
```
1. 文献检索 → Tavily Search + Manus
   - 输入：研究主题 + 时间范围
   - 输出：20-30篇相关文献摘要

2. 文献综述 → Claude Code
   - 输入：PDF文献批量上传
   - 输出：结构化综述（研究现状、方法对比、创新点）

3. 论文初稿 → Claude 3.7 Sonnet
   - 输入：大纲 + 数据图表
   - 输出：完整初稿（含逻辑衔接、专业术语）

4. 润色校对 → DeepSeek Chat
   - 输入：初稿 + 目标期刊要求
   - 输出：语言润色 + 格式调整

5. 参考文献管理 → Zotero + AI自动整理
```

**效率提升：** 原20小时 → 现6小时，节省70%时间

---

### 2.2 数据分析场景

**标准工作流：**
```
1. 数据清洗 → Cursor + Pandas
   - 输入：原始数据文件
   - 输出：清洗脚本 + 清洗后数据

2. 探索性分析 → Claude Code
   - 输入：清洗后数据
   - 输出：统计分析 + 可视化图表

3. 建模分析 → Python + AI代码生成
   - 输入：分析目标
   - 输出：模型代码 + 结果解释

4. 报告生成 → Markdown + AI总结
   - 输入：分析结果
   - 输出：完整分析报告
```

**效率提升：** 原16小时 → 现4小时，节省75%时间

---

### 2.3 邮件处理场景

**标准工作流：**
```
1. 邮件分类 → AI自动标签
   - 紧急（2小时内回复）
   - 重要（24小时内回复）
   - 常规（48小时内回复）
   - 垃圾/广告（自动归档）

2. 回复草稿生成 → Claude
   - 输入：邮件内容 + 回复风格
   - 输出：3个备选回复方案

3. 附件处理 → 自动提取关键信息
   - PDF合同 → 提取关键条款
   - Excel报表 → 生成数据摘要

4. 待办提取 → 自动同步到Taskflow
```

**🔒 授权说明：** 涉及敏感邮件内容，需用户明确授权后启用自动处理

**效率提升：** 原2小时/天 → 现30分钟/天，节省75%时间

---

### 2.4 会议纪要场景

**标准工作流：**
```
1. 录音转写 → OpenAI Whisper
   - 输入：会议录音文件
   - 输出：精确转写文本（含说话人识别）

2. 纪要生成 → Claude
   - 输入：转写文本
   - 输出：结构化纪要（议题、讨论、结论）

3. 行动项提取 → AI结构化输出
   - 负责人 | 任务描述 | 截止日期

4. 任务分发 → 自动同步到看板系统

5. 会议资料归档 → 自动整理索引
```

**🔒 授权说明：** 会议录音可能包含敏感信息，需用户确认后再进行处理

**效率提升：** 原2小时会议 → 15分钟整理，节省87.5%时间

4. 学术化表达，逻辑严谨

1. **逐步启用：** 先从低敏感场景（如文献处理、公开会议）开始，逐步扩展
