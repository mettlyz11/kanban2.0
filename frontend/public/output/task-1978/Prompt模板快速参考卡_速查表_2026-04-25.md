# Prompt模板快速参考卡

**版本**: V1.0 | **更新**: 2026-04-25  
*打印出来贴在显示器旁，随时取用*

---

## 📝 科研写作

### 1. 文献速读
```
请总结这篇论文的【核心创新点】【关键结果】【对我的启发】
```

### 2. 论文大纲
```
写一篇{主题}的论文，目标期刊{期刊}，生成详细三级大纲
```

### 3. 审稿回复
```
审稿意见：{内容} → 生成礼貌专业的逐条回复信
```

### 4. 摘要润色
```
把这段改写成符合Nature子刊风格的摘要，150词
```

---

## 💻 代码开发

### 5. Code Review
```
审查这段代码的【bug】【性能】【可读性】【安全】问题
```

### 6. 代码重构
```
重构此代码：增加类型注解、减少重复、添加单元测试
```

### 7. 错误调试
```
错误信息：{traceback} → 列出3-5个排查步骤和解决方案
```

### 8. 解释代码
```
用中文解释这段代码的逻辑，分步骤说明每部分做了什么
```

---

## 📧 商务沟通

### 9. 邮件回复
```
收到邮件：{内容} | 回复意图：{要点} | 生成简洁正式的回信
```

### 10. 会议议程
```
会议主题{X}，时长{Y}小时 → 生成含时间分配的详细议程
```

### 11. 谈判邮件
```
我方诉求{X}，对方立场{Y} → 生成双赢导向的谈判邮件
```

---

## ⚡ 日常效率

### 12. 任务分解
```
大任务：{描述} → 用MECE原则分解成可执行小任务，排优先级
```

### 13. 知识整理
```
学习内容：{材料} → 整理成【核心概念】【关键知识点】【应用场景】
```

### 14. 决策辅助
```
选项A{...} vs 选项B{...} → 列出Pros/Cons+成功率+推荐
```

### 15. 周报生成
```
本周工作：{清单} → 生成【成果量化+问题+下周计划】的周报
```

---

## 🎯 高级技巧

### 16. 链式思考
```
一步步思考，先分析问题，再给出方案，最后验证
```

### 17. 输出约束
```
输出必须：1. 不超过300字 2. 分3点 3. 每个点有具体例子
```

### 18. 角色设定
```
你是资深{行业}专家，有20年经验，用专业但易懂的语言回答
```

---

## 💡 万能Prompt公式

```
【角色】 + 【任务】 + 【背景】 + 【输出要求】
```

*例：你是资深VC分析师（角色），请评估这个创业项目（任务），这是BP（背景），用3页PPT结构输出（要求）*
