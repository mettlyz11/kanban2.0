## 二、快速上手指南

### 《和光智成平台 - 5分钟快速上手指南》

#### 1. 平台概览
```
┌─────────────────────────────────────────┐

├─────────────────────────────────────────┤

│                                         │
└─────────────────────────────────────────┘
```

#### 2. 第一个计算任务（以DFT为例）

**步骤1：新建项目**
- 点击「+ 新建项目」
- 选择「DFT计算」→「几何优化」
- 输入项目名称："我的第一个计算"

**步骤2：上传结构**
- 支持格式：CIF, POSCAR, XYZ, VASP
- 或直接在在线编辑器中绘制结构
- 点击「下一步」

**步骤3：设置参数**
- 选择泛函：PBE（推荐新手）
- 设置截断能：400 eV
- k点设置：自动（推荐）
- 点击「下一步」

**步骤4：提交计算**
- 确认参数设置
- 预估核时消耗
- 点击「提交计算」

**步骤5：查看结果**
- 计算进度实时显示
- 完成后收到邮件通知
- 在「项目详情」中查看：
  - 结构可视化
  - 能量收敛曲线
  - 详细输出报告
  - 数据下载

#### 3. 核时使用技巧

💡 **节省核时的小技巧**：
1. 从小体系开始测试参数
2. 使用预优化结构
3. 合理设置收敛标准
4. 充分利用模板和示例项目

#### 4. 常见问题

**Q: 计算任务排队很久？**
A: 高峰时段（工作日9-18点）可能排队，建议错峰提交

**Q: 计算失败怎么办？**
A: 查看失败日志 → 检查输入文件 → 联系技术支持

**Q: 核时不够用怎么办？**
A: 可在控制台购买核时包，或联系销售升级方案
