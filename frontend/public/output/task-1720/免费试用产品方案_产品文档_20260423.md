# 和光智成 - 30天免费试用产品方案

## 一、方案概述

### 1.1 方案目标
- 降低客户试用门槛，提升注册转化率
- 让客户充分体验产品核心价值
- 建立高效的试用转付费转化路径
- 目标：试用转付费率 ≥ 25%

### 1.2 核心价值主张
> **"零风险体验AI材料计算的全部能力"**
- 无需信用卡，无需预充值
- 30天全功能开放体验
- 充足计算额度支持真实项目验证

## 二、免费试用权益设计

### 2.1 权益清单

| 权益项 | 规格 | 说明 |
|--------|------|------|
| **试用时长** | 30天 | 自开通之日起计算 |
| **功能权限** | 全功能开放 | 所有模块无限制使用 |
| **计算额度** | 1000核时 | 支持中型计算任务 |
| **技术支持** | 1次专属支持 | 1对1线上技术咨询（30分钟） |
| **存储空间** | 50GB | 项目数据存储 |
| **并发任务** | 5个 | 同时运行的计算任务数 |

### 2.2 核时使用说明
- 核时 = CPU核心数 × 运行时间
- 1000核时可支持：
  - DFT计算：约20-30个中等规模体系
  - MD模拟：约10-15个纳米尺度模拟
  - 机器学习训练：约5-8个模型训练任务
- 核时用完后计算任务自动暂停，可购买补充

### 2.3 技术支持权益
- 支持范围：产品使用指导、计算方案咨询
- 预约方式：官网预约 / 客服申请
- 有效期：试用期内有效
- 超出部分：按299元/次标准收费

### 3.1 目标客户群体
- 材料科学领域科研人员

### 3.2 申请条件

- 填写完整的用户信息

- 签署试用服务协议

## 四、试用限制与规则

### 4.1 使用限制
- 不得用于非法或违规计算
- 不得转借、转让试用账号
- 不得进行恶意挖矿或滥用资源
- 不得批量注册账号

### 4.2 违规处理
- 首次违规：警告 + 资源限制
- 二次违规：暂停试用账号
- 严重违规：永久封禁 + 法律追责

### 4.3 数据保留
- 试用期结束后数据保留30天
- 30天后未付费则数据自动删除
- 付费用户数据永久保留
