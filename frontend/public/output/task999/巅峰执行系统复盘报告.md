## 🏭 三、高优执行逻辑萃取（3套SOP）

### SOP-1: 创业/产品双线推进的「优先级过滤漏斗」

**适用场景**: 多项目并行，资源竞争决策

```
        新任务进入
            ↓
    ┌───────┴───────┐
    │  第1层:北极星对齐  │  → 是否符合季度OKR?
    └───────┬───────┘
            ↓ 是
    ┌───────┴───────┐
    │  第2层:杠杆率评估  │  → 1小时投入能产生几小时价值?
    └───────┬───────┘
            ↓ ≥3x
    ┌───────┴───────┐
    │  第3层:资源匹配    │  → 当前资源能否支撑?
    └───────┬───────┘
            ↓ 是
      进入执行队列
```

**触发条件**: 新任务产生时、每日规划时、资源冲突时  
**异常处理**: 未通过第1层→归档; 未通过第2层→委托/延迟; 未通过第3层→拆分/求助

---

### SOP-2: 学术/个人成长的「深度工作块」排期法

**适用场景**: 需要深度思考、创造性产出的任务

**核心原则**:
1. **时间块固定化**: 每日2-3个90分钟深度工作块
2. **上下文隔离**: 深度块期间，通讯工具静默
3. **能量匹配**: 高能量时段安排高难度任务
4. **仪式感启动**: 固定前导动作触发心流状态

**日度排期模板**:
```
06:00-07:30  深度块1 (高能量 → 战略性任务)
07:30-08:30  缓冲/运动
08:30-10:00  深度块2 (中能量 → 创造性任务)
10:00-10:30  缓冲/邮件
10:30-12:00  协作块 (会议/沟通)
...下午类似结构
```

**触发条件**: 每日规划时、重大任务启动前  
**异常处理**: 深度块被打断→记录打断源→优化环境; 状态不佳→降级为浅层任务

---

### SOP-3: 家庭/生活零Pending的「边界守护协议」

**适用场景**: 工作与生活边界模糊，生活事务堆积

**核心机制**:
1. **物理边界**: 工作区与生活区空间分离
2. **时间边界**: 19:00后非紧急不处理工作
3. **事务边界**: 生活事务15分钟规则（能15分钟完成的不堆积）
4. **数字边界**: 家庭时间手机勿扰模式

**周度检查清单**:
- [ ] 生活类Pending任务 ≤ 2项
- [ ] 家庭专属时间 ≥ 10小时/周
- [ ] 个人充电活动完成 ≥ 2次/周

**触发条件**: 每日晚间、每周日复盘  
**异常处理**: 紧急工作入侵→与家属协商→补偿时间; 生活任务堆积→启动批量处理日
