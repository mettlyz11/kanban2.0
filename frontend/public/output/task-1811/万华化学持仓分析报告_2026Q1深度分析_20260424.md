**核心结论**：全球MDI市场呈现"五寡头垄断+万华一家独大"格局。万华占据成本曲线最左端，拥有全球33%+市场份额，规模优势和成本优势形成双重护城河。

### 2.2 竞争格局演变趋势

**供给侧重大变化**：
1. **中东供应中断**：2026年3月霍尔木兹海峡通航受阻，沙特Sadara（40万吨MDI+20万吨TDI）全线关停，造成全球万吨级供应缺口
2. **欧洲产能承压**：亨斯迈荷兰装置意外停车，巴斯夫比利时装置低负荷运行，欧洲天然气附加费推高成本
3. **产能退出加速**：2023-2025年，巴斯夫关闭德国TDI装置、日本东曹停产、阿根廷Petroquímica退出、三井化学缩减产能
4. **万华逆势扩产**：福建MDI技改扩能70万吨预计2026Q2完成，全球MDI产能将跃升至450万吨/年

**需求侧支撑**：
- 冰箱冷柜出口超预期
- 建筑节能保温材料需求增长
- 汽车轻量化材料渗透率提升
- 3月聚合MDI出口9.0万吨（同比+19%），TDI出口5.8万吨（同比+14%）

### 2.3 价格与价差走势

**价格传导链条**：中东地缘冲突 → 欧洲能源成本飙升 → 全球化工巨头集体提价（200-500欧元/吨）→ 万华匈牙利子公司MDI涨价500欧元/吨 → 国内价格跟涨 → Q2价差大幅走阔

## 三、核心竞争优势分析

### 3.1 成本优势：全球化工界的"沙特"

| 成本驱动因素 | 具体措施 | 效益测算 |
|-------------|---------|---------|
| **乙烯原料切换** | 烟台一期100万吨乙烯装置从丙烷裂解改为乙烷/丙烷双原料 | 吨成本节约1200元以上，年利润增量超10亿元 |
| **乙烷进口优势** | 利用美国低成本乙烷，避开中东石脑油高价 | 乙烷裂解制乙烯成本显著低于石脑油路线 |
| **MDI规模效应** | 全球产能第一，单套装置规模最大 | 单位固定成本行业最低 |
| **一体化协同** | MDI/TDI/聚醚/乙烯全产业链布局 | 中间产品内部消化，减少交易成本 |

### 3.2 技术壁垒：第八代MDI技术

- 研发投入：2025年48.65亿元（占营收2.39%），研发人员4833人
- 专利布局：全年申请发明专利1230+件，新获授权715+件
- 技术代际：第八代MDI技术持续迭代，煤浆提浓优化生产效能
- 新材料突破：VA全产业链、MS高端光学材料、XLPE、POE等

### 3.3 全球化布局

- **国内基地**：烟台（总部）、宁波、福建、蓬莱
- **海外基地**：匈牙利BC公司（欧洲桥头堡）
- **出口占比**：2025年境外收入963.21亿元，占总收入47.40%，同比+24.16%
- **战略合作**：引入科威特石化工业公司为长期战略投资者

| 风险 | 影响程度 | 发生概率 | 应对策略 |

2. **新材料业务不及预期**：电池材料、POE等新业务竞争激烈
