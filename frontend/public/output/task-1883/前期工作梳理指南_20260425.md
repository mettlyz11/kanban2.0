# 前期工作梳理指南
## 2026年度国家自然科学基金面上项目申请支撑材料

**适用：** 北航化院AI催化方向申请人  
**目的：** 系统梳理已有研究基础，为申请书前期工作部分提供素材

---

## 一、前期工作梳理思路

### 核心原则：从申请内容"倒推"前期工作

不要先列前期成果，再找与申请的关联，而应该：

```
明确申请方向
    ↓
识别申请的核心主张（我能做X的原因是...）
    ↓
找出支撑核心主张的证据链（前期成果A → B → C）
    ↓
组织成递进逻辑呈现
```

---

## 二、AI催化方向可用前期工作类型

### 2.1 直接相关工作（权重：高）

#### 计算化学基础工作
- 过渡金属催化的DFT计算研究
  - 重点：是否有过渡态计算、反应机理计算经验？
  - 期刊目标：JACS、ACS Catalysis、J. Catal.、Organometallics

- 分子动力学模拟工作
  - 重点：体系规模、力场选择、模拟时长
  - 期刊目标：JPCL、JCTC、PCCP

#### AI/机器学习应用工作
- 已发表的机器学习辅助化学研究
  - 描述符开发、性质预测、数据驱动建模
  - 期刊目标：Digital Discovery、J. Chem. Inf. Model.、Nat. Commun.

### 2.2 间接相关工作（权重：中）

- 均相/多相催化的实验研究（了解催化体系）
- 材料高通量计算/筛选（了解大规模计算方法）
- 化学信息学工具开发（分子表示、数据库构建）

### 2.3 预实验数据（权重：极高）

即使规模小，也要展示：
- 小规模过渡态机器学习预测测试（50-100个体系）
- 图神经网络应用于催化性质预测的初步结果
- 主动学习数据采样策略的可行性验证

## 四、前期工作不足时的补救策略

### 情况1：缺乏AI/ML应用工作

**补救方案A（推荐）：** 在申请前6个月，做小规模预实验
- 用已有的DFT数据（50-100个体系）训练简单GNN
- 即使误差不够小，也能展示"AI方法在本课题组已验证可用"

**补救方案B：** 与AI/计算化学强组建立合作
- 联名申请或列为合作者
- 在申请书中明确分工

**补救方案C：** 聚焦更扎实的计算方向
- 若AI基础弱，方向三（双金属协同效应）比方向一（逆向设计）更保险
- 技术门槛稍低，前期工作更易覆盖

### 情况2：缺乏实验验证基础

**应对策略：**
- 明确说明与实验组的合作关系
- 提供合作单位协议或合作意向函
- 在研究方案中详细描述合作分工

## 六、2026年NSFC政策导向要点

### 重点支持方向（根据公开信息整理）

1. **"人工智能赋能基础研究"** — 与AI催化高度契合
2. **"原创性、引领性科学研究"** — 强调"从0到1"
3. **"有组织科研"** — 鼓励与国家需求对接
4. **碳中和/绿色化学** — 催化与能源转化

### 申请书撰写语言建议

在立项依据中，适当呼应以下词汇：
- "新质生产力"
- "人工智能与科学研究深度融合"
- "基础研究强基"
- "催化科学对碳中和的支撑作用"
