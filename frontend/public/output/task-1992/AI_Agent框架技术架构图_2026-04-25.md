## 4. 数据流架构图

```mermaid
sequenceDiagram
    participant U as 用户
    participant G as OpenClaw Gateway
    participant R as 路由Agent
    participant A as 业务Agent
    participant L as LangGraph
    participant S as Skill/工具
    participant M as 记忆系统
    participant LLM as LLM Provider

    U->>G: 发送请求
    G->>G: 认证鉴权
    G->>R: 路由分发
    R->>M: 查询用户上下文
    M-->>R: 返回历史记录
    R->>A: 分配任务
    A->>LLM: 意图识别
    LLM-->>A: 返回意图
    A->>L: 启动工作流
    L->>S: 调用工具
    S-->>L: 返回结果
    L->>LLM: 生成回复
    LLM-->>L: 返回内容
    L-->>A: 工作流完成
    A->>M: 保存对话记录
    A-->>G: 返回结果
    G-->>U: 展示回复
```
