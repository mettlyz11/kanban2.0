## SOP-1: 深度工作块管理

### 触发条件
- 任务优先级 ≥ P1
- 预估耗时 > 2小时
- 需要高度专注的认知工作

### 执行路径

```
┌─────────────────────────────────────────────────────────────┐
│ Step 1: 预约时间块 (T-24h)                                   │
│ • 在日历中锁定90-120分钟时间块                               │
│ • 标注"深度工作 - [任务名称]"                                │
│ • 设置15分钟前置准备提醒                                     │
└─────────────────────────────────────────────────────────────┘
                              ↓
┌─────────────────────────────────────────────────────────────┐
│ Step 2: 断网准备 (T-30min)                                   │
│ • 关闭邮件、消息、社交媒体通知                               │
│ • 设置手机勿扰模式                                           │
│ • 准备所需材料，消除中断诱因                                 │
│ • 设置番茄钟 (90分钟)                                        │
└─────────────────────────────────────────────────────────────┘
                              ↓
┌─────────────────────────────────────────────────────────────┐
│ Step 3: 深度工作 (90min)                                     │
│ • 单一任务专注，禁止多任务切换                               │
│ • 遇到阻塞记录问题，不立即求解                               │
│ • 保持心流状态，不自我评判                                   │
└─────────────────────────────────────────────────────────────┘
                              ↓
┌─────────────────────────────────────────────────────────────┐
│ Step 4: 主动休息 (15min)                                     │
│ • 离开工作区域                                               │
│ • 轻度身体活动（散步、拉伸）                                 │
│ • 补充水分                                                   │
│ • 不看屏幕                                                   │
└─────────────────────────────────────────────────────────────┘
                              ↓
┌─────────────────────────────────────────────────────────────┐
│ Step 5: 产出归档 (T+0)                                       │
│ • 将产出物保存到指定位置                                     │
│ • 更新任务状态                                               │
│ • 记录完成时间与质量自评                                     │
└─────────────────────────────────────────────────────────────┘
```

### 止损阈值
- **连续3次被打断**: 重新预约时间块，分析中断原因
- **心流状态未达成**: 检查环境设置，调整触发条件

### 成功标准
- 90分钟内无中断
- 产出物达到预期质量的80%以上
- 主观心流体验评分≥7/10

## SOP-2: 快速决策协议

### 触发条件
- 决策延迟 > 24小时
- 信息完备度 < 80%但仍需决策
- 潜在影响范围中等（非战略级）

### 执行路径

```
┌─────────────────────────────────────────────────────────────┐
│ Step 1: 设定边界 (5分钟倒计时)                               │
│ • 启动5分钟计时器                                            │
│ • 明确决策截止时间点                                         │
│ • 接受"足够好"标准，放弃"完美"                               │
└─────────────────────────────────────────────────────────────┘
                              ↓
┌─────────────────────────────────────────────────────────────┐
│ Step 2: 快速分析 (2分钟)                                     │
│ 列出选项A（执行）的3个理由:                                   │
│ 1. _________________________________                        │
│ 2. _________________________________                        │
│ 3. _________________________________                        │
│                                                             │
│ 列出选项B（放弃）的3个理由:                                   │
│ 1. _________________________________                        │
│ 2. _________________________________                        │
│ 3. _________________________________                        │
└─────────────────────────────────────────────────────────────┘
                              ↓
┌─────────────────────────────────────────────────────────────┐
│ Step 3: 直觉选择 (1分钟)                                     │
│ • 听从第一反应                                               │
│ • 不反复纠结                                                 │
│ • 明确选择并记录                                             │
└─────────────────────────────────────────────────────────────┘
                              ↓
┌─────────────────────────────────────────────────────────────┐
│ Step 4: 决策归档 (1分钟)                                     │
│ • 记录决策结果                                               │
│ • 记录决策依据（关键理由）                                   │
│ • 设定复盘时间点（1周后）                                    │
└─────────────────────────────────────────────────────────────┘
                              ↓
┌─────────────────────────────────────────────────────────────┐
│ Step 5: 立即执行 (剩余时间)                                  │
│ • 决策后立即采取第一个行动                                   │
│ • 建立动量，避免二次犹豫                                     │
└─────────────────────────────────────────────────────────────┘
```

### 止损阈值
- **潜在损失 > 可逆成本**: 启动专家评审
- **信息完备度 < 50%**: 延长决策时间至信息完备度≥50%
- **战略级决策**: 不适用本SOP，改用战略决策流程

### 成功标准
- 决策时间 ≤ 5分钟
- 决策后立即行动
- 复盘时决策满意度 ≥ 7/10

## SOP-3: 抗干扰屏蔽机制

### 触发条件
- 进入深度工作块
- 需要持续专注 ≥ 60分钟
- 环境存在潜在干扰源

### 执行路径

```
┌─────────────────────────────────────────────────────────────┐
│ 物理层屏蔽                                                   │
├─────────────────────────────────────────────────────────────┤
│ • 选择安静、独立的工作空间                                   │
│ • 使用降噪耳机或白噪音                                       │
│ • 清理桌面，仅保留当前任务相关物品                           │
│ • 关闭房门或使用"请勿打扰"标识                               │
└─────────────────────────────────────────────────────────────┘
                              ↓
┌─────────────────────────────────────────────────────────────┐
│ 数字层屏蔽                                                   │
├─────────────────────────────────────────────────────────────┤
│ • 关闭所有非必要应用程序                                     │
│ • 启用勿扰模式（仅允许紧急电话）                             │
│ • 退出即时通讯工具                                           │
│ • 使用网站屏蔽工具（如需要）                                 │
└─────────────────────────────────────────────────────────────┘
                              ↓
┌─────────────────────────────────────────────────────────────┐
│ 社交层屏蔽                                                   │
├─────────────────────────────────────────────────────────────┤
│ • 设置状态签名: "深度工作中，[时间]后回复"                   │
│ • 告知同事/家人当前不便打扰                                  │
│ • 指定紧急联系通道（仅P0级紧急事项）                         │
│ • 约定统一处理时间（工作块结束后）                           │
└─────────────────────────────────────────────────────────────┘
                              ↓
┌─────────────────────────────────────────────────────────────┐
│ 心理层屏蔽                                                   │
├─────────────────────────────────────────────────────────────┤
│ • 接纳"暂时不处理"的焦虑                                     │
│ • 将闪现的杂念记录到"待处理清单"                             │
│ • 不自我批评，不追求完美                                     │
│ • 专注当下任务，不担忧未来                                   │
└─────────────────────────────────────────────────────────────┘
```

### 紧急中断处理流程

```
收到中断请求
    ↓
判断紧急程度
    ├── P0 (危及生命/重大损失) → 立即处理
    ├── P1 (重要且紧急) → 记录，当前工作块结束后处理
    └── P2及以下 → 记录到待处理清单，统一时间处理
```

### 止损阈值
- **连续中断 ≥ 3次**: 重新评估当前环境，必要时更换工作空间
- **P0级紧急事项 > 1次/深度工作块**: 审查任务安排，预留应急缓冲

### 成功标准
- 深度工作块内零非紧急中断
- 紧急事项正确处理率100%
- 待处理清单在当日清零

### 启动时机
- 新周期开始时
- 发现执行效率下降时
