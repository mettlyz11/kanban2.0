# T109企业版技术授权方案
## 一、T109当前可授权能力边界
T109是面向材料研发领域的AI辅助研发平台，当前开放授权的能力范围：
✅ 已验证可授权：
1. 材料分子性质预测（包含有机/无机/高分子材料，支持120+性质维度预测）
2. 逆向分子生成（目标性质导向的分子结构设计，支持约束条件自定义）
3. 合成路径规划（小分子/高分子材料合成路线智能推荐，支持实验室级/工业级场景）
4. 实验数据智能分析（结构化提取、异常值识别、规律挖掘）
5. 材料知识图谱查询（包含1亿+化合物、2000万+文献、500万+专利数据）
❌ 暂不开放授权：
1. 核心模型权重与训练代码
2. 和光智成内部专属数据集（军工/涉密领域数据）
3. 面向特定客户定制的专属功能模块（需单独签订定制协议）
4. 平台底层算力调度系统
