## 🔥 TOP 5 故障速查

### F-001 子代理超时
**症状:** spawn/send无返回 → **操作:** 重试+加倍timeout → **降级:** 换更快模型

### F-002 模型API降级失败  
**症状:** fallback链全部失败 → **操作:** 跳过aliyun(欠费) → **告警:** 连续3次失败通知用户

### F-003 Memory搜索不可用
**症状:** memory_search返回disabled → **操作:** 回退到grep本地搜索 → **修复:** 检查HUOSHAN_API_KEY

### F-004 子代理资源耗尽
**症状:** spawn频繁OOM → **操作:** 并发限≤3 → **检查:** 内存/磁盘

### F-005 子代理死锁
**症状:** 互相等待无响应 → **操作:** kill僵尸代理 → **预防:** 检测循环依赖

### F-006 文件锁冲突
**症状:** 多代理写同一文件 → **操作:** 领域隔离写入 → **方案:** 原子写入(temp+rename)

### F-007 数据库连接失败
**症状:** 任务更新失败 → **操作:** 重试3次(5/10/20s) → **降级:** 写本地文件稍后同步

### F-008 子代理Spawn失败
**症状:** spawn返回错误 → **操作:** 检查runtime+agentId → **降级:** acp→subagent

### F-011 上下文溢出
**症状:** token limit exceeded → **操作:** 分段读取+清理历史 → **预防:** 按需加载
