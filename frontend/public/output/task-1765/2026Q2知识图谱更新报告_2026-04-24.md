## 一、知识图谱架构演进

### 1.1 从v1.0到v2.1的三层架构升级

过去3个月，知识图谱架构经历了两次重大升级，从最初的简单概念网络演进为生产级的五层Graph RAG架构。

**架构v1.0（2026-04-20，#1537）：**
- 核心概念层：18个基础概念（记忆、任务、监控等）
- 关系层：12条基础关系（is_a, part_of, related_to）
- 规则层：6条基础行为规则

**架构v2.0（2026-04-20，#1552）：**
- 概念扩展：新增多Agent编排、Graph RAG、语义推理等12个概念，总数达30
- 关系扩展：新增depends_on, enhances, supports, implements等关系类型，总数达55
- 能力层：新增Agent能力注册中心，定义4类Agent（research/analysis/execution/wiki）
- 检索管道：3阶段检索（向量粗筛→图路径扩展→语义排序）

**架构v2.1（2026-04-20，#1599）：**
- 类脑知识图谱Schema设计完成
- 五层架构正式确立：
  1. 情景记忆层（Episodic Memory）- 每日事件、会议记录
  2. 实体关系层（Entity-Relation）- 人物/机构/项目/概念
  3. 文献概念层（Literature Concepts）- 论文笔记、学术概念
  4. 跨域关联层（Cross-domain Links）- 领域间桥接关系
  5. 程序技能层（Procedural Skills）- SOP、工具链、工作流

### 1.2 三大核心知识库协同体系

知识管理已从单一workspace记忆扩展为"三大云端知识库 + 本地辅助知识库"的协同体系：

| 知识库 | 位置 | 规模 | 核心用途 |
|--------|------|------|---------|
| **wiki实体图谱** | iCloud Drive | 14,937文件，802实体 | 以实体为中心的结构化知识 |
| **llmwiki素材库** | iCloud Drive | 14,305文件，14,115原始素材 | 原始素材处理 + 半结构化wiki |
| **wiki-papers论文库** | iCloud Drive | 1,921论文笔记 | 专业学术论文管理 |
| **workspace本地记忆** | 本地SSD | 内存级快速访问 | 系统运行记忆、核心原则 |

**知识库间的数据流：**
```
原始素材 → llmwiki/raw → 结构化处理 → wiki/entities
                      ↘ 论文提取 → wiki-papers/papers
                                      ↘ concepts提取 → wiki/concepts
```
