# 关于加快人工智能驱动的材料科学创新的政策建议报告（框架）

**提案单位：** 拟通过政协/人大科技界别渠道提交  
**提案日期：** 2026年4月  
**提案人：** 刘宇宙 教授（北京航空航天大学化学学院、和光智成）

---

## 一、提案背景与意义

### 1.1 国家战略需求
- 材料科学是制造业的基石，是"卡脖子"技术的核心领域
- 传统材料研发周期长（10-20年）、成本高、效率低
- AI+材料有望将研发周期缩短至1-2年，实现范式变革

### 1.2 国际竞争态势
- 美国：材料基因组计划(MGI)二期投入10亿美元
- 欧盟：Horizon Europe投入20亿欧元支持数字材料科学
- 日本：超智能社会5.0战略将AI材料列为重点
- 中国：面临"起个大早、赶个晚集"的风险

### 1.3 产业痛点
- 缺乏国家级AI材料统一数据库平台
- 算力成本高昂，中小企业难以承受
- 计算与实验脱节，"两张皮"现象严重
- 人才培养体系滞后，交叉人才稀缺
- 知识产权制度不适应AI时代

---

## 二、现状分析与问题识别

### 2.1 我国AI材料领域发展现状
**成绩：**
- 论文发表数量全球第一
- 部分算法研究达到国际先进水平
- 出现了和光智成等一批创业公司

**差距：**
- 缺乏世界级通用AI材料平台
- 工业软件几乎全部依赖进口
- 工业界实际应用渗透率<5%
- 产学研用协同机制不健全

### 2.2 政策体系存在的问题

| 政策维度 | 现存问题 | 改进方向 |
|---------|---------|---------|
| **资金支持** | 重基础研究、轻工程化；支持分散碎片化 | 设立专项，全链条支持 |
| **平台建设** | 重复建设，数据孤岛，缺乏统一标准 | 建设国家级开放平台 |
| **人才政策** | 传统学科评价体系不鼓励交叉研究 | 建立交叉学科评价标准 |
| **数据政策** | 数据权属不清，共享激励不足 | 建立数据要素市场机制 |
| **产业生态** | 缺乏标杆应用场景和成功案例 | 政府带头开放应用场景 |

## 三、具体政策建议

### 建议一：设立"国家AI材料科技创新2030重大专项"

**具体措施：**
1. 中央财政投入100亿元，带动地方和社会资本500亿元
2. 重点支持四大方向：
   - AI材料大模型与通用计算平台
   - 高通量自动化实验机器人系统
   - 关键战略材料（半导体、新能源、航空航天）
   - 工业材料软件国产化替代

3. 实施机制：
   - 采用"揭榜挂帅"机制，不唯论文、唯实效
   - 设立首席科学家负责制，给予充分科研自主权
   - 建立里程碑考核与动态调整机制

### 建议二：建设"国家AI材料公共服务平台"

**具体措施：**
1. 依托顶尖高校和科研院所建设国家级平台
2. 整合全国材料数据资源，建立统一数据标准
3. 开放算力资源，降低中小企业使用门槛
4. 提供"研发即服务"(R&DaaS)模式，按用量付费

**运营模式：**
- 事业单位性质，企业化运营
- 基础服务公益化，增值服务市场化
- 建立数据共享激励机制，数据贡献者可兑换算力

### 建议三：建立AI材料人才培养与评价新体系

**具体措施：**
1. 在高校设立"材料信息学"交叉学科专业
2. 建立"代表作+专利+产业价值"多元评价体系
3. 鼓励高校教师离岗创业，保留编制3-5年
4. 设立"AI材料青年科学家"专项人才计划

### 建议四：完善适应AI时代的知识产权制度

**具体措施：**
1. 明确AI生成材料设计方案的专利保护范围
2. 建立AI模型专利的快速审查通道
3. 探索数据知识产权保护制度
4. 建立材料数据库知识产权共享机制

### 建议五：实施"AI材料应用场景示范工程"

**具体措施：**
1. 在航空航天、新能源、半导体等领域选择10个示范项目
2. 由央企、国企带头开放真实应用场景
3. "先使用、后付费"，降低企业试错成本
4. 建立首台（套）重大技术装备保险补偿机制

---

## 四、预期效果与效益分析

### 4.1 经济效益
- 带动AI材料产业规模达到1000亿元
- 材料研发效率提升5-10倍
- 降低材料研发成本30-50%
- 培育10-20家世界级AI材料企业

### 4.2 社会效益
- 突破一批"卡脖子"关键材料
- 提升我国制造业核心竞争力
- 实现碳达峰碳中和目标贡献材料领域力量
- 树立科技自立自强的典范

### 4.3 战略价值
- 抢占全球材料科学革命制高点
- 确立我国在下一代材料研发范式中的领先地位
- 为其他科学领域AI赋能提供示范

## 五、实施路线图与保障措施

### 5.1 三年实施路线图

| 时间节点 | 关键里程碑 |
|---------|-----------|
| **2026年Q3** | 专项正式启动，完成顶层设计 |
| **2026年Q4** | 首批项目立项，平台建设启动 |
| **2027年** | 国家级平台上线运行，首批示范项目启动 |
| **2028年** | 形成完整政策体系，产出首批重大成果 |

### 5.2 组织保障
1. 成立由科技部牵头的跨部门协调机制
2. 设立专家咨询委员会（含产业界代表≥40%）
3. 建立第三方评估机制
4. 定期向国务院汇报进展

### 5.3 资金保障
- 中央财政：100亿元
- 地方政府配套：100亿元
- 引导社会资本：300亿元
- 金融工具支持：贷款贴息、担保、股权投
