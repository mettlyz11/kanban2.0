```

```

         → approved: 继续执行 | rejected: 停止并记录

## 四、新评估基线模型

### 4.1 战略杠杆率 (Strategic Leverage)

评估任务的战略价值与资源投入比：

```
杠杆率 = (长期影响 × 可复用性) / (当前投入 × 维护成本)

高杠杆任务特征:
- 一次建设，长期受益
- 可自动化/工具化
- 减少未来重复工作
- 认知带宽释放

低杠杆任务特征:
- 重复性手工操作
- 单次使用即废弃
- 高维护成本
- 无复利效应
```

### 4.2 精力健康度 (Energy Health)

评估任务对身心状态的影响：

| 等级 | 状态 | 特征 | 处理策略 |
|------|------|------|----------|
| 🟢 绿色 | 充沛 | 高专注、创造力峰值 | 安排深度工作 |
| 🟡 黄色 | 平稳 | 常规处理能力 | 安排常规任务 |
| 🔴 红色 | 耗竭 | 注意力涣散、易出错 | 强制休息/切换 |

### 4.3 双维度决策矩阵

```
                高精力健康度
                     ▲
        ┌────────────┼────────────┐
        │  战略深耕   │  杠杆建设   │
        │ (核心创作)  │ (系统搭建)  │
  低────┼────────────┼────────────┼────高
  杠杆  │  战术应付   │  恢复充电   │  杠杆
        │ (必要但低值)│ (休息+学习) │
        └────────────┼────────────┘
                     ▼
                低精力健康度
```
