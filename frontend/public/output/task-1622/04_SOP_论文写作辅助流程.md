# SOP: 论文写作辅助标准化流程

> 适用场景: 学术论文撰写、润色、翻译、格式调整
> 版本: v1.0 | 2026-04-23

---

## 1. 场景概述

利用 OpenClaw 的 AI 能力辅助学术论文写作，涵盖结构设计、内容撰写、语法润色、语言翻译、参考文献格式化等环节。

**涉及能力：**
- 文本生成与编辑（大模型）
- 文献检索与引用管理
- 写作计划与大纲设计
- 格式转换（支持 LaTeX / Word / Markdown）

---

## 2. 前置条件

- [ ] OpenClaw 已正常运行
- [ ] 有明确的目标期刊（确定格式要求）
- [ ] 已有核心数据和图表（实验/计算结果）
- [ ] Zotero 已安装并配置好文献库

---

## 3. 论文写作全流程

### 3.1 阶段一：选题与大纲设计

**目标：** 确定论文主题、核心创新点、目标期刊

```
用户指令示例:
"我研究的是高通量计算筛选钙钛矿材料，核心创新点是结合图神经网络
和主动学习策略。请帮我设计一个 Nature Materials 级别的论文大纲。"

系统输出:
1. 评估研究创新性
2. 推荐目标期刊（备选3个）
3. 生成结构化大纲（含各部分字数建议）
4. 标注关键竞争力分析
```

**质量门禁：** 大纲需用户确认后才能进入写作阶段

### 3.2 阶段二：文献综述撰写

**目标：** 撰写 Introduction 及相关工作部分

```
步骤:
1. 用户提供研究背景关键词
2. 系统搜索相关文献（通过 paper-fetcher / Tavily 搜索）
3. 获取核心参考文献
4. 生成文献综述草稿
5. 用户审查并补充

指令示例:
"帮我写 Introduction 部分。我的研究背景是AI驱动的材料筛选，
需要引用5篇2025-2026年的最新文献，展示该领域的发展脉络。"
```

**注意事项：**
- 所有引用必须提供真实文献
- 系统会标注引用来源，用户需核实
- 建议使用 Zotero 进行引用管理

### 3.3 阶段三：方法部分撰写

**目标：** 清晰描述实验/计算方法

```
指令示例:
"我使用了 MP 数据集、CGCNN 模型架构、10折交叉验证。
请帮我写 Methods 部分，包含以下细节：[描述实验参数]"
```

### 3.4 阶段四：结果与讨论

**目标：** 分析数据、解释结果

```
指令示例:
"以下是我的实验结果表格：[数据]。请帮我分析结果趋势，
并与 Zhang et al. (2025) 的工作进行对比。"
```

### 3.5 阶段五：语言润色

**目标：** 提升语言质量（英文学术写作）

```
指令示例:
"以下是我的论文段落，请进行学术英语润色。保持学术严谨风格，
被动语态更佳：[粘贴段落]"

常用润色模式:
1. 学术风格润色（标准模式）
2. 紧凑精炼（字数限制）
3. 简化表达（适合非母语读者）
4. 期刊特定风格（按投稿指南调整）
```

### 3.6 阶段六：格式输出

**目标：** 生成目标期刊格式

```
指令示例:
"请将我的论文转换为 ACS 期刊格式，包括标题页、摘要、
关键词、参考文献格式。"
```

## 6. 质量标准

### 6.1 输出检查清单

- [ ] 语言通顺无误（语法、拼写、标点）
- [ ] 引用链接真实可用
- [ ] 无事实性错误（数据、单位、公式）
- [ ] 符合目标期刊格式要求
- [ ] 图表引用正确
- [ ] 无抄袭或过度引用（合理原创度）

### 6.2 常见问题处理

| 问题 | 对策 |
|------|------|
| 模型生成内容与事实不符 | 人工核实关键数据和引用 |
| 语言过于AI化（空洞、重复） | 缩小范围，提供更多上下文 |
| 引用格式不一致 | 使用 Zotero 统一管理 |
| 篇幅超标/不足 | 二次精炼指令调整 |

## 7. 高级技巧

### 7.1 利用上下文记忆

在同一个会话内，系统会记住之前的对话内容，可以实现长文档的连贯写作：

```
"基于我刚才提供的 Introduction 内容，继续写 Results and Discussion 部分，
重点关注图3和图4的趋势分析。"
```

### 7.2 分章节提交

对于长论文（10页以上），建议分章节提交而不是一次性全文：

```
Session 1: Title + Abstract
Session 2: Introduction + Related Work
Session 3: Methods
Session 4: Results
Session 5: Discussion + Conclusion
Session 6: References + Supplementary
```

### 7.3 新用户提示

对于首次使用 AI 辅助写作的用户，建议从少量内容开始（200-300词段落），逐步适应后再进行全篇撰写。
