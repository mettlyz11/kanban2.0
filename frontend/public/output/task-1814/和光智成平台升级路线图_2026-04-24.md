# 和光智成AISF平台升级路线图

**日期：2026年4月24日**  
**任务编号：#1814**  
**规划周期：2026-2030（5年）**

---

## 一、战略愿景

**目标**：用5年时间，将和光智成从"AI计算驱动的材料发现平台"升级为"中国首个材料科学AI工厂（AISF for Materials）"，实现材料研发效率10倍提升。

**核心理念**：
> 不追求复制Lila的"大而全"（生命+化学+材料三领域），而是聚焦材料科学单点突破，做"小而精、专而深"的中国版AISF，建立在材料科学领域的相对优势。

---

## 二、总体路线图概览

| 阶段 | 时间 | 主题 | 核心目标 | 成熟度目标 |
|------|------|------|----------|-----------|
| **第一阶段** | 2026.05-2027.06 | 基础能力建设期 | 建成最小化自动化实验闭环 | L2→L3 |
| **第二阶段** | 2027.07-2028.12 | 能力全面升级期 | AI自主设计+自动化执行完整闭环 | L3→L4 |
| **第三阶段** | 2029.01-2030.06 | 平台化扩展期 | 开放AISF平台，建立生态 | L4 |

## 三、分阶段详细规划

### 第一阶段：基础能力建设期（2026.05-2027.06，14个月）

#### 3.1 核心目标
- 建成和光首个**最小化自动化材料实验室（Mini-AISF）**
- 实现至少1类材料体系（如催化剂/合金）的实验半自动化
- 初步形成"数据采集→模型更新"的自动化闭环

#### 3.2 关键里程碑（按季度）

**Q3 2026（5-7月）：启动与招聘**
- [ ] 招聘自动化实验室负责人（1人，有化学/材料自动化经验优先）
- [ ] 招聘机器人/自动化工程师（2-3人）
- [ ] 完成Mini-AISF需求调研与方案设计
- [ ] 选定1-2个重点材料体系作为试点（如CO₂还原催化剂）

**Q4 2026（8-10月）：采购与建设**
- [ ] 完成核心仪器设备采购（液体处理机器人、合成工作站、表征仪器）
- [ ] 选定实验室场地（建议北京/上海，靠近高校/产业集群）
- [ ] AI团队启动"实验设计辅助模块"开发
- [ ] 数据团队设计实时数据采集管道

**Q1 2027（11月-1月）：集成与调试**
- [ ] 实验室硬件安装与调试完成
- [ ] 实现仪器联网与数据自动采集
- [ ] "实验设计辅助模块"上线测试
- [ ] 首批自动化合成实验验证

**Q2 2027（2-4月）：验证与优化**
- [ ] 完成100+自动化实验，验证流程稳定性
- [ ] 实验数据自动回哺模型功能上线
- [ ] 迭代优化自动化流程，成功率达到85%+
- [ ] 第一阶段成果验收与总结

#### 3.3 投资预算估算
- **人员成本**：自动化团队5人×14个月 ≈ 350万
- **设备采购**：小型自动化合成+表征系统 ≈ 800-1200万
- **场地与运维**：实验室租金+耗材 ≈ 150万
- **软件开发**：AI+数据团队投入 ≈ 200万
- **合计**：约1500-1900万人民币

#### 3.4 成功指标
- ✅ 自动化实验成功率 ≥ 85%
- ✅ 单周实验通量 ≥ 人类团队的2倍
- ✅ 数据从产生到进入模型的时间 ≤ 24小时
- ✅ 至少1项材料性能优化成果由AI辅助设计完成

---

### 第二阶段：能力全面升级期（2027.07-2028.12，18个月）

#### 3.1 核心目标
- AI从"辅助设计"升级为"自主设计实验"
- 扩展自动化能力覆盖3-5类材料体系
- 商业模式升级为"服务+里程碑分成"模式
- 组织完成跨学科融合转型

#### 3.2 关键里程碑

**Q3 2027（7-9月）：AI能力升级**
- [ ] "实验自主设计模块"上线，AI可独立生成完整实验方案
- [ ] 引入生成式科学模型，具备假设生成能力
- [ ] 建设材料科学知识图谱，支持跨子领域推理

**Q4 2027（10-12月）：自动化扩展**
- [ ] 实验室二期扩建，增加3-5个机器人工作站
- [ ] 新增2-3类材料体系的自动化流程
- [ ] 样品自动化存储与追溯系统上线
- [ ] 7×24小时无人值守实验验证

**Q1 2028（1-3月）：商业模式升级**
- [ ] 与1-2家龙头材料企业签署"里程碑+royalty"合作协议
- [ ] 设立"高潜力发现"专项基金，探索内部孵化机制
- [ ] IP战略启动，建立专利挖掘与布局流程

**Q2 2028（4-6月）：组织与流程**
- [ ] 成立跨学科敏捷小组（AI+材料+自动化），同地协作
- [ ] 实施"AI协作科学家"计划，培训科学家与AI协作
- [ ] 建立每周创意评审会机制，筛选AI高潜力方向
- [ ] 自动化率达到50%以上

**Q3-Q4 2028（7-12月）：能力深化**
- [ ] AI自主迭代实验循环跑通，人工仅做战略把关
- [ ] 完成与2-3所顶尖高校的联合实验室建设
- [ ] 平台对外合作项目达到10个以上
- [ ] 累计专利申请量达到50+件

#### 3.3 投资预算估算
- **实验室扩建**：新增工作站+仪器 ≈ 2000-2500万
- **AI研发投入**：生成式模型+知识图谱 ≈ 800万
- **团队扩张**：自动化团队扩至15人，AI团队扩编 ≈ 800万
- **市场与生态**：战略合作+高校合作 ≈ 300万
- **合计**：约3900-4400万人民币

#### 3.4 成功指标
- ✅ AI自主设计并执行的实验占比 ≥ 50%
- ✅ 实验通量达到人类团队的5倍以上
- ✅ 里程碑合作项目合同额 ≥ 5000万
- ✅ 跨学科团队协作模式常态化运行

### 第三阶段：平台化扩展期（2029.01-2030.06，18个月）

#### 3.1 核心目标
- AISF平台向外部合作伙伴开放
- 建立"和光AISF生态"，吸引中小企业客户
- 验证PaaS商业模式，实现规模化增长
- 首个内部孵化项目分拆成功

#### 3.2 关键里程碑

**Q1-Q2 2029：平台准备**
- [ ] AISF平台多租户架构开发完成
- [ ] 合作伙伴访问控制系统上线
- [ ] 设计PaaS定价策略（订阅+按实验量计费）
- [ ] 首批5家试点合作伙伴接入

**Q3-Q4 2029：生态扩展**
- [ ] 举办首届"AISF材料科学开发者大会"
- [ ] 合作伙伴数量达到20+家
- [ ] 设立"和光AISF加速器"，扶持创业团队
- [ ] 首个内部孵化项目完成天使轮融资独立分拆

**2030年上半年：规模化运营**
- [ ] PaaS收入占总收入比例达到30%
- [ ] 累计服务客户/合作伙伴达到50+
- [ ] 自动化实验室标准化方案成型，可复制
- [ ] 启动上海/深圳分中心规划

#### 3.3 成功指标
- ✅ 外部合作伙伴活跃数 ≥ 30家
- ✅ PaaS模式收入占比 ≥ 30%
- ✅ 成功分拆孵化1-2家子公司
- ✅ 平台专利累计 ≥ 150件

---

### 第四阶段：价值深化期（2030.07+）

#### 3.1 核心目标
- 成为中国材料科学AISF领域的绝对领导者
- IP运营成为重要收入来源
- 探索向相邻领域（如精细化工）延伸
- 具备挑战国际前沿（Lila等）的技术实力

#### 3.2 发展方向
1. **IP资产证券化**：建立专利运营基金，通过授权/诉讼/交叉许可实现IP价值变现
2. **领域横向拓展**：从材料科学向精细化工、制药CRO等相邻领域延伸
3. **国际化布局**：在新加坡/欧洲设立海外实验室，服务全球客户
4. **基础研究突破**：设立和光研究院，冲击材料科学领域的诺奖级成果

## 四、关键成功保障措施

### 4.1 组织保障
- **设立AISF专项领导小组**：CEO直接挂帅，CTO、首席科学家、新任命的自动化负责人组成核心决策小组
- **建立跨学科KPI体系**：不再单独考核AI准确率或实验成功率，而是考核"从目标到成果的端到端效率"
- **人才激励机制**：自动化团队享有与AI团队同等的激励权重，核心成员可参与孵化项目股权分配

### 4.2 资本保障
- **设立"和光AISF专项基金"**：在现有融资基础上，设立3-5亿专项发展基金，专门用于自动化实验室建设和早期项目孵化
- **引入战略投资方**：重点引进具有深科技孵化经验的投资机构，而非纯财务投资者
- **与政府产业基金合作**：争取北京/上海等地的新材料产业基金支持，降低资本压力

### 4.3 生态保障
- **高校战略合作**：与北航、清华、中科院等建立联合实验室，共享人才与设备
- **产业龙头共建**：与中石化、中芯国际、宁德时代等共建行业专属AISF
- **投资机构联动**：与红杉、高瓴、深创投等建立项目孵化合作，共同培育新材料创业公司

## 五、风险与应对策略

| 风险 | 概率 | 影响 | 应对策略 |
|------|------|------|----------|
| 自动化技术难度超预期，进度延期 | 中 | 高 | 分阶段建设，先做最小可行版本，不追求一步到位；引入外部自动化集成商合作 |
| 人才招聘困难，自动化团队组建慢 | 高 | 高 | 从制药CRO行业挖人（药明康德等已有自动化经验）；给予有竞争力的股权激励 |
| 资本需求大，后续融资跟不上 | 中 | 高 | 第一阶段控制投入规模，用结果验证融资；积极争取政府产业基金支持 |
| 商业模式验证失败，客户不愿付费 | 低 | 中 | 先从现有客户中找试点，用"基础服务费+成功分成"降低客户风险 |
| 与现有业务冲突，组织内部阻力 | 中 | 中 | 成立独立的AISF事业部，与现有业务线并行发展，成熟后逐步整合 |
