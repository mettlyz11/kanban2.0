## 二、接单规则

### 2.1 接单原则
1. **个人用户咨询**：通过知乎Live、在行等平台，全程平台托管付款，先付后服务
2. **企业咨询**：签订简版咨询协议，先付50%定金，服务完成后付尾款
3. **敏感行业回避**：涉及敏感军工、法律纠纷等领域不接单
4. **学生优惠**：在读博士生可申请5折优惠（限每月2名）

### 2.2 接单容量（每月上限）
| 类型 | 每月上限 |
|-----|---------|
| 30分钟快速答疑 | 不限 |
| 60分钟标准咨询 | ≤ 8次 |
| 2小时深度咨询 | ≤ 3次 |
| 企业项目制 | ≤ 2个 |
| 内训/演讲 | ≤ 2场 |

> 超出容量时，自动进入排期队列，等待下月档期

## 三、排期规则

### 3.1 可用时间窗口
| 时段 | 状态 |
|-----|------|
| 周一~周五 09:00~11:00 | ✅ 优先开放 |
| 周一~周五 14:00~16:00 | ✅ 开放 |
| 周六 10:00~12:00 | ✅ 有限开放（每月2次） |
| 晚间 / 节假日 | ❌ 原则上不接 |

### 3.2 预约流程
```
客户发起需求 → 沟通主题范围（15分钟免费沟通）→ 确认报价与时间 → 
客户付款 → 确认进入日历 → 准时开始咨询 → 交付成果（如适用）
```

### 3.3 取消与退款政策
| 情况 | 处理方式 |
|-----|---------|
| 客户提前48小时取消 | 全额退款 |
| 客户提前24小时取消 | 退款50% |
| 客户提前<24小时取消 | 不退款（可改期1次） |
| 专家取消 | 全额退款 + 补偿下次9折 |

## 四、发票与合规

- 个人用途咨询：可提供电子收据（个人经营或通过平台开票）
- 企业咨询：可通过和光智成公司开具增值税专用发票（6%或3%）
- 境外付款：支持Stripe、PayPal、电汇（USD/CNY）

---

## 五、服务承诺

✅ 咨询前：提供10~15分钟免费需求确认通话  
✅ 咨询中：全程录音（双方同意后）  
✅ 咨询后：关键结论整理为500字书面摘要（48小时内发送）  
✅ 后续：1次免费追问（文字，24小时内回复，限7天内）
