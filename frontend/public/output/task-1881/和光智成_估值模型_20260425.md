# 和光智成 Pre-A轮 估值模型

**模型版本**: v1.0  
**建模日期**: 2026年4月25日  
**估值区间**: 5.0 - 8.0亿元人民币  
**推荐估值**: 6.5亿元（投前）

---

## 一、模型框架

采用**五维度综合估值法**：

```
企业价值 = 基础估值 × 技术系数 × 市场系数 × 团队系数 × 阶段调整系数
```

---

## 四、综合估值计算

### 4.1 方法一：多维度综合法

```
基础估值 = 3.0亿元（Pre-A轮早期硬科技企业基准）

企业价值 = 3.0 × 1.096 × 1.092 × 1.103 × 1.038 × 1.10
         = 3.0 × 1.507
         = 4.52亿元（基础区间下限）
```

考虑**AI+新材料赛道溢价20%**（瑞德林等案例参考）：

```
调整后估值 = 4.52 × 1.20 = 5.42亿元
```

### 4.2 方法二：可比公司法

| 可比公司 | 融资轮次 | 估值 | 阶段 | PS/PE | 和光智成对标倍数 |
|----------|---------|------|------|-------|----------------|
| 中科国生 | A+轮 | 18亿 | 百吨级工厂 | - | 0.35x（阶段差） |
| 蓝晶微生物 | B4轮 | 累计20亿+ | 商业化初期 | - | 0.30x |
| 瑞德林生物 | C轮 | 50亿+ | 规模化 | - | 0.12x |
| 恩和生物 | B轮 | 50亿+ | 平台型 | - | 0.12x |

**可比估值区间 = 50亿 × (0.12-0.35) = 6.0 - 17.5亿元**

考虑阶段差异（Pre-A vs A-C轮），取**0.25-0.40x**调整：

```
可比法估值 = 50亿 × 0.13 = 6.5亿元（中值）
```

### 4.3 方法三：专利/技术资产法

| 资产类别 | 数量 | 单项估值 | 合计 |
|----------|------|---------|------|
| 核心发明专利（已授权/申请） | 5项 | 1500万/项 | 7500万 |
| AI模型/算法 | 3套 | 3000万/套 | 9000万 |
| 专有数据库 | 1个 | 5000万 | 5000万 |
| know-how/工艺包 | 2个 | 3000万/个 | 6000万 |
| **技术资产合计** | - | - | **2.75亿元** |

考虑技术资产溢价系数（市场机会+团队+阶段）：

```
估值 = 2.75 × 2.2 = 6.05亿元
```

### 4.4 方法四：风险投资阶段法

| 阶段 | 典型估值区间 | 和光智成匹配度 |
|------|-------------|--------------|
| 天使轮 | 1-3亿元 | 已超越 |
| Pre-A轮 | 3-8亿元 | **当前阶段** |
| A轮 | 5-15亿元 | 目标（2年后） |
| B轮 | 10-30亿元 | 远期目标 |

Pre-A轮（技术验证完成+MVP）典型估值：**5-8亿元**
