## 一、每日健康打卡模板

### 1.1 每日打卡表（CSV格式）

```csv
日期,星期,起床时间,入睡时间,睡眠时长,运动类型,运动时长,运动强度,早餐质量,午餐质量,晚餐质量,外卖次数,酒精摄入,咖啡因摄入,冥想时长,压力评分(1-10),血压_早_收缩,血压_早_舒张,血压_晚_收缩,血压_晚_舒张,体重,备注,完成率
2026-05-01,周四,,,,,,,,,,,,,,,,,,,,,
2026-05-02,周五,,,,,,,,,,,,,,,,,,,,,
2026-05-03,周六,,,,,,,,,,,,,,,,,,,,,
```

### 1.2 打卡说明

| 字段 | 填写说明 | 目标值 |
|------|----------|--------|
| 睡眠时长 | 小时 | ≥7小时 |
| 运动类型 | 有氧/力量/HIIT/休息 | 每周至少5天 |
| 运动时长 | 分钟 | 见方案 |
| 运动强度 | 低/中/高 | 中等为主 |
| 三餐质量 | 优/良/中/差 | 良以上 |
| 外卖次数 | 次/天 | ≤1次 |
| 酒精摄入 | 是/否+量 | 尽量不饮 |
| 咖啡因摄入 | 杯数 | ≤2杯/天 |
| 冥想时长 | 分钟 | ≥15分钟/天 |
| 压力评分 | 1-10分 | ≤5分 |
| 完成率 | 自动计算 | ≥85% |

### 1.3 每日打分标准

```
每日满分100分：
├── 睡眠：20分（7小时以上得满分）
├── 运动：25分（按计划完成得满分）
├── 饮食：25分（三餐质量+外卖控制）
├── 压力管理：15分（冥想+压力评分）
├── 监测数据：15分（血压+体重记录）
└── 额外加分：5分（超额完成运动/无外卖）
```

## 三、季度复查提醒机制

### 3.1 提醒时间轴

```
2026-05-01 → 方案启动日
    ↓
每周末 → 周度回顾（5分钟）
    ↓
每月最后一天 → 月度总结（30分钟）
    ↓
2026-07-26（提前5天）→ 复查预约提醒
    ↓
2026-07-31 → 季度复查日
    ↓
2026-08-05 → 报告解读+下季度方案调整
```

### 3.2 复查项目清单

| 类别 | 必查项目 | 可选项目 |
|------|----------|----------|
| 血液 | 血脂四项、空腹血糖、HbA1c、同型半胱氨酸、尿酸、肝肾功能 | hs-CRP、脂蛋白(a) |
| 心脏 | 心电图、血压监测 | 心脏超声、运动平板 |
| 血管 | 颈动脉超声 | 脉搏波传导速度 |
| 生活方式 | 3个月打卡数据分析 | 运动心肺功能测试 |

### 3.3 自动提醒设置

- **Apple提醒事项**：设置季度复查重复提醒
- **日历事件**：预约复查后添加到日历
- **本系统**：每完成一个月自动提示进度
