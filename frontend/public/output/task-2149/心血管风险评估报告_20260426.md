# 45岁男性创业者心血管风险评估报告（2026年4月）
## 一、基础风险因子基准（参考中国45岁男性健康人群标准）
| 指标 | 中国健康男性基准值 | 风险阈值 |
|------|------------------|----------|
| 静息收缩压 | <120mmHg | ≥140mmHg为高风险 |
| 总胆固醇 | <5.2mmol/L | ≥6.2mmol/L为高风险 |
| 低密度脂蛋白LDL | <3.4mmol/L | ≥4.1mmol/L为高风险 |
| 空腹血糖 | <5.6mmol/L | ≥7.0mmol/L为高风险 |
| 同型半胱氨酸 | <15μmol/L | ≥20μmol/L为高风险 |
| BMI | 18.5-23.9 | ≥28为肥胖高风险 |

## 二、Framingham 10年心血管风险评估模型
### 评分规则（男性）：
1. 年龄：45岁得3分
2. 收缩压：120-129mmHg得1分，≥140得3分
3. 总胆固醇≥5.2mmol/L得2分
4. 吸烟得2分
5. 糖尿病得3分
### 风险分层：
- <10分：低风险（<10%发病概率）
- 10-15分：中风险（10-20%发病概率）
- ≥16分：高风险（>20%发病概率）

## 三、初步评估结论
针对创业者高压工作特性（久坐、长期压力、作息不规律），默认属于中风险基线，需通过干预将风险降至低风险区间。
