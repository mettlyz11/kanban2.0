## 一、项目概述

基于 Tavily Research 2026年结果，主流Agent调度系统普遍采用"幂等性设计 + 频率限制 + 去重校验"三层保障机制。本项目为SDS（Smart Decision System）调度系统实现了完整的三层保障架构，确保任务生成的可控性和可靠性。

## 二、核心交付物

### 2.1 频率限制模块
- **文件**: `sds/core/rate_limit_v43.py`
- **功能**: 每目标(goal_id)每24小时最多生成2个任务
- **附加功能**: pending任务水位控制（每目标最多3个）
- **实现方式**: 滑动窗口计数，精确到秒，基于数据库tasks表查询

### 2.2 语义去重算法
- **文件**: `sds/core/task_generation_guard_v46.py` (SemanticDedupLayer)
- **双层去重策略**:
  - 第一层：标题前15字快速匹配（LIKE查询）
  - 第二层：Levenshtein距离语义相似度计算
- **阈值**: 相似度≥0.85判定为重复
- **文本标准化**: 去除标点、空格、大小写差异

### 2.3 幂等性保障
- **文件**: `sds/core/task_generation_guard_v46.py` (IdempotencyLayer)
- **幂等键生成**: SHA-256哈希，基于标题+目标ID+描述前缀
- **检查机制**: 本地日志文件持久化存储 + 内存检查
- **清理策略**: 支持30天过期日志自动清理

### 2.4 集成协调器
- **文件**: `sds/core/task_generation_guard_v46.py` (TaskGenerationGuard)
- **三层协同**: 幂等性 → 频率限制 → 语义去重，逐层拦截
- **安全插入**: `create_task_safely()` 方法实现检查+创建原子操作
- **批量过滤**: `filter_recommendations()` 支持批量推荐任务过滤

### 3.3 关键边界场景覆盖

1. **频率限制边界**:
   - 当前数量=最大值（应拦截）
   - 当前数量=最大值-1（应允许）
   - max_tasks=0（永远拦截）
   - 极大窗口时间（168小时）

2. **语义去重边界**:
   - 恰好0.85阈值的字符串
   - 刚好高于/低于阈值的字符串
   - 1000字符超长字符串
   - 仅特殊字符/仅空格标题
   - Unicode字符（中文、日文）

3. **幂等性边界**:
   - 空标题键生成
   - None值处理
   - 首尾空格去除
   - 超长描述截断（100字）
   - 并发键生成一致性

## 六、使用方式

# 初始化守卫
guard = TaskGenerationGuard()

# 检查单个任务

    # 安全创建任务
