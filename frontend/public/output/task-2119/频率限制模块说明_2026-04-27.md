# 频率限制模块说明文档

**任务**: #2119  
**日期**: 2026-04-27  
**版本**: V4.6

## 模块位置

- `sds/modules/task_rate_limiter.py`
- `sds/core/rate_limit_v43.py`

## 核心功能

为 SDS 调度系统任务生成模块添加生成频率限制，防止同一目标在短时间内产生过多自动任务。

### 限制规则

1. **24小时窗口限制**: 每 `goal_id` / `project_id` 每 24 小时最多生成 **2 个** `auto_generated` 类型任务
2. **Pending 水位限制**: 每目标当前 `pending` 状态任务最多 **3 个**
3. 两个条件必须同时满足，任务才能被生成

### 关键类与方法

#### `TaskRateLimiter` (modules/task_rate_limiter.py)

```python
class TaskRateLimiter:
    DEFAULT_MAX_TASKS_PER_24H = 2
    DEFAULT_WINDOW_HOURS = 24

    def check_rate_limit(self, project_id: int) -> Tuple[bool, Dict]:
        """检查指定目标是否超出24小时频率限制"""

    def check_batch_rate_limit(self, project_ids: list) -> Dict[int, Tuple[bool, Dict]]:
        """批量检查多个目标的频率限制"""

    def get_all_targets_status(self) -> list:
        """获取所有目标的频率限制状态"""
```

#### `RateLimitLayerV43` (core/rate_limit_v43.py)

```python
class RateLimitLayerV43:
    def check_rate_limit(self, goal_id: int) -> Dict:
        """24小时滑动窗口计数"""

    def check_pending_watermark(self, goal_id: int) -> Dict:
        """pending任务水位检查"""

    def check_all(self, goal_id: int) -> RateLimitDecision:
        """组合检查（频率+水位），返回决策对象"""

    def get_audit_stats(self, hours: int = 24) -> Dict:
        """审计统计：各目标生成/完成/阻塞数量"""
```

### 决策返回结构

```json
{
  "can_generate": true,
  "current_count": 1,
  "max_allowed": 2,
  "remaining_slots": 1,
  "window_hours": 24,
  "window_start": "2026-04-26T04:00:00",
  "goal_id": 1,
  "check_type": "rate_limit"
}
```

### 配置参数

| 参数 | 默认值 | 说明 |
|------|--------|------|
| `max_tasks_per_24h` | 2 | 每24小时最大生成任务数 |
| `max_pending_per_goal` | 3 | 每目标最大pending任务数 |
| `window_hours` | 24 | 滑动窗口小时数 |

### 使用示例

```python
from sds.modules.task_rate_limiter import TaskRateLimiter

limiter = TaskRateLimiter(max_tasks=2, window_hours=24)
allowed, info = limiter.check_rate_limit(project_id=1)

if allowed:
    print(f"允许生成，当前 {info['current_count']}/{info['max_allowed']}")
else:
    print(f"已超限，下次可生成: {info.get('next_available')}")
```
