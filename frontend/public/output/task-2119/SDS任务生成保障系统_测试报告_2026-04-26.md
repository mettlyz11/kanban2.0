## 三、模块详细说明

### 3.1 频率限制器 (TaskRateLimiter)

**功能**: 为每个目标(project_id)设置频率限制，防止任务泛滥。

**核心参数**:
- `max_tasks`: 每窗口最大任务数，默认2
- `window_hours`: 时间窗口（小时），默认24

**工作原理**:
1. 以当前时间为基准，回溯24小时作为时间窗口
2. 查询该窗口内自动生成的任务数量
3. 若数量 ≥ max_tasks，则拒绝新任务生成
4. 返回详细的允许/拒绝信息及下次可生成时间

**接口**:
```python
limiter = TaskRateLimiter(max_tasks=2, window_hours=24)
allowed, info = limiter.check_rate_limit(project_id=80)
# info包含: allowed, project_id, current_count, max_allowed,
#          window_hours, window_start, remaining, next_available
```

### 3.2 语义去重器 (SemanticDeduplicator)

**功能**: 基于标题语义相似度防止重复任务生成，采用双层去重策略。

**核心参数**:
- `prefix_length`: 标题前缀匹配长度，默认15
- `similarity_threshold`: 语义相似度阈值，默认0.85（0-1之间）

**双层去重策略**:
1. **第一层 - 前缀快速匹配**: 使用SQL LIKE查询标题前缀相同的已有任务
2. **第二层 - 语义相似度精算**: 对候选任务计算Levenshtein编辑距离，转换为相似度分数

**相似度计算**:
- 使用纯Python实现的Levenshtein编辑距离算法
- 空间复杂度优化至O(min(m,n))
- 相似度 = 1 - (编辑距离 / 最大长度)
- 文本标准化：去除标点、转小写，保留中英文和数字

**接口**:
```python
dedup = SemanticDeduplicator(prefix_length=15, similarity_threshold=0.85)
is_dup, info = dedup.is_duplicate("T1: 法务纠纷处理 - 证据清单整理")
# info包含: is_duplicate, new_title, prefix_length, similarity_threshold,
#          prefix_matches, semantic_matches, matched_tasks
```

### 3.3 幂等性保障器 (IdempotencyGuard)

**功能**: 确保同一任务请求不会产生重复执行，保障幂等性。

**核心机制**:
1. **幂等性键生成**: 基于标题+项目ID+描述前缀生成确定性SHA-256哈希（前16位）
2. **本地日志记录**: 记录已执行的幂等性键，防止重复
3. **三重保障安全插入**: 幂等性检查 → 频率限制 → 语义去重 → 安全插入

**接口**:
```python
guard = IdempotencyGuard()
success, result = guard.safe_insert(
    title="T2: 和光智成商业化 - AI融资BP更新",
    description="更新商业计划书...",
    project_id=76,
    priority=2,
    execution_mode='auto'
)
```

**三重保障流程**:
1. **幂等性检查**: 相同输入是否已生成过任务
2. **频率限制**: 该目标是否超出24小时任务数上限
3. **语义去重**: 新任务标题是否与已有任务高度相似
4. 通过所有检查 → 安全插入数据库 + 记录幂等性

## 五、已知限制

1. **数据库依赖**: 去重检查和频率限制需要数据库连接，无DB连接时仅验证算法层
2. **Levenshtein复杂度**: O(m×n)时间复杂度，对超长标题（>500字）可能较慢
3. **本地幂等日志**: 使用JSONL文件存储，单机部署适用，分布式部署需改用Redis/DB

## 六、使用建议

### 6.1 推荐调用方式
```python
from sds.task_idempotency import IdempotencyGuard

guard = IdempotencyGuard()
success, result = guard.safe_insert(
    title="新任务标题",
    description="任务描述...",
    project_id=75,
    priority=2,
    execution_mode='auto'
)

if success:
    print(f"任务已插入，ID={result['task_id']}")
else:
    print(f"任务被拦截: {result['reason']}")
```

### 6.2 单独使用各模块

from sds.task_rate_limiter import TaskRateLimiter
