# SDS任务生成频率限制模块 V4.6

## 概述
基于Tavily Research 2026年结果和OpenAI Swarm框架最佳实践，为SDS调度系统任务生成模块实现频率限制机制。

## 核心功能

### 1. 滑动窗口频率限制
- **每目标(goal_id)每24小时最多2个任务**
- 精确到秒的滑动窗口计数
- 查询数据库中 `task_type LIKE 'auto_generated%'` 且 `created_at >= NOW() - INTERVAL 24 HOUR` 的任务数量

### 2. Pending水位控制
- **每目标最多3个pending任务**
- 防止任务积压导致系统过载
- 当pending任务达到上限时暂停新任务生成

### 3. 批量检查
- 支持批量检查多个目标的频率限制状态
- 返回详细的限制信息（当前数量、最大允许、剩余槽位、下次可生成时间）

## 配置参数

| 参数 | 默认值 | 说明 |
|------|--------|------|
| max_tasks_per_24h | 2 | 每24小时最大任务数 |
| max_pending_per_goal | 3 | 每目标最大pending任务数 |
| window_hours | 24 | 滑动窗口小时数 |

## 使用方式

```python
from core.task_generation_guard_v46 import RateLimitLayer

# 初始化
limiter = RateLimitLayer(max_tasks=2, max_pending=3)

# 检查单一目标
result = limiter.check_all(goal_id=1)
# result['can_generate'] = True/False
# result['blocked_reason'] = 拦截原因（如果有）
```

## 文件位置
- `sds/core/task_generation_guard_v46.py` - RateLimitLayer 类
- `sds/modules/task_rate_limiter.py` - 独立频率限制器模块
