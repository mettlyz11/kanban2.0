## 一、Research依据

基于 Tavily Research 2026年调研结果，主流多Agent调度系统（包括OpenAI Swarm框架）普遍采用以下三层保障机制：

1. **频率限制 (Rate Limiting)** - 防止单目标任务泛滥
2. **语义去重 (Semantic Deduplication)** - 防止重复任务生成
3. **幂等性保障 (Idempotency)** - 确保同一请求不会重复执行

---

## 二、实现模块

### 2.1 频率限制模块 (task_rate_limiter.py)

**核心功能**:
- 每目标(project_id)每24小时最多生成 **2个任务**
- 支持自定义窗口时间和最大任务数
- 提供批量检查能力
- 计算下次可生成时间

**关键类**: `TaskRateLimiter`
- `check_rate_limit(project_id)` - 单目标频率检查
- `check_batch_rate_limit(project_ids)` - 批量检查
- `get_all_targets_status()` - 全目标状态概览

**配置项**:
```python
DEFAULT_MAX_TASKS_PER_24H = 2
DEFAULT_WINDOW_HOURS = 24
```

### 2.2 语义去重算法 (task_dedup.py)

**核心功能**:
- **第一层 - 前缀快速匹配**: 标题前15字相同即触发候选
- **第二层 - 语义相似度精算**: Levenshtein编辑距离 → 相似度分数
- **阈值判断**: 相似度 ≥ 0.85 判定为重复
- **文本标准化**: 去除标点、空格、大小写差异

**关键类**: `SemanticDeduplicator`
- `prefix_match(title)` - 前缀匹配候选
- `semantic_check(title, scope_project_id)` - 语义相似度计算
- `is_duplicate(title, scope_project_id)` - 综合去重判断
- `batch_check(titles)` - 批量去重

**算法细节**:
- 使用优化版Levenshtein DP算法，空间复杂度 O(min(m,n))
- 支持中英文混合、Unicode字符
- 同时计算标准化文本和原始文本相似度，取较高值

### 2.3 幂等性保障模块 (task_idempotency.py)

**核心功能**:
- 基于标题+项目ID+描述前缀生成确定性SHA-256哈希键
- 本地日志文件持久化已执行任务
- 三重保障协同：幂等性 → 频率限制 → 语义去重

**关键类**: `IdempotencyGuard`
- `generate_idempotency_key(title, project_id, description_prefix)` - 生成16位幂等键
- `check_idempotency(key)` - 检查键是否已存在
- `record_execution(key, task_id, title, project_id)` - 记录执行
- `safe_insert(...)` - 三重保障安全插入入口

**幂等键生成规则**:
```python
key_data = json.dumps({
    'title': title.strip(),
    'project_id': project_id,
    'desc_prefix': description_prefix[:100].strip(),
}, ensure_ascii=False, sort_keys=True)
# SHA-256前16位
```

### 2.4 集成协调器 (core/task_generation_guard_v46.py)

**三层协同决策流程**:
1. **幂等性检查** → BLOCKED_IDEMPOTENT
2. **频率限制检查** → BLOCKED_RATE_LIMIT
3. **语义去重检查** → BLOCKED_DUPLICATE
4. **全部通过** → ALLOWED

## 五、部署建议

1. 任务生成模块调用 `IdempotencyGuard.safe_insert()` 作为统一入口
2. 定期执行 `cleanup_old_logs(days=30)` 清理过期幂等日志
3. 监控频率限制拦截率，必要时调整各目标的例外配置
4. 语义去重阈值可根据业务需求动态调整（默认0.85）
