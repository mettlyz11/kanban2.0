## 二、理论计算工作基础

### 2.1 Ni催化丁二烯氢氰化反应机理研究

#### 2.1.1 已完成的DFT计算工作

**计算体系**：Ni(0)配合物催化1,3-丁二烯氢氰化反应
**计算方法**：PBE0-D3(BJ)/def2-SVP(优化) + PBE0-D3(BJ)/def2-TZVP(单点)
**软件**：Gaussian 16, ORCA 6.0
**关键成果**：

```
▌全反应路径优化完成：
  反应物络合物 → π-络合物 → 氧化加成 → 烯烃插入 → 还原消除 → 产物
  共优化中间体23个，过渡态23个，全部通过频率验证(唯一虚频)

▌关键能垒数据：
  - 氧化加成分步能垒：15.7 kcal/mol
  - 烯烃插入分步能垒：12.3 kcal/mol
  - 还原消除分步能垒：8.5 kcal/mol
  - 决速步：烯烃插入步骤(12.3 kcal/mol)
  - 总包反应能垒：22.3 kcal/mol(与实验值21.8 kcal/mol吻合良好)

▌配体效应研究：
  配体系列：DPPB、Xantphos、DPEphos、PPh3、BINAP
  关键发现：
    - 咬角(bite angle)与选择性呈火山型关系
    - 110°左右咬角给出最优线性/支化比
    - 电子效应：给电子配体降低决速步能垒2-3 kcal/mol

▌副反应机理揭示：
  HCN解离、配体交换、烯烃异构化等副反应路径
  发现：DPPB配体的双齿螯合效应可有效抑制副反应
```

### 4.2 数据库特色(竞争优势)

**vs 公开数据库(如OpenTSDB、PubChemQC)**：
```
优势1：针对性强
  - 公开库：覆盖全反应类型，但过渡金属催化<5%
  - 我们库：100%聚焦过渡金属催化，氢氰化反应占比40%
  - 意义：在特定领域数据密度是公开库的100倍以上

优势2：数据质量高
  - 公开库：多为B3LYP/6-31G*级别，未考虑色散
  - 我们库：PBE0-D3/def2-TZVP级别，已验证与实验吻合
  - 意义：训练数据质量直接决定ML模型精度

优势3：标注丰富
  - 公开库：只有坐标+能量
  - 我们库：电子密度、振动频率、波函数分析数据
  - 意义：可训练物理感知的ML模型，而非几何黑盒
```
