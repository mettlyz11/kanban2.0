## 第一页：封面摘要（Executive Summary）

和光智成是**北航背书的 AI 材料发现与自动化实验一体化平台**，致力于将传统材料研发周期从数年压缩至数周。公司由北京航空航天大学化学学院教授刘宇宙创立，融合大语言模型、高通量计算与自动化实验，面向新能源、半导体、航天等高端制造领域提供材料智能化研发解决方案。

**核心亮点：**
- 北航顶尖学术资源 + 工程化落地能力
- AI 材料发现平台（自研大模型 + 知识图谱）
- 自动化实验闭环（机器人合成 + 高通量表征）
- 已有标杆客户合作意向

---

## 第二页：问题与机遇

### 材料研发的痛点
1. **周期长**：传统新材料从发现到产业化平均 10–20 年
2. **成本高**：研发试错成本占制造业创新支出 30% 以上
3. **人才短缺**：高端材料科学家供给严重不足

### 市场机遇
- **全球生成式 AI 材料市场**：2034 年达 **117 亿美元**，CAGR ~35%
- **中国 AI 材料市场**：CAGR **31.2%**，政策驱动（新质生产力、制造强国）
- **国产替代**：高端材料卡脖子问题推动自主创新需求爆发

### 和光智成一体化平台

```
[材料大模型] → [高通量计算筛选] → [自动化合成机器人] → [高通量表征] → [AI优化闭环]
```

**三大核心模块：**
1. **MatGen-LLM**：材料生成大模型，支持新型晶体结构预测与性质优化

## 第六页：商业模式

### 四大收入来源

```
1. 平台订阅（SaaS）      → 材料企业 / 科研院所年费制
2. 研发服务（项目制）    → 定制化材料发现与优化
3. 数据授权              → 高质量材料数据集 API 授权
4. 联合研发（战略合作）  → 与头部制造企业共同研发，利润分成
```

### 定价策略
- 基础订阅：20 万/年起
- 项目制：100–500 万/项目
- 数据 API：5–50 万/年（按用量）

   - 目标客户：中航工业、航天科工、商飞
