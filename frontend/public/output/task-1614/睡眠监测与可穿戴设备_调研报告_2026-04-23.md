## 一、睡眠质量的核心指标

根据 Sleep Foundation 及多项临床研究，睡眠质量主要由以下指标衡量：

| 指标 | 说明 | 健康范围 |
|------|------|----------|
| **入睡潜伏期** | 从躺下到入睡所需时间 | 15-20分钟 |
| **睡眠效率** | 实际睡眠时间 / 卧床时间 | ≥85% |
| **入睡后清醒时间 (WASO)** | 入睡后累计清醒时间 | <30分钟 |
| **睡眠周期完整性** | 完整的90分钟周期数 | 4-6个/晚 |
| **深睡比例 (N3)** | 慢波睡眠占总睡眠比例 | 15-25% |
| **REM睡眠比例** | 快速眼动睡眠占比 | 20-25% |
| **总睡眠时间** | 整夜累计睡眠时长 | 7-9小时（成人） |

## 二、主流睡眠监测设备对比

### 2.1 Oura Ring 4（智能戒指）

- **价格**：$349-$499 + $5.99/月订阅费
- **平台**：iOS, Android, Windows 兼容
- **核心优势**：
  - 睡眠追踪精度最高（多项研究验证）
  - 提供综合睡眠质量评分
  - 佩戴舒适度远超手表，夜间无感
  - 详细的健康数据可视化
  - 心率变异性(HRV)、体温趋势、血氧监测
- **局限**：需付费订阅才能获取完整数据；无睡眠呼吸暂停检测
- **适用人群**：追求精准睡眠数据、希望长期追踪的用户

### 2.2 Apple Watch Series 10/11

- **价格**：$399起（铝壳），$699起（钛壳）
- **平台**：仅 iOS
- **核心优势**：
  - 新增睡眠呼吸暂停检测功能
  - 新增睡眠评分功能（2024年更新）
  - 生态整合度高（与iPhone/Apple Health深度集成）
  - 无额外订阅费用
  - 日间活动追踪能力强
- **局限**：佩戴睡觉舒适度一般；睡眠数据深度不如Oura Ring
- **适用人群**：已有Apple生态、希望同时管理日间运动和夜间睡眠

## 三、可穿戴设备数据在睡眠医学中的应用

根据多项研究（Berryhill 2020; Glazer Baron 2022; Bensen-Boakes 2023）：

### 3.1 有效性证据

- **行为睡眠医学**：可穿戴设备数据已成功用于CBT-I（认知行为治疗-失眠）的辅助治疗
- **可穿戴设备干预**：Berryhill等人(2020)的随机交叉试验证明可穿戴设备对健康个体睡眠有积极影响
- **AI睡眠教练**：Liu等人研究显示，基于实时数据的AI睡眠教练在30天内可将整体睡眠效率提升20%

### 3.2 客观测量 vs 主观报告

- Cudney等人(2022)综述指出：客观睡眠测量与自我报告睡眠质量之间存在差异
- 建议：**同时使用设备数据 + 主观睡眠日记**，交叉验证

- **月成本**：$5.99
- **适合**：预算允许、希望全方位健康监测

## 五、睡眠监测关键指标追踪建议

建议每日/每周跟踪以下核心指标：

### 每日记录（设备自动采集）
1. 入睡时间 & 起床时间
2. 总睡眠时长
3. 深睡/浅睡/REM比例
4. HRV（心率变异性）趋势
5. 静息心率
6. 夜间体温变化

### 每日自评（主观）
1. 主观睡眠质量评分（1-10分）
2. 次日白天精神状态评分（1-10分）
3. 午间精力低谷时间

### 每周分析
1. 睡眠规律性（入睡/起床时间波动）
2. 深睡比例趋势
3. 夜间清醒次数趋势
4. HRV周平均值趋势
