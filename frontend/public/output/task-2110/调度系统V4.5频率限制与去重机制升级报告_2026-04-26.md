### 2.1 核心模块实现

#### 模块1: `core/rate_limiter_v45.py` - 频率限制核心
**新增功能**:
- ✅ `RateLimitConfig` - 可配置的频率限制参数
- ✅ `TaskGenerationAuditLog` - 任务生成审计日志（数据库持久化）
- ✅ `RateLimitChecker` - 频率限制检查器

  - 支持例外目标配置
- ✅ `TitlePrefixDeduplicator` - 标题前缀去重器

  - 支持历史重复 + 同批次重复检测

### 2.2 关键技术实现

#### 频率限制算法
```python
# 滑动窗口计数
SELECT COUNT(*) 
FROM task_generation_audit 
WHERE goal_id = ? 
  AND generated_at > NOW() - INTERVAL 24 HOUR
  AND passed_all_checks = TRUE
```

#### 去重算法
```python
# 1. 前缀精确匹配
LEFT(title, 15) = @prefix

# 2. 同批次交叉检测
other_titles[...][:15] == title[:15]

# 3. 语义相似度（V4.6增强）
Levenshtein距离 + 标准化文本比较
相似度阈值: 0.85
```

#### Pending水位控制
```python
# 每目标最多3个pending任务
MAX_PENDING_PER_GOAL = 3
```

### 3.2 审计日志表结构
```sql
CREATE TABLE task_generation_audit (
    id INT AUTO_INCREMENT PRIMARY KEY,
    generation_batch_id VARCHAR(64),
    goal_id INT,
    task_id INT,
    task_title VARCHAR(500),
    title_prefix VARCHAR(50),
    generation_reason TEXT,
    rate_limit_check JSON,
    deduplication_check JSON,
    passed_all_checks BOOLEAN,
    blocked_reason VARCHAR(500),
    quality_score DECIMAL(5,3),
    generated_at DATETIME DEFAULT CURRENT_TIMESTAMP,
    INDEX idx_goal_time (goal_id, generated_at),
    INDEX idx_prefix_time (title_prefix, generated_at),
    INDEX idx_batch_id (generation_batch_id)
)
```
