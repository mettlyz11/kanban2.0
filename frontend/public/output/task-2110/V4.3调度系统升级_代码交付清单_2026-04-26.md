### 检测到的核心问题
1. **81%的任务没有绑定project_id** - 系统生成了大量"孤儿任务"
2. **相同标题前缀重复生成** - 最高重复达13次
3. **缺乏审计追踪** - 无法追溯任务生成被拒绝的原因
4. **没有频率限制机制** - 无法防止过度生成

## 📋 数据库表结构

### 新增: `task_generation_audit` 审计表
```sql
CREATE TABLE task_generation_audit (
    id INT AUTO_INCREMENT PRIMARY KEY,
    title VARCHAR(500) NOT NULL DEFAULT '',
    title_prefix VARCHAR(15) NOT NULL DEFAULT '',
    project_id INT DEFAULT NULL,
    target_id INT DEFAULT NULL,
    accepted TINYINT(1) NOT NULL DEFAULT 0,
    reject_reasons TEXT,
    task_id INT DEFAULT NULL,
    logged_at DATETIME NOT NULL DEFAULT CURRENT_TIMESTAMP,
    INDEX idx_logged_at (logged_at),
    INDEX idx_accepted (accepted),
    INDEX idx_project_id (project_id)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4
```

## 🚀 使用方式

### 在调度器中集成 V4.3
```python
from scripts.v4.3.frequency_limiter import (
    FrequencyLimiter,
    TaskDeduplicator,
    GenerationAuditor,
    ensure_audit_table
)

# 1. 初始化
ensure_audit_table()
limiter = FrequencyLimiter()
deduplicator = TaskDeduplicator(limiter)
auditor = GenerationAuditor()

# 2. 生成任务前检查
result = deduplicator.check_all(task_title, project_id)

if result['pass']:
    # 创建任务
    task_id = create_new_task(...)
    auditor.log_generation_attempt(
        task_title, project_id, 
        accepted=True, task_id=task_id
    )
else:
    # 拒绝生成，记录原因
    auditor.log_generation_attempt(
        task_title, project_id,
        accepted=False, reject_reasons=result['reject_reasons']
    )
```
