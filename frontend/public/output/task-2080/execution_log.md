## 一、任务目标回顾

本任务目标为执行2026年Q2全球AI材料科学领域融资情报收集与分析，具体包括：

1. 收集2026年2月-4月期间该领域所有融资事件，筛选金额>1000万元的事件
2. 整理成结构化表格，包含公司名称、赛道方向、融资轮次、融资金额、投资方、成立时间、核心产品/技术、估值等
3. 分析当前AI材料领域的投资热点方向和估值变化趋势
4. 重点识别和光智成同类竞品的融资情况，对比优劣势
5. 识别潜在值得对接的战略投资者，标注建议
6. 产出完整的融资情报分析报告（不少于2000字）

## 二、执行方法与工具

### 2.1 数据收集工具

采用 Tavily Search API 进行全网信息检索，该工具具备以下优势：
- 支持高级搜索语法，可精准定位融资事件
- 具备自然语言理解能力，能自动提取关键信息
- 覆盖全球主流财经媒体、公司官网、投资机构公告
- 支持中文检索，适配国内融资信息获取

### 2.2 检索策略设计

采用多轮递进式检索策略：

**第一轮：广度检索**
- 检索关键词："AI材料科学 融资 2026年2月 3月 4月"
- 检索关键词："人工智能 新材料 投融资 超过1000万"
- 目的：获取该时间段内的整体融资概况，识别主要融资事件

**第二轮：深度聚焦检索**
- 检索关键词："AI for Science 材料科学 融资 2026年 深势科技 晶泰科技 分子模拟"
- 检索关键词："AI材料研发公司 融资 2026 和光智成 新研智材 迈高科技"
- 目的：聚焦国内代表性企业，获取竞品详细信息

**第三轮：特定公司定向检索**
- 针对Periodic Labs、AMI Labs、World Labs等国际头部企业进行定向检索
- 获取其融资细节、技术路线、投资方背景
- 目的：对比国际前沿动态，完善全球视角

### 2.3 数据处理流程

1. **信息提取**：从搜索结果中提取融资事件的核心要素
2. **交叉验证**：对同一事件的多个信息源进行比对，确保准确性
3. **结构化整理**：将非结构化文本转化为表格格式
4. **趋势分析**：基于整理后的数据进行投资热点和估值趋势分析
5. **竞品对标**：构建和光智成与主要竞品的对比分析框架
6. **报告撰写**：整合所有分析结果，输出完整报告

## 四、遇到的问题与解决方案

### 问题1：部分融资事件金额未披露

**现象描述：**
深度原理A2轮融资未披露具体金额，仅披露投资方信息。

**解决方案：**
- 通过投资方背景（金蚂投资、晶泰科技、百度风投等）和行业惯例进行估算
- 在报告中标注为"数千万级"，如实反映信息边界
- 重点分析其技术路线和商业化进展，弥补金额信息的不足

### 问题2：和光智成自身融资信息的公开信息有限

**现象描述：**
公开渠道中关于和光智成融资的直接信息较少，难以获取精准的融资轮次和金额。

**解决方案：**
- 通过关联企业深云智合的公开信息进行侧面印证
- 从创始人刘宇宙教授的公开报道中提取技术能力和业务进展
- 重点聚焦于竞品对比分析，通过对标行业平均水平来评估和光智成的相对位置
- 在报告中明确标注信息来源，保持严谨性

### 问题3：国际公司与国内公司的融资币种和估值体系差异

**现象描述：**
国际公司融资多以美元计价，国内公司以人民币计价，直接对比可能产生偏差。

**解决方案：**
- 统一换算为人民币或美元进行横向对比
- 在估值趋势分析中单独区分国际和国内两个市场
- 分析中美市场估值差异的深层原因（创始人背景溢价、资本市场成熟度等）

### 问题4：部分融资事件时间跨度的界定问题

**现象描述：**
深势科技C轮融资完成于2025年12月，但其对行业的影响延续至2026年Q1。

**解决方案：**
- 在表格中明确标注融资完成时间
- 在分析部分说明该事件对2026年Q1行业格局的影响
- 保持时间线的清晰，避免混淆融资发生时间与影响时间
