# 微信好友自动通过操作指南

## 前置准备
1. 确认微信客户端已经打开并登录
2. 确保微信窗口处于可见状态，没有被其他窗口遮挡

## 操作步骤
1. 点击微信左侧菜单栏的「通讯录」图标（通常是小人形状）
2. 在通讯录页面顶部找到「新的朋友」选项并点击进入
3. 查看好友申请列表，识别等待通过的好友申请
4. 对于每个待处理的申请，点击右侧的「接受」按钮
5. 等待接受成功提示出现后，再处理下一个申请
6. 所有申请处理完成后，可返回聊天列表确认

## 注意事项
- 如果申请带有验证消息，可以先查看验证内容再决定是否通过
- 遇到网络延迟时，等待1-2秒再进行下一步操作，避免重复点击
- 处理完成后确认「接受」按钮变为「已添加」状态
