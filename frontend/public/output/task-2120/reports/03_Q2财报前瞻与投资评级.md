## 四、投资策略建议

### 4.1 核心配置思路

1. **优先配置CMP赛道龙头**：受益AI芯片产能扩张最直接，业绩确定性最高
   - 推荐：鼎龙股份、安集科技、华海诚科

2. **重点配置光刻胶全产业链公司**：具备原材料自主可控能力的平台型公司
   - 推荐：彤程新材、晶瑞电材、雅克科技

3. **标配湿电子化学品龙头**：半导体产能扩张核心受益，国产替代空间大
   - 推荐：晶瑞电材、江化微

4. **选择性配置靶材龙头**：关注技术壁垒高、7nm及以下制程突破的公司
   - 推荐：江丰电子

### 4.2 投资组合建议

| 配置比例 | 标的名称 | 配置逻辑 |
|----------|----------|----------|
| 20% | 鼎龙股份 | 平台型龙头，业绩确定性最高 |
| 15% | 安集科技 | CMP抛光液绝对龙头，技术壁垒高 |
| 15% | 华海诚科 | 先进封装材料新星，业绩弹性最大 |
| 12% | 雅克科技 | 半导体材料综合平台，估值合理 |
| 10% | 彤程新材 | 光刻胶材料一体化龙头 |
| 10% | 晶瑞电材 | 湿电子化学品G5级龙头 |
| 8% | 江丰电子 | 溅射靶材龙头，7nm突破 |
| 5% | 江化微 | 湿电子化学品专业厂商 |
| 5% | 万润股份 | OLED+光刻胶双轮驱动 |

## 五、风险提示

1. **技术研发风险**：高端材料研发进度不及预期
2. **客户认证风险**：新产品验证周期长于预期
3. **行业竞争加剧**：新进入者增多，价格战风险
4. **地缘政治风险**：国际贸易摩擦加剧，出口受限
5. **产能过剩风险**：行业扩产过快，产能利用率下降
6. **估值回调风险**：板块估值处于历史高位，存在回调压力
