## 四、整体操作策略

### 4.1 月度操作日历
| 时间 | 重点操作 |
|------|----------|
| 4月28日-5月10日 | 建仓核心标的（鼎龙、安集、华海诚科、晶瑞） |
| 5月11日-5月20日 | 观察业绩，优化弹性配置 |
| 5月21日-5月31日 | 减持持有评级标的，集中仓位到核心标的 |
| 6月1日-6月15日 | 关注半年报预告，调整持仓 |
| 6月16日-6月30日 | 半年报发布后，评估业绩兑现情况 |

### 4.2 仓位管理原则
- **分批建仓**：任何标的不一次性满仓，分3-5批建仓
- **逢低买入**：不追高，回调5%以上再买入
- **动态调整**：每季度调整一次持仓结构
- **严格止损**：达到止损位坚决执行，不抱有侥幸心理
