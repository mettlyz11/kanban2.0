# CBT-I 4周睡眠改善执行手册

> **科学依据**：认知行为疗法治疗失眠（CBT-I）被ACP（美国医师协会）推荐为慢性失眠的一线治疗方案，4-8周有效率70%-80%，效果持久优于药物。

---

## 一、核心原理：CBT-I五大支柱

1. **认知重构** — 改变对睡眠的错误认知和焦虑
2. **刺激控制** — 重建床与睡眠的条件反射
3. **睡眠限制** — 压缩卧床时间，提高睡眠效率
4. **睡眠卫生** — 优化睡眠环境和习惯
5. **放松训练** — 降低生理唤醒水平

---

## 二、4周执行时间表

### 第1周：建立基线 + 刺激控制

**目标**：记录睡眠模式，建立"床=睡眠"联结

| 时间 | 行动 | 具体操作 |
|------|------|---------|
| 每天早晨 | 填写睡眠日记 | 记录就寝时间、入睡时间、觉醒次数、起床时间、日间小睡 |
| 白天 | 禁止小睡 | 无论多困，白天不打盹 |
| 晚间 | 固定起床时间 | 无论几点入睡，每天同一时间起床（建议6:30-7:00） |
| 床上 | 20分钟规则 | 卧床20分钟未入睡→起床到昏暗环境做单调活动→有睡意再回床 |
| 床上 | 禁用电子产品 | 手机不带上床，闹钟放远处 |

**第1周认知重构练习**：
- 识别自动思维："我必须睡够8小时"
- 替代思维："7小时高质量睡眠足够我精力充沛"

---

### 第2周：睡眠限制疗法启动

**目标**：提高睡眠效率（SE = 实际睡眠时间/卧床时间 ≥ 85%）

**计算方法**：
1. 根据第1周睡眠日记，计算平均实际睡眠时间
2. 设定初始卧床时间 = 平均实际睡眠时间（不低于5小时）
3. 固定起床时间，倒推就寝时间

**示例**：
- 平均实际睡眠：6小时
- 固定起床时间：6:30
- 初始就寝时间：0:30（即使11点上床也只能0:30关灯）

**第2周关键规则**：
- [ ] 严格遵守时间窗，不提前上床
- [ ] 睡眠效率>85%后，每周增加15分钟卧床时间
- [ ] 白天依然禁止小睡
- [ ] 持续记录睡眠日记

---

### 第3周：深度放松训练整合

**目标**：降低入睡前生理唤醒水平

**每日放松练习（睡前30分钟）**：

#### 渐进式肌肉放松（PMR）15分钟
```
1. 找一个安静舒适的位置坐下或躺下
2. 从脚趾开始，依次紧绷-放松各肌群（5秒紧绷，10秒放松）
3. 顺序：脚趾→小腿→大腿→臀部→腹部→胸部→手臂→肩膀→面部
4. 注意紧张与放松的对比感受
```

#### 腹式呼吸 5分钟
```
1. 一手放腹部，一手放胸部
2. 吸气4秒（腹部隆起，胸部不动）
3. 屏息2秒
4. 呼气6秒（腹部下沉）
5. 重复10-15次循环
```

#### 正念身体扫描 10分钟
- 使用APP引导（推荐：潮汐/小睡眠/Headspace）
- 关注身体各部位感受，不评判，只是觉察

---

### 第4周：巩固优化 + 长期维持

**目标**：建立可持续的睡眠模式，制定长期维护策略

**第4周评估**：
- [ ] 睡眠效率是否达到85%以上？
- [ ] 入睡潜伏期是否缩短到30分钟以内？
- [ ] 夜间觉醒次数是否减少？
- [ ] 日间功能是否改善？

**优化调整**：
- 如效果好：逐步扩展卧床时间至7-7.5小时
- 如效果一般：检查刺激控制和睡眠限制执行严格度
- 如效果不佳：建议寻求专业CBT-I治疗师

## 三、睡眠环境优化方案

### 光照管理

| 时段 | 光照策略 |
|------|---------|
| 早晨（起床后1小时内） | 接受自然光10-15分钟，重置生物钟 |
| 白天 | 保持工作环境明亮 |
| 傍晚（日落后） | 调暗室内灯光，避免白光 |
| 睡前2小时 | 启用夜间模式，所有屏幕蓝光过滤 |
| 卧室 | 完全遮光（遮光窗帘或眼罩） |

### 温度控制
- **最佳睡眠室温**：18-22°C
- **睡前1小时**：洗个温水澡（40°C左右），体温下降触发睡意
- **被褥选择**：透气材质，避免过热

### 床垫与枕头
- **床垫硬度**：中等偏硬，支撑脊柱自然曲线
- **枕头高度**：仰卧时下巴微收，颈椎呈自然曲线
- **更换周期**：床垫7-10年，枕头1-2年

### 噪音控制
- **白噪音**：使用白噪音机或APP（如"小睡眠"）掩盖突发噪音
- **耳塞**：安耳悠蜡丸耳塞（舒适度高）
- **卧室门**：保持关闭，减少外部干扰

## 四、睡前数字戒断方案

### 电子设备宵禁

| 时间 | 规则 |
|------|------|
| 睡前90分钟 | 停止所有工作邮件和消息回复 |
| 睡前60分钟 | 关闭电脑，停止短视频/新闻浏览 |
| 睡前30分钟 | 手机调至勿扰模式，放离床至少2米 |

### 替代活动清单
- [ ] 纸质书籍阅读（非悬疑/刺激类）
- [ ] 轻度拉伸或瑜伽
- [ ] 冥想或呼吸练习
- [ ] 日记书写（记录当日3件好事）
- [ ] 与伴侣轻松交谈

### 周度睡眠效率计算

```
睡眠效率（SE）= 总实际睡眠时间 / 总卧床时间 × 100%

目标：
- 第1周：了解基线，不设目标
- 第2周：SE ≥ 80%
- 第3-4周：SE ≥ 85%
- 长期维持：SE ≥ 90%
```

## 七、常见问题与应对

| 问题 | 应对策略 |
|------|---------|
| "睡眠限制让我更困" | 正常反应，坚持1-2周会改善 |
| "周末想补觉" | 保持固定起床时间，可小睡20分钟 |
| "出差/跨时区如何执行" | 提前调整作息，使用褪黑素辅助 |
| "有重要会议睡不着" | 提前做放松练习，认知重构"即使少睡也能表现好" |
| "效果不明显" | 检查执行严格度，或寻求专业治疗师 |

## 八、何时寻求专业帮助

- [ ] 执行CBT-I 4周仍无明显改善
- [ ] 失眠持续超过3个月
- [ ] 伴有严重日间功能损害
- [ ] 有抑郁/焦虑症状
- [ ] 疑似睡眠呼吸暂停（打鼾、白天嗜睡）

**推荐就诊**：北京协和医院睡眠医学中心 / 301医院睡眠科
