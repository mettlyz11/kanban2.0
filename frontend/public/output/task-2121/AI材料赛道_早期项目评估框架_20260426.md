# AI材料赛道早期项目评估框架
## 天使轮-A轮项目投资评级体系 V1.0

> 制定日期：2026年4月26日
> 适用阶段：种子轮、天使轮、Pre-A轮、A轮早期项目
> 评分权重：团队(30%) / 技术壁垒(30%) / 市场空间(25%) / 商业模式(15%) / 附加分(+10%)

---

## 一、评估框架总览

### 1.1 四维评分体系

| 维度 | 权重 | 核心评价要素 | 评分区间 |
|------|------|--------------|----------|
| **团队维度** | 30% | 创始人背景、团队完整性、产业经验、学术背景 | 0-30分 |
| **技术壁垒** | 30% | 原创性、可验证性、技术护城河、专利布局 | 0-30分 |
| **市场空间** | 25% | TAM/SAM/SOM、增长速度、政策支持、竞争格局 | 0-25分 |
| **商业模式** | 15% | 变现路径清晰性、客户验证、付费意愿、毛利率 | 0-15分 |
| **附加加分** | +10% | 头部机构背书、产业订单、里程碑突破、政策加持 | 0-10分 |

### 1.2 评级标准

| 评级 | 总分区间 | 投资建议 | 预期回报倍数 |
|------|----------|----------|--------------|
| **S级** | 85-110分 | 强烈推荐，立即跟进 | 20-50x+ |
| **A级** | 70-84分 | 推荐，重点关注 | 10-20x |
| **B级** | 55-69分 | 观察，持续跟踪 | 3-10x |
| **C级** | <55分 | 暂缓投资 | <3x或风险较高 |

## 二、团队维度评估细则 (30%)

### 2.1 创始人背景 (10分)

| 评分 | 评价标准 |
|------|----------|
| **9-10分** | 国际顶尖高校博士(麻省理工/斯坦福/剑桥/牛津等)，曾在顶级科技公司(OpenAI/DeepMind/微软研究院/谷歌)担任核心研究员，有成功创业退出经验 |
| **7-8分** | 国内顶尖高校博士(清北/中科大/中科院)，曾在头部科技公司或科研院所担任重要职位，有产业转化经验 |
| **5-6分** | 博士学历，有5年以上材料科学或AI领域研发经验，技术能力强但商业化经验不足 |
| **3-4分** | 硕士及以上学历，有一定研发经验，但缺乏顶尖机构背景 |
| **0-2分** | 团队学历背景一般，缺乏材料+AI交叉领域经验 |

### 2.2 团队完整性与互补性 (10分)

| 评分 | 评价标准 |
|------|----------|
| **9-10分** | AI算法+材料科学+产业落地+商业化四位一体完整团队，核心成员共事1年以上，配合默契 |
| **7-8分** | 三大核心角色齐全，有2-3名核心成员具备跨学科背景，团队凝聚力强 |
| **5-6分** | 技术团队强但商业化团队薄弱，或反之，存在明显短板 |
| **3-4分** | 只有单一背景创始人，缺乏关键角色 |
| **0-2分** | 团队不完整，核心岗位空缺 |

### 2.3 产业与学术资源 (10分)

| 评分 | 评价标准 |
|------|----------|
| **9-10分** | 掌握稀缺产业资源，与头部企业有深度合作，在顶级期刊发表过开创性论文，有院士/行业泰斗背书 |
| **7-8分** | 有一定产业合作基础，与知名高校/科研院所建立合作关系，学术成果较丰富 |
| **5-6分** | 有基本的产学研合作，发表过一定数量的学术论文 |
| **3-4分** | 产业资源较少，主要依靠团队自身能力 |
| **0-2分** | 几乎没有外部产业或学术资源支持 |

## 三、技术壁垒维度评估细则 (30%)

### 3.1 技术原创性与领先性 (12分)

| 评分 | 评价标准 |
|------|----------|
| **10-12分** | 全球首创技术路线，在Nature/Science等顶刊发表相关论文，技术指标领先国际同行30%以上 |
| **8-9分** | 国内首创或国际先进水平，在顶级子刊发表论文，技术指标领先同行15-30% |
| **6-7分** | 技术路线有一定创新性，处于国内先进水平，有核心算法专利 |
| **4-5分** | 技术路线较常规，基于开源模型进行优化，原创性一般 |
| **0-3分** | 技术门槛较低，容易被复制，无核心差异化 |

### 3.2 可验证性与POC进展 (10分)

| 评分 | 评价标准 |
|------|----------|
| **9-10分** | 已完成多个客户POC并获得付费订单，技术效果得到第三方权威机构验证，有明确量化指标提升 |
| **7-8分** | 完成至少1个头部客户POC，效果显著，正在洽谈商业合作，有实验室数据验证 |
| **5-6分** | 实验室阶段验证完成，有明确的技术指标数据，正在准备客户POC |
| **3-4分** | 技术原理验证阶段，仅有仿真或小规模实验数据 |
| **0-2分** | 仍处于概念阶段，无实质性验证成果 |

### 3.3 专利与知识产权布局 (8分)

| 评分 | 评价标准 |
|------|----------|
| **7-8分** | 已申请10+项核心发明专利，含PCT国际专利，构建了完整的专利护城河，无知识产权纠纷 |
| **5-6分** | 已申请3-10项核心专利，有明确的知识产权保护策略 |
| **3-4分** | 正在申请专利，有基本的知识产权保护意识 |
| **0-2分** | 无专利布局或知识产权存在潜在风险 |

## 四、市场空间维度评估细则 (25%)

### 4.1 市场规模与增速 (10分)

| 评分 | 评价标准 |
|------|----------|
| **9-10分** | TAM > 1000亿美元，年复合增长率 > 50%，处于爆发前夜的蓝海市场 |
| **7-8分** | TAM 100-1000亿美元，年复合增长率 30-50%，高速增长市场 |
| **5-6分** | TAM 10-100亿美元，年复合增长率 15-30%，稳定增长市场 |
| **3-4分** | TAM 1-10亿美元，年复合增长率 < 15%，市场规模有限 |
| **0-2分** | TAM < 1亿美元，细分市场过于狭小 |

### 4.2 政策与战略价值 (8分)

| 评分 | 评价标准 |
|------|----------|
| **7-8分** | 国家战略级赛道，属于"卡脖子"技术领域，有明确的国家级政策支持和专项基金 |
| **5-6分** | 符合国家产业政策方向，有地方政府支持和产业园区扶持 |
| **3-4分** | 政策支持力度一般，不属于重点扶持领域 |
| **0-2分** | 存在政策监管风险或不符合产业导向 |

### 4.3 竞争格局 (7分)

| 评分 | 评价标准 |
|------|----------|
| **6-7分** | 几乎没有直接竞争对手，或领先竞争对手12个月以上，具备先发优势 |
| **4-5分** | 竞争对手较少(<5家)，与主要竞争对手各有优势，存在差异化竞争空间 |
| **2-3分** | 竞争对手较多(5-15家)，市场开始出现同质化竞争 |
| **0-1分** | 竞争极其激烈，巨头已下场布局，创业公司生存空间有限 |

## 五、商业模式维度评估细则 (15%)

### 5.1 变现路径清晰性 (7分)

| 评分 | 评价标准 |
|------|----------|
| **6-7分** | 商业模式经过市场验证，有明确的付费客户和可复制的销售模式，毛利率 > 60% |
| **4-5分** | 商业模式清晰，已有意向客户，预期毛利率 40-60% |
| **2-3分** | 商业模式基本成型，但还需要市场验证，盈利路径较长 |
| **0-1分** | 商业模式不清晰，缺乏明确的盈利路径 |

### 5.2 客户验证与付费意愿 (8分)

| 评分 | 评价标准 |
|------|----------|
| **7-8分** | 已有3家以上付费客户，客单价 > 100万元，客户续约意愿强烈，有头部企业战略投资 |
| **5-6分** | 已有1-2家付费客户，或多家明确意向客户，客单价50-100万元 |
| **3-4分** | 有潜在客户接触，客户表示有兴趣但尚未付费，客单价 < 50万元 |
| **0-2分** | 尚未与潜在客户进行实质性接触，付费意愿不明确 |

## 七、风险评估维度

### 7.1 核心风险清单

| 风险类型 | 高风险信号 | 中风险信号 | 低风险信号 |
|----------|------------|------------|------------|
| **技术风险** | 技术路线存在根本性缺陷，难以落地 | 技术难度大，开发周期存在不确定性 | 技术路线清晰，验证进展顺利 |
| **团队风险** | 核心成员离职风险高，团队内讧 | 关键岗位人才招聘困难 | 团队稳定，凝聚力强 |
| **市场风险** | 市场接受度低，付费意愿弱 | 市场教育周期长于预期 | 市场需求明确，客户付费意愿强 |
| **竞争风险** | 巨头全面下场，创业公司无差异化 | 竞争对手增多，价格战风险 | 竞争格局良好，先发优势明显 |
| **政策风险** | 监管政策收紧，行业准入门槛提高 | 政策存在不确定性 | 政策大力支持，监管环境友好 |

### 7.2 风险调整系数

| 风险等级 | 调整系数 | 最终评级调整 |
|----------|----------|--------------|
| 低风险 | ×1.0 | 维持原评级 |
| 中风险 | ×0.9 | 可能下调一级 |
| 高风险 | ×0.75 | 通常下调1-2级 |

## 八、评估流程

1. **初步筛选**：基于BP和公开信息进行初评，筛选出B级以上项目
2. **深度尽调**：对A级/S级项目开展技术尽调、团队访谈、客户访谈
3. **专家评审**：邀请行业技术专家和产业专家进行独立评审
4. **综合评分**：按照本框架进行量化评分，确定最终评级
5. **投资决策**：基于评级和风险评估做出投资决策

## 九、AI材料赛道特有评估要点

### 9.1 技术评估特殊考量

- **"AI+材料"而非"材料+AI"**：评估AI是否真正提升研发效率，而非简单应用包装
- **数据闭环能力**：是否具备从模型预测→实验验证→数据回流的完整闭环
- **Scaling Law验证**：材料大模型是否遵循Scaling Law，参数量与效果正相关
- **从预测到发现**：能否真正发现新材料，而非仅预测已知材料性质

### 9.2 商业落地特殊考量

- **研发周期匹配**：AI研发周期(月级)与材料产业化周期(年级)的匹配度
- **客单价天花板**：材料企业付费能力与意愿评估
- **IP归属问题**：AI发现的新材料知识产权归属
- **量产放大风险**：实验室成果到工业化量产的放大效应风险
