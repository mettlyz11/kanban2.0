## 1. 项目概述

### 1.1 展会基本信息

| 项目 | 详情 |
|------|------|
| **展会名称** | 第二十一届中国国际化工装备展览会（CTEF2026） |
| **展会时间** | 2026年6月12日-14日（周五-周日） |
| **布展时间** | 2026年6月9日-11日 |
| **撤展时间** | 2026年6月14日14:00后 |
| **展会地点** | 国家会展中心（上海） |
| **展位位置** | 馆号待定，建议核心馆主通道附近 |
| **展位面积** | 108㎡（12m × 9m）特装展位 |
| **预计观众** | 100,000+人次 |
| **预计展商** | 1,500+家 |

### 1.2 展会战略意义

CTEF2026是亚洲规模最大、影响力最强的化工装备展览会，是和光智成：

1. **品牌发布平台：** 首次正式发布AI催化剂即服务（CaaS）商业模式
2. **客户对接平台：** 集中对接300+目标客户关键决策人
3. **行业发声平台：** 确立AI-CaaS行业领导者地位
4. **生态合作平台：** 建立渠道合作伙伴网络

### 1.3 参展主题

**主主题：** AI催化剂即服务——开启化工产业新范式

**副主题：**
- 技术：AI驱动 · 智能催化
- 模式：从产品到服务 · 共创价值
- 价值：零初始投资 · 性能保证 · 全生命周期服务

### 3.2 各功能区详细设计

#### 3.2.1 品牌形象展示区

**位置：** 展位入口左侧，3m × 3m

**设计要点：**
- 大型LED屏幕（55寸×4拼接屏）循环播放企业宣传片
- 公司Logo立体字展示
- 核心Slogan：AI催化剂即服务——开启化工产业新范式
- 灯箱展示：四大服务模块图标与简介

**物料清单：**
- LED拼接屏 + 控制系统
- 企业宣传片（3分钟版 + 15秒版）
- 服务模式介绍动画
- 立体Logo字 + 发光字
- 接待台1个（配2名接待人员）

#### 3.2.2 技术演示互动区

**位置：** 展位右侧前方，6m × 4.5m

**设计要点：**
- 三大演示工作站：
  - **AI催化剂研发平台**：实时演示AI筛选过程，观众可输入参数体验
  - **CatalystCloud™智能监测系统**：大屏展示模拟工厂实时数据
  - **ROI计算器互动屏**：观众输入自身情况，即时生成投资回报分析
- 中央圆形吧台式设计，方便技术人员与观众互动
- 配备4台触摸屏终端 + 2台75寸演示大屏

**演示脚本要点：**
1. AI研发平台：3分钟演示，展示从分子设计到实验验证全过程
2. 在线监测系统：3分钟演示，展示异常预警、性能预测功能
3. ROI计算器：2分钟操作，现场生成个性化报告

#### 3.2.3 客户洽谈VIP区

**位置：** 展位后方，9m × 4.5m

**设计要点：**
- 5个独立封闭式洽谈室（每间约6㎡）
- 1间大型VIP洽谈室（约12㎡，供董事长级会晤）
- 每间配备：会议桌、4把椅子、电源插座、HDMI接口、白板
- 隔音设计，保障会谈私密性
- 整体采用半透明玻璃隔断，兼顾开放与私密

**配套服务：**
- 每间洽谈室配备矿泉水、薄荷糖、笔记本
- 专属茶水服务（按需提供）
- 资料架放置全套销售材料

#### 3.2.4 成功案例墙

**位置：** 展位入口右侧，3m × 3m

**设计要点：**
- 灯箱形式展示3-5个标杆案例
- 每个案例包含：客户Logo、痛点、解决方案、成效数据
- 设计突出数据可视化（图表、数字）
- 配二维码，扫码可下载完整案例报告

#### 3.2.5 茶歇与签约区

**位置：** 展位右侧后方，6m × 3m

**设计要点：**
- 提供咖啡、茶饮、小点心
- 设置签约仪式背景墙
- 配备专业摄影师
- 可容纳20人同时休息

### 3.3 视觉识别系统（VI）规范

**主色调：**
- 科技蓝（#0066FF）：主品牌色，代表科技与信任
- 活力绿（#00CC66）：辅助色，代表绿色与环保
- 深灰（#333333）：文字色，专业稳重

**字体规范：**
- 标题：思源黑体 Bold
- 正文：思源黑体 Regular

**Logo使用规范：**
- 最小使用尺寸：50mm
- 预留安全空间：四周各10%
- 背景对比度要求：≥70%

### 3.4 搭建商选择与时间安排

**搭建商资质要求：**
- 具有大型化工展特装搭建经验（5年以上）
- 具备国家会展中心（上海）搭建资质
- 自有工厂与施工团队
- 可提供设计、制作、搭建、维护一条龙服务

**时间安排：**
| 阶段 | 时间 | 关键节点 |
|------|------|---------|
| 设计方案确认 | 4月30日前 | 效果图、施工图确认 |
| 制作阶段 | 5月1日-5月25日 | 工厂制作 |
| 预搭建验收 | 5月26日-5月30日 | 工厂预搭，整改完善 |
| 现场搭建 | 6月9日-6月11日 | 进场搭建、调试、验收 |

## 4. 会前预热与客户邀约计划

### 4.1 预热阶段划分与核心动作

#### 第一阶段：启动期（4月27日-5月10日）

**核心目标：** 信息发布，引起关注

**关键动作：**
1. 官网发布参展公告
2. 微信公众号、LinkedIn同步发布
3. 向现有客户发送参展邀请函
4. 启动媒体沟通，发布首篇预热稿

**预热稿主题：**
《和光智成将亮相CTEF2026，发布AI催化剂即服务创新模式》

#### 第二阶段：高潮期（5月11日-5月31日）

**核心目标：** 深度传播，精准邀约

**关键动作：**
1. 发布《CaaS商业模式白皮书》摘要版
2. 行业媒体深度专题报道（3-5篇）
3. 启动目标客户一对一邀约
4. 举办1-2场线上预热沙龙
5. 董事长专访发布

**传播内容矩阵：**
- 趋势洞察：《催化剂即服务——化工行业下一个十年风口》
- 技术解析：《AI如何重塑催化剂研发范式》
- 客户证言：首批试点客户采访（匿名处理）

#### 第三阶段：冲刺期（6月1日-6月11日）

**核心目标：** 确认行程，最后提醒

**关键动作：**
1. 发送最终提醒邮件/短信
2. 公布展会期间活动日程
3. 发布展位指引与交通攻略
4. 释放现场签约优惠政策

### 4.2 目标客户邀约策略

#### 4.2.1 邀约对象分层

| 层级 | 定义 | 数量目标 | 邀约方式 |
|------|------|----------|---------|
| VIP客户 | A类客户，决策人级别 | 20家 | 董事长/CEO亲自打电话邀请 |
| 重点客户 | B类客户，高管级别 | 50家 | 销售总监一对一电话邀约 |
| 普通客户 | C类客户，技术/采购级别 | 100家 | 客户经理邮件+电话跟进 |

#### 4.2.2 VIP客户邀约流程

1. **准备阶段（4月27日-5月7日）**
   - 确认20家VIP客户名单
   - 准备个性化邀请函（定制内容 + 亲笔签名）
   - 准备专属礼品

2. **邀约执行（5月8日-5月22日）**
   - 董事长亲自打电话邀请
   - 快递纸质邀请函 + 白皮书摘要 + 礼品
   - 3天后发送电子邀请函跟进
   - 1周后确认行程

3. **会前接待（6月1日-6月11日）**
   - 指定专属接待人员
   - 安排接送车辆（如需）
   - 预约展会谈时间
   - 安排午宴/晚宴

#### 4.2.3 客户邀约激励政策

**展前预约激励：**
- 预约面谈即可获赠《CaaS白皮书》完整版（价值2000元）
- 预约并到场获赠精美商务礼品一份

**现场签约激励：**
- 展会期间签约享受服务费8折优惠
- 赠送首年CatalystCloud™在线监测系统服务
- 优先参与联合研发项目（限前5家）
- 成为荣誉客户，案例包装宣传
