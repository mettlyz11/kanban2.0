## Week 1: 基线监测期（2026/4/27 - 5/3）

### 每日必做
1. **设备佩戴**: 每晚睡前确保睡眠监测设备正确佩戴并开启监测
   - Apple Watch: 设置 > 睡眠 > 开启睡眠模式
   - 手环类: 确保电量充足，佩戴松紧适中
2. **手动记录**（睡前5分钟）:
   - 主观睡眠质量评分 (1-10)
   - 次日晨起记录日间精力评分 (1-10)
   - 记录当日咖啡因摄入（时间+种类+量）
   - 记录当日运动情况
   - 记录睡前1小时主要活动

## Week 2: 环境优化期（2026/5/4 - 5/10）

**目标**: 系统性优化卧室睡眠环境。

### Day 1-2: 温度与湿度
- [ ] 测量卧室当前温度和湿度（使用温湿度计）
- [ ] 调整空调设定：目标温度 18-20°C
- [ ] 如湿度<40%，开启加湿器；如>60%，开启除湿机
- [ ] 设置空调定时：入睡后2小时自动调高1°C

### Day 3-4: 光线管理
- [ ] 评估卧室遮光情况：拉上窗帘后是否完全黑暗？
- [ ] 如有漏光，安装遮光窗帘（遮光率≥95%）
- [ ] 准备睡眠眼罩（推荐真丝材质）
- [ ] 移除或遮盖卧室内的指示灯（路由器、充电器等LED灯）

### Day 5-6: 声音管理
- [ ] 评估卧室噪音水平（可用手机分贝仪App测量）
- [ ] 准备白噪音App：潮汐/小睡眠，推荐声音：雨声/风扇声/白噪音
- [ ] 准备3M隔音耳塞（如环境噪音>30分贝）
- [ ] 检查并处理异常噪音源（空调异响、水管噪音等）

### Day 7: 床品评估
- [ ] 评估床垫舒适度：是否塌陷？是否有异响？
- [ ] 评估枕头高度：仰卧时颈部是否自然？侧卧时颈椎是否水平？
- [ ] 检查被褥：是否适合当前季节？
- [ ] 如需更换，优先更换枕头（性价比最高的床品升级）

## Week 3: 作息调整期（2026/5/11 - 5/17）

**目标**: 建立固定的作息时间+睡前仪式。

### 固定作息执行
- [ ] 设定固定起床时间（推荐06:30-07:00），周末偏差不超过±1小时
- [ ] 设定固定上床时间（推荐22:30-23:00）
- [ ] 起床后立即拉开窗帘/接触自然光5分钟
- [ ] 下午14:00后停止咖啡因摄入
- [ ] 午睡控制在20-30分钟，不超过15:00

### 睡前仪式执行（60分钟流程）

**21:00-21:30 放松阶段**
- 关闭工作通知，手机开启勿扰模式
- 轻量阅读纸质书（非工作相关）
- 温水泡脚15分钟（40-42°C）

**21:30-22:00 过渡阶段**
- 洗漱（温水澡）
- 调暗卧室灯光
- 准备第二天物品

**22:00-22:30 入睡准备**
- 4-7-8呼吸法：吸气4秒→屏息7秒→呼气8秒，重复4次
- 感恩日记：写下3件今天值得感恩的事
- 上床，保持卧室完全黑暗安静

### 执行追踪
每日睡前在追踪表中记录"睡前仪式完成度"（完全/部分/未完成）

## Week 4: 综合优化期（2026/5/18 - 5/24）

**目标**: 根据前三周数据微调，固化有效习惯。

### 数据分析（周日，30分钟）
1. 对比Week 1 vs Week 3的睡眠数据变化
2. 识别最有效的2-3个改善措施
3. 识别效果不明显的措施，考虑调整或放弃

### 微调方向
| 如果问题 | 调整建议 |
|---------|---------|
| 入睡时间>30分钟 | 提前开始睡前仪式15分钟，增加冥想时长 |
| 夜间醒来>2次 | 检查睡前饮水量，减少睡前1小时液体摄入 |
| 深睡占比<15% | 增加下午运动量，检查卧室温度是否过高 |
| 日间精力低 | 检查总睡眠时长是否≥7小时，考虑提前上床15分钟 |
| 周末睡眠变差 | 严格控制周末起床时间偏差不超过1小时 |

### 习惯固化
- 将最有效的3个习惯标记为"永久习惯"
- 在追踪表中标记哪些习惯已自然形成（不再需要刻意提醒）
- 制定后续8周的维持计划

## 异常情况应对

### 失眠应对
- **入睡困难（>30分钟）**: 起床到客厅，做放松活动（阅读/冥想），困了再回床
- **夜间醒来**: 不看手机，做4-7-8呼吸法
- **早醒无法再睡**: 直接起床，保持当日正常作息，晚上适当提前入睡
- **持续失眠>2周**: 考虑就医（睡眠门诊/神经内科）

### 出差/旅行
- 携带：眼罩 + 耳塞 + 便携白噪音App
- 到达后：立即按当地时间活动，不立即补觉
- 时差调整：必要时短期使用褪黑素（0.5-3mg），连续使用不超过1周

### 生病/特殊情况
- 发烧/感冒期间：适当增加睡眠时间，身体需要恢复
- 重要考试/演讲前：提前1-2天开始加强睡前仪式，不要临时改变作息
