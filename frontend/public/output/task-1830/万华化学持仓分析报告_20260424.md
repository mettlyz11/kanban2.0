## 二、业绩驱动因素分析

### 2.1 聚氨酯业务——核心主业回暖
- **产销同比增长约14%**，量价双升
- 纯MDI均价约20,000元/吨，聚合MDI约15,500元/吨，TDI约15,800元/吨，软泡聚醚约15,800元/吨
- MDI海外涨价已开始向国内传导，东曹HDI大幅提价利好市场情绪
- **美国对华MDI终裁税率大幅低于初裁**，出口前景改善

### 2.2 石化板块——技改红利释放
- 核心驱动：**烟台乙烯一期装置（100万吨/年）** 2025年6月停产技改，升级为乙烷/丙烷双原料灵活切换路线
- 2026年1月复���，乙烷裂解相较传统石脑油路线显著降本
- 产销高增，多数石化产品价格环比上涨
- ⚠️ 主要原料丙烷市场均价环比明显上涨，成本压力仍需关注

### 2.3 新材料业务
- 三大业务（聚氨酯、石化、新材料）整体稳健发展
- 新材料业务贡献增量，长期成长逻辑持续

- 2026 Q1化工行业整体受益于大宗商品价格企稳和下游需求回暖

## 六、持仓评估与投资建议

### 综合评分：⭐⭐⭐⭐ （4/5，建议持有/适当加仓）

**支持持仓的理由：**
1. **基本面反转确立**：Q1营收净利双创历史新高，全年盈利上行趋势明确
2. **催化剂充分**：乙烯技改红利持续释放、MDI涨价趋势、贸易税率边际改善
3. **机构高度认可**：多家大行维持"买入"，2026年净利润预测均超2025年
4. **估值安全边际**：当前PE约21x（TTM），以2026年预期净利润计算PE仅约12-15x，具备向上空间
5. **股东回报**：2025年度分红近40亿元，现金回报稳定

**需要关注的风险：**
1. 应收账款持续攀升，若下游客户资金链紧张可能引发坏账
2. 资产负债率64.57%偏高，利率上行环境下财务成本压力增加
3. 原材料（丙烷、乙烷）价格波动对石化板块盈利的侵蚀
4. 全球贸易政策不确定性（中美关税、地缘冲突）

### 操作建议

| 情景 | 建议 |
|------|------|
| 当前持仓（盈利中） | **持有**，等待聚氨酯景气度进一步回升确认，可设止盈线90-95元 |
| 当前持仓（亏损中） | **持有等待修复**，基本面向好，Q2业绩有望继续超预期 |
| 无持仓 | **可考虑逢回调布局**，80-83元区间为较好入场点 |
| 加仓意愿强 | **分批建仓**，不超过组合25%仓位，注意分散化工板块集中风险 |
