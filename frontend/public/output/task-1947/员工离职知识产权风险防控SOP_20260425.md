## 一、适用范围与原则

### 1.1 适用范围
本 SOP 适用于和光智成所有正式员工、实习生、外包人员、顾问及合作研究人员。

### 1.2 核心原则
- **预防为主**: 在入职时就建立完整的知识产权归属约定
- **分级管理**: 根据涉密等级采取不同强度的防控措施
- **全程留痕**: 所有操作可追溯、可审计
- **依法合规**: 严格遵守竞业限制的法定条件和补偿标准

### 1.3 人员分类

| 类别 | 定义 | 防控强度 | 竞业限制 |
|------|------|---------|---------|
| **A 类 — 核心涉密人员** | 接触 L4 绝密级资产的人员（核心算法/数据） | 最高 | 24 个月 |
| **B 类 — 一般涉密人员** | 接触 L3 机密级资产的人员（工程实现/运营数据） | 高 | 12 个月 |
| **C 类 — 内部知悉人员** | 接触 L2 内部级资产的人员（一般业务信息） | 中 | 6 个月 |
| **D 类 — 非涉密人员** | 仅接触 L1 公开信息的人员 | 基础 | 不适用 |

## 三、在职期间管理

### 3.1 定期审查

| 审查项目 | 频率 | 执行人 | 审查内容 |
|---------|------|--------|---------|
| 权限审查 | 每月 | IT 安全官 | 访问权限是否与岗位匹配 |
| 操作审计 | 每周（A类）/每月（B类） | IT 安全官 | 异常数据访问/下载行为 |
| 保密协议有效性 | 每半年 | HR + 法务 | 协议是否仍有效、是否需要更新 |
| 竞业限制跟踪 | 每季度 | HR | 竞业人员名单更新、补偿金发放 |

### 3.2 异常行为预警指标

以下行为触发自动告警：

- [ ] 非工作时间大量下载/导出数据
- [ ] 访问超出权限范围的资源
- [ ] 频繁使用 U 盘/外部存储设备
- [ ] 在个人邮箱/网盘上传公司文件
- [ ] 打印大量含敏感信息的文件
- [ ] 连续多次登录失败后尝试访问敏感数据
- [ ] 离职意向信号（更新简历、频繁请假面试等）

## 四、离职流程（核心防控环节）

### 4.1 离职流程总览

```
┌─────────────┐    ┌─────────────┐    ┌─────────────┐    ┌─────────────┐
│  离职申请    │───▶│  风险评估    │───▶│  交接执行    │───▶│  离职确认    │
│  (提前30天)  │    │  (3个工作日) │    │  (5个工作日) │    │  (当天)      │
└─────────────┘    └─────────────┘    └─────────────┘    └─────────────┘
       │                  │                  │                  │
       ▼                  ▼                  ▼                  ▼
  确认离职日期       确定涉密等级       逐项交接清单       签署离职确认书
  启动风险评估       制定交接计划       权限逐步回收       竞业限制生效
  通知相关部门       审计操作日志       最终权限清零       存证归档
```

### 4.2 风险评估（离职申请提交后 3 个工作日内完成）

#### 4.2.1 风险评级矩阵

| 评估维度 | 高风险指标 | 中风险指标 | 低风险指标 |
|---------|-----------|-----------|-----------|
| **涉密等级** | A 类（绝密） | B 类（机密） | C/D 类 |
| **离职去向** | 直接竞争对手 | 相关行业 | 不相关/升学 |
| **岗位角色** | 核心技术决策者 | 技术执行者 | 支持性岗位 |
| **在职时长** | ≥2 年（积累大量信息） | 1-2 年 | <1 年 |
| **在职期间行为** | 有异常访问记录 | 偶有越权行为 | 无异常 |
| **离职态度** | 拒绝配合/异常匆忙 | 正常配合 | 积极配合 |

#### 4.2.2 风险等级判定

- **🔴 高风险**: 任一维度为高风险 → 启动全面防控流程
- **🟡 中风险**: 存在中风险维度但无高风险 → 启动标准防控流程
- **🟢 低风险**: 全部为低风险 → 简化流程

### 4.3 交接清单模板

| 5 | 系统权限 | 列出所有系统账号和权限 | IT 安全官 | 权限清单签字 |
| 6 | 外部联系人 | 列出所有与客户/合作方的联系记录 | 业务主管 | 联系人清单签字 |

#### 🟡 中风险人员交接清单

| 序号 | 交接项目 | 具体要求 | 责任人 | 完成标志 |
|------|---------|---------|--------|---------|
| 1 | 代码/文档 | 提交所有经手的工作成果 | 直属主管 | 工作成果清单签字 |

| 3 | 硬件设备 | 归还所有公司设备 | IT 部门 | 设备归还清单签字 |
| 4 | 操作日志审计 | 审计离职前 30 天的操作日志 | IT 安全官 | 审计报告 |

### 4.4 权限回收时间表

| 时间节点 | 操作 | 执行人 |
|---------|------|--------|
| **离职申请提交当日** | 标记员工账号，开启额外监控 | IT 安全官 |
| **交接开始日** | 冻结 L4 绝密级数据访问权限 | IT 安全官 |
| **交接第 3 天** | 冻结 L3 机密级数据访问权限 | IT 安全官 |
| **交接最后日** | 回收全部系统访问权限 | IT 安全官 |
| **离职当天** | 注销所有账号，收回物理门禁 | HR + IT |
| **离职后 7 天** | 最终确认所有权限已清零 | IT 安全官 |

### 4.5 离职面谈

**面谈执行者**: HR + 直属主管（高风险人员加法务）

**必问问题清单**:
1. 离职原因（记录并评估风险）
2. 去向确认（公司名称、岗位、是否与本公司业务相关）
3. 是否计划创业（如是，了解创业方向）
4. 确认已归还/销毁所有公司资产
5. 确认未私自复制/传输任何公司数据
6. 确认竞业限制条款的理解和承诺
7. 确认离职后的保密义务持续有效

**面谈记录**: 形成书面记录，双方签字确认，存档备查。

## 五、竞业限制管理

### 5.1 竞业限制条款核心要素

| 要素 | 内容 | 法律依据 |
|------|------|---------|
| **适用人员** | A/B/C 类涉密人员 | 《劳动合同法》第 24 条 |
| **限制期限** | A类 24个月 / B类 12个月 / C类 6个月 | 法定最长 24 个月 |
| **补偿标准** | 月平均工资的 30%-50%（不低于当地最低标准） | 《最高人民法院关于审理劳动争议案件适用法律问题的解释》 |
| **限制范围** | 明确列出竞争对手名单和业务领域 | 必须具体明确 |
| **违约责任** | 违约金（通常为补偿金的 2-5 倍） + 赔偿实际损失 | 需合理约定 |

### 5.2 竞业限制补偿金发放

| 事项 | 要求 |
|------|------|
| 发放周期 | 按月发放 |
| 发放方式 | 银行转账（留存凭证） |
| 首次发放 | 离职次月开始 |
| 停发条件 | 员工违反竞业限制 / 公司书面通知解除 |
| 跟踪方式 | 定期确认就业状态 |

### 5.3 竞业限制跟踪

| 周期 | 跟踪内容 | 执行方式 |
|------|---------|---------|
| 每月 | 确认补偿金正常发放 | HR 财务对账 |
| 每季度 | 了解员工就业状态 | 电话/微信联系 + 公开信息查询 |
| 每半年 | 全面竞业限制执行情况评估 | HR + 法务联合审查 |

## 六、违规处理流程

### 6.1 违规类型及处理

| 违规行为 | 处理措施 | 法律依据 |
|---------|---------|---------|
| 私自复制/传输商业秘密 | 立即启动调查 → 保全证据 → 行政处罚/刑事报案 | 《反不正当竞争法》第 9 条 |
| 违反竞业限制入职竞争对手 | 要求支付违约金 → 申请劳动仲裁 → 申请禁令 | 《劳动合同法》第 23-24 条 |
| 离职后使用商业秘密创业 | 民事诉讼索赔 + 刑事报案（如涉及） | 《刑法》第 219 条 |
| 未归还公司资产 | 要求归还 → 评估损失 → 索赔 | 《民法典》相关条款 |

### 6.2 证据保全（按新规电子证据规则）

| 证据类型 | 保全方式 | 存证方式 |
|---------|---------|---------|
| 系统操作日志 | 原始日志导出 + 哈希校验 | 区块链存证 |
| 邮件/聊天记录 | 原始数据导出 + 时间戳 | 公证存证 |
| 文件传输记录 | 网络日志导出 | 区块链存证 |
| 设备使用记录 | 设备审计日志 | 公证存证 |
