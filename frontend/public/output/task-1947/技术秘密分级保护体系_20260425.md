## 一、分级体系总览

基于新版《商业秘密保护规定》对"商业价值"的扩展定义（包含现实的或潜在的、直接的或间接的竞争优势），本分级体系将 T109 技术资产划分为四个等级：

| 等级 | 名称 | 定义 | 泄露影响 | 保护强度 |
|------|------|------|---------|---------|
| **L4** | 绝密 (Top Secret) | 泄露将直接导致核心技术被复制，丧失竞争优势 | 毁灭性 | 最高 |
| **L3** | 机密 (Confidential) | 泄露将削弱技术壁垒，增加竞争风险 | 严重 | 高 |
| **L2** | 内部 (Internal) | 泄露将造成一定商业损失，但不直接影响技术优势 | 中等 | 中 |
| **L1** | 公开 (Public) | 已公开或可公开的信息，不构成商业秘密 | 无 | 基础 |

## 二、核心算法（L4 绝密级）

### 2.1 分类清单

| 编号 | 技术资产 | 具体内容 | 保护方式 | 知悉范围 |

| **A03** | 超参数配置 | 学习率、batch size、优化器选择、正则化策略 | 配置加密 + 访问审批 | 核心算法团队 ≤3人 |
| **A04** | 特征工程方法 | 分子描述符选择、图特征提取方法、特征编码策略 | 加密存储 | 核心算法团队 ≤5人 |
| **A05** | 损失函数设计 | 自定义损失函数公式、权重分配策略 | 代码加密 | 核心算法团队 ≤3人 |
| **A06** | 收敛策略 | 模型训练中的早停策略、学习率衰减策略 | 配置加密 | 核心算法团队 ≤5人 |

### 2.2 保护措施

```
┌──────────────────────────────────────────────────────────┐
│  L4 绝密级 — 核心算法                                     │
├──────────────────────────────────────────────────────────┤
│  存储:    HSM 硬件加密模块 / 离线冷存储                     │
│  传输:    TLS 1.3 + 端到端加密                              │
│  访问:    双人授权 (4-eyes principle) + 临时授权            │
│  日志:    完整操作审计（谁、何时、做了什么）                  │
│  备份:    异地多份加密备份                                   │
│  销毁:    密码学擦除 + 物理销毁（存储介质）                   │
│  审计:    每周一次权限审查 + 每月一次安全审计                 │
│  合同:    入职签署绝密协议 + 离职竞业限制 24 个月             │
└──────────────────────────────────────────────────────────┘
```

### 2.3 电子存证要求

- **版本存证**: 每次算法更新后 24 小时内，将代码 Git commit 哈希值 + 模型权重哈希值上链存证
- **训练存证**: 每次模型训练完成后，将训练日志摘要上链存证（含数据版本、超参数、训练时间、执行人）
- **存证周期**: 永久保存

## 四、计算结果（L2 内部级 / L3 机密级）

### 4.1 分类清单

| 编号 | 结果类别 | 密级 | 具体内容 | 保护方式 | 对外策略 |
|------|---------|------|---------|---------|---------|
| **R01** | 客户专属计算结果 | L3 | 特定客户的计算任务输出 | 加密交付 + 水印 | 仅限客户本人访问 |
| **R02** | 聚合分析结果 | L2 | 多客户数据的统计分析（不含个体信息） | 脱敏 | 可用于宣传/报告 |
| **R03** | 平台性能数据 | L2 | 计算精度、响应时间、系统稳定性指标 | 内部公开 | 部分可用于宣传 |
| **R04** | 基准测试结果 | L2 | 与行业标准的对比结果 | 内部公开 | 可选择性公开 |
| **R05** | 失败案例分析 | L3 | 计算失败的案例及其原因分析 | 加密存储 | 内部改进，不公开 |

### 4.2 输出水印方案

为防止客户将计算结果泄露给竞争对手，所有对外输出应嵌入隐形水印：

| 水印类型 | 实施方式 | 检测方式 |
|---------|---------|---------|
| **数字水印** | 在输出的分子结构数据中嵌入微小扰动（不影响精度） | 专用检测工具识别 |
| **元数据水印** | 在输出文件中嵌入客户标识和交付时间 | 文件属性检查 |
| **行为水印** | 在 API 响应中嵌入可追踪的请求标识 | 日志分析 |

## 六、分级保护对照表

| 措施 | L4 绝密 | L3 机密 | L2 内部 | L1 公开 |
|------|---------|---------|---------|---------|

| 备份策略 | 异地多份+离线 | 异地备份 | 本地备份 | 无需 |
| 销毁方式 | 密码学擦除+物理 | 密码学擦除 | 安全删除 | 无需 |
| 审计周期 | 每周 | 每月 | 每季度 | 无需 |
| 合同约束 | 绝密协议+24月竞业 | 保密协议+12月竞业 | 保密协议 | 无需 |
| 电子存证 | 版本+训练哈希上链 | 版本哈希上链 | 可选 | 无需 |
