## 执行摘要

Pepi（Papers Extraordinary Downloader Intelligence）从文献下载工具升级为**学术科研数字员工**。本文档定义了Pepi的三层能力体系（视觉+操作+思考），完成了2026年技术选型、MVP范围界定、分阶段里程碑设计，以及与T109 Hermes平台的集成方案。

**核心结论**：
1. **差异化定位**：Pepi ≠ 通用数字人，而是**化学/AI材料领域的专属科研数字员工**
2. **三位一体架构**：视觉层（看）+ 操作层（做）+ 思考层（想） = 完整科研助理
3. **MVP聚焦**：4个月内完成L1+L2基础能力，实现文献自动检索下载+基础数据整理
4. **学术杠杆**：Pepi系统本身可产出1-2篇高水平论文（AI科研自动化方向）

## 五、 MVP范围定义

### 5.1 MVP核心场景（4个月，2026 Q2-Q3）

**场景1：智能文献助手（优先级最高）**
```
用户说："帮我找最近关于[主题]的论文"
  → Pepi L3: 理解需求，生成检索关键词
  → Pepi L2: 浏览器自动搜索Google Scholar/Web of Science
  → Pepi L2: 自动下载PDF，分类入库(Zotero)
  → Pepi L3: 阅读论文，生成摘要+关键发现
  → Pepi L1: 用语音+数字人形象汇报结果
```

**场景2：计算任务提交**
```
用户说："帮我提交一个[分子]的过渡态搜索计算"
  → Pepi L3: 理解分子结构，生成输入文件
  → Pepi L2: 通过SSH提交到Server 3
  → Pepi L2: 监控计算进度
  → Pepi L3: 分析计算结果
  → Pepi L1: 汇报完成状态
```

### 5.2 MVP能力清单

| 层级 | 必须实现 | MVP范围 | 非MVP |
|------|---------|---------|-------|
| **L1** | 文本对话+基础语音 | 2D数字人(视频生成级) | 3D实时渲染/情感表达/分子可视化 |
| **L2** | 文献下载+Office | browser-use+python-docx | ChemDraw/Gaussian/SolidWorks |
| **L3** | 文献理解+任务规划 | 论文摘要提取+关键词检索 | 实验设计/知识推理/趋势洞察 |

### 5.3 MVP成功标准

| 指标 | 目标值 | 验证方式 |
|------|--------|---------|
| 文献检索准确率 | ≥90% | 100个测试query对比人工 |
| 下载成功率 | ≥85% | 100个DOI实际下载 |
| 摘要生成质量 | 与人工摘要BLEU≥0.4 | 专家评审 |
| 响应延迟 | ≤5s(文本)/≤10s(语音) | 端到端计时 |
| 系统可用性 | ≥95% uptime | 30天连续监控 |

## 七、 与T109 Hermes平台集成方案

### 7.1 集成定位

```
Pepi = 用户界面层（前端交互）
  ↓ 调用
Hermes = 计算引擎层（后端计算）
```

**Pepi作为Hermes的自然语言入口**：
- 用户用自然语言描述计算需求 → Pepi理解并转换为Hermes输入
- Hermes执行计算 → Pepi获取结果并可视化展示
- Pepi监控计算进度 → 异常时主动通知用户

### 7.2 集成接口

| 接口 | 方向 | 协议 | 说明 |
|------|------|------|------|
| **任务提交** | Pepi → Hermes | REST API / MCP | 自然语言→结构化计算任务 |
| **进度查询** | Pepi ← Hermes | WebSocket | 实时进度推送 |
| **结果获取** | Pepi ← Hermes | REST API | 计算结果+可视化数据 |
| **异常通知** | Pepi ← Hermes | Webhook | 计算失败/超时通知 |

### 7.3 集成场景示例

```
用户: "Pepi, 帮我算一下这个分子的过渡态，用DFT B3LYP/6-31G*"
  ↓
Pepi L3: 解析意图 → 提取: 任务=TS搜索, 方法=DFT, 泛函=B3LYP, 基组=6-31G*
  ↓
Pepi L2: 生成Gaussian输入文件(.gjf)
  ↓
Pepi → Hermes: POST /api/calculate {type: "TS", method: "B3LYP", basis: "6-31G*", input: file}
  ↓
Hermes: 执行计算，WebSocket推送进度
  ↓
Pepi L1: "计算中...预计15分钟"（数字人展示+语音）
  ↓
Hermes: 计算完成
  ↓
Pepi L3: 分析结果 → 生成可视化 → 判断合理性
  ↓
Pepi L1: "过渡态已找到！虚频-1234 cm⁻¹。3D结构已展示，要查看详细数据吗？"
```
