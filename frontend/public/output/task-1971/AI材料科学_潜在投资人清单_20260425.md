## 六、对接执行计划

### 第一阶段（2026年5-6月）：S级机构密集对接
- 目标：红杉中国、高瓴创投、深创投三家核心机构
- 动作：正式BP路演，技术深度交流，实验室参访
- 目标产出：至少1张TS意向书

### 第二阶段（2026年6-7月）：A级机构同步推进
- 目标：五源资本、经纬创投、中金资本、达晨财智
- 动作：同步路演，制造竞争氛围
- 目标产出：3-5张TS，估值区间锁定

### 第三阶段（2026年7-8月）：战略投资者引入
- 目标：宁德时代CVC、中化战投、华为哈勃中选择1-2家
- 动作：产业合作洽谈，绑定业务合作
- 目标产出：1家战略投资者领投/跟投

### 第四阶段（2026年8-9月）：交割完成
- 动作：尽调、谈判、交割、打款
- 目标：融资3000-5000万元，估值1.5-2亿元

## 七、关键准备事项

### 资料准备清单
- [ ] 商业计划书（中英文版本）
- [ ] 技术白皮书（详细算法说明）
- [ ] 客户意向书/合作协议（至少3份）
- [ ] 财务模型（3年预测）
- [ ] 专利清单及申请状态
- [ ] 团队介绍及背景资料
- [ ] Data Room整理（虚拟数据室）

### 谈判要点
- **估值底线**：不低于1.2亿元
- **融资金额**：不低于3000万元
- **董事会席位**：不超过1席给财务投资人
- **反稀释条款**：争取最惠国待遇
- **投资者权利**：否决权范围严格限定
