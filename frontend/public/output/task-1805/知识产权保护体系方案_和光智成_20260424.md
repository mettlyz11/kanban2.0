## 二、知识产权分层保护策略

### 2.1 保护分层模型

```
                      公开
                       ↑
              ┌──────────────────┐
              │   专利保护层      │  ← 公开换取垄断保护
              │（算法发明专利）   │
              ├──────────────────┤
              │   著作权层        │  ← 保护表达不保护思想
              │（软件著作权/论文） │
              ├──────────────────┤
              │   商标层          │  ← 品牌资产保护
              │（注册商标/域名）   │
              ├──────────────────┤
              │   商业秘密层      │  ← 核心技术不公开
              │（源代码/数据集）   │
              └──────────────────┘
                       ↓
                       机密
```

### 2.2 各层级保护策略详述

#### 【第一层：专利保护——核心算法与方法】

**保护策略**：选择性地将可逆工程的核心算法申请发明专利，构建技术护城河。

**优先申请方向**：

| 序号 | 技术方向 | 申请时机 | 预期保护范围 |
|:----:|---------|:--------:|------------|
| 1 | 基于扩散模型的分子生成方法 | 模型定型后立即申请 | 方法+系统+介质 |
| 2 | 图神经网络分子性质预测方法 | V2.8稳定后申请 | 方法+系统+介质 |
| 3 | 自动化实验数据驱动的主动学习框架 | 框架验证后申请 | 方法+系统 |
| 4 | 多任务分子表示迁移学习方法 | 跨领域验证后申请 | 方法+系统 |
| 5 | 分子智能筛选与合成联动系统 | 系统集成后申请 | 系统+方法+装置 |

**行动建议**：
- ✅ 2026年Q3前完成3-5件核心发明专利的申请文件准备
- ✅ 利用北航联合实验室资源，与北航技术转移办公室对接
- ✅ 考虑PCT国际申请路径，为海外布局预留窗口（优先期限12个月）
- ✅ 委托专业专利代理机构（推荐化工/材料背景的双证代理）

#### 【第二层：著作权保护——软件平台与文档】

**保护策略**：为独立发布的软件模块申请软件著作权登记，为重要技术文档进行著作权登记。

**优先登记清单**：
1. 分子智能平台前端系统 - 软著登（UI/UX + 核心功能界面）
2. 自动化实验调度引擎 - 软著登（实验流程编排核心）
3. 数据采集与预处理管线 - 软著登（多源数据集成处理）
4. 分子性质预测API服务 - 软著登（后端服务架构）

**行动建议**：
- ✅ 以上4件软著可在1个月内完成中国版权保护中心提交
- ✅ 软著权属请确认为"和光智成（北京）科技有限公司"
- ✅ 注意区分"开源组件"与"自有代码"，在备案时明确权属边界

#### 【第三层：商标保护——品牌资产】

**保护策略**：建立完整的商标族群，覆盖核心业务范围。

## 三、IP全生命周期管理流程

### 3.1 IP创建流程（申请到授权）

```
技术成果产生
      ↓
发明人提交《技术成果披露表》
      ↓
IP评审委员会（每双周）← 跨部门评审
 ├──→ 可专利 → 专利代理机构撰写 → 审核定稿 → 提交申请 → 审查答复 → 授权/驳回
 ├──→ 商业秘密 → 分级标记 → 纳入保密管理 → 定期审计
 ├──→ 著作权 → 材料准备 → 登记提交 → 获得证书
 └──→ 开源/发表 → 技术委员会审批 → 信息脱敏 → 发表/发布
```

| 字段 | 内容 |
|------|------|

**会议频率**：每双周召开（如无待议事项可跳过）
**决策方式**：简单多数+CEO一票否决权

## 四、对外合作IP归属框架

### 4.1 不同合作模式的IP归属原则

| 合作模式 | IP归属原则 | 说明 |
|---------|-----------|------|
| **委托研发**（客户付费） | 成果归甲方，和光保留改进权和通用模块使用权 | 确保核心平台不被割裂 |
| **联合研发**（共同投入） | 共同申请+按贡献约定份额 | 约定共有专利的行使规则 |
| **产学研合作**（高校） | 背景IP各自保留，前景IP按贡献协商 | 注意高校职务发明规则 |
| **技术服务** | 交付成果归客户，方法论IP归和光 | 与SaaS模式一致的IP策略 |
| **人才合作**（兼职/咨询） | 和光相关成果归公司 | 协议必须明确约定 |

### 4.2 IP归属条款关键设计

**必含核心条款**：
1. **背景IP保留条款**："双方各自保留合作前已拥有的知识产权，未经对方书面许可不得用于合作范围之外"
2. **前景IP归属条款**：明确约定合作期间产生的IP归属方式
3. **改进权条款**："接收方有权在本项目成果基础上进行改进，改进成果归改进方所有"
4. **共有IP行使规则**：约定共有专利的许可权、收益分配、维持费用分摊
5. **保密期条款**：合作结束后保密义务继续有效（建议≥3年）
6. **成果公开审查条款**：任何一方的论文发表/开源发布前，需经另一方书面审查
7. **背景IP许可条款**：合作范围内，各方向对方授予免费的背景IP使用许可

### 4.3 合作方IP风险分级

| 风险等级 | 合作方类型 | 管理措施 |
|:--------:|-----------|---------|
| 🔴 高风险 | 新合作方、竞争对手关联方、无保密协议的机构 | ①严格NDA签署前置 ②分段交付不提供全量代码 ③协议增加违约金条款 |
| 🟡 中风险 | 已有合作基础的客户、已签NDA的潜在合作方 | ①标准模板合同 ②技术交付物打标 ③季度IP审计 |
| 🟢 低风险 | 北航等长期战略合作伙伴、已投资机构 | ①框架协议 ②定期IP盘点 ③联审机制 |

## 五、IP管理组织与制度

### 5.1 IP管理委员会工作机制

- **季度IP盘点会**：每季度最后一个工作周，全面盘点IP资产状态
- **年度IP战略会**：每年12月，制定下年度IP战略规划与预算
- **应急响应**：发现IP泄露/侵权/无效风险时，48小时内启动应急响应

### 5.2 IP预算规划（2026年度参考）

| 项目 | 预算（万元/年） | 说明 |
|------|:----------:|------|
| 专利申请（国内） | 5-10 | 3-5件发明专利（含代理费） |
| PCT/海外申请 | 待定 | Q3评估后决定是否启动 |
| 软著登记 | 1-2 | 4件软著登记 |
| 商标注册 | 1-2 | 核心类别注册+防御注册 |
| 年度代理维护 | 3-5 | 专利维持费、商标续展 |
| 法律顾问 | 5-10 | IP专项法律顾问 |
| **合计** | **15-29** | 占年运营预算约3-5% |

### 5.3 IP风险应急预案

| 场景 | 响应等级 | 行动方案 |
|------|:-------:|---------|
| 员工泄漏核心技术 | 🔴 最高 | ①立即固定证据（日志/截图） ②启动法律程序 ③通知涉密合作方 ④更改系统权限 |
| 发现第三方侵权 | 🟡 高 | ①取证（公证/截图） ②发送律师函 ③决定是否诉讼/和解 |
| 专利被无效挑战 | 🟡 高 | ①评估无效理由 ②准备答辩材料 ③考虑补充申请 |
| 合作方IP权属争议 | 🟡 中 | ①审查合作协议 ②协商解决 ③仲裁/诉讼 |
| 域名/商标被抢注 | 🟢 中 | ①评估注册状态 ②提出异议申请 ③协商购买/更换 |
