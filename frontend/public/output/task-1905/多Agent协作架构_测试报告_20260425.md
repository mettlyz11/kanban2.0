## 四、智能路由器 (`agent_router.py`)

### 路由算法
1. **关键词匹配评分**: 遍历任务文本与Agent关键词库，计算命中率
2. **归一化处理**: 分数 = 命中关键词数 / 总关键词数
3. **最优选择**: 取最高分Agent；分数为0时使用fallback Agent
4. **多Agent协作**: 超过阈值(0.6)的Agent均加入协作队列（最多2个）

### 核心功能
```
AgentRouter.route(task)           → 单Agent路由
AgentRouter.route_multi(task)     → 多Agent协作路由
AgentRouter.assign_task(task)     → 完整任务分配流程
AgentRouter.collaboration_workflow(task)  → 协作工作流
```

## 五、ACP通信协议 - 6种消息类型

| 消息类型 | 方向 | 用途 |
|----------|------|------|
| `TASK_ASSIGN` | Router → Agent | 分配任务 |
| `TASK_RESULT` | Agent → Router | 返回结果 |
| `CAPABILITY_QUERY` | Router → Agent | 查询能力 |
| `CAPABILITY_RESPONSE` | Agent → Router | 返回能力信息 |
| `COLLABORATION_REQUEST` | Router → Agents | 发起协作 |
| `COLLABORATION_COMPLETE` | Agent → Router | 协作完成通知 |
