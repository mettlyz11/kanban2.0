## 2. 四大高频场景标准化工作流

### 2.1 科研写作工作流

#### 标准流程：
```
文献检索 → 摘要整理 → 大纲撰写 → 分章写作 → 润色优化 → 引用格式调整
```

#### 具体步骤：
1. **文献检索**: 使用Google Scholar + SciHub + Zotero批量下载
2. **摘要整理**: AI批量阅读PDF，提取核心观点和方法
3. **大纲撰写**: Claude 3.7 Sonnet生成三级论文大纲
4. **分章写作**: 按大纲分段生成，每段人工审核调整
5. **润色优化**: 使用学术写作专用Prompt进行语言提升
6. **引用格式**: Zotero自动生成BibTeX，统一格式

#### 工具组合：
- Zotero（文献管理）
- Claude Code（内容生成）
- Obsidian（笔记整合）
- Overleaf（最终排版）

---

### 2.2 数据分析工作流

#### 标准流程：
```
数据清洗 → 探索性分析 → 统计建模 → 可视化 → 报告生成
```

#### 具体步骤：
1. **数据清洗**: Pandas + AI自动识别异常值和缺失值
2. **探索性分析**: AI自动生成描述性统计和相关性矩阵
3. **统计建模**: 根据数据特征推荐合适的模型（回归/分类/聚类）
4. **可视化**: Matplotlib/Seaborn自动生成出版级图表
5. **报告生成**: Jupyter Notebook + Quarto输出分析报告

#### 关键Prompt：
- "分析这个数据集的质量问题，给出清洗方案"
- "推荐适合这个业务问题的统计模型，并解释理由"
- "生成5个最有洞察的可视化图表，带解读"

---

### 2.3 邮件处理工作流

#### 标准流程：
```
邮件分类 → 优先级排序 → 自动回复草稿 → 人工审核发送 → 归档整理
```

#### 具体步骤：
1. **邮件分类**: AI自动识别邮件类型（工作/私人/垃圾/待办）
2. **优先级**: 根据发件人、内容紧急程度打分排序
3. **草稿生成**: 针对常规邮件自动生成回复草稿
4. **审核发送**: 人工快速审核，一键发送
5. **自动归档**: 根据分类自动移入对应文件夹

#### 安全注意事项：
⚠️ 敏感邮件（法务、财务、人事）必须人工全程处理  
⚠️ 自动回复仅用于常规事务性邮件

### 2.4 会议纪要工作流

#### 标准流程：
```
录音转写 → 说话人识别 → 内容结构化 → 行动项提取 → 任务分发
```

#### 具体步骤：
1. **录音转写**: Whisper API高精度语音转文字（97%准确率）
2. **说话人分离**: 识别不同参会人，标记发言内容
3. **结构化整理**: 自动生成【议题】【讨论】【决议】【行动项】
4. **行动项提取**: 提取责任人、截止日期、具体任务
5. **任务分发**: 自动同步到任务管理系统（Things/Notion）

#### 工具链：
- OpenAI Whisper（语音转写）
- Claude Code（内容理解和结构化）
- Things 3（任务管理）

## 4. 常用Prompt模板库（15个）

### 4.1 科研写作类

#### 模板1: 文献总结
```
请阅读以下学术论文摘要，用中文总结：
1. 核心研究问题
2. 主要方法创新点
3. 关键实验结果
4. 对我的研究方向的启示

论文内容：{论文文本}
```

#### 模板2: 论文大纲生成
```
我要写一篇关于{主题}的学术论文。目标期刊是{期刊名}。
请生成包含以下部分的详细三级大纲：
- 摘要
- 引言（研究背景+问题+创新点）
- 相关工作
- 方法
- 实验
- 结果与讨论
- 结论
- 参考文献

要求符合该期刊的写作风格。
```

#### 模板3: 方法部分润色
```
请将以下方法描述改写成符合学术论文标准的正式英文表达，
要求逻辑清晰、专业术语准确，字数约{字数}。
内容：{原文}
```

#### 模板4: 审稿意见回复
```
我收到了审稿意见，需要礼貌且专业地回复。
审稿意见：{意见内容}
我的想法：{我的回应要点}

请生成一封结构清晰、语气诚恳的回复信，
包含：感谢、逐条回应、说明修改位置。
```
