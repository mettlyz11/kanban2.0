## 三、数据可视化与报告

### 每日晨报（自动生成）
每天早晨查看以下指标：
1. 昨夜睡眠质量（时长+深睡比例+觉醒次数）
2. 晨起静息心率 & HRV
3. 晨起血压读数
4. 昨日步数 & 运动量

### 每周复盘（每周日执行，15分钟）
1. 查看Apple Health周报告
2. 对比上周指标变化趋势
3. 标记异常数据（红色预警项）
4. 调整下周运动/睡眠计划

### 月度健康报告（每月1日，30分钟）
1. 汇总全月血压/心率/睡眠数据
2. 评估运动目标达成率
3. 压力趋势分析
4. 制定下月健康目标

## 四、预警与行动机制

### 🚨 红色预警（立即行动）
- 血压 ≥180/120 mmHg → **立即就医**
- 静息心率持续 >100 bpm 超过2小时 → **就医**
- HRV持续 <20 ms 超过3天 → **减少工作强度，休息**
- 胸痛/胸闷/呼吸困难 → **拨打120**

### ⚠️ 黄色预警（关注调整）
- 连续3天睡眠 <6小时 → **调整工作安排，优先补觉**
- 血压连续1周 >140/90 → **预约心内科复诊**
- 压力评分 >7 持续3天 → **增加冥想/运动时间**
- HRV下降 >20% 较基线 → **评估近期工作负荷**

### ✅ 绿色正常（保持）
- 所有指标在目标范围内 → **继续保持当前习惯**
