## 二、核心法律框架

### 商业秘密成立的三要件
1. **不为公众所知悉** → 需要技术查新报告 + 司法鉴定
2. **具有商业价值** → 需要财务数据 + 资产评估报告
3. **采取合理保密措施** → 需要保密协议 + 管理制度 + 执行记录

### 侵权认定的"接触+相似"原则
- 证明被告有**接触**商业秘密的客观条件
- 证明被告使用的信息与商业秘密**实质性相似**
- 满足两者即可初步推定侵权，举证责任转移至被告

## 三、证据收集优先事项（按紧急程度排序）

### 🔴 最紧急（立即执行）
1. **电子证据保全**：邮件、系统日志、聊天记录 → 公证处保全/区块链存证
2. **人员流向排查**：核心技术人员离职后去向
3. **保密协议收集**：所有签署过的保密协议、竞业限制协议

### 🟡 高优先级（1个月内）
4. 技术查新报告（委托科技信息研究所）
5. 技术研发记录整理（实验记录本、配方变更）
6. 商业合同与财务数据（证明商业价值）

### 🟢 中期（2-3个月）
7. 司法鉴定（非公知性鉴定）
8. 资产评估（技术价值评估）
9. 被告产品购买与反向工程分析

## 五、损害赔偿计算路径

1. **实际损失** → 销售收入减少、利润损失
2. **侵权获利** → 被告违法所得
3. **合理许可费** → 参照同类技术许可费标准
4. **法定赔偿** → 500万元以下（以上均无法确定时）
5. **惩罚性赔偿** → 1-5倍（恶意侵权+情节严重）
6. **维权费用** → 律师费、鉴定费、公证费等
