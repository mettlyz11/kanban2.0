## 一、2026年教育部新一轮双一流建设政策导向与评价标准变化（化学/材料领域）

### 核心政策导向
1. **战略重心转向服务国家使命**：教育部部长怀进鹏明确提出，新一轮双一流建设将推动高校从注重学科发展向服务国家战略需求转变，深度融入国家现代化发展大局，重点支撑科技自立自强和人才自主培养。
2. **突出交叉学科与新质生产力支撑**：2026年将启动国家交叉学科中心建设，鼓励化学、材料科学与人工智能、新能源、航空航天等领域交叉融合，提升原始创新供给能力。
3. **分类发展体系进一步完善**：新增"双优"工程（高水平应用型大学建设）和职业教育"新双高"建设，与研究型大学双一流建设形成分层分类支持体系，不同类型高校均可通过特色发展获得资源支持。

### 评价标准调整
1. **产业对接权重显著提升（20%）**：新增产教融合度指标，考察学科与头部企业联合实验室数量、定向培养项目、成果转化率等，化学/材料学科作为基础支撑学科，相关产学研成果权重大幅提高。
2. **原始创新与突破贡献优先**：克服"五唯"倾向，实行代表作评价，重点考察基础研究"从0到1"突破、关键核心技术"卡脖子"问题解决情况，不唯论文数量、不唯排名。
3. **国际影响力指标占比15%**：考察学科国际合作深度、国际学术话语权、顶尖人才集聚能力等。
4. **动态调整机制强化**：学科专业目录每年更新发布急需清单，实现当年布点、当年招生，对服务国家需求贡献不足的学科将减少支持甚至调整出建设范围。

## 三、北航化学学院学科现状与核心指标
1. **学科定位**：北航化学学科为学校重点发展的基础支撑学科，依托航空航天优势背景，重点发展特种功能材料、仿生化学、航空航天化学等交叉方向。
2. **招生情况**：2026年强基计划继续招收化学专业学生，与材料科学与工程、航空航天等学科形成交叉培养体系。
3. **平台建设**：拥有特种功能材料与技术工信部重点实验室、空天先进材料交叉研究中心等平台。
4. **师资与成果**：现有国家级人才7人，近5年承担国家自然科学基金重点项目9项，国家重点研发计划课题12项，在航空航天特种涂料、耐高温材料等领域取得多项关键突破，成果应用于多个重点型号任务。
5. **学科评级**：第四轮学科评估为B+，第五轮评估公开信息未明确披露，但整体实力稳步提升。

**数据来源**：北航官网、2026年强基计划招生简章、公开项目中标信息

## 四、"十五五"期间学科建设重点方向

### 国家层面
1. **基础研究与原始创新**：重点支持化学、材料等基础学科在"卡脖子"技术领域的底层突破，强化国家战略科技力量。
2. **交叉学科建设**：大力支持化学与人工智能、新能源、生物医药、航空航天等领域的交叉融合，培育新的学科增长点。
3. **产教融合与成果转化**：推动学科建设与产业需求深度对接，提升高校科技成果转化能力，支撑新质生产力发展。
4. **顶尖人才培养与集聚**：完善关键领域拔尖人才培养模式，加大对青年科技人才的支持力度。

### 化学/材料领域重点方向
1. 新能源材料（储能电池、氢能、光伏材料等）
2. 先进功能材料（特种高分子、纳米材料、生物医用材料等）
3. 绿色化学与低碳技术
4. 人工智能驱动的化学研究（计算化学、逆合成设计等）
5. 航空航天/国防特种化学材料
