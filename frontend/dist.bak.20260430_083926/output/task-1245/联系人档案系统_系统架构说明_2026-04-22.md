# 联系人档案系统 - 系统架构说明

## 1. 系统概述

本系统为刘宇宙教授的个人和商业联系人提供结构化、可检索的档案管理体系，支持关系维护、价值评估和合作追踪。

## 3. 档案内容标准

每个联系人档案包含以下6大模块：

### 3.1 基本信息模块
- 姓名（含别名/英文名）
- 职位
- 公司/机构
- 联系方式：手机、邮箱、微信、地址
- 照片（可选）

### 3.2 背景信息模块
- 教育经历（院校、专业、学位、年份）
- 工作经历（公司、职位、时间段）
- 专业领域与专长
- 主要成就与出版物

### 3.3 关系信息模块
- 认识途径（如何认识、时间、地点）
- 关系强度（1-5分：5=挚友，1=仅有一面之缘）
- 信任度评估（1-5分：5=完全信任）
- 共同好友/介绍人

### 3.4 互动历史模块
按时间倒序记录每次互动：
- 日期
- 互动方式（面谈/电话/微信/邮件/会议）
- 谈话要点
- 对方承诺事项
- 我方承诺事项
- 后续行动计划

### 3.5 价值评估模块
- 对方能提供的帮助（资源/信息/介绍/建议）
- 对方需要的帮助（我能提供什么）
- 合作潜力评级（1-5分）
- 近期合作机会
- 长期战略价值

### 3.6 隐私标记模块
- 隐私级别：公开/内部/机密/绝密
- 敏感信息备注
- 信息来源验证状态

## 4. 分类体系说明

| 分类 | 说明 | 优先级 |
|------|------|--------|
| 投资人 | VC/PE/天使投资人、FA、LP | 高 |
| 学术合作者 | 教授、研究员、博士后、博士生 | 高 |
| 政府官员 | 科技部、教育部、统战部、各地科委 | 高 |
| 商业伙伴 | 客户、供应商、技术合作方 | 高 |
| 校友网络 | 清华、NYU、Milliken、北航校友 | 中 |
| 家庭成员 | 直系亲属、重要亲戚 | 中 |
| 社会人士 | 党派成员、校友会理事、朋友 | 低 |

## 5. 数据来源与录入流程

### 5.1 数据来源
1. **微信通讯录分析** - 自动提取基本信息
2. **邮件往来整理** - 提取互动历史
3. **名片扫描录入** - OCR识别名片信息
4. **会议/活动记录** - 手工录入互动内容
5. **名片照片识别** - AI识别名片信息

### 5.2 录入流程
```
数据收集 → 信息验证 → 分类归档 → 关系评估 → 定期更新
```

## 6. 命名规范

档案文件名：`人物档案_{姓名}_{公司/机构}.md`
示例：`人物档案_张三_红杉资本.md`

## 7. 更新频率

- 高优先级联系人：每季度更新
- 中优先级联系人：每半年更新
- 低优先级联系人：每年更新
- 重要互动后：即时更新

## 8. 安全与备份

- 所有档案存储在本地加密目录
- 每日自动备份到加密云存储
- 绝密级信息单独加密存储
- 定期导出CSV格式备份
