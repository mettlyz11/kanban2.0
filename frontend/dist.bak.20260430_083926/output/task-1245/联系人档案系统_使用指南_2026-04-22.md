# 联系人档案系统 - 使用指南

## 🚀 快速开始

### 第一步：初始化目录结构
```bash
mkdir -p contacts/{投资人,学术合作者,政府官员,商业伙伴,校友网络,家庭成员,社会人士}
cp 联系人档案系统_档案模板_2026-04-22.md contacts/人物档案模板.md
```

### 第二步：录入首个联系人
1. 复制模板文件
2. 按分类放入对应目录
3. 命名为：`人物档案_{姓名}_{公司}.md`
4. 填充6大模块信息

### 第三步：更新索引
录入新联系人后，更新 `分类索引.md` 中的统计信息

## 📋 数据录入规范

### 1. 基本信息录入
- **姓名**：使用全名，不使用昵称
- **职位**：使用官方职位全称
- **联系方式**：优先录入常用手机号和工作邮箱
- **微信号**：建议录入，便于快速查找

### 2. 背景信息录入
- 教育经历从最高学历开始倒序排列
- 工作经历只列出重要的、1年以上的
- 专业领域控制在3-5个关键词
- 主要成就选最有代表性的3-5项

### 3. 关系信息录入
- **关系强度评分标准**：
  - ⭐⭐⭐⭐⭐ 5分：挚友、深度信任、可托付
  - ⭐⭐⭐⭐ 4分：好友、经常联系、互相帮助
  - ⭐⭐⭐ 3分：认识、有过合作、保持联系
  - ⭐⭐ 2分：仅有几次接触、不熟悉
  - ⭐ 1分：仅有一面之缘、名片关系

- **信任度评分标准**：
  - ⭐⭐⭐⭐⭐ 5分：完全信任、可分享机密
  - ⭐⭐⭐⭐ 4分：比较信任、可分享内部信息
  - ⭐⭐⭐ 3分：一般信任、公事公办
  - ⭐⭐ 2分：谨慎、需要验证信息
  - ⭐ 1分：不信任、保持距离

### 4. 互动历史录入
- 每次重要互动后立即记录
- 记录要点：决策、承诺、行动项
- 使用待办事项标记 [ ] 未完成、[x] 已完成
- 定期回顾并跟进承诺事项

### 5. 价值评估录入
- 实事求是，不要高估也不要低估
- 区分短期价值和长期价值
- 列出具体的合作点，不要空泛

### 6. 隐私标记规范
- **🔓公开**：可对外分享的公开信息
- **🔒内部**：仅限内部使用的信息
- **🔐机密**：仅限少数人知道的敏感信息
- **🔑绝密**：仅限刘教授本人知道的核心信息

## 🔧 数据来源处理

### 微信通讯录处理
1. 导出微信通讯录为CSV格式
2. 提取姓名、备注、标签信息
3. 根据备注判断分类
4. 批量创建档案草稿

### 名片处理
1. 拍摄名片高清照片
2. 使用OCR工具识别信息
3. 人工校验识别结果
4. 补充到对应档案

### 邮件处理
1. 搜索与特定联系人的邮件
2. 提取时间、主题、关键内容
3. 作为互动历史录入
4. 标记重要附件和链接

### 会议记录处理
1. 回顾会议纪要
2. 提取与该联系人相关的内容
3. 记录谈话要点和承诺
4. 更新关系评估

## 💡 使用技巧

### 1. 快速查找联系人
- 使用系统文件搜索功能
- 按姓名、公司、关键词搜索
- 使用分类目录导航

### 2. 关系维护提醒
- 在互动历史中标记下次联系时间
- 设置日历提醒
- 重要节日前批量查看

### 3. 合作机会追踪
- 每个联系人标注潜在合作点
- 定期筛选有合作机会的联系人
- 建立合作项目追踪表

3. **及时更新**：重要互动后24小时内完成记录
4. **实事求是**：客观评估，不夸大不贬低
5. **长期坚持**：关系管理是长期工作，贵在持续
