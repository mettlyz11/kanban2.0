## 四、个人任职证明（P10-P13）

### 4.1 单位任职证明 ✅ 核心中的核心！

**📝 标准模板（必须包含以下要素）**
```
任职证明

兹证明XXX（身份证号：XXXXXXXXXXXXXXXXXX）
自XXXX年XX月起在我单位工作，现任职务为：
首席技术官（CTO）/副总裁/技术总监（选择适合的）

该同志属于我公司核心管理团队成员，
负责公司核心技术研发/战略规划等重要工作。

特此证明。

XXXXXXXX科技有限公司（公章）
人事部门联系人：XXX
联系电话：XXXXXXXXXXX
2026年5月XX日
```

**⚠️ 关键要素缺一不可**：
✅ 职务名称必须包含"核心""高级""首席""总监"等高管字样
✅ 必须有人事部门联系人及电话（便于教委核实）
✅ 必须加盖企业公章（红章，复印章无效）
✅ 任职年限建议写"3年以上"（不满2年可能影响审核）

### 4.2 社保缴纳证明 ✅ 必备
- **时间范围**：近3年连续缴纳记录
- **开具渠道**：支付宝/微信→社保查询→缴费证明→下载打印
- **关键要求**：缴纳单位必须与申报单位一致
- **注意事项**：不能有中断，补缴记录需说明原因

### 4.3 劳动合同复印件 ⭐ 加分项
- 合同期内有效
- 职位条款与任职证明一致
- 复印件加盖公司公章

### 4.4 个税缴纳证明 ⭐ 加分项
- 近1年个人所得税完税证明
- 年收入50万以上可体现高管身份
- 个税APP可直接下载打印

## 九、提交方式与注意事项

### 9.1 提交渠道
| 政保类型 | 提交渠道 |
|----------|----------|
| **单位统一申报** | 由单位人事部门统一提交至区教委 |
| **个人申报** | 海淀区教委义务教育入学服务平台上传 |
| **线下提交** | 海淀区政务服务中心教育窗口 |

### 9.2 注意事项
⚠️ **重要提醒（过来人血泪教训）**：
1. **不要晚交**：截止日期后系统自动关闭，无补报机会
2. **不要造假**：材料虚假一票否决，记入诚信档案，影响孩子一生
3. **不要遗漏**：每一项材料都有其作用，不要想当然省略
4. **不要装订错误**：建议先打一份样稿，检查无误后正式装订
5. **保留证据**：提交时拍照/录像，取得接收回执，保留沟通记录

### 9.3 后续跟进要点
| 时间节点 | 跟进动作 |

## 十、常见问题与解决方案

| 常见问题 | 解决方案 |
|----------|----------|
| **社保中间断过1个月** | 提供补缴证明+单位说明信，解释原因（如跳槽） |
| **企业去年才拿到高新证书** | 重点强调企业发展潜力和未来纳税预期 |
| **职位名称不是"高管"** | 任职证明中写"核心管理团队成员""技术负责人" |
| **没有任何人才认定** | 侧重企业纳税规模和行业影响力，用企业实力弥补 |
| **孩子成绩一般** | 突出品德、特长、综合素质，不要编造成绩 |
