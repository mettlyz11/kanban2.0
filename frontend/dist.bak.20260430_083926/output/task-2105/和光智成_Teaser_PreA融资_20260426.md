## 5. 公司定位

### 核心定位

> **北航背书的AI材料发现与自动化实验一体化平台——中国的Periodic Labs**

### 品牌叙事三要素

```
和光智成 = 北航学术权威 × AI材料+药物双引擎 × 中国刚需市场
           (信任锚)      (差异化核心)       (商业场景)
```

### 四大差异化优势（USP）

1. **🎓 北航联合实验室独家合作**
   - 3个联合实验室，北京市重点实验室已揭牌
   - 独家学术数据接入 + 客户引荐渠道

2. **🧪 AI+湿实验闭环体系**
   - 计算预测 → 合成规划 → 实验验证 → AI迭代
   - 纯软件竞品不具备湿实验验证能力

3. **💰 中国成本，全球质量**
   - 研发成本仅为美国1/3-1/5
   - 同等质量，价格比竞品低50-70%

4. **🚀 材料+药物双引擎协同**
   - 电池材料 + 半导体材料 + AI药物发现
   - TAM是单一赛道的3倍，技术/人才/客户三重协同
