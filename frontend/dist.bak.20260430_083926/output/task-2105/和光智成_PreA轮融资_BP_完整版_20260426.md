## 1. 执行摘要

### 1.1 公司概览

| 核心指标 | 详情 |
|---------|------|
| **成立时间** | 2025年 |
| **总部** | 北京 |
| **核心定位** | 北航背书的AI材料发现与自动化实验一体化平台 |
| **技术壁垒** | AI建模 + 自动化实验 + 北航专属材料数据库 |
| **学术资质** | 北航联合实验室 + 北京市重点实验室 |
| **创始人** | 刘宇宙博士（北航化学学院教授，AI材料科学专家） |

## 3. 行业痛点

### 3.1 传统材料研发的五大痛点

| 痛点 | 描述 | 影响 |
|------|------|------|
| **研发周期长** | 新材料从发现到商业化需要5-10年 | 错失市场窗口，投资回报期长 |
| **成功率低** | 平均成功率仅30%左右 | 大量资源浪费在失败实验上 |
| **成本高昂** | 单个新材料研发成本可达数千万 | 中小企业难以承担研发风险 |
| **数据分散** | 实验数据分散，难以复用和分析 | 知识沉淀困难，研发效率低 |
| **人才稀缺** | 跨学科（材料+AI+自动化）人才匮乏 | 技术创新受限，团队组建困难 |

### 3.2 现有解决方案的不足

| 方案类型 | 代表公司 | 优势 | 不足 |
|----------|---------|------|------|
| **纯计算化学软件** | Schrödinger | 成熟，市场渗透率高 | 缺乏实验闭环，无法验证结果 |
| **AI药物发现** | XtalPi, Insilico | 商业模式验证，融资顺利 | 仅限药物领域，材料赛道空白 |
| **AI材料发现** | Periodic Labs, Kebotix | 技术先进，估值高 | 美国公司，中国本土化不足 |
| **传统CRO/CMO** | 药明康德等 | 实验能力强 | AI集成度低，效率提升有限 |

### 3.3 市场缺口

**中国市场需要一个：**
✅ 扎根中国本土，了解中国产业需求  
✅ 拥有权威学术背书，获得客户和投资人信任  
✅ 提供AI+实验完整闭环，不仅是软件  
✅ 覆盖材料+药物双赛道，最大化市场空间  
✅ 具有成本优势，服务中国广大中小企业

### 9.1 四大核心护城河

#### 🏆 1. 学术壁垒：北航独家资源，不可复制

- **北航-和光智成AI材料合成联合实验室**（已通过北航联席办公会）

- 北航人才输送管道 + 学术成果优先转化权
- 创始人教授身份 = 投资人信心 + 客户信任 + 政府资源

#### 🏆 2. 数据壁垒：北航专属材料数据库

- 北航数十年材料研究数据积累（独家授权）
- 自动化实验平台持续生成新的实验数据
- 数据闭环：实验数据反馈优化AI模型，越用越准
- 文献自动爬取 + 专利结构化分析，构建全面知识图谱

#### 🏆 3. 技术壁垒：干实验 + 湿实验完整闭环

- AI分子建模与预测（干实验）+ 自动化实验平台（湿实验）
- 端到端解决方案，区别于纯软件公司（如Schrödinger）
- 研发周期缩短75%，成功率提升3倍，客户价值可量化
- 技术栈可复用：材料发现技术可快速迁移到药物发现

#### 🏆 4. 模式壁垒：材料 + 药物双引擎协同

- 不像XtalPi只做药物，不像Periodic Labs只做材料
- 双赛道覆盖，TAM最大化（材料$25亿 + 药物$50亿+）
- 技术栈共享，研发效率更高，边际成本更低
- 风险分散：单一赛道波动不影响整体发展
