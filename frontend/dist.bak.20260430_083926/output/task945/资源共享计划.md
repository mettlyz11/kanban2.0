### 3.3 数据质量与标准化

#### 分子数据标准格式
```json
{
  "molecule_id": "MOL_001",
  "smiles": "CCO",
  "inchi": "InChI=1S/C2H6O/c1-2-3...",
  "properties": {
    "molecular_weight": 46.07,
    "logp": -0.14,
    "tpsa": 20.23
  },
  "source": "DrugMol-DB",
  "data_quality": "validated",
  "last_updated": "2026-04-17"
}
```

#### 反应数据标准格式
```json
{
  "reaction_id": "RXN_001",
  "reactants": ["CCO", "CC(=O)O"],
  "products": ["CCOC(=O)C"],
  "conditions": {
    "temperature": 80,
    "solvent": "toluene",
    "catalyst": "H2SO4"
  },
  "yield": 0.85,
  "source": "SynthPath-DB"
}
```

## 六、资源共享治理

### 6.1 治理架构

| 角色 | 职责 | 人员 |
|------|------|------|
| **资源管理委员会主任** | 总体决策、争议仲裁 | 刘宇宙教授 |
| **技术资源管理员** | 模型/算法共享管理 | 双方CTO轮流 |
| **数据资源管理员** | 数据共享平台运维 | 指定数据工程师 |
| **基础设施管理员** | 算力/设备调度 | 双方运维负责人 |

### 6.2 共享协议要点

1. **知识产权归属**:
   - 原有技术归各自所有
   - 联合开发成果按贡献比例共享
   - 学术论文发表需双方同意

2. **数据使用限制**:
   - 仅用于双方业务范围内
   - 不得向第三方泄露
   - 定期审计使用情况

3. **保密义务**:
   - 签署NDA
   - 分级保密管理
   - 离职后保密义务延续

### 6.3 绩效考核指标

| 指标类别 | 具体指标 | 目标值 |
|----------|----------|--------|
| **技术共享** | 共享模型数量 | 5+ |
| **数据共享** | 共享数据量 | 1000万+ 分子 |
| **算力共享** | 跨方算力使用时长 | 500+ GPU小时/月 |
| **人员交流** | 技术分享会次数 | 12次/年 |
| **联合产出** | 联合发表论文 | 3-5篇/年 |
