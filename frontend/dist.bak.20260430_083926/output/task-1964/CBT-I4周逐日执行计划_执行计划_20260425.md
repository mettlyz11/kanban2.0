## 📅 第2周：睡眠限制启动期

### 核心任务
- 根据第1周数据设定卧床时间
- 严格执行睡眠限制
- 继续刺激控制

### 初始参数计算
```
第1周平均总睡眠时间 = ______ 小时
初始卧床时间 = 第1周平均总睡眠时间（≥5小时）
固定起床时间 = 6:30
上床时间 = 6:30 - 卧床时间 = ______
```

### 逐日计划表

| 日期 | 任务 | 检查点 |
|-----|------|--------|
| **第8天** | 开始执行睡眠限制时间表 | [ ] 按时上床按时起床 |
| **第9天** | 白天绝对不睡觉 | [ ] 没有午休/打盹 |
| **第10天** | 感到困倦时坚持活动 | [ ] 困了就站立走动 |
| **第11天** | 起床后立即见自然光 | [ ] 10分钟户外光照 |
| **第12天** | 继续严格执行时间表 | [ ] 上下床时间差<15分钟 |
| **第13天** | 周末也严格执行 | [ ] 起床时间仍为6:30 |
| **第14天** | 计算第2周数据，评估效率 | [ ] 完成周总结 |

### 睡眠效率判断
- 效率 ≥ 90%：下周增加15分钟卧床时间
- 效率 85-89%：维持不变
- 效率 < 85%：下周减少15分钟卧床时间

## 📝 标准睡眠日记模板

### 【晨间填写】（起床后立即填写）

```
日期：____年___月___日 星期___

1. 昨晚我上床时间：____:____
2. 我花了____分钟才睡着
3. 夜间我醒来____次
4. 每次醒来持续时间：___ ___ ___ 分钟
5. 今早我起床时间：____:____
6. 我昨晚总共睡了约____小时
7. 我的睡眠质量：□ 很差 □ 一般 □ 好 □ 很好
8. 今早起床感觉：□ 非常疲倦 □ 有点累 □ 清醒 □ 精力充沛
```

### 【晚间填写】（睡前填写）

```
日期：____年___月___日

1. 今天我喝咖啡因（咖啡/茶/可乐）____次，最后一次在____:____
2. 今天我喝酒____杯，最后一次在____:____
3. 今天我运动了____分钟，在____:____结束
4. 今天我午睡/打盹____分钟，在____:____
5. 今天的压力水平（0-10）：____
6. 今天主要情绪：________________
7. 睡前1小时我在做：________________
8. 睡前我的想法：________________
```
