## 二、6维评分卡

### 评分说明
- 每项1-10分，10分为最优
- 加权计算公式: 总分 = Σ(维度分 × 权重)

| 维度 | 权重 | 评分标准 | 得分 | 加权得分 |
|------|------|----------|------|----------|
| 技术壁垒 | 25% | 10=国际领先有专利/顶刊; 7=国内领先; 4=有独特技术; 1=无差异化 | | |
| 团队背景 | 25% | 10=顶尖科学家+产业经验; 7=优秀学术背景; 4=有相关经验; 1=经验不足 | | |
| 市场空间 | 20% | 10=万亿级刚需; 7=千亿级; 4=百亿级; 1=市场小或不确定 | | |
| 商业模式 | 10% | 10=已验证有收入; 7=有明确路径; 4=尚在探索; 1=不清晰 | | |
| 融资能力 | 10% | 10=顶级VC超额加注; 7=知名机构; 4=有机构认可; 1=无人问津 | | |
| 协同价值 | 10% | 10=技术互补+客户共享; 7=有协同; 4=间接相关; 1=无协同 | | |
| **加权总分** | **100%** | **≥7.0通过** | | |

## 三、尽职调查Checklist

### 3.1 技术尽调
- [ ] 核心技术原理是否理解? 简述:
- [ ] 是否有专利/软件著作权? 数量:
- [ ] 是否有顶刊论文发表? 期刊/数量:
- [ ] 技术是否经过第三方验证?
- [ ] 与竞品相比的技术优势?
- [ ] 技术被替代/颠覆的风险?
- [ ] 技术从实验室到量产的风险评估?

### 3.2 团队尽调
- [ ] 创始人背景核实(学历/工作履历)?
- [ ] 核心团队成员稳定性评估?
- [ ] 股权结构是否合理?
- [ ] 是否有竞业限制/知识产权纠纷?
- [ ] 团队执行力验证(过往成果)?
- [ ] 创始人商业意识评估?
- [ ] 是否进行过背调(前同事/投资人)?

### 3.3 商业尽调
- [ ] 现有营收数据核实?
- [ ] 客户/合作方真实性验证?
- [ ] 商业模式可持续性评估?
- [ ] 市场规模估算依据?
- [ ] 竞品分析是否完整?
- [ ] 融资轮次/历史估值核实?
- [ ] 主要股东背景核实?

### 3.4 法律/财务尽调
- [ ] 公司注册信息核实?
- [ ] 知识产权归属确认?
- [ ] 是否有未披露负债/纠纷?
- [ ] 资金使用计划是否合理?
- [ ] 投资协议核心条款审阅?
- [ ] 关联交易风险排查?
- [ ] 退出机制是否明确?
