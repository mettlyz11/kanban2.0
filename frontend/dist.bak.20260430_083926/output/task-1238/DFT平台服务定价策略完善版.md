# DFT平台服务定价策略完善版

## 1. 定价策略总览

### 1.1 定价原则
- **价值导向**：基于为客户创造的价值定价，而非成本加成
- **分层定价**：三级体系覆盖不同客户群体
- **灵活计费**：支持订阅制、按需计费、资源包多种模式
- **生态协同**：与XuanLab实验平台捆绑优惠
- **市场导向**：对标竞品，保持价格竞争力

### 1.2 定价模型对比
| 模型 | 优点 | 缺点 | 适用场景 |
|------|------|------|----------|
| **订阅制** | 收入可预测，客户粘性高 | 使用量可能不匹配 | 长期稳定使用 |
| **按需计费** | 完全按使用付费，灵活 | 收入波动大，成本不可预测 | 偶发性需求 |
| **资源包** | 预付费，现金流好 | 可能用不完造成浪费 | 项目制需求 |
| **混合模式** | 兼顾灵活性和稳定性 | 计费复杂 | 主流选择 |

## 3. 按核时计费详细标准

### 3.1 核时定义
**1核时** = 1个CPU核心运行1小时
- 支持Intel/AMD x86_64架构
- 支持ARM架构（折扣系数0.8）
- GPU核时单独计算（1 GPU小时 = 10 CPU核时）

## 4. 任务复杂度评估模型

### 4.1 复杂度评分公式
```
复杂度分数 = 基础分数 × 方法系数 × 体系系数 × 功能系数

其中：
基础分数 = 原子数 / 10
方法系数 = 见3.4节
体系系数 = 见3.3节
功能系数 = 任务类型系数（单点=1.0，优化=1.5，频率=2.0，过渡态=3.0）
```

```python
def estimate_task_complexity(task_params):
    """自动评估任务复杂度"""
    # 计算基础分数
    base_score = task_params['num_atoms'] / 10
    
    # 应用系数
    method_coef = get_method_coefficient(task_params['method'])

    function_coef = get_function_coefficient(task_params['task_type'])
    
    # 计算总分数
    total_score = base_score * method_coef * system_coef * function_coef
    
    # 确定等级和价格

    price_coef = get_price_coefficient(level)
    
    return {
        'score': total_score,
        'level': level,
        'price_coefficient': price_coef,
        'estimated_core_hours': estimate_core_hours(total_score),
    }
```

```
2. 费用计算
```

```python
        'intangible_benefits': intangible_benefits,
    }
```
