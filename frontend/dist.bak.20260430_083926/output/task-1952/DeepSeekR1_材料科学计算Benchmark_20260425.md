## 测试用例详情与标准答案

### 一、分子式计算（4题）

#### TC-001: 摩尔质量计算
**题目**: 计算LiFePO₄（磷酸铁锂）的摩尔质量，已知各元素原子量：Li=6.94, Fe=55.85, P=30.97, O=16.00。
**标准答案**: 157.76 g/mol
**计算过程**: 6.94 + 55.85 + 30.97 + (4 × 16.00) = 157.76

#### TC-002: 元素质量百分比
**题目**: 计算Ti₆Al₄V（钛合金）中Al元素的质量百分比，已知原子量：Ti=47.87, Al=26.98, V=50.94。
**标准答案**: 6.01%
**计算过程**: 总质量 = 6×47.87 + 4×26.98 + 1×50.94 = 446.08；Al质量 = 4×26.98 = 107.92；百分比 = (107.92/446.08) × 100% = 24.19%

*修正: 正确答案应为24.19%*

#### TC-003: 化学计量比计算
**题目**: 在甲烷燃烧反应 CH₄ + 2O₂ → CO₂ + 2H₂O 中，完全燃烧16克CH₄需要多少克O₂？已知C=12.01, H=1.008, O=16.00。
**标准答案**: 64.00克
**计算过程**: CH₄摩尔质量 = 16.04 g/mol；16g CH₄ = 0.9975 mol；需要O₂ = 2 × 0.9975 = 1.995 mol；O₂质量 = 1.995 × 32 = 63.84 ≈ 64克

#### TC-004: 晶体化学式确定
**题目**: 某钙钛矿结构氧化物晶胞中，Sr位于顶点（8个），Ti位于体心（1个），O位于面心（6个）。求该晶体的化学式。
**标准答案**: SrTiO₃
**计算过程**: Sr: 8×1/8=1；Ti: 1×1=1；O: 6×1/2=3 → SrTiO₃

### 二、反应热力学分析（3题）

#### TC-005: 反应焓变计算
**题目**: 计算反应 2Al + Fe₂O₃ → Al₂O₃ + 2Fe 的标准焓变ΔH°。已知生成焓：ΔH°_f(Fe₂O₃) = -824 kJ/mol，ΔH°_f(Al₂O₃) = -1676 kJ/mol，单质生成焓为0。
**标准答案**: -852 kJ/mol
**计算过程**: ΔH° = ΣΔH°_f(产物) - ΣΔH°_f(反应物) = (-1676) - (-824) = -852 kJ/mol

#### TC-006: Gibbs自由能与反应自发性
**题目**: 298K时，反应 CaCO₃(s) → CaO(s) + CO₂(g) 的ΔH° = 178 kJ/mol，ΔS° = 160 J/(mol·K)。计算ΔG°并判断反应是否自发。
**标准答案**: ΔG° = 130.3 kJ/mol，反应非自发
**计算过程**: ΔG° = ΔH° - TΔS° = 178000 - 298×160 = 178000 - 47680 = 130320 J/mol = 130.3 kJ/mol > 0，非自发

#### TC-007: 平衡常数计算
**题目**: 某化学反应在300K时ΔG° = -20 kJ/mol，计算平衡常数K。气体常数R = 8.314 J/(mol·K)。
**标准答案**: K ≈ 3000（精确值：e^(8.034) ≈ 3100）
**计算过程**: ΔG° = -RTlnK → lnK = -ΔG°/(RT) = 20000/(8.314×300) = 8.034 → K = e^8.034 ≈ 3100

### 三、晶体结构预测（3题）

#### TC-008: 晶胞参数与密度计算
**题目**: NaCl晶体为面心立方结构，晶胞边长a = 5.64 Å（1Å = 10^-8 cm）。每个晶胞含4个Na⁺和4个Cl⁻。计算NaCl晶体密度。已知Na=22.99, Cl=35.45，阿伏伽德罗常数N_A = 6.022×10²³ mol⁻¹。
**标准答案**: 2.17 g/cm³
**计算过程**: 晶胞质量 = 4×(22.99+35.45)/6.022×10²³ = 234.11×10⁻²³ g；晶胞体积 = (5.64×10⁻⁸ cm)³ = 179.4×10⁻²⁴ cm³；密度 = 234.11×10⁻²³ / 179.4×10⁻²⁴ = 2.17 g/cm³

#### TC-009: 布拉格衍射与晶面间距
**题目**: X射线衍射实验中，Cu Kα射线波长λ = 1.54 Å，在2θ = 30°处观察到一级衍射（n=1）。计算该晶面间距d。
**标准答案**: d = 2.97 Å
**计算过程**: 布拉格定律 2d sinθ = nλ；θ = 15°；sin15° ≈ 0.2588；d = 1×1.54/(2×0.2588) = 1.54/0.5176 = 2.97 Å

#### TC-010: 原子堆积因子计算
**题目**: 体心立方（BCC）结构晶胞中，原子半径r与晶胞边长a的关系为a = 4r/√3。计算BCC结构的原子堆积因子（APF）。
**标准答案**: APF = 0.68（68%）
**计算过程**: 晶胞原子数 = 2；原子总体积 = 2 × (4/3)πr³；晶胞体积 = a³ = (4r/√3)³ = 64r³/(3√3)；APF = [8πr³/3] / [64r³/(3√3)] = (8π√3)/64 = π√3/8 ≈ 0.6802
