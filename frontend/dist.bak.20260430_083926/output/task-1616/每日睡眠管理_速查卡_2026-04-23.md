# 每日睡眠管理速查卡

> **任务编号**: #1616 | **父任务**: #1578
> **用途**: 打印或保存在手机桌面，每日对照执行

---

## ☀️ 晨起流程（5分钟）

- [ ] 固定时间起床（周末也保持，偏差≤1小时）
- [ ] 立即拉开窗帘/接触阳光5分钟
- [ ] 饮水300ml（温水最佳）
- [ ] 记录：醒来时间、总睡眠时长、主观评分（1-10）
- [ ] 轻度拉伸5分钟

---

## 🌅 日间管理

### 上午
- [ ] 早餐：高蛋白+复合碳水
- [ ] 如需咖啡，在10:00前完成
- [ ] 每工作50分钟，起身活动5分钟

### 中午
- [ ] 午餐7分饱
- [ ] 午睡：20-30分钟（13:00-14:30之间），不超过30分钟
- [ ] **14:00后停止一切咖啡因摄入**

### 下午
- [ ] 运动30-45分钟（最佳时段16:00-18:00）
  - 周一/三/五：中等强度有氧
  - 周二/四：力量训练
  - 周六/日：户外活动

### 晚餐（18:30-19:30）
- [ ] 轻食为主，7分饱
- [ ] 避免油腻、辛辣、高糖
- [ ] 20:00后不进食

---

## 🌙 睡前仪式（60分钟）

### 21:00 开始放松
- [ ] 手机开启勿扰模式，关闭工作通知
- [ ] 阅读纸质书（非工作相关）或听轻音乐
- [ ] 温水泡脚15分钟（40-42°C）
- [ ] 准备第二天物品（减少次日焦虑）

### 22:00 过渡准备
- [ ] 洗漱（温水澡）
- [ ] 调暗卧室灯光
- [ ] 检查卧室环境：
  - 温度：18-20°C ✓
  - 窗帘：完全遮光 ✓
  - 噪音：<30分贝 ✓
  - 手机：放远/飞行模式 ✓

### 22:15 入睡准备
- [ ] 4-7-8呼吸法 × 4次
  - 吸气4秒 → 屏息7秒 → 呼气8秒
- [ ] 感恩日记：写3件值得感恩的事
- [ ] 上床，闭眼

## 🚨 异常应对速查

| 情况 | 应对 |
|------|------|
| 躺下30分钟没睡着 | 起床→客厅→放松活动→困了再回床 |
| 半夜醒来 | 不看手机→4-7-8呼吸法→闭眼等待 |
| 早醒无法再睡 | 直接起床→保持当日正常作息→晚上提前睡 |
| 出差旅行 | 带眼罩+耳塞→按当地时间活动→不立即补觉 |
| 连续失眠>2周 | 就医：睡眠门诊/神经内科 |

## 🎯 每周复盘清单（周日晚上15分钟）

- [ ] 计算本周平均睡眠时长、深睡%、主观评分
- [ ] 对比上周数据，标记变化（↑/↓/→）
- [ ] 识别本周最有效和最无效的习惯
- [ ] 调整下周行动计划
- [ ] 填写PSQI自评量表（每月末）
