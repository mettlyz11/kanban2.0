# IBDP选课最优方案报告

## 一、IBDP课程体系深度解析

### 1.1 六大学科组选课策略

IBDP课程要求学生从以下6个学科组中各选一门课程，其中至少3门为高级水平（HL），其余为标准水平（SL）：

| 学科组 | 核心课程 | 适合理工方向的选择 |
|--------|----------|-------------------|
| **第一组：语言A** | 中文A文学/语言与文学 | 中文A语言与文学（SL） |
| **第二组：语言B** | 英语B/其他语言 | 英语B（HL）- 理工必备学术英语 |
| **第三组：个人与社会** | 经济/历史/地理/商务管理 | 经济学（HL）- 培养逻辑思维 |
| **第四组：实验科学** | 物理/化学/生物/计算机科学 | 物理（HL）+ 化学（SL）双选 |
| **第五组：数学** | 分析与方法/应用与解释 | 数学AA（HL）- 理工核心基础 |
| **第六组：艺术** | 视觉艺术/音乐/戏剧 | 计算机科学（HL）替代艺术组 |

### 1.2 核心课程：TOK/EE/IA评分标准

**TOK（知识论）- 满分3分**
- 10分钟口头报告（10分）
- 1600字论文（10分）
- 评分等级：A/B/C/D/E，A+B=3分，A+C/B+B=2分

**EE（拓展论文）- 满分3分**
- 4000字独立研究论文
- 理工方向强烈建议选择：物理/化学/数学/计算机科学
- 评分等级与TOK共同构成核心加分（最多3分）

**IA（内部评估）- 每门课20-30%权重**
- 实验报告、研究项目、口头展示等
- 由校内老师评分，IBO外部抽样审核
- 理工科目IA占比高，是GPA提分关键

### 1.3 理工方向选课组合最优解

#### 推荐组合A（最强理工导向，目标牛津/剑桥/MIT）

| 学科 | 级别 | 理由 |
|------|------|------|
| 中文A语言与文学 | SL | 母语基础好，节省精力给理科 |
| 英语B | HL | 学术英语能力，大学必备 |
| 经济学 | HL | 培养逻辑，HL相对易拿7分 |
| 物理 | HL | 理工专业硬性要求 |
| 数学分析与方法（AA） | HL | 所有顶尖理工强制要求 |
| 计算机科学 | HL | 替代第六组，实用技能 |

**优势：** 4门HL，理工含金量最高，满足所有顶尖大学要求
**风险：** 课业负担重，需要极强时间管理能力

|------|------|------|

| 英语B | HL | |
| 经济学 | SL | 减轻负担 |
| 物理 | HL | |

| 化学 | SL | 生物/医学方向可换生物 |

**优势：** 3门HL，负担合理，GPA可控
**劣势：** 计算机科学缺失，部分CS专业受限

#### 推荐组合C（保底型，目标加拿大/澳大利亚）

**优势：** 仅2门HL，GPA保障度高
**劣势：** 顶尖理工大学竞争力不足

## 二、选课关键决策点

### 2.1 HL vs SL选择原则
- **必选HL：** 数学AA、物理（理工方向硬性要求）
- **推荐HL：** 英语B（大学学术写作必备）
- **可选HL：** 计算机科学/经济学（看兴趣和能力）
- **避免HL：** 中文A（母语7分率低，SL足够）

### 2.2 7分率数据参考（2025年IB全球统计）
| 科目 | HL 7分率 | SL 7分率 |
|------|----------|----------|
| 数学AA | 14% | 11% |
| 物理 | 16% | 18% |
| 化学 | 17% | 19% |
| 计算机科学 | 25% | 22% |
| 经济学 | 21% | 18% |
| 英语B | 17% | 15% |
| 中文A | 8% | 7% |

### 2.3 大学专业对应选课要求

| 专业方向 | 强制要求 | 强烈推荐 |
|----------|----------|----------|
| 工程类 | 物理HL + 数学AA HL | 化学SL/HL |
| 计算机科学 | 数学AA HL | CS HL + 物理HL |
| 数学/物理 | 数学AA HL + 物理HL | CS HL |
| 化学/材料 | 化学HL + 数学AA HL | 物理SL |
| 经济/金融 | 数学AA HL | 经济HL |
