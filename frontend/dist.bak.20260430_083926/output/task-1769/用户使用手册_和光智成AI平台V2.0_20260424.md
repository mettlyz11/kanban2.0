## 二、核心功能详解

### 2.1 材料数据管理

#### 数据导入
支持多种数据格式导入：
- **Excel/CSV**: 批量导入结构化数据
- **CIF/POSCAR**: 晶体结构文件
- **JSON**: 自定义格式数据
- **数据库直连**: PostgreSQL/MySQL/MongoDB

**操作步骤**:
1. 进入"数据管理" → "导入数据"
2. 选择文件或连接数据库
3. 映射字段（平台自动识别常见字段名）
4. 预览并确认，开始导入

> ⚠️ **注意**: 单次导入建议不超过10万行，超大数据请分批导入

#### 数据质量检查
导入后平台自动进行质量检测：
- ✅ 数据完整性检查（缺失值统计）
- ✅ 异常值检测（离群点识别）
- ✅ 重复数据去重
- ✅ 单位标准化转换

点击"数据报告"查看详细质检结果。

### 2.2 可视化分析

平台提供多种可视化图表类型：
| 图表类型 | 适用场景 | 示例 |
|---------|---------|------|
| 散点图 | 相关性分析 | 带隙 vs 形成能 |
| 热图 | 多维度对比 | 元素组合性能矩阵 |
| 3D结构 | 分子可视化 | 晶体结构渲染 |
| 趋势图 | 时序预测 | 性能变化曲线 |
| 平行坐标 | 多参数筛选 | 材料筛选器 |

**操作技巧**:
- 拖拽横纵轴切换分析维度
- 框选数据点可批量操作
- 点击图例可隐藏/显示数据系列
- 所有图表支持PNG/SVG/PDF导出

## 三、AI预测引擎使用指南

### 3.1 可用预测模型

| 模型名称 | 预测目标 | 准确率 | 计算耗时 | 积分消耗 |
|---------|---------|-------|---------|---------|
| CrystalNet-v3 | 晶体结构预测 | 94% | 2~5秒 | 50分/次 |
| BandGapNet | 带隙预测 | 92% | 1~3秒 | 30分/次 |
| FormationE | 形成能预测 | 91% | 1~2秒 | 30分/次 |
| Stability | 稳定性评估 | 88% | 3~8秒 | 80分/次 |
| Custom Model | 用户自定义 | - | 取决于模型 | 自定义 |

### 3.2 预测操作流程

1. **选择数据**: 从项目中选择要预测的数据集
2. **选择模型**: 根据预测目标选择合适模型
3. **配置参数**: 设置批次大小、置信度阈值等
4. **提交任务**: 确认积分消耗后提交
5. **查看结果**: 任务完成后邮件通知，可在线查看和导出

### 3.3 批量预测
对于大规模预测任务：
- 支持一次提交最多10000条数据
- 任务排队执行，可随时查看进度
- 支持任务暂停、取消、优先级调整
- 失败自动重试3次

> 💡 **省钱技巧**: 非紧急任务选择"闲时调度"，积分消耗打5折

## 四、数据管理最佳实践

### 4.1 数据组织建议
```
项目根目录/
├── 原始数据/          # 不修改，保留原始备份
├── 清洗后数据/        # 标准化后的可用数据
├── 模型输入/          # AI预测专用格式
├── 预测结果/          # 按日期/版本归档
└── 导出报告/          # 最终交付物
```

### 4.2 数据备份
- 平台自动每日备份（保留30天）
- 重要项目建议手动导出备份
- 支持一键导出整个项目（数据+模型+设置）

### 4.3 性能优化技巧
1. **合理分区**: 大数据集按时间/类别分区
2. **索引优化**: 常用查询字段建议标记为"索引字段"
3. **缓存设置**: 频繁访问的数据开启缓存
4. **定期清理**: 删除不再使用的临时数据

## 五、API集成指南

### 5.1 获取API密钥
1. 进入"个人设置" → "API密钥"
2. 点击"生成新密钥"，设置过期时间
3. 保存密钥（仅显示一次！）

> ⚠️ **安全提醒**: 不要将API密钥提交到代码仓库或公开场所

### 5.2 Python SDK快速开始

```python
import heguangai

# 初始化客户端
client = heguangai.Client(api_key="your-api-key")

# 提交预测任务
result = client.predict(
    model="BandGapNet",
    data=[
        {"formula": "Si", "structure": "cif_content"},
        {"formula": "GaAs", "structure": "cif_content"}
    ]
)

# 获取预测结果
print(result.predictions)
```

- 专业版: 10000次/天，100次/分钟
- 企业版: 无限制，可定制SLA

## 六、常见问题FAQ

### Q: 导入数据失败怎么办？
A: 请检查：
1. 文件编码是否为UTF-8
2. 是否有特殊字符或空行
3. 文件大小是否超过500MB限制
4. 查看导入日志中的具体错误信息

### Q: 预测任务一直排队怎么办？
A: 
- 检查计算积分是否充足
- 高峰时段（工作日9-11点, 14-17点）可能延迟
- 紧急任务可联系客服调整优先级
- 企业用户享有专属计算资源队列

### Q: 如何申请自定义模型？
A: 
1. 准备标注好的训练数据（至少1000条）
2. 联系客户经理提交定制需求
3. 评估后给出开发周期和报价
4. 模型训练完成后专属部署

### Q: 数据安全如何保障？
A:
- 所有数据传输和存储全程加密
- 企业用户支持私有化部署
- 可签署数据保密协议（NDA）
- 平台通过ISO27001、等保三级认证
