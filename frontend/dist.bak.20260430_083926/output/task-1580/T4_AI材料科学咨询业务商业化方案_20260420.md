## 七、合规框架

### 7.1 利益冲突管理

| 风险场景 | 管控措施 |
|----------|----------|
| 咨询客户与和光智成竞争 | 提前评估，如存在直接竞争关系则拒绝 |
| 咨询中涉及和光智成商业机密 | 严格区分：只谈公开知识和通用方法论 |
| 咨询内容与T109技术相关 | 只提供概念性指导，不提供代码/算法细节 |
| 时间冲突 | 咨询时间严格限制在非工作时间或周末 |

**利益冲突评估清单**（每次咨询前）：
- [ ] 客户业务是否与和光智成直接竞争？
- [ ] 咨询内容是否涉及和光智成未公开技术？
- [ ] 咨询内容是否涉及T109核心算法？
- [ ] 是否存在保密协议限制？
- [ ] 是否已告知和光智成合伙人？

### 7.2 税务优化方案

| 收入类型 | 税务处理 | 建议 |
|----------|----------|------|
| GLG美元收入 | 个人劳务报酬（20-40%） | 建议设立个体工商户 |
| Capvision人民币收入 | 平台代扣或个人申报 | 个体户统一申报 |
| 直接客户收入 | 个体户经营所得（5-35%累进） | 以工作室名义签约 |
| 年度顾问收入 | 个体户/公司收入 | 大额合同走公司 |

**推荐方案**：设立个体工商户（科技咨询类工作室）
- 注册地：北京中关村/北航科技园
- 名称建议：北京XX科技咨询工作室
- 税率：经营所得5-35%累进（小规模纳税人可享优惠）
- 优势：可以开增值税发票、合规处理所有咨询收入

### 7.3 声誉保护

| 风险 | 防护措施 |
|------|----------|
| 学术声誉 | 咨询内容保持客观，不做投资推荐 |
| 利益冲突 | 所有公开内容声明"个人观点" |
| 过度曝光 | 控制公开发言频率，保持稀缺性 |
| 内容质量 | 所有文章/报告经AI辅助检查（OpenClaw自动校对） |
| 凯盛合规 | 不涉及任何涉密/敏感信息，只提供公开技术知识 |
