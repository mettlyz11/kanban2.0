# 致公党2026参政议政重点方向与选题指南

**编制日期：2026年4月25日**

---

## 一、致公党2026参政议政总体方向

### 1.1 时代背景
2026年是"十五五"规划开局之年，也是中国式现代化建设的关键一年。致公党作为具有"侨海"特色的参政党，将紧扣国家发展大局，聚焦高质量发展，扎实推进参政议政各项工作。

### 1.2 核心指导思想
- 坚持政治引领，深刻领悟"两个确立"决定性意义
- 党委有部署、致公有行动，政府有需求、致公有作为
- 坚持"不调研不建言"的致公特色
- 质量优先、量质双升，做到建言中肯、研判精准、对策可行

## 二、致公党中央重点关注领域

### 2.1 科技创新领域
- **以企业为主体的科技创新体系建设**
  - 筑牢企业创新主体地位
  - 厚植产学研深度融合生态
  - 拓展国际合作新空间
  - 优化人才引进培育环境
  - 营造包容高效的创新友好生态

- **人工智能与实体经济深度融合**
  - 先进制造与人工智能融合
  - "人工智能+"行动在各行业的落地应用
  - 人工智能开源社区建设
  - 人工智能安全风险防治体系建设

### 2.2 经济发展领域
- 高质量发展与新质生产力培育
- 营商环境优化与民营经济发展
- 外资外贸稳定与高水平对外开放
- 创业投资与天使投资发展
- 国有经济布局优化和结构调整

### 2.3 生态环境保护
- 长江生态环境保护民主监督成果深化
- 绿色低碳转型与"双碳"目标实现
- 生物多样性保护
- 碳排放双控工作推进

### 2.4 侨海特色领域
- 海外侨胞、归侨侨眷和留学人员联系服务
- 讲好中国故事，凝聚和增进共识
- 侨资企业发展与海外人才引智
- 海峡两岸融合发展

### 2.5 民生与社会领域
- 银发经济与养老服务体系
- 医疗卫生与健康中国建设
- 乡村振兴与农业现代化
- 教育科技人才一体化发展

## 四、科技领域参政议政选题指南

### 4.1 优先选题方向（高匹配度）

#### ✅ 人工智能+新材料创新发展
- 设立国家AI材料实验室的战略必要性
- 材料大数据基础设施建设与数据要素流通
- 智能实验室建设与新材料研发范式变革
- 材料科学大模型与垂类模型研发
- "AI+新材料"融合创新生态建设

#### ✅ 企业为主体的科技创新体系
- 强化企业科技创新主体地位的政策建议
- 产学研深度融合机制创新
- 科技成果转化中试平台建设
- 专精特新企业培育与支持政策

#### ✅ 人才发展与创新生态
- 复合型科技人才培养机制
- 海外高层次人才引进政策
- 科技评价体系改革
- 科技创新容错机制建设

#### ✅ 数字经济与未来产业
- 全国一体化算力网建设
- 数据要素基础制度与数据市场建设
- 量子科技、绿色氢能、生物制造等未来产业布局
- 可控核聚变商业化应用前瞻

### 4.2 选题原则与质量要求

#### 选题三原则
1. **国家战略契合度**：紧扣"十五五"规划开局之年重点任务
2. **致公特色匹配度**：发挥"侨海"优势和致公党长期关注领域
3. **专业领域准确度**：立足专业背景，确保建议科学可行

#### 高质量提案标准
- **问题导向**：聚焦真实存在的产业痛点和政策堵点
- **调研深入**：有数据支撑、有案例分析、有实地调研
- **对策具体**：建议可操作、可落地、可考核
- **视野前瞻**：具有战略性、前瞻性、系统性

## 五、提案提交渠道与时间节点

### 5.1 提交渠道
1. **全国政协层面**：通过致公党中央提交全国政协提案
2. **地方政协层面**：通过地方致公党组织提交地方政协提案
3. **社情民意信息**：短小精悍的专项建议可作为社情民意信息报送
4. **专题调研报告**：重大课题可形成专题调研报告报送相关部门

### 5.2 时间节点建议
- **4-6月**：课题立项与调研方案制定
- **7-9月**：实地调研与数据收集
- **10-11月**：报告撰写与专家论证
- **12月-次年1月**：提案修改完善与提交

### 5.3 成果转化路径
- 提案 → 政协立案 → 部门办理 → 政策落地
- 调研报告 → 领导批示 → 纳入决策
- 社情民意 → 上级采用 → 推动问题解决
