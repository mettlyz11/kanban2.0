# 北航校内系统操作指南

## 前置准备
1. 打开Safari或Chrome浏览器
2. 确保网络连接正常，可以访问北航校内网站

## 操作步骤
1. 在浏览器地址栏输入北航统一身份认证地址：https://auth.buaa.edu.cn
2. 等待页面加载完成后，点击「统一身份认证登录」按钮
3. 在用户名输入框输入校园账号，密码输入框输入对应密码
4. 完成验证码验证后点击登录按钮
5. 登录成功后，在服务列表中找到需要操作的系统（如教务系统、办公系统）
6. 点击对应系统入口进入目标系统
7. 根据需要执行查看通知、下载文件、提交表单等操作
8. 操作完成后点击退出登录按钮，确保账号安全

## 注意事项
- 登录时注意区分大小写，避免多次错误导致账号锁定
- 访问校内系统时如果出现连接问题，检查VPN是否已连接
- 重要操作提交前再次确认填写内容是否正确
- 不要在公共设备上保存登录密码
