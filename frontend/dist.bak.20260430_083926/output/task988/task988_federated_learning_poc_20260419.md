## 一、POC概述

### 1.1 目标
验证深云智合与和光智成在AI材料合成领域的联邦学习技术可行性，以固态电解质材料体系为试点，证明联合模型预测精度优于单方基线15%以上。

### 1.2 试点材料体系
**固态电解质（Solid-State Electrolyte, SSE）**
- 首选体系: LLZO (Li₇La₃Zr₂O₁₂) 及其掺杂变体
- 备选体系: LATP (Li₁.₃Al₀.₃Ti₁.₇(PO₄)₃), LGPS (Li₁₀GeP₂S₁₂)
- 目标性能: 离子电导率 > 10⁻³ S/cm，电化学窗口 > 4V

### 1.3 为什么选择固态电解质
| 维度 | 说明 |
|------|------|
| 数据互补性 | 深云有合成反应数据，和光有材料表征数据 |
| 申报覆盖度 | 新能源/固态电池为热点，多个申报指南覆盖 |
| 技术可行性 | 数据维度适中，模型收敛周期可控（4-6周） |
| 商业价值 | 固态电池为下一代储能技术，市场空间巨大 |

## 三、模型架构

### 3.1 基线模型

| 模型 | 所属方 | 架构 | 输入 | 输出 |
|------|--------|------|------|------|
| MolGNN-SSE | 深云智合 | 图神经网络 (GNN) | 分子图 | 离子电导率预测 |
| ChemTrans-SSE | 和光智成 | Transformer | 组成+结构编码 | 多性质预测 |

### 3.2 联邦学习框架

**推荐框架**: Flower (flwr.dev) — 轻量级、支持PyTorch、差分隐私集成

```
联邦训练流程:
1. 中央服务器初始化全局模型权重 w₀
2. 每轮训练:
   a. 服务器广播 wₜ 到各方节点
   b. 各方节点用本地数据训练 k 轮 → 得到 wₜⁱ
   c. 各方上传加密梯度 Δwⁱ = wₜⁱ - wₜ
   d. 安全聚合: Δw = Σ(αᵢ × Δwⁱ)  // αᵢ为权重系数
   e. 更新全局模型: wₜ₊₁ = wₜ + Δw
   f. 差分隐私噪声注入
3. 收敛条件: Loss变化 < ε 或达到最大轮次
```

### 3.3 联邦算法选择

| 算法 | 适用场景 | 优点 | 缺点 |
|------|----------|------|------|
| FedAvg | 数据IID分布 | 简单、收敛快 | 非IID时性能下降 |
| FedProx | 数据Non-IID | 处理数据异构性好 | 需要调μ参数 |
| FedBN | 特征分布不同 | 处理BatchNorm差异 | 需要额外通信 |

**推荐**: FedProx (材料数据天然Non-IID，各方数据分布差异大)
