## 三、韧性评估模型

### 3.1 韧性指数 (Resilience Index, RI)

韧性 = 应激恢复速度 + 抗压稳定性 + 生理储备能力

**计算公式**：
```
RI (0-100) = 
  恢复速度分 × 0.40 +
  稳定性分 × 0.35 +
  储备能力分 × 0.25
```

**恢复速度分**：运动后HR恢复至基线的时间（分钟）
- ≤ 3min → 100分
- 3-5min → 80分  
- 5-8min → 60分
- > 8min → 40分

**稳定性分**：高压工作日HRV与平均值的偏差
- 偏差 < 10% → 100分
- 偏差 10-20% → 75分
- 偏差 20-35% → 50分
- 偏差 > 35% → 25分

**储备能力分**：基于VO2max估算（Watch可测）
- > 45 ml/kg/min → 100分
- 38-45 → 75分
- 30-38 → 50分
- < 30 → 25分
