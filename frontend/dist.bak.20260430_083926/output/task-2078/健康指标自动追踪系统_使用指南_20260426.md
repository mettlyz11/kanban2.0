# 健康指标自动追踪系统 — 使用指南

**版本**: v1.0 | **创建日期**: 2026-04-26 | **适用对象**: 刘宇宙（教授/创始人）

---

## 一、系统概述

本系统是一套**可执行的健康指标自动追踪方案**，基于已有Apple Watch健康数据 + 手动记录，实现：

- ✅ **每日自动健康自检**（60秒快速记录）
- ✅ **每周自动健康报告**（一键生成）
- ✅ **月度健康趋势仪表盘**（Markdown可视化）
- ✅ **异常预警机制**（关键指标偏离自动提示）

---

## 二、核心文件清单

| 文件 | 类型 | 说明 |
|------|------|------|
| `health-track.py` | 脚本 | 每日健康数据录入 & 存储 |
| `health-report.py` | 脚本 | 自动生成周报/月报 |
| `health-dashboard.md` | 仪表盘 | 实时健康状态总览 |
| `health-data.json` | 数据库 | 所有健康数据存储 |
| `health-config.json` | 配置 | 指标定义与预警阈值 |
| `健康指标定义与标准_20260426.md` | 文档 | 完整指标体系 |

## 三、快速开始

### 3.1 首次设置

```bash
# 进入脚本目录
cd output/task-2078/

# 运行每日健康录入（首次会初始化数据文件）
python3 health-track.py daily

# 生成首份周报
python3 health-report.py weekly

# 查看仪表盘
cat health-dashboard.md
```

### 3.2 每日使用（~60秒）

```bash
python3 health-track.py daily
```

系统会引导你输入以下核心指标：
- 晨起体重 (kg)
- 晨起血压 (收缩压/舒张压)
- 晨起心率 (bpm)
- 昨晚睡眠时长 (小时)
- 主观精力评分 (1-10)
- 今日运动计划 (跑步/力量/休息)

### 3.3 每周使用（~1分钟）

```bash
python3 health-report.py weekly
```

自动生成上周健康报告，包含：
- 各指标周平均值 + 趋势方向（↑↓→）
- 达标率统计
- 异常预警
- 下周建议

### 3.4 查看仪表盘

```bash
cat health-dashboard.md
```

实时查看最近7天/30天健康状态概览。

## 四、与Apple Watch集成

### 方案A：手动录入（当前）
- Apple Watch 查看数据 → 手动输入脚本

### 方案B：快捷指令半自动（推荐）
- iPhone 创建"健康导出"快捷指令
- 每日早晨自动导出CSV → 脚本自动解析

### 方案C：全自动（未来）
- Health Auto Export → JSON API → 自动同步
- 需要安装第三方App：`Health Auto Export`（App Store）

## 五、预警机制

当以下指标偏离正常范围时，脚本会自动标记 ⚠️：

| 指标 | 正常范围 | 预警条件 |
|------|---------|---------|
| 收缩压 | 90-120 mmHg | <85 或 >130 |
| 舒张压 | 60-80 mmHg | <55 或 >90 |
| 静息心率 | 50-80 bpm | >90 或 <45 |
| 睡眠时长 | 7-8.5 小时 | <6 或 >10 |
| 精力评分 | ≥6/10 | ≤4 连续3天 |
| 体重波动 | ±1kg/周 | ±2kg/周 |

## 七、扩展建议

1. **连接Apple Health API**（需iOS快捷指令）→ 自动数据导入
2. **连接Ringconn/Oura API** → 自动睡眠+HRV数据
3. **设置定时任务**（cron）→ 每日早8点自动生成健康报告
4. **邮件/微信通知** → 异常时自动提醒

## 八、隐私与安全

- 所有数据存储在本地 JSON 文件
- 不上传任何云端
- 可定期备份到加密目录
- 删除命令：`rm health-data.json` 即可完全清除
