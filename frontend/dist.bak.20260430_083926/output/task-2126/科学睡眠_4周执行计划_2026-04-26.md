### 每日时间表
```
06:30  起床，立即拉开窗帘，晒太阳10分钟（关键！）
07:00  轻度运动 + 早餐（避免高糖）
15:00  ☕ 咖啡因截止时间（之后只喝脱咖/草本茶）
20:00  📱 开始降低屏幕亮度，开启夜间模式
21:30  停止工作，关闭所有工作软件
22:00  🧘 睡前仪式开始
22:30  放下所有电子设备
23:00  💤 熄灯入睡
```

## 📅 第2周：习惯固化期（5月4日 - 5月10日）

### 核心目标
建立自动化的日间行为和睡前仪式，消除睡眠干扰源

### 日间行为准则
1. **运动时间**：早晨或下午，避免20:00后剧烈运动
2. **饮食限制**：
   - 20:00后不进食
   - 21:00后不大量饮水（减少起夜）
   - 避免晚餐辛辣/油腻
3. **酒精禁令**：完全禁酒（酒精严重破坏深睡结构）

### 45分钟睡前仪式（22:00-22:45）
```
第0-10分钟  📝 大脑转储：写下所有待办事项和思绪
第10-25分钟 🧘 呼吸冥想：4-7-8呼吸法 × 5轮
第25-35分钟 📖 纸质书阅读（非工作内容）
第35-40分钟 🧴 温和拉伸 + 面部护理
第40-45分钟 🌙 调暗灯光，准备入睡
```

### 4-7-8呼吸法详解
> 哈佛大学验证的快速入睡技术
1. 用鼻子吸气4秒
2. 屏住呼吸7秒
3. 用嘴缓慢呼气8秒
4. 重复5轮 → 60%的人3分钟内入睡

### 第2周验收标准
✅ 至少6天在23:15前入睡  
✅ 至少6天在6:45前起床  
✅ 夜间觉醒次数 < 3次/晚  
✅ 睡眠效率 > 80%

## 📅 第3周：优化精进期（5月11日 - 5月17日）

### 核心目标
精细化调整，优化睡眠结构，提升深睡和REM占比

### 90分钟周期对齐验证
**理论验证：** 23:00入睡 + 5个周期 = 06:30起床 ✓
**实际验证：** 连续3天记录醒来后的状态
- 😊 精力充沛 = 对齐成功
- 😵 昏昏沉沉 = 提前或推迟30分钟尝试

### 数据追踪精细化
每日记录以下指标（见模板文件）：
1. 入睡时间 / 起床时间
2. 夜间觉醒次数
3. 深睡时长 / REM时长
4. 日间精力评分（1-10，每2小时一次）
5. 当天干扰因素（压力、酒精、运动等）

### 针对性优化
| 如果出现 | 解决方案 |
|---------|---------|
| 入睡困难 (>30分钟) | 增加15分钟轻度运动，推迟30分钟上床 |
| 凌晨早醒 (3-4点) | 检查室温是否过低，增加晚餐蛋白质 |
| 深睡不足 (<15%) | 增加白天日晒时间，下午增加力量训练 |
| REM不足 (<18%) | 减少酒精，优化睡前减压仪式 |

### 第3周验收标准
✅ 睡眠效率 > 85%  
✅ 深睡占比 > 20%  
✅ 日间精力评分均值 > 7.5  
✅ 3天以上出现"完美睡眠"（醒来神清气爽）

## 📅 第4周：维持内化期（5月18日 - 5月24日）

### 核心目标
将好习惯自动化，建立应急预案，形成终身睡眠系统

### 自动化检查清单
- [ ] iPhone睡眠模式已自动化
- [ ] 所有电子设备定时进入夜间模式
- [ ] 窗帘自动定时开关（如使用智能窗帘）
- [ ] 温度已设置自动调节

### 应急预案建立

#### 场景1：熬夜工作
```
触发条件：工作需要必须超过23:00
应对策略：
1. 23:30必须停止（绝不超过00:00）
2. 次日仍然6:30起床（不补觉！避免昼夜节律紊乱）
3. 中午小憩20分钟（绝不超过30分钟）
4. 当晚提前30分钟恢复正常作息
```

#### 场景2：旅行/出差
```
应对策略：
1. 携带眼罩 + 耳塞（保持黑暗环境）
2. 保持相同起床时间（±30分钟内）
3. 到达目的地立即接受当地日照
4. 睡前避免酒店咖啡因
```

#### 场景3：高压力日
```
应对策略：
1. 增加20分钟午间冥想
2. 睡前大脑转储延长至15分钟
3. 接受"今晚可能睡不好"，减少焦虑反而睡得更好
```

### 第4周验收标准
✅ 无需闹钟在6:30±15分钟自然醒来  
✅ 7天中至少6天睡眠质量评分 > 8分  
✅ 日间精力稳定，无明显下午崩溃  
✅ 可以自主应对干扰场景
