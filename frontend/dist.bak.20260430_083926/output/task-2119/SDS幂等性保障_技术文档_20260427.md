# SDS任务生成幂等性保障 V4.6

## 概述
确保同一任务请求不会产生重复执行，基于SHA-256确定性哈希和双重检查机制。

## 核心功能

### 1. 确定性幂等键生成
- 基于任务标题 + 目标ID + 描述前缀生成SHA-256哈希
- **相同输入永远生成相同输出**（确定性）
- 取前16位作为幂等键
- 超长描述自动截断至前100字

### 2. 双重检查机制
- **本地日志检查**：检查 `sds-idempotency-v46.log` 文件
- **数据库隐式检查**：通过语义去重层间接验证
- 任一检查命中即拦截重复请求

### 3. 安全插入流程
```
Step 1: 生成幂等键
Step 2: 检查本地日志（是否已存在）
Step 3: 检查频率限制
Step 4: 检查语义去重
Step 5: 数据库安全插入
Step 6: 记录幂等性日志
```

### 4. 日志持久化
- 每条执行记录以JSON格式追加写入日志文件
- 包含：幂等键、任务ID、标题、目标ID、创建时间、版本
- 支持30天自动清理过期记录

## 关键特性

| 特性 | 说明 |
|------|------|
| 确定性 | 相同输入 → 相同键 |
| 抗碰撞 | SHA-256前16位，碰撞概率极低 |
| 空格免疫 | 首尾空格自动trim |
| 多语言支持 | Unicode/中文/英文混合标题 |
| 并发安全 | 追加写入日志，无锁设计 |

## 使用方式

```python
from core.task_generation_guard_v46 import IdempotencyLayer

layer = IdempotencyLayer()

# 生成幂等键
key = layer.generate_key("任务标题", goal_id=1, description="描述")

# 检查是否可安全执行
result = layer.check(key)
# result['is_safe'] = True/False

# 记录执行
layer.record(key, task_id=123, title="任务标题", goal_id=1)
```
