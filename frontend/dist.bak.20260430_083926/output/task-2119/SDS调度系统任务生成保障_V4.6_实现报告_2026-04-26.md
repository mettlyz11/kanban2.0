## 一、Research 依据

基于Tavily Research 2026年多Agent调度系统核心优化方向：

1. **三层保障机制成为主流**：2026年主流Agent调度系统（OpenAI Swarm、AutoGen、LangGraph等）普遍采用"幂等性设计 + 频率限制 + 去重校验"三层保障机制
2. **OpenAI Swarm最佳实践**：任务生成模块必须具备幂等性保障，防止同一请求因网络重试或调度异常被重复执行
3. **频率限制必要性**：缺乏频率限制的调度系统容易产生任务泛滥，导致资源耗尽和执行队列拥塞

## 二、交付物清单

### 2.1 频率限制模块代码
- **文件**: `sds/core/task_generation_guard_v46.py`
- **类**: `RateLimitLayer`
- **核心功能**:
  - 每目标(goal_id)每24小时最多生成2个任务
  - 滑动窗口计数，精确到秒级
  - pending水位控制（每目标最多3个pending任务）
  - 组合检查接口，统一返回拦截原因

### 2.2 语义去重算法实现
- **文件**: `sds/core/task_generation_guard_v46.py`
- **类**: `SemanticDedupLayer`
- **核心功能**:
  - 标题前15字快速匹配（数据库LIKE查询优化）
  - Levenshtein编辑距离语义相似度计算（O(min(m,n))空间优化）
  - 相似度阈值0.85（可配置）
  - 双层标准化：原始文本 + 去除标点/空格/大小写后文本
  - 同项目近期任务全扫描兜底

### 2.3 幂等性保障模块
- **文件**: `sds/core/task_generation_guard_v46.py`
- **类**: `IdempotencyLayer`
- **核心功能**:
  - 基于SHA-256的确定性幂等键生成（前16位）
  - 本地JSONL日志持久化
  - 自动过期清理（默认30天）
  - 支持并发安全（只追加写入）

### 2.4 统一协调器
- **文件**: `sds/core/task_generation_guard_v46.py`
- **类**: `TaskGenerationGuard`
- **核心功能**:
  - 三层保障顺序执行：幂等性 → 频率限制 → 语义去重
  - 任一层面拦截即终止，返回明确原因
  - 批量推荐任务过滤
  - 安全创建任务（检查通过后自动插入 + 幂等记录）
  - 系统状态概览

### 2.5 集成到任务生成器
- **文件**: `sds/auto_task_generator_v46.py`
- **类**: `AutoTaskGeneratorV46`
- **集成方式**:
  - `create_single_task()` 方法自动调用 `TaskGenerationGuard.check()`
  - 被拦截任务记录到 `blocked_tasks` 审计日志
  - 通过任务记录到 `generated_tasks` 并写入幂等日志

## 四、三层保障执行流程

```
任务生成请求
    │
    ▼
┌─────────────────┐
│ Layer 1: 幂等性  │ ──→ 已存在？→ BLOCKED_IDEMPOTENT
│ 生成SHA-256键    │
│ 检查本地日志     │
└─────────────────┘
    │ 通过
    ▼
┌─────────────────┐
│ Layer 2: 频率限制 │ ──→ 超限？→ BLOCKED_RATE_LIMIT
│ 24h窗口计数      │
│ pending水位检查  │
└─────────────────┘
    │ 通过
    ▼
┌─────────────────┐
│ Layer 3: 语义去重 │ ──→ 重复？→ BLOCKED_DUPLICATE
│ 前15字前缀匹配   │
│ Levenshtein相似度│
│ 阈值0.85判断     │
└─────────────────┘
    │ 通过
    ▼
  ALLOWED → 安全创建任务 → 记录幂等性 → 完成
```

## 五、关键设计决策

1. **Levenshtein距离选择**: 相比cosine相似度，编辑距离对短文本（任务标题通常<100字）更敏感，且无需外部依赖
2. **双层标准化**: 同时计算原始文本和标准化文本的相似度，取较高值，避免过度标准化导致漏判
3. **本地JSONL日志**: 幂等性日志采用追加写入的JSONL格式，支持并发安全，便于后续分析
4. **批次ID追踪**: 每次生成会话生成唯一批次ID，便于审计和问题排查

## 七、后续优化建议

1. **数据库层幂等表**: 当前幂等性仅依赖本地日志，建议增加数据库幂等表实现跨实例一致性
2. **向量语义相似度**: 对于长文本任务描述，可考虑引入轻量级embedding模型替代Levenshtein距离
3. **动态阈值调整**: 根据历史去重准确率动态调整相似度阈值
4. **熔断机制**: 当连续拦截率过高时，自动告警并暂停任务生成
