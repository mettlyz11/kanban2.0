## 二、关键算法

### 2.1 Levenshtein编辑距离（空间优化版）

```python
def levenshtein_distance(s1, s2):
    if len(s1) < len(s2):
        return levenshtein_distance(s2, s1)
    if len(s2) == 0:
        return len(s1)
    
    previous_row = range(len(s2) + 1)
    for i, c1 in enumerate(s1):
        current_row = [i + 1]
        for j, c2 in enumerate(s2):
            insertions = previous_row[j + 1] + 1
            deletions = current_row[j] + 1
            substitutions = previous_row[j] + (c1 != c2)
            current_row.append(min(insertions, deletions, substitutions))
        previous_row = current_row
    return previous_row[-1]
```

**特点**: 使用滚动数组将空间复杂度从O(m×n)降至O(min(m,n))

### 2.2 幂等性键生成

```python
def generate_idempotency_key(title, project_id, description_prefix):
    key_data = json.dumps({
        'title': title.strip(),
        'project_id': project_id,
        'desc_prefix': description_prefix[:100].strip(),
    }, ensure_ascii=False, sort_keys=True)
    return hashlib.sha256(key_data.encode('utf-8')).hexdigest()[:16]
```

**特点**: 
- 确定性：相同输入→相同输出
- 短哈希：取SHA-256前16位，兼顾唯一性和存储效率
- 空白处理：strip()消除首尾空白差异

## 四、安全特性

1. **空指针保护**: 所有DB查询结果都做None检查
2. **参数校验**: 构造函数使用`is not None`而非`or`，正确处理0值
3. **异常处理**: DB操作失败时回滚并返回明确错误信息
4. **日志清理**: 定期清理过期幂等性日志（默认30天）
