# 和光智成 - 核心产品矩阵定义文档

## 一、产品战略定位

**使命：** 用AI+自动化加速新材料从设计到验证的全流程，让中国材料企业研发效率提升10倍

**目标市场：**
- 一级：新能源材料（电池、光伏、氢能）
- 二级：半导体材料、化工催化、高分子材料
- 三级：医药中间体、金属合金

## 三、产品线详细定义

### 3.1 LumiDFT - AI加速DFT计算平台 ⭐核心产品

**产品定位：** 面向材料科学家的智能计算平台，将DFT计算从"周"加速到"小时"

**功能模块：**

| 模块 | 功能描述 | 技术亮点 | 目标版本 |
|------|---------|---------|---------|
| **过渡态搜索** | 自动寻找反应路径和活化能 | AI预筛选+DFT精修，加速100x | V1.0 (MVP) |
| **光谱模拟** | IR/Raman/NMR/UV-Vis光谱预测 | 机器学习势+TD-DFT混合 | V1.2 |
| **力学性质** | 弹性模量、硬度、断裂韧性 | 高通量应力-应变计算 | V1.3 |
| **晶形预测** | 多晶型筛选与稳定性排序 | 结合机器学习的晶格能计算 | V1.5 |
| **高通量筛选** | 千级材料并行计算 | 云原生弹性伸缩 | V2.0 |
| **AI代理模型** | 快速性质预测替代昂贵DFT | 图神经网络势能面 | V2.0 |

**技术架构：**
- 底层：VASP/Quantum ESPRESSO/CP2K
- 中间层：任务调度系统 + AI预筛选层
- 上层：Web界面 + Python SDK + REST API

**目标客户：**
- 材料企业R&D部门（50-500人规模）
- 高校材料/化学课题组
- 政府科研院所

**定价策略：**
- 学术版：¥5,000/年（限1用户，1000核时/月）
- 专业版：¥50,000/年（5用户，10000核时/月）
- 企业版：¥200,000/年起（不限用户，专属集群）
- 计算资源：¥0.5/核时（超量计费）

---

### 3.2 LumiAuto - 实验室自动化系统 ⭐核心产品

**产品定位：** 连接计算与实验的桥梁，实现"设计-合成-表征-反馈"闭环

**功能模块：**

| 模块 | 功能描述 | 硬件集成 | 目标版本 |
|------|---------|---------|---------|
| **实验设计** | AI推荐最优实验方案 | 纯软件 | V1.0 (MVP) |
| **合成自动化** | 自动配液、反应、后处理 | 液体处理机器人+反应器 | V1.5 |
| **表征自动化** | 自动取样、测试、上传数据 | XRD/XPS/SEM等联用 | V2.0 |
| **数据闭环** | 实验数据自动回流优化模型 | 软件+数据中台 | V1.0 |
| **数字孪生** | 实验过程虚拟仿真预演 | 软件+计算平台 | V2.0 |

**技术架构：**
- 控制层：Python + ROS2（机器人）+ OPC-UA（设备）
- 软件层：实验设计AI + LIMS系统
- 数据层：与LumiData打通

**目标客户：**
- 大型材料企业（有自研实验室）
- CRO/CDMO公司
- 政府实验室

**定价策略：**
- 软件License：¥100,000/年（实验设计+数据管理）
- 半自动工作站：¥500,000-1,000,000/套（含硬件）
- 全自动产线：¥3,000,000+/套（定制开发）

---

### 3.3 LumiData - 材料数据中台

**产品定位：** 材料研发的数据基础设施，统一管理计算+实验数据

**功能模块：**
- 多源数据接入（计算结果、实验记录、文献数据）
- 材料知识图谱（结构-工艺-性能关联）
- 数据版本控制与可追溯性
- 可视化分析与报表
- 合规管理（满足IPO/审计要求）

**目标客户：** 所有使用LumiDFT和LumiAuto的客户

**定价策略：**
- 随核心产品赠送基础版
- 高级版：¥30,000/年（高级分析+知识图谱）

---

### 3.4 LumiChem - 化学工具箱

**产品定位：** 面向化学家的日常工具集合

**功能模块：**
- 分子编辑器与3D可视化
- 性质快速估算（溶解度、LogP、沸点等）
- 文献检索与知识管理
- 实验记录电子化管理(ELN)

**目标客户：** 化学/材料研究者个人用户

**定价策略：**
- 基础版：免费（引流获客）
- 专业版：¥99/月

---

### 3.5 LumiAPI - 开放平台

**产品定位：** 将和光智成的能力开放给第三方开发者

**功能模块：**
- RESTful API（计算任务提交、结果查询）
- Python SDK
- 预训练模型API（性质预测、分子生成）
- 插件市场

**定价策略：**
- 免费额度：1000次API调用/月
- 付费：¥0.1-1/次（按接口复杂度）

## 五、产品间协同效应

```
LumiChem（获客） → LumiDFT（核心收入） → LumiAuto（高客单）
       │                │                      │
       └────────────────┴──────────────────────┘
                          │
                    LumiData（数据沉淀）
                          │
                    LumiAPI（生态扩展）
```

**飞轮效应：**
1. LumiChem免费版吸引大量化学家
2. 转化为LumiDFT付费用户
3. 计算结果沉淀到LumiData
4. 数据训练更准的AI模型
5. 更准的模型吸引更多用户
