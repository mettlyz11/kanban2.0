# 压力预警信号识别清单
> 早期识别，及时干预，防止压力累积成burnout

---

## 🔴 高警戒：立即干预信号

以下信号出现**3项或以上**，需立即停止工作，寻求休息/帮助：

- [ ] 连续2天以上难以入睡或睡眠质量极差
- [ ] 头痛、肩颈疼痛、胃部不适持续出现
- [ ] 对工作产生明显排斥感或恐惧感
- [ ] 注意力涣散，无法集中超过10分钟
- [ ] 容易因小事暴怒或崩溃哭泣
- [ ] 感到完全失控，不知从哪开始
- [ ] 出现"什么都无所谓"的冷漠感

---

## 🟠 中度预警：需要调整节奏

以下信号出现**2项或以上**，需调整工作节奏，增加恢复活动：

### 身体信号
- [ ] 频繁打哈欠，即使睡够了还是疲惫
- [ ] 肩膀、后颈持续紧绷感
- [ ] 消化不良、食欲变化（暴食或厌食）
- [ ] 眼睛酸涩，视力模糊感增加
- [ ] 免疫力下降，容易感冒

### 心理信号
- [ ] 难以做简单决定（选午饭都很费力）
- [ ] 拖延行为明显增加
- [ ] 对以前喜欢的事情失去兴趣
- [ ] 工作时思绪不断游荡到"还有很多事没做"
- [ ] 对他人的耐心明显减少

### 行为信号
- [ ] 工作时间越来越长但产出越来越少
- [ ] 开始逃避某些会议或任务
- [ ] 社交回避（不想回信息，不想参加活动）
- [ ] 咖啡/奶茶等刺激物用量明显增加

---

## 🟡 轻度预警：注意观察

以下信号持续**超过3天**，需主动关注：

- [ ] 早上起床需要"强迫自己"
- [ ] 午后能量明显低落（非正常午后困倦）
- [ ] 工作时频繁刷手机/社交媒体作为逃避
- [ ] 对未完成的任务反复焦虑
- [ ] 睡前脑子停不下来

---

## 📊 每周压力自评（0-10分）

| 维度 | 评分 | 说明 |
|------|------|------|
| 工作负荷感 | /10 | 0=轻松，10=不堪重负 |
| 情绪稳定性 | /10 | 0=极不稳定，10=非常稳定 |
| 睡眠质量 | /10 | 0=极差，10=极好 |
| 工作满意度 | /10 | 0=极不满意，10=非常满意 |
| 身体状态 | /10 | 0=很差，10=精力充沛 |

**总分 < 25分** → 启动减压方案  
**总分 25-35分** → 保持监控，适度调整  
**总分 > 35分** → 继续保持当前状态

---

## 🆘 触发紧急干预的情况

以下任何一项出现，立即寻求支持：

- 持续2周以上情绪低落，无法自行调整
- 出现"活着没意思"等消极念头
- 身体疼痛持续1周以上
- 与家人/同事的冲突明显增加
