### 2.3 核心分析引擎实现

**时间**: 09:35 - 09:36

#### 2.3.1 重要性分级算法
- **优先级域名匹配: 投资人、学术、法律、银行等优先域名自动标记为重要
- **紧急关键词匹配**: 包含"紧急"、"ASAP"、"今日截止"等
- **重要关键词匹配**: 包含"重要"、"需要行动"、"请回复"等
- **截止日期检测**: 包含截止日期的邮件提升重要性
- **权重计算: 主题中关键词权重×3，正文中权重×1

#### 2.3.2 邮件分类算法
支持11个分类维度:
- 融资/投资: 投资人、TS、尽调、估值等关键词
- 学术/期刊/基金: JACS、Nature、NSFC、审稿、投稿
- 财务/银行: 银行、支付、交易、股票、基金
- 法律/合同: 合同、诉讼、专利、知识产权
- 工作/商务: 项目、会议、客户、报告
- 家庭/学校: 学校、老师、家长、教育
- 党派/统战: 党派、委员会、组织
- 发票/账单: 发票、收据、报销、费用
- 会议/日程: 会议邀请、日历、Zoom
- 订阅/新闻: 新闻订阅、周报、月报
- 其他: 无法分类的邮件

#### 2.3.3 待办事项与截止日期提取
使用正则表达式匹配:
- 待办模式: "需要/请/应该+动作+日期
- 日期模式: YYYY-MM-DD、中文日期、相对日期
- 金额模式: ¥$€£+数字、万/亿单位
- 特殊信息: 合同号、发票号、会议ID、电话号码

#### 2.3.4 关系强度算法
```python
# 关系强度 = 基础分 + 互动频率加成 + 最近互动加成
# 基础分: 50分
# 每次互动: +10分
# 最近互动(7天内): +额外加分
```

## 三、技术实现细节

### 3.1 IMAP邮件获取流程
```
1. 建立SSL加密连接
2. 登录邮箱账户
3. 选择邮箱文件夹（默认INBOX）
4. 搜索邮件ID列表
5. 获取最新N封邮件原始数据
6. 解析邮件头和正文
7. 提取附件信息
8. 关闭连接
```

### 3.2 邮件解析难点处理：

1. **编码问题**: 多编码支持UTF-8/GBK/ISO-8859-1自动检测
2. **多部分邮件**: 递归解析multipart邮件结构
3. **邮件头解码**: 正确处理MIME编码的主题和发件人

### 3.3 中文NLP简化实现
由于不依赖重型NLP库，采用了优化的规则引擎：

- 关键词词典: 50+分类关键词×3种重要性关键词
- 模式匹配: 10+正则表达式模式
- 上下文感知: 主题关键词权重×正文关键词
- 启发式规则: 附件存在提升重要性
