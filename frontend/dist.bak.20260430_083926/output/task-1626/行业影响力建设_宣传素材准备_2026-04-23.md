## 二、演讲PPT内容框架 (适用于三个主题)

### 通用结构
```
封面 → 问题陈述 → AI解决方案 → 技术路线 → 案例展示 → 合作模式 → 未来展望 → Q&A
```

### 每部分建议页数
- 封面: 1页 (含Helight Logo、演讲者信息)
- 问题陈述: 2-3页 (行业痛点、现有方案局限)
- AI解决方案: 4-6页 (核心技术架构、关键创新点)
- 技术路线: 3-4页 (方法论、实验设计、验证结果)
- 案例展示: 3-5页 (1-2个具体案例, 数据对比)
- 合作模式: 2-3页 (产学研合作、商业化路径)
- 未来展望: 1-2页 (愿景、下一步计划)
- Q&A: 1页
- **总计**: 17-25页, 演讲时间30-45分钟

## 四、品牌视觉规范建议

### Helight品牌要素
- **主色调**: 科技蓝 (#1A73E8) + 深灰 (#2D2D2D)
- **辅助色**: 活力橙 (#FF6B35) - 用于强调
- **字体**: 中文-思源黑体 / 英文-Roboto
- **Logo使用**: 始终使用高清矢量版, 背景留白不小于10%
- **图片风格**: 实验室实景、AI可视化图表、团队合影

### 个人品牌要素
- **专业照片**: 白底证件照 + 学术环境半身照各一张
- **签名**: 统一使用学术签名样式
- **头衔**: "北京航空航天大学教授 | 和光智成创始人"
