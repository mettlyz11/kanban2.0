## 分类采购指南

### 超市采购顺序（避免化冻）

```
1️⃣ 冷冻区 → 虾仁、冷冻蔬菜
2️⃣ 冷藏区 → 肉类、鱼类、鸡蛋、酸奶、牛奶
3️⃣ 蔬菜区 → 绿叶菜先装，耐放的后装
4️⃣ 水果区 → 注意不要压坏
5️⃣ 杂粮区 → 燕麦、糙米等
6️⃣ 调味品区 → 最后拿
```

### 线上 vs 线下

| 渠道 | 优点 | 缺点 | 适合购买 |
|------|------|------|---------|
| **盒马/山姆** | 品质好，配送快 | 价格略高 | 肉类、鱼类、海鲜 |
| **京东到家** | 选择多，对比方便 | 品质参差 | 日常食材 |
| **菜市场** | 新鲜，可挑选 | 费时间 | 绿叶蔬菜 |
| **Costco/山姆会员店** | 量大优惠 | 需要会员+储存空间 | 杂粮、坚果、油 |

## 食材保存方法

### 🥩 肉类保存技巧

#### 鸡胸肉/牛肉
```
1. 采购回家立即处理，不要在室温放置
2. 按150g/份分装（一餐量）
3. 用保鲜袋/保鲜膜单独包裹
4. 挤出空气，贴标签写日期
5. 3天内吃的放冷藏，其余冷冻
6. 前一晚从冷冻移到冷藏化冻
```

#### 鱼类
```
1. 三文鱼/鳕鱼：切片分装，120g/份
2. 整鱼：处理干净后整条冷冻
3. 化冻：冷藏化冻 > 流水化冻 > 室温化冻
4. 不要反复化冻冷冻
```

#### 鸡蛋
```
1. 尖头朝下放入冰箱门
2. 不要清洗（蛋壳有保护膜）
3. 保质期：冷藏4-5周
```

### 🥬 蔬菜保存技巧

#### 西兰花/花菜
```
1. 不要洗，用厨房纸包裹
2. 放入保鲜袋，留透气孔
3. 冷藏可保存7-10天
4. 吃的时候再切洗
```

#### 绿叶菜（菠菜/油麦菜/生菜）
```
1. 去除发黄烂叶
2. 稍微晾干表面水分
3. 厨房纸包裹后装袋
4. 冷藏可保存3-5天
5. 优先吃，不要放太久
```

#### 番茄/黄瓜/彩椒
```
1. 不要放冰箱（10℃以下会冻伤）
2. 阴凉通风处存放
3. 番茄蒂部朝下放置
4. 可保存5-7天
```

#### 蘑菇/香菇
```
1. 不要洗，用纸袋装
2. 冷藏可保存5-7天
3. 吃前再清洗
```

### 🍠 根茎类保存

```
红薯/紫薯/土豆/洋葱
  1. 常温阴凉通风处
  2. 不要放冰箱（低温会让淀粉变糖）
  3. 不要和苹果放在一起（苹果释放乙烯催熟）
  4. 可保存2-4周
```

### 🍎 水果保存

```
苹果/橙子/梨 → 阴凉处可放1-2周
香蕉 → 常温，变黑的可以剥皮冷冻做smoothie
蓝莓/草莓 → 原盒冷藏，吃前再洗，3-5天
牛油果 → 硬的放室温催熟，软了放冷藏
```

## 周末备餐流程 (2小时搞定一周)

### ⏰ 时间表

| 时间 | 任务 | 耗时 |
|------|------|------|
| 13:00-13:10 | 备餐前准备：清洗工具，整理食材 | 10min |
| 13:10-13:30 | 处理主食：煮饭+蒸红薯 | 20min |
| 13:30-14:00 | 处理蛋白质：腌制鸡胸+煮鸡蛋 | 30min |
| 14:00-14:30 | 烘烤：鸡胸肉+蔬菜一起烤 | 30min |
| 14:30-14:50 | 分装+储存+清洁 | 20min |
| **合计** | - | **120min** |

### 🍚 主食备餐

```
糙米饭/杂粮饭
  1. 煮4-5天的量（约800g生米）
  2. 按150g/份分装到保鲜盒
  3. 冷藏3天，其余冷冻
  4. 吃的时候微波炉加热2分钟

红薯/紫薯
  1. 蒸10-15分钟到熟透
  2. 放凉后用保鲜膜单个包裹
  3. 冷藏可保存5天
```

### 🥩 蛋白质备餐

```
鸡胸肉批量处理
  1. 500g鸡胸肉切薄片或条
  2. 腌制：生抽+黑胡椒+蒜末+少许橄榄油
  3. 平铺在烤盘，180℃烤15-20分钟
  4. 放凉后按150g/份分装
  5. 冷藏3天，冷冻1个月

水煮蛋批量煮
  1. 一次煮10个鸡蛋
  2. 水开后煮8分钟，过凉水
  3. 剥壳，冷藏可保存5天
  4. 早餐/加餐随时用
```

### 🥬 蔬菜备餐

```
西兰花/芦笋
  1. 切好后焯水2分钟
  2. 过凉水保持脆绿
  3. 沥干水分分装
  4. 吃的时候微波/快炒即可

备餐注意：
  ✅ 耐放蔬菜可以预处理
  ❌ 绿叶菜不要预处理，现吃现做
  ❌ 蘑菇不要预处理，容易氧化
```

## 购物技巧

### 1. 购物清单管理

- **永远带着清单购物**（手机备忘录即可）
- 按超市布局排列清单，不走回头路
- 不要饿着肚子购物（容易买零食）
- 不要被促销迷惑（不需要的再便宜也不买）

### 2. 食材选择技巧

#### 选肉
```
鸡胸肉：选粉色有光泽，不发黏
牛肉：选大理石纹均匀的
鱼：眼睛透亮，腮鲜红，鱼鳞完整
```

#### 选蔬菜
```
西兰花：花球紧实，颜色深绿，没有发黄
番茄：颜色均匀，有自然红晕，捏着有弹性
绿叶菜：叶片挺拔，没有枯萎发黄
```

#### 选水果
```
苹果：闻起来有果香，表皮有自然纹理
香蕉：表皮有少量芝麻点时最甜
橙子：同样大小选重的，皮越薄越好
```

### 3. 省钱技巧

1. **买当季食材** - 便宜又好吃
2. **大包装更划算** - 但要确保吃得完
3. **冷冻也健康** - 冷冻蔬菜营养不比新鲜差
4. **临期打折** - 酸奶/牛奶临期折扣可以买（3天内吃完）
5. **会员日采购** - 很多超市周中会员日有折扣
