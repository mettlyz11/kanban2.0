### ⭐ 每日评分标准 (10分制)

| 项目 | 分值 | 评分标准 |
|------|------|---------|
| **称重** | 1分 | 每天晨起空腹称重 |
| **早餐质量** | 1分 | 蛋白质≥30g + 有蔬菜 |
| **午餐质量** | 1分 | 蛋白质≥40g + 有蔬菜 |
| **晚餐质量** | 1分 | 蛋白质≥40g + 8点前吃完 |
| **不吃零食** | 1分 | 没有吃垃圾食品/含糖饮料 |
| **饮水** | 1分 | ≥8杯（2L以上） |
| **运动** | 2分 | 30分钟以上得2分，10-30分得1分 |
| **睡眠** | 1分 | ≥7小时 |
| **整体感受** | 1分 | 主观满意度 |

### 评分解读

- **9-10分** 🌟 完美执行 - 保持！
- **7-8分** ✅ 良好执行 - 微调即可
- **5-6分** 🟡 一般 - 找出1-2个重点改进
- **<5分** 🔴 需要重视 - 复盘原因，重新规划

## 反馈调整机制

### 🔄 三级反馈循环

#### 1️⃣ 每日即时反馈 (微调整)

**触发条件:** 当日评分<6分

**调整动作:**
```
如果评分<6分，当天晚上花2分钟：
1. 找出扣分最多的1-2项
2. 写下明天具体改进动作
3. 把改进措施放在手机提醒

示例：
❌ 问题：今天只喝了3杯水
✅ 改进：设置每小时提醒，在工位放水杯
```

#### 2️⃣ 每周反馈 (中调整)

**触发条件:** 连续3天<7分，或周均<6分

**调整动作:**
```
周复盘时重点分析：
1. 是意志力问题？还是方法问题？
2. 是目标太高？还是执行不够？
3. 是否需要调整餐单？
4. 是否需要增加支持系统？

调整工具包：
→ 降低目标（先稳定5-6分）
→ 简化餐单（减少决策成本）
→ 增加奖励机制（完成目标给自己奖励）
→ 找人监督（告诉家人/朋友你的计划）
```

#### 3️⃣ 月度反馈 (大调整)

**触发条件:**
- 连续2周体重无变化
- 月度减重<0.5kg或>3kg
- 连续感到疲惫、饥饿、情绪低落

**调整动作:**
```
系统性调整：
1. 重新计算热量需求（可能代谢适应了）
2. 调整宏量营养素比例
3. 增加/减少热量100-200千卡
4. 检查是否有隐藏热量（油、酱、饮料）
5. 检查睡眠、压力、运动等生活因素
```

### 📐 体重变化解读表

| 周体重变化 | 解读 | 行动 |
|-----------|------|------|
| **<-1 kg** | 减得太快 | 增加100-200千卡热量 |
| **-0.5 ~ -1 kg** | 理想速度 | ✅ 保持当前方案 |
| **-0.2 ~ -0.5 kg** | 偏慢但正常 | 保持观察，或增加一点运动 |
| **-0.1 ~ +0.1 kg** | 平台期 | 执行平台期突破策略 |
| **>+0.5 kg** | 反向增长 | 立即复盘饮食，找出问题 |

> ⚠️ **重要提醒:** 体重每天波动1-2kg是正常的（水分、食物残渣），要看**周平均趋势**，不要纠结单日数字！

## 常见问题排查

### 🔍 问题诊断树

#### 问题1: 体重不动

```
体重不动
  ├─ 吃得比想像多？
  │   ├─ 油放多了？→ 用喷油壶或称重
  │   ├─ 酱汁没算？→ 所有酱汁都要算热量
  │   └─ 零食偷吃？→ 记录每天吃的所有东西
  ├─ 消耗比想像少？
  │   ├─ 运动强度不够？→ 增加运动时间/强度
  │   └─ NEAT太少？→ 多站、多走、多活动
  └─ 身体在适应？
      ├─ 坚持了多久？→ 至少坚持2周再调整
      └─ 围度是否有变化？→ 有时体重不变但体脂在降
```

#### 问题2: 太饿坚持不下去

```
太饿
  ├─ 蛋白质不够？→ 增加到2.2g/kg体重
  ├─ 蔬菜不够？→ 每餐至少200g蔬菜
  ├─ 水喝少了？→ 饭前1杯，每天≥2.5L
  ├─ 脂肪太少？→ 适当增加健康脂肪
  └─ 热量赤字太大？→ 减少赤字，先保证可持续
```

#### 问题3: 运动表现下降

```
运动表现下降
  ├─ 碳水不够？→ 运动前后增加碳水
  ├─ 热量太少？→ 适当增加100-200千卡
  ├─ 休息不够？→ 检查睡眠，是否需要休息日
  └─ 电解质不足？→ 适当补充盐分/钾
```

#### 问题4: 情绪低落/想吃垃圾食品

```
 cravings强烈
  ├─ 是不是太严格了？→ 每周安排1顿放纵餐
  ├─ 是不是太无聊了？→ 找事情做，转移注意力
  ├─ 是不是压力大？→ 用非饮食方式缓解压力
  └─ 是不是睡眠不足？→ 改善睡眠（睡眠不足会增加食欲）
```

## 成功保障系统

### 🎁 奖励机制

| 成就 | 奖励建议 |
|------|---------|
| **连续7天称重** | 买一件想要的小东西 |
| **第一周完成** | 看一场电影 |
| **第一月完成** | 买一件新衣服（庆祝身材变化） |
| **达到目标体重** | 一次旅行/大餐庆祝 |

### 👥 社会支持

- **告诉家人** - 让他们支持你，不要诱惑你
- **找伙伴** - 和朋友一起减肥，互相监督
- **公开承诺** - 在朋友圈/群里宣布你的目标

### 🧠 心理建设

- **接受不完美** - 偶尔一顿吃多了没关系，不要破罐破摔
- **关注过程** - 不要只看体重，关注习惯养成
- **庆祝小胜利** - 每完成一周，给自己一点奖励
- **长期视角** - 这是生活方式改变，不是短期节食
