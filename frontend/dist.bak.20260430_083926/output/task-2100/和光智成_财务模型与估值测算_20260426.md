## 5. DCF估值模型

### 5.1 核心假设

| 参数 | 数值 | 依据 |
|------|------|------|
| 无风险利率（rf） | 2.5% | 中国10年期国债收益率 |
| 市场风险溢价（MRP） | 7.5% | A股市场历史平均 |
| Beta系数（β） | 1.8 | 硬科技/AI行业平均Beta |
| 债务成本（rd） | 5.0% | 银行贷款利率 |
| 目标资本结构（D/E） | 0% | 早期科技公司无债 |
| **WACC** | **16.0%** | CAPM计算：2.5% + 1.8×7.5% = 16.0% |
| 永续增长率（g） | 3.5% | 中国GDP长期增长预期 |
| 预测期 | 5年（2026-2030） | 成长期至稳定期过渡 |

### 5.2 自由现金流（FCF）预测（单位：万元）

| 项目 | 2026E | 2027E | 2028E | 2029E | 2030E |
|------|-------|-------|-------|-------|-------|
| EBIT | -275 | -300 | 600 | 3900 | 10650 |
| 减：EBIT税负 | 0 | 0 | 150 | 975 | 2663 |
| NOPAT | -275 | -300 | 450 | 2925 | 7988 |
| 加：折旧摊销 | 25 | 100 | 200 | 300 | 400 |
| 减：资本支出（Capex） | 500 | 800 | 500 | 300 | 200 |
| 减：营运资本增加 | 50 | 100 | 200 | 300 | 500 |
| **自由现金流（FCF）** | **-800** | **-1100** | **-50** | **2625** | **7688** |

### 5.3 终端价值（TV）计算

```
方法A：永续增长法
TV_2030 = FCF_2030 × (1+g) / (WACC - g)
        = 7688 × 1.035 / (0.16 - 0.035)
        = 7957 / 0.125
        = 63,656万元 ≈ 6.37亿元

方法B：退出倍数法（EV/EBITDA）
TV_2030 = EBITDA_2030 × 退出倍数
        = 9500 × 12x（科技公司上市时估值水平）
        = 114,000万元 = 11.4亿元

取两者平均值：
TV = (6.37亿 + 11.4亿) / 2 = 8.88亿元
```

### 6.3 和光智成估值计算

#### 方法A：2027年营收PS法
```
2027年目标营收 = 2000万元
适用PS倍数 = 30x（考虑早期风险，取行业平均的75%）
估值 = 2000万 × 30 = 6.0亿元
```

#### 方法B：2028年营收PS法（折现）
```
2028年目标营收 = 6000万元
适用PS倍数 = 20x（成熟期倍数，更保守）
2028年估值 = 6000万 × 20 = 12亿元
折现到2026年（WACC 16%）：
当前估值 = 12亿 / (1.16)² = 12亿 / 1.3456 = 8.92亿元
```

#### 方法C：客户价值倍数法
```
2026年目标客户 = 10家
单客户平均估值（SaaS行业基准）= 5000-8000万/客户
估值区间 = 5.0亿 - 8.0亿元
中值 = 6.5亿元
```

#### 方法D：风险投资阶段法
```
Pre-A轮（技术验证完成+MVP启动）
市场典型估值区间：5-8亿元
考虑北航背书+北京市重点实验室+3个PoC进行中
估值定位：6.5亿元（区间中高值）
```
