## 五、Phase 4: 风险管理体系

### 5.1 融资风险红线

| 风险指标 | 红线值 | 触发动作 |
|----------|-------|---------|
| 融资维持担保比例 | < 140% | 强制减仓 |
| 单策略最大回撤 | > 15% | 停止该策略 |
| 整体组合回撤 | > 10% | 降至零杠杆 |
| 融资利息覆盖 | 利息>月现金流30% | 停止新增融资 |
| 集中度 | 单一标的>30% | 强制分散 |

### 5.2 止损机制

```
三级止损体系：

Level 1 (预警线): 组合回撤达5%
  → 检查策略逻辑，记录分析

Level 2 (行动线): 组合回撤达8%
  → 减半融资仓位，降低杠杆

Level 3 (清仓线): 组合回撤达10%
  → 全部清仓融资部分，回归零杠杆
```

## 九、关键风险提示

1. **杠杆双刃剑**: 融资放大收益的同时也放大亏损，必须严格执行止损
2. **策略失效风险**: 市场环境变化可能导致已验证策略失效，需持续迭代
3. **流动性风险**: 极端市场下可能出现融资平仓风险，预留足够保证金
4. **合规风险**: 经营贷用于投资可能违反银行规定，需谨慎操作
5. **利率风险**: LPR下调趋势可能影响未来融资成本
