# PDF#503 任务描述格式模板库

## 1. 概述

本模板库旨在为组织内各类任务的描述提供标准化、结构化的格式参考。通过统一任务ID、标题、描述、输入、输出、预期成果、责任人、优先级、截止日期等核心字段，减少沟通成本，提升任务分发与执行效率。模板库覆盖通用场景及六大常见专业场景（开发、设计、分析、写作、测试、运维），并附有字段说明与使用示例，可直接应用于项目管理工具、工单系统或文档中。

---

## 2. 通用任务描述模板

### 2.1 模板结构

```markdown
---
task_id: TASK-YYYYMMDD-XXX
title: [简短概括性标题]
description: [对任务的详细描述，包括背景、目标、范围]
inputs:
  - [输入1：所需数据、文档、资源等]
  - [输入2]
outputs:
  - [输出1：产出的具体形式（报告、代码、设计稿等）]
  - [输出2]
expected_result: [可量化的成果或验收标准]
assignee: [责任人姓名/角色]
priority: [P0/P1/P2/P3]
due_date: [YYYY-MM-DD]
labels: [可选标签，例如“功能”、“修复”、“优化”]
---
```

### 2.2 实际示例

```markdown
---
task_id: TASK-20250317-001
title: 实现用户登录接口防暴力破解机制
description: 当前登录接口未对连续失败次数进行限制，存在安全风险。需要在5分钟内连续失败5次后，锁定该IP地址30分钟，并记录日志。同时支持管理员手动解锁。后端使用Go语言，数据库Redis存储计数器。
inputs:
  - 现有登录接口代码（/api/v1/login）
  - 项目Redis集群连接信息
outputs:
  - 修改后的登录接口代码（包含限流逻辑）
  - 单元测试代码覆盖主要场景
  - 接口文档更新（新增限流说明）
expected_result: 
  - 同一IP在5分钟内失败≥5次后返回HTTP 429，并触发锁定。
  - 锁定期间任何IP尝试返回锁定提示。
  - 30分钟后自动解除锁定。
  - 管理员可通过后台API手动清除锁定。
  - 所有操作记录到审计日志。
assignee: 张三
priority: P1
due_date: 2025-03-20
labels: ["安全", "后端"]
---
```

## 4. 字段说明与填写指南

### 4.1 `task_id`
- **定义**：任务的唯一标识符，用于追踪、索引与关联。
- **格式**：`[前缀]-YYYYMMDD-`＋3-4位数字序号（按天自增）。示例：`TASK-20250317-001`。
- **填写建议**：由任务管理工具自动生成；如手动创建，需确保全局唯一。

### 4.2 `title`
- **定义**：任务的简短标题，一眼可知任务核心内容。
- **格式**：动词
