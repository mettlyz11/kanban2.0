## 5. 更新CRM的操作注意事项

### 5.1 数据录入规范

1. **字段映射**：确保CRM系统中“当前阶段”字段与上述表格一致，避免使用自定义标签。标准阶段应为：线索 → 意向客户 → 方案沟通 → 商务谈判 → 已成交（闭环）。
2. **成交概率更新**：根据销售方法论，每个阶段应有固定的概率区间。本次数据中，线索阶段10%~15%、意向阶段28%~35%、方案阶段45%~55%、谈判阶段65%~70%、成交100%。录入时应参考上述区间微调，不可随意填写。
3. **最近跟进日期**：必须填写最新一次真实沟通日期，包括电话、会议、邮件、现场拜访等。若近期未跟进，可列为“近期无跟进”，并设置提醒任务。
4. **金额验证**：预计成交金额应与客户预算、报价单或初步意向一致，避免虚高或严重偏离实际。建议根据CO（合同机会）创建后客户的确认信息回填。

### 5.2 阶段迁移规则

- **线索→意向**：需满足“客户已明确表达需求”且“完成初步需求沟通”。不应单纯因为收到客户名片就迁移。
- **意向→方案**：客户已接受初步方案演示或已提供技术需求文档，并且内部立项流程启动。
- **方案→谈判**：客户已完成方案评审并发出报价邀请或进行商务条件谈判。
- **谈判→成交**：需收到正式PO或签字合同，且付款条件已达成一致。
- **成交→售后**：成交阶段应设有限时（如7天），到期后自动变为“已交付”或进入客户成功漏斗。

### 5.3 手动更新批量操作步骤

1. 导出CRM中当前Q1目标客户列表。
2. 比对上方12个客户记录的“当前阶段”与CRM实际字段，标记差异。
3. 对每个差异客户：
   - 更新阶段选择框。
   - 修改预计成交概率（如果系统支持公式自动计算则无需手动）。
   - 核实并修改预计成交金额（如系统支持，建议由销售主管复核）。
   - 填写/更新最近跟进日期及跟进摘要（至少保留50字纪要）。
4. 对于过渡到“成交”的客户（中科融合数据公司），需确认是否已录入合同金额与回款计划，并关闭该商机。
5. 批量更新后，运行一次CRM的“漏斗报表”检查一致性。

### 5.5 常见陷阱与规避

- **阶段混淆**：部分销售将“方案阶段”与“谈判阶段”混用。判断标准：若客户已进入商务条款讨论（如付款方式、交付周期）则为谈判，否则为方案。本次数据中星辰网络、鼎信物联、云峰数字能源仍处于技术方案论证，故归为方案阶段。
- **概率夸大**：有人为提高概率以美化管道的行为。实际录入时应以销售方法论规定的最高上限为准，如方案阶段最高不超过60%。
- **录入滞后**：由于季末冲刺，部分跟进记录可能未及时更新。建议更新后立即在CRM系统内执行一次“管道健康度扫描”，关注过期未跟进客户。
