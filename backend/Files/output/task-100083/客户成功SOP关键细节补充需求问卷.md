## 第一部分：问卷说明

### 1.1 调研目的

本次调研旨在全面了解公司客户成功业务的运营现状、实践经验及痛点需求，为构建标准化、流程化的客户成功SOP体系提供基础数据支撑。请各部门同事根据实际业务情况如实填写，本问卷所有内容将作为SOP制定的核心参考依据。

### 1.2 填写对象

| 部门/岗位 | 填写优先级 | 重点关注内容 |
|----------|----------|-------------|
| 客户成功团队（CSM） | 必填 | 全流程执行细节、客户接触经验 |
| 销售团队（SDR/Account Executive） | 必填 | 售前-售中交接、客户画像 |
| 产品运营团队 | 必填 | 客户使用数据、产品反馈 |
| 客户支持团队（Support） | 必填 | 客户问题处理、满意度 |
| 管理层（VP/总监） | 必填 | 战略方向、指标设定 |
| 技术/实施团队 | 建议填写 | 实施交付、集成配置 |

### 1.3 填写方式

- 本问卷采用在线表单形式提交，请于 **[填写截止日期]** 前完成
