## 3. 提取方法

### 3.1 正则表达式设计

我们需要从 Markdown 内容中定位到“依赖状态统计”表格，并提取三行数据。表格的典型匹配模式如下：

```
\| 状态 \| 数量 \|
\|[-]+\|[-]+\|
\| 成功 \| (\d+) \|
\| 失败 \| (\d+) \|
\| 跳过 \| (\d+) \|
```

考虑可能的中文全角空格、多种分隔符间距，实际使用的正则表达式更加鲁棒：

```
状态\s*\|\s*数量\s*\n\s*\|[-]+\|[-]+\|\s*\n\s*\|成功\s*\|\s*(\d+)\s*\|\s*\n\s*\|失败\s*\|\s*(\d+)\s*\|\s*\n\s*\|跳过\s*\|\s*(\d+)\s*\|
```

**说明**：
- `\s*` 匹配任意空白（包括空格、制表符），使表达式不依赖具体空格数量。
- `\|` 需要转义，因为 Markdown 表格中竖线是语法字符。
- `[-]+` 匹配至少一个短横线，用于分隔行。

### 3.2 Python 提取代码

以下为完整的提取函数，使用 `re` 模块实现，并返回一个字典：

```python
import re

def extract_dependency_stats(md_content: str) -> dict:
    """
    从Markdown内容中提取依赖状态统计数量。
    返回值格式：{'success': int, 'failure': int, 'skipped': int}
    若未找到则返回 None。
    """
    pattern = (
        r'状态\s*\|\s*数量\s*\n'  # 表头行
        r'\s*\|[-]+\|[-]+\|\s*\n'  # 分隔行
        r'\s*\|成功\s*\|\s*(\d+)\s*\|\s*\n'  # 成功行
        r'\s*\|失败\s*\|\s*(\d+)\s*\|\s*\n'  # 失败行
        r'\s*\|跳过\s*\|\s*(\d+)\s*\|'      # 跳过行
    )
    
    match = re.search(pattern, md_content, re.MULTILINE)
    if match:
        return {
            'success': int(match.group(1)),
            'failure': int(match.group(2)),
            'skipped': int(match.group(3)),
        }
    else:
        return None
```

### 4.2 绘制饼图（占比）

饼图可以直观展示每个报告中各状态占总数的比例。我们使用 `matplotlib.pyplot.pie` 进行绘制，并添加百分比标签。

```python
import matplotlib.pyplot as plt

def plot_pie(stats_dict, title, file_name):
    labels = ['成功', '失败', '跳过']
    values = [stats_dict['success'], stats_dict['failure'], stats_dict['skipped']]
    colors = ['#4CAF50', '#F44336', '#FFC107']
    explode = (0.02, 0.02, 0.02)  # 轻微分离
    
    plt.figure(figsize=(6, 6))
    plt.pie(values, labels=labels, colors=colors, autopct='%1.1f%%',
            startangle=90, explode=explode, shadow=False)
    plt.title(title)
    plt.axis('equal')
    plt.tight_layout()
    plt.savefig(file_name, dpi=150)
    plt.show()
```

调用：

```python
plot_pie(stats_0731, '报告0731 依赖状态占比', 'pie_0731.png')

```

### 4.3 绘制对比柱状图

为了对比两个报告中各状态的绝对数量，我们使用分组柱状图。

```python
def plot_comparison_bar(stats1, stats2, label1='0731', label2='0738', file_name='comparison_bar.png'):
    categories = ['成功', '失败', '跳过']
    values1 = [stats1['success'], stats1['failure'], stats1['skipped']]
    values2 = [stats2['success'], stats2['failure'], stats2['skipped']]
    
    x = range(len(categories))
    width = 0.35
    
    fig, ax = plt.subplots(figsize=(8, 5))
    rects1 = ax.bar([p - width/2 for p in x], values1, width, label=label1, color='#2196F3')
    rects2 = ax.bar([p + width/2 for p in x], values2, width, label=label2, color='#FF9800')
    
    ax.set_xlabel('状态')
    ax.set_ylabel('数量')
    ax.set_title('两个报告依赖状态数量对比')
    ax.set_xticks(x)
    ax.set_xticklabels(categories)
    ax.legend()
    
    # 在柱子上方显示数值
    for rect in rects1:
        height = rect.get_height()
        ax.annotate(f'{int(height)}', xy=(rect.get_x() + rect.get_width() / 2, height),
                    xytext=(0, 3), textcoords="offset points", ha='center', va='bottom')
    for rect in rects2:
        height = rect.get_height()
        ax.annotate(f'{int(height)}', xy=(rect.get_x() + rect.get_width() / 2, height),
                    xytext=(0, 3), textcoords="offset points", ha='center', va='bottom')
    
    plt.tight_layout()
    plt.savefig(file_name, dpi=150)
    plt.show()
```

调用：

```python
plot_comparison_bar(stats_0731, stats_0738, '0731', '0738', 'comparison_bar.png')
```

## 5. 图表解读

### 5.1 报告0731 状态占比

根据提取的数据（成功 142，失败 12，跳过 8），总数 = 142 + 12 + 8 = 162。

| 状态 | 数量 | 占比   |
|------|------|--------|
| 成功 | 142  | 87.65% |
| 失败 | 12   | 7.41%  |
| 跳过 | 8    | 4.94%  |

**解读**：  
- 成功比例接近 88%，表明大部分依赖项已通过测试，整体健康状况良好。  
- 失败项占比约 7.4%，属于可接受范围，但需要跟踪具体失败原因。  
- 跳过项占比不足 5%，可能表示部分依赖项在本次报告周期中未被执行（例如环境限制或人为排除）。

### 5.2 报告0738 状态占比

数据：成功 131，失败 19，跳过 5。总数 = 131 + 19 + 5 = 155。

| 状态 | 数量 | 占比   |
|------|------|--------|
| 成功 | 131  | 84.52% |
| 失败 | 19   | 12.26% |
| 跳过 | 5    | 3.23%  |

**解读**：  
- 成功比例降至 84.5%，比 0731 降低了约 3 个百分点。  
- 失败比例升至 12.26%，几乎翻倍，说明 0738 阶段引入了更多问题或测试范围扩大导致暴露更多缺陷。  
- 跳过比例略有下降（3.23%），可能因为某些原本跳过的用例被重新启用或取消跳过。

### 5.3 对比分析

以下为两个报告的直接对比摘要：

| 维度     | 0731      | 0738      | 变化趋势       |
|----------|-----------|-----------|----------------|
| 成功数   | 142       | 131       | ↓ 11 项        |
| 失败数   | 12        | 19        | ↑ 7 项         |
| 跳过数   | 8         | 5         | ↓ 3 项         |
| 成功率   | 87.65%    | 84.52%    | ↓ 3.13%        |
| 失败率   | 7.41%     | 12.26%    | ↑ 4.85%        |
| 跳率     | 4.94%     | 3.23%     | ↓ 1.71%        |

**核心发现**：
1.  从 0731 到 0738，成功数量减少 11 项，但总项数也减少（162 → 155），说明有些依赖项被移除或合并，但失败数量反而增加，表明新引入的依赖或变更导致了更多故障。
2.  失败率上升近 5 个百分点，这是一个值得警报的信号——需要立即审查 0738 期间发生的配置或代码更改，定位新增的 7 个失败项。
3.  跳过项减少 3 个，可能反映了测试覆盖率的提升或跳过策略的调整，但数量较小，对整体影响有限。

**可视化辅助解读**：  
- 饼图清楚显示两个报告中成功区域都占主体，但 0738 的失败扇区明显增大。  
- 对比柱状图在“失败”一栏上 0738 的柱子明显高于 0731，成功柱子则降低，视觉上非常直观。

**结论**：  
依赖状态从 0731 到 0738 出现质量下滑，主要风险集中在失败项的激增。建议立即对失败项进行根因分析，并考虑回滚部分变更或加强测试环境一致性。同时，持续监控跳过项的变化，确保不遗漏关键依赖。

### 6.3 可能的误差与局限性

1. **表格匹配**：如果 Markdown 文件中存在多个格式相似的表格，正则表达式默认仅匹配第一个。若有多个“依赖状态统计”表格，需手动指定或修改提取逻辑（例如根据章节号定位）。
2. **数据准确性**：假设原始 Markdown 表格数值正确无误。若原始数据存在格式错误（如非数字字符），提取会失败并返回 `None`。本脚本未做错误回退，实际应用时应增加校验。
3. **图表中文显示**：matplotlib 默认字体不支持中文，可能显示方块。本代码未设置中文字体，若需输出图表中包含中文，需额外配置（如使用 `plt.rcParams['font.sans-serif'] = ['SimHei']`）。本说明文档中的图表示例假定已配置或使用英文标签（实际代码中为中文，需用户本地环境支持）。
4. **数值精度**：饼图百分比保留一位小数，在数据量很小时可能丢失精度，但对于当前数据量（总数>150）足够。
