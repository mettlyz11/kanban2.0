# 5月客户拜访计划 - 待办清单

## 一、总体任务概览

**目标**：5月份完成10家目标客户的拜访，覆盖现有重点客户5家、潜在新客户3家、流失预警客户2家。

**时间周期**：2025年5月6日 - 5月30日（每周安排2-3家拜访）

**负责人**：销售团队全员（按客户分配）

**关键指标**：
- 拜访完成率：100%（10/10）
- 意向转化率：≥40%（至少4家进入下一步谈判）
- 客户满意度评分：≥4.5/5.0

## 二、拜访前准备阶段（每家客户至少提前3天启动）

### 2.1 客户背景复习

- [ ] **调取客户档案**：从CRM中导出客户最新基本资料（公司全称、所属行业、规模、年营收、主要产品/服务）
- [ ] **关键人物分析**：确认本次拜访对象（姓名、职位、决策角色、沟通风格偏好）
- [ ] **历史合作回顾**：查看过去12个月内的所有互动记录（电话、邮件、会议、报价单、合同）
- [ ] **行业动态扫描**：通过天眼查/企查查/行业报告，了解客户近期大事件（融资、新品发布、组织调整、负面舆情）
- [ ] **竞争情报收集**：检查客户是否接触过竞品（最近3个月内有无比价、试用、合作记录）

**具体检查清单示例（以客户A为例）**：
| 项目 | 数据/状态 | 备注 |
|------|-----------|------|
| 客户行业 | 智能制造 | 细分：工业机器人 |
| 决策人 | 张总（技术总监） | 偏好数据型沟通 |
| 上次联系 | 2025-04-15，讨论技术方案 | 未明确拒绝 |
| 近期动态 | 4月20日发布新品 | 可能产生新需求 |
| 竞品动态 | 竞品X在4月25日提交了报价 | 需针对性准备 |

### 2.2 历史跟进记录确认

- [ ] **整理未关闭事项**：列出上次拜访遗留的待办（技术问题、报价调整、内部审批等）
- [ ] **确认承诺兑现**：检查自己是否已经完成了对客户的所有承诺（发送资料、介绍对接人、提供试用账号等）
- [ ] **分析沟通瓶颈**：标记出之前未达成共识的关键分歧点（价格、交付周期、售后条款等）
- [ ] **更新联系人信息**：确认联系人手机、邮箱、微信是否仍然有效

### 2.3 竞品动态了解

- [ ] **搜索竞品最新动作**：在36氪、亿欧、钛媒体等平台检索竞品新闻（重点：产品更新、融资、大客户签约）
- [ ] **对比优劣势**：制作一份A4纸大小的竞品对比表（我方 vs 主要竞品X vs 竞品Y）
- [ ] **准备应对话术**：针对竞品可能使用的攻击点（价格低、功能多、服务快），准备3个核心反驳论据
- [ ] **收集客户反馈**：如果客户之前提到过竞品，整理出客户对竞品的具体评价

### 2.4 议程预沟通

- [ ] **发送会议邀请**：提前3个工作日通过邮件+微信双重确认拜访时间
- [ ] **提供初步议程**：邮件中附上会议议程草案（时长建议90分钟），包括：开场破冰（10分钟）→ 需求确认（20分钟）→ 方案演示（30分钟）→ 问答讨论（20分钟）→ 下一步计划（10分钟）
- [ ] **确认参与人员**：请客户告知还有哪些同事会参与，并了解他们的角色（决策者、使用者、技术评估者）
- [ ] **了解客户期望**：直接问“您希望这次会议重点解决什么问题？”

### 2.5 材料准备

- [ ] **定制化方案PPT**：基于客户行业和需求，修改通用模板，确保首页有客户Logo和定制标语
- [ ] **打印纸质资料**：方案摘要（1页）、成功案例（2页）、产品彩页、名片（至少5张）
- [ ] **准备演示设备**：笔记本电脑（充满电、提前打开文件）、转接头（VGA/HDMI）、翻页笔、投影仪（如客户没有）
- [ ] **备用材料**：U盘（存有所有文件的PDF版本）、纸质笔记本和笔（防止电子设备故障）
- [ ] **礼品准备**：根据客户喜好准备小礼物（公司定制礼品/行业白皮书/客户喜欢的书籍）

### 2.6 预约确认

- [ ] **前一天提醒**：拜访前一天下午4点前，通过微信或短信发送确认信息（时间、地点、联系人、天气提醒）
- [ ] **路线规划**：使用高德/百度地图规划最佳路线，考虑早高峰/午高峰拥堵，预留30分钟缓冲时间
- [ ] **应急方案**：如果客户临时取消，准备一个电话会议替代方案（提前和客户约定备选时间）

## 三、拜访当日执行阶段

### 3.1 提前到达

- [ ] **到达时间**：比约定时间早到15-20分钟（在大堂或附近咖啡厅等待，不要提前上楼）
- [ ] **着装规范**：根据客户行业选择着装（金融/法律：正装；互联网/创意：商务休闲）
- [ ] **前台登记**：提前准备好身份证/健康码/访客码，礼貌告知前台找谁
- [ ] **环境观察**：进入客户办公区后，留意公司文化展示（标语、奖杯、员工状态），作为破冰素材

### 3.2 破冰话题

- [ ] **开场问候**：微笑握手，简短寒暄（天气、最近忙的项目、上次见面的趣事）
- [ ] **个性化话题**：根据客户社交媒体动态或行业新闻展开（“看到贵司上周获得了XX奖项，恭喜！”）
- [ ] **建立共鸣**：分享一个客户行业近期的小趋势或痛点（“最近很多制造业客户都在关注XX问题，您这边有遇到吗？”）
- [ ] **确认议程**：快速过一遍会议议程，询问客户是否有调整需求

### 3.3 需求探询

- [ ] **开放式提问**：使用SPIN提问法（Situation-Problem-Implication-Need-payoff）：
  - 情境问题：“目前贵司在XX环节是如何操作的？”
  - 难点问题：“在这个过程中，您遇到的最大挑战是什么？”
  - 暗示问题：“如果这个问题不解决，对贵司的业务有什么影响？”
  - 需求-效益问题：“如果我们能帮您解决这个问题，会带来什么价值？”
- [ ] **倾听与记录**：客户说话时不要打断，用笔记本记录关键点（确保客户看到你在认真记录）
- [ ] **确认理解**：每讨论完一个要点，用自己的话复述一遍：“我理解您的意思是……对吗？”
- [ ] **挖掘隐性需求**：当客户说“我们目前没什么问题”时，追问“如果有一个机会能让XX指标提升20%，您会感兴趣吗？”

### 3.4 方案呈现

- [ ] **以客户为中心**：不要照读PPT，而是围绕客户之前提到的痛点来组织讲解
- [ ] **数据驱动**：每个观点都要有数据支撑（ROI计算、行业基准对比、成功案例数据）
- [ ] **可视化展示**：使用图表、demo、视频片段来增强说服力
- [ ] **互动环节**：每讲完一个模块，停下来问“这个部分对您来说是否相关？”
- [ ] **时间控制**：严格把控时间，如果客户对某部分特别感兴趣，可以适当延长但确保不超时30%

### 3.5 异议处理

- [ ] **倾听完整**：客户提出异议时，不要立即反驳，先让客户把话说完
- [ ] **确认理解**：“您担心的主要是价格方面的问题，对吗？”
- [ ] **分类应对**：
  - 价格异议：强调TCO（总拥有成本）和ROI（投资回报率），提供分期付款或折扣方案
  - 功能异议：展示对标竞品的差异化功能，或承诺未来版本更新
  - 信任异议：提供更多客户证言、第三方评测报告、免费试用期
- [ ] **迂回策略**：如果当场无法解决，记录问题并承诺“我回去后和产品团队讨论，周四前给您书面答复”

### 3.6 下一步共识

- [ ] **明确行动项**：在会议结束前15分钟，总结双方达成的共识：
  - 我方行动：发送详细方案、安排技术对接、提供试用账号
  - 客户行动：内部讨论、提供更多需求细节、安排二次会议
- [ ] **设定时间线**：为每个行动项设定明确的截止日期（例如：5月12日前发送报价单）
- [ ] **确认决策流程**：询问“接下来还需要哪些人参与决策？我们如何推动下一步？”
- [ ] **表达感谢**：真诚感谢客户的时间和分享，重申合作意愿

### 3.7 现场记录

- [ ] **实时笔记**：使用笔记本或平板记录关键信息（客户的原话、表情反应、非语言信号）
- [ ] **拍照留念**：如客户同意，可拍摄会议现场照片（用于内部复盘和客户跟进邮件）
- [ ] **录音备份**：征得客户同意后，使用手机录音（用于后续整理纪要，但需告知客户）
- [ ] **记录客户承诺**：特别记录客户口头承诺的任何事项（“我下周会安排技术团队评估”）

## 四、拜访后跟进阶段

### 4.1 感谢信息发送

- [ ] **时间**：拜访结束后2小时内发送（趁热打铁）
- [ ] **渠道**：优先使用微信（如已添加），其次邮件
- [ ] **内容模板**：
  > 张总好，今天非常荣幸能拜访贵司。感谢您和团队抽出时间深入交流。我们重点讨论了XX和XX两个方向，我整理了一份会议纪要，稍后发送给您。接下来我会在周四前完成XX方案的更新，期待我们的进一步合作。祝您工作顺利！
- [ ] **个性化**：提及一两个会议中的细节（“您提到的XX观点非常启发我”）

### 4.2 会议纪要整理

- [ ] **当天完成**：拜访当天晚上12点前完成会议纪要
- [ ] **标准格式**：
  - 会议基本信息（时间、地点、参与人）
  - 会议目标与议程回顾
  - 关键讨论点（客户痛点、需求、决策标准）
  - 双方达成的共识与行动项
  - 下一步计划与时间线
- [ ] **发送给客户**：24小时内发送给客户，并请客户确认是否有遗漏或错误
- [ ] **存档**：将会议纪要上传至CRM系统，关联客户档案

### 4.3 内部同步

- [ ] **口头汇报**：拜访第二天早会上，口头向销售主管汇报关键发现和下一步计划
- [ ] **邮件同步**：发送给相关部门（产品、技术、客服）的邮件，说明客户需求和承诺
- [ ] **创建协作任务**：在项目管理工具（如Teambition/飞书）中创建任务，分配给相关人员（如技术部5月15日前完成demo搭建）
- [ ] **风险预警**：如果客户有流失风险或竞品威胁，立即升级给管理层

### 4.4 CRM更新

- [ ] **录入拜访记录**：在CRM中创建新的拜访记录，填写时间、地点、参与人、讨论要点
- [ ] **更新客户阶段**：根据拜访结果，将客户移入对应的销售漏斗阶段（意向客户/方案评估/商务谈判/赢单）
- [ ] **更新联系人信息**：新增或修改联系人资料（如新加入的技术评估人员）
- [ ] **设置下次提醒**：根据约定的下次联系日期，在CRM中设置提醒（如5月20日发送方案）

### 4.5 待办事项分配

- [ ] **自我任务**：列出自己需要完成的事项（如5月14日前完成方案修改）
- [ ] **团队任务**：分配给其他部门的任务（如产品部5月12日前提供技术参数）
- [ ] **客户任务**：记录客户承诺的事项（如客户说5月18日前内部讨论）
- [ ] **优先级排序**：使用四象限法则（紧急-重要）对任务排序，优先处理高紧急高重要事项

### 4.6 下次拜访预约

- [ ] **试探性预约**：在感谢信息或会议纪要中，提出“下周二或周四是否方便进行第二次沟通？”
- [ ] **预留时间**：在个人日历中为每个客户预留2-3个备选时间
- [ ] **建立节奏**：对于高意向客户，建议每周一次沟通；对于一般客户，每两周一次

## 五、月度复盘要点

### 5.1 拜访完成率

| 周次 | 计划拜访数 | 实际完成数 | 完成率 | 未完成原因 |
|------|-----------|-----------|--------|-----------|
| 第1周（5/6-5/10） | 2 | 2 | 100% | - |
| 第2周（5/13-5/17） | 3 | 2 | 67% | 客户A临时出差 |
| 第3周（5/20-5/24） | 3 | 3 | 100% | - |
| 第4周（5/27-5/30） | 2 | 2 | 100% | - |
| **合计** | **10** | **9** | **90%** | 1家延期至6月 |

**分析**：90%完成率，接近目标。客户A延期是因为其CEO临时出国，已在5月20日完成电话沟通，6月初安排新拜访。

### 5.2 目标达成率

| 客户类型 | 拜访数 | 进入下一阶段数 | 转化率 | 预期目标 |
|----------|-------|--------------|--------|---------|
| 现有重点客户 | 5 | 4 | 80% | 80% |
| 潜在新客户 | 3 | 1 | 33% | 50% |
| 流失预警客户 | 2 | 1 | 50% | 30% |
| **合计** | **10** | **6** | **60%** | **≥40%** |

**分析**：整体转化率60%，超过目标40%。但新客户转化率偏低（33%），需要优化新客户拜访前的需求挖掘。

### 5.3 转化漏斗分析

```
全部拜访（10家）
    ↓
进入意向阶段（7家，70%）
    ↓
进入方案评估（5家，50%）
    ↓
进入商务谈判（3家，30%）
    ↓
预计赢单（2家，20%）
```

**瓶颈点**：
- 从意向到方案评估的转化率较低（71% → 71%），说明方案呈现环节需要加强
- 商务谈判阶段的客户流失主要因为价格分歧（2家客户明确表示预算不足）

### 5.4 典型问题总结

| 问题类型 | 具体表现 | 发生次数 | 影响程度 |
|----------|---------|---------|---------|
| 客户决策周期长 | 客户内部审批流程复杂，需要多轮沟通 | 4次 | 高 |
| 竞品低价竞争 | 竞品X以低于我方20%的价格抢单 | 3次 | 中 |
| 客户需求不明确 | 客户自己也不清楚需要什么，需求频繁变更 | 2次 | 低 |
| 内部资源协调慢 | 技术部demo交付延迟，影响客户信心 | 1次 | 中 |

### 5.5 下月优化建议

- [ ] 制作一份“客户决策地图”，帮助销售团队理清每个客户的决策链和关键影响人

**长期行动（Q3规划）**：

- [ ] 推行“拜访复盘会”制度，每周五下午1小时，团队分享成功经验和失败教训
