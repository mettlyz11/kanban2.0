# 新收入来源探索项目下周工作计划和里程碑

## 一、项目概述

### 1.1 项目背景
为应对当前主营业务增长放缓、市场竞争加剧的挑战，公司于2025年1月正式启动“新收入来源探索项目”，旨在通过系统化的市场研究与商业验证，发现并评估至少3个潜在的新收入方向，并在6个月内完成可行性论证和概念验证。项目至今已运行3周，完成了外部环境初筛和内部能力盘点。

### 1.2 本周进展概况（2025年4月14日-4月18日）
- **已完成事项**：
  - 完成宏观趋势报告（覆盖AI应用、绿色经济、银发经济、跨境出海4个领域）
  - 组织两次内部脑暴会，收集23个初步创意方向
  - 筛选出8个高潜力候选方向，完成初步市场规模估算
  - 组建项目团队，确认各成员角色（5人核心组+2人兼职支持）
- **存在问题**：
  - 候选方向的竞争格局信息不完整（仅完成60%）
  - 内部数据资源（客户画像、历史收入拆解）尚未完全整合
  - 下周需与财务部、法务部进行首次资源协同沟通

### 1.3 下周工作目标（2025年4月21日-4月25日）
- **核心目标**：针对8个候选方向完成竞争格局深度扫描（覆盖率≥80%），输出《候选方向竞争分析报告》初稿
- **量化指标**：
  - 每个方向至少获取5个直接竞争对手信息（规模、产品、定价、渠道）
  - 完成2个方向的客户假设验证访谈（每人不少于3场）
  - 提交财务模型初版（收入假设+成本结构）供评审
- **协同目标**：与财务部、法务部完成首次沟通，明确合作流程与合规边界

### 2.2 任务详细描述

#### T-01 竞争格局深度扫描
- **目标**：对8个候选方向的竞争格局进行全面扫描，输出结构化数据表。
- **方法**：采用二手数据源（行业报告、公司官网、天眼查、招聘网站、社交媒体）结合一手调研（匿名询价、客户评价分析）。
- **输出**：每个方向一个独立的数据表，包含以下字段：竞争对手名称、成立时间、融资阶段、估/收入规模、核心产品/服务、定价区间、主要渠道、市场份额（如有）、竞争优势与劣势、近期动态。
- **质量标准**：使用标准化模板，信息源需标注（如“XX报告2025”、“官网访问2025-04-21”），每个方向有效竞争对手数量≥5家，整体信息完整度≥80%。
- **风险提示**：部分细分方向（如“宠物殡葬智能服务”）可能公开信息较少，需启用专家访谈预案（已联系2位行业顾问）。

#### T-02 客户假设验证访谈
- **目标**：针对“AI心理健康轻问诊”和“中小企业绿色认证代办”两个方向，通过与潜在客户对话验证业务假设。
- **访谈对象筛选标准**：
  - 方向A（AI心理）：用户画像为25-40岁、有轻度焦虑/睡眠问题、月收入1万以上、曾尝试过心理咨询或数字疗法。
  - 方向B（绿色认证）：企业类型为制造/出口型中小企业，员工50-300人，年营收500万-1亿，有出口欧盟或供应链合规需求。
- **数量要求**：每个方向至少访谈8人（预计成功邀约10人，按80%出席率计算）。当前已通过付费样本库预招募20人，周一上午确认最终名单。
- **访谈提纲**：30分钟半结构化访谈，重点验证：①痛点严重程度（0-10分）②现有解决方案及付费意愿③决策流程④替代方案价格敏感度。
- **记录方式**：全程录音（经同意）+ 即时笔记，访谈结束后2小时内整理纪要。

#### T-03 财务模型V1.0搭建
- **目标**：为8个候选方向建立统一的财务评估模型框架，包含收入测算、成本结构、现金流预测。
- **模型结构**：
  - 输入页：市场规模、渗透率假设、定价、获客成本（CAC）、年续费率、人员配置、固定成本（设备、场地、合规）
  - 计算页：5年收入预测（按保守/中性/乐观三情景）、毛利率、净利率、投资回收期、ROI、NPV
  - 输出页：可视化图表（瀑布图、敏感性分析、盈亏平衡点）
- **依赖**：需要T-01的竞争定价数据，以及T-04的内部资源成本数据。模型计划周三启动，周四下午完成初版。
- **工具**：Excel + Python脚本（用于敏感性模拟，可选），本次仅需Excel版本。

#### T-04 内部资源数据整合
- **目标**：从公司内部系统（CRM、财务系统、HR系统）提取与候选方向相关的历史数据。
- **数据清单**：
  - 现有客户行业分布（近3年）→ 判断新方向与现有客户的重合度
  - 各产品线毛利率数据 → 设定新方向成本基准参考
  - 销售团队能力分布（行业经验、语言能力）→ 判断所需人力补充
- **输出**：一份清洗后的数据集（CSV格式）+ 数据字典，字段包括客户ID、所属行业、近12月消费额、产品线、销售代表等。
- **注意事项**：需与IT部门协调接口权限，已提前联系数据库管理员（周一上午会议确认）。

#### T-05 跨部门协同沟通
- **目标**：与财务部（赵岩）和法务部（刘律师）敲定项目协作方式。
- **议程**：
  - 财务：预算审批流程、成本分摊规则、收入确认原则
  - 法务：知识产权归属（新业务可能涉及商标/专利）、合规风险排查建议、客户数据使用边界
- **输出**：会议纪要+双方确认的协作流程图（含时间节点和审批人）。

#### T-06 竞争分析报告框架
- **说明**：先由李娜搭建报告大纲，供周五团队内部评审。框架需包含：执行摘要、方法说明、各方向竞争格局矩阵、领先者分析、空白机会识别、风险提示、下一步建议。
- **交付**：Word模板（标题级别+预期内容提示），周二下午提交初版框架讨论。

#### T-07 周度汇报材料
- **内容**：按照公司PMO标准格式，本周完成工作概览、下周计划、关键问题、需要决策的事项。
- **提交流程**：周五上午10点前提交至项目管理文件夹，供组长审阅后下午3点向创新委员会邮件汇报。

#### T-08 项目管理系统更新
