📌 **步骤2：核心指标计算（Excel/BI直接套用）**
在清洗后的数据表中新增以下计算列（以Excel为例）：
- `实际销售额 = SUM(实收金额) - SUM(退款金额)`
- `订单转化率 = 成交订单数 / 活动点击量（或线索量）`
- `活动ROI = 实际销售额 / 活动总成本（含投放+优惠券+人力分摊）`
- `客单价 = 实际销售额 / 成交订单数`
- `目标达成率 = 实际销售额 / 4月目标销售额`
- `同比/环比增长率 = (本月值-对比月值)/对比月值`
