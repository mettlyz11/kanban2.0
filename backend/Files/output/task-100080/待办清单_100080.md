# 任务 #100080 - 需人工完成

## 任务: 分析5个重点客户的决策链并制定下一步接触计划

## 需要人工完成的事项



1. **最需要的具体产出**：5份《客户决策链映射与下一步接触作战表》。需包含：各客户决策角色清单（EB/TB/UB/Coach/采购守门人）、权力与态度评估、当前关系断点、核心业务痛点、下一步优先触达对象、触达渠道、定制化价值主张、预期目标、时间节点及内部协同资源。

2. **能否生成**：不能。该任务高度依赖企业内部私有数据（客户真实背景、历史跟进记录、已知联系人、我方产品/服务定位、竞争态势及预算周期），AI无法凭空获取或推断真实企业的内部决策结构。

3. **需要人工完成的具体待办事项清单**：
   - **【数据输入】**整理5个重点客户的基础档案：公司名称、所属行业、当前商机阶段（线索/验证/谈判/续约）、历史沟通纪要摘要、已知对接人名单及职务。
   - **【角色识别】**通过公开渠道（官网/年报/领英/招投标信息）及内部复盘，为每个客户标注决策链关键节点，明确谁是“拍板人”、谁是“技术把关人”、谁是“内部推手（Coach）”、谁是“流程卡点”。
   - **【态度与权力评估】**对每个已识别角色进行二维打标：影响力（高/中/低） × 对我方态度（支持/中立/反对/未知），找出当前决策链中的“空白区”或“阻力点”。
   - **【价值匹配】**针对每个关键角色，提炼其核心KPI/痛点（如EB关注ROI与合规，TB关注兼容性与安全，UB关注效率与培训成本），并匹配我方对应的案例/数据/解决方案。
   - **【制定接触节奏】**输出30-60-90天分步计划：明确下一步“打谁、怎么打、带什么弹药、要什么结果”。例如：第1周通过Coach引荐技术评审；第3周安排高管拜访EB对齐战略价值；第6周推动采购走比价流程。
   - **【内部资源确认】**盘点每次关键触达所需的内部支持（售前方案、高管站台、POC环境、法务合同模板、折扣权限），指定主责人及复盘机制。
