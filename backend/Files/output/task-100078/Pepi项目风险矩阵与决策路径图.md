## 2. 风险概率-影响量化评估矩阵

### 2.1 评估标准定义

**概率等级**：
- **很高** (5)：>80% 概率发生
- **高** (4)：60%-80% 概率发生
- **中等** (3)：40%-60% 概率发生
- **低** (2)：20%-40% 概率发生
- **很低** (1)：<20% 概率发生

**影响等级**（以财务损失计）：
- **灾难性** (5)：>500万美元 或 项目终止
- **重大** (4)：200-500万美元 或 功能严重缺失
- **中等** (3)：50-200万美元 或 核心功能受损
- **轻微** (2)：10-50万美元 或 次要功能受影响
- **可忽略** (1)：<10万美元 或 无可见影响
