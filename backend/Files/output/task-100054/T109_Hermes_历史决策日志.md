### D-T-02：决定使用QLoRA（量化+LoRA）

| 字段 | 内容 |
|------|------|
| **决策编号** | D-T-02 |
| **日期** | 2025-02-20 |
| **背景与问题** | 全参数微调需要70GB显存（模型fp16），但服务器共享使用，需节省资源。考虑使用PEFT。 |
| **最终决策内容** | 采用QLoRA：4bit量化（NF4），LoRA rank=8，alpha=16，target modules为q_proj, v_proj。 |
| **核心依据/数据** | QLoRA可降低显存至16GB，性能损失<2%（在100条验证集上评估）。LoRA rank=8比rank=16快30%且效果接近。 |
| **被否决的备选方案** | 全参数微调（资源不足，需排队等待）；LoRA（无量化，仍显存约24GB，但推荐QLoRA更省）。 |
