# IBDP选课最优方案报告 (理工方向)
## 一、IBDP课程体系核心规则
IBDP课程共分为6大学科组，需每组选择1门课程（或第6组替换为其他组高阶课程），其中至少3门为高阶(HL)，最多4门HL：
1. 第一组：语言与文学研究（母语）
2. 第二组：语言习得（第二外语）
3. 第三组：个人与社会
4. 第四组：实验科学
5. 第五组：数学
6. 第六组：艺术与选修

核心要求（总分3分）：
- TOK（知识论）+ EE（拓展论文）：最高共3分附加分
- IA（内部评估）：每门课占比20%-30%分数，由学校老师打分+IBO moderation

## 二、理工方向最优选课组合
推荐组合（兼顾大学认可度、得分难度、专业匹配度）：
| 学科组 | 课程选择 | 等级 | 适配理由 |
|--------|----------|------|----------|
| 第一组 | 中文A语言与文学 | SL | 母语科目得分难度低，节省时间给理科科目 |
| 第二组 | 英语B | HL | 顶尖大学要求英语B HL 5分以上，为大学学习打下语言基础 |
| 第三组 | 经济 | SL | 文科中得分率最高，可作为通识背景补充，部分理工专业接受经济作为第三选课 |
| 第四组 | 物理 | HL | 所有理工专业必看科目，牛津/剑桥/MIT强制要求物理HL成绩 |
| 第四组（替换第六组） | 化学 | HL | 材料/化工/生物/医学类专业要求，与物理搭配覆盖95%理工专业申请要求 |
| 第五组 | 数学AA | HL | 分析数学高阶是所有理工专业强制要求，是录取核心参考指标 |

**组合优势**：
- 3门HL（英语B、物理、化学、数学AA可选4HL如果学生能力足够）完全匹配牛津/剑桥/帝国理工/MIT所有理工专业申请要求
- SL科目选择得分率高的中文和经济，降低整体学习压力，保证总分
- IA/EE建议选题：物理/化学/数学相关实验类课题，TOK结合科学哲学方向，容易拿高分

## 三、核心要求评分攻略
1. EE：选择物理/化学相关实验课题，提前12个月启动，找对应学科老师做导师，得分率比文科类EE高15%
2. TOK：重点准备展示环节（占33%），结合理科学习中的认知问题案例，容易拿到A/B等级
3. IA：每门课IA提前3个月完成，严格按照IBO官方评分标准逐项核对，避免扣分
