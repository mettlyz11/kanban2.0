## 一、展会背景分析

### 1.1 展会基本信息

| 项目 | 内容 |
|------|------|
| 展会名称 | 中国国际化工装备博览会（CTEF2026） |
| 时间 | 2026年6月（预计） |
| 地点 | 上海新国际博览中心（预计） |
| 预计规模 | 参展商800+，专业观众30000+ |
| 主办单位 | 中国化工装备协会等 |
| 展会周期 | 一年一届 |

### 1.2 展会定位与价值

CTEF是中国化工装备领域最具影响力的专业展会之一，涵盖：
- 化工成套装置及设备
- 分离过滤设备
- 干燥设备
- 流体机械
- 反应器及催化剂
- 自动化及仪器仪表
- 化工环保设备

**对和光智成的战略价值**：
1. **品牌曝光**：向全行业展示AI催化剂即服务（CaaS）创新模式
2. **客户对接**：与目标客户建立初步联系，获取销售线索
3. **行业洞察**：了解竞争对手动态和行业最新趋势
4. **合作拓展**：寻找技术合作伙伴和渠道合作伙伴
5. **媒体关注**：获取行业媒体报道，提升知名度

### 1.3 目标受众分析

| 受众类型 | 占比 | 关注点 | 对接策略 |
|---------|------|--------|---------|
| 化工企业采购/技术负责人 | 40% | 催化剂性能、成本、服务 | 技术交流+商务洽谈 |
| 工程公司/设计院 | 25% | 技术方案、合作伙伴 | 技术合作+渠道拓展 |
| 催化剂生产商 | 15% | 竞争情报、合作机会 | 差异化展示+合作探讨 |
| 科研机构/高校 | 10% | 前沿技术、产学研合作 | 技术交流+人才引进 |
| 投资机构/媒体 | 10% | 商业模式、投资价值 | 品牌宣传+融资对接 |

## 三、展位规划

### 3.1 展位选址策略

**推荐位置**：
- **首选**：反应器及催化剂专区（如有）
- **次选**：化工环保设备区（废剂回收相关）
- **备选**：主通道附近，人流量大的位置

**展位面积建议**：
- 标准展位：9m×9m = 81㎡（最小）
- 推荐展位：12m×12m = 144㎡（最佳）

### 3.2 展位布局设计

```
┌─────────────────────────────────────────┐
│              入口/接待区                 │
│         （品牌墙+接待台+资料架）          │
├─────────────────────────────────────────┤
│  ┌─────────┐  ┌─────────┐  ┌─────────┐ │
│  │ 产品展示 │  │ 产品展示 │  │ 洽谈区  │ │
│  │  区域A   │  │  区域B   │  │        │ │
│  │ (催化剂) │  │ (监测设备)│  │  圆桌  │ │
│  └─────────┘  └─────────┘  └─────────┘ │
├─────────────────────────────────────────┤
│  ┌─────────────────────────────────┐   │
│  │         演示体验区               │   │
│  │    （AI平台demo+VR体验）         │   │
│  └─────────────────────────────────┘   │
├─────────────────────────────────────────┤
│              屏幕/舞台区                 │
│         （循环播放宣传片+小型发布）       │
└─────────────────────────────────────────┘
```

### 3.3 展位设计要点

**视觉设计**：
- 主色调：科技蓝+环保绿（体现AI+绿色化学）
- 品牌元素：和光智成logo、CaaS服务标识
- 核心信息："AI催化剂即服务"、"降本增效·绿色转型"

**展示内容**：
1. **品牌墙**：企业介绍、核心优势、服务流程
2. **产品展示区**：
   - 催化剂样品展示
   - IoT监测设备展示
   - 废剂回收流程展示
3. **演示体验区**：
   - AI催化剂设计平台实时演示
   - 在线监测数据大屏
   - VR工厂巡检体验
4. **洽谈区**：
   - 舒适的商务洽谈环境
   - 私密性良好的会议室（可选）

## 五、客户对接策略

### 5.1 客户分级对接

#### A级客户（高优先级，15家）

**对接策略**：
- 展前1个月预约洽谈时间
- 展会期间安排专属商务经理对接
- 邀请参加闭门技术研讨会
- CEO/高管亲自接待关键客户

**A级客户清单**：
1. 中石化
2. 中石油
3. 中海油
4. 恒力集团
5. 荣盛集团
6. 盛虹集团
7. 万华化学
8. 国家能源集团
9. 陕煤化集团
10. 浙江新和成
11. 联化科技
12. 博腾制药
13. 药明康德
14. 宁德时代
15. 比亚迪

#### B级客户（中优先级，25家）

**对接策略**：
- 展前发送邀请函和资料
- 展会期间安排标准商务洽谈
- 邀请参加发布会
- 收集需求，安排展后跟进

#### C级客户（低优先级，10家）

**对接策略**：
- 展会现场接待
- 收集名片和需求
- 展后邮件跟进
- 长期培育

### 5.2 客户洽谈流程

```
客户到达展位
    ↓
接待登记（扫码/名片）
    ↓
初步需求了解（2分钟）
    ↓
┌─────────┬─────────┐
↓         ↓         ↓
A级客户   B级客户   C级客户
↓         ↓         ↓
专属经理  标准接待  资料发放
深度洽谈  产品介绍  信息收集
方案讨论  需求记录  展后跟进
↓         ↓         ↓
预约展后  邀请参加  录入CRM
拜访      发布会    系统
```

### 5.3 客户信息收集

**收集内容**：
- 企业基本信息
- 催化剂使用现状
- 主要痛点和需求
- 决策流程和关键人
- 合作意向和时机

**收集工具**：
- 电子表单（iPad/手机）
- 纸质名片
- 微信扫码关注

### 5.4 展后跟进计划

**跟进时间节点**：

| 时间 | 行动 | 负责人 |
|------|------|--------|
| 展会结束后1天内 | 发送感谢邮件 | 销售团队 |
| 展会结束后3天内 | 电话回访A级客户 | 销售经理 |
| 展会结束后1周内 | 发送定制化方案（A级） | 技术团队 |
| 展会结束后2周内 | 安排客户拜访 | 销售团队 |
| 展会结束后1个月内 | 完成所有线索首次跟进 | 销售团队 |
| 展会结束后3个月内 | 达成试点合作意向 | 商务团队 |
