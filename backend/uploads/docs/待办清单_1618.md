# 任务 #1618 - 需人工完成

## 任务: T3: 学术影响力 - 2026下半年基金申报路线图（自然基金/重点研发/海外）

## 需要人工完成的事项



**待办事项清单（需人工完成）：**

1. **确认个人研究方向与学术背景**  
   - 整理近5年已发表论文、专利、获奖、项目主持/参与情况  
   - 明确自身研究领域在自然基金（面上/重点/优青/杰青）、重点研发计划、海外合作项目中的匹配度  

2. **调研2026年基金申报指南与政策变化**  
   - 等待国家自然科学基金委、科技部等官方发布2026年度项目指南（通常在2025年底至2026年初）  
   - 关注重点研发计划专项设置、海外人才项目（如海外优青、国际(地区)合作与交流项目）的申报条件更新  

3. **分析竞争环境与时间节点**  
   - 梳理往年同类项目的资助率、平均资助强度、评审周期  
   - 制定2026年1月-12月的关键时间表（如：自然基金通常在3月截止；重点研发预申报多在4-5月；海外项目可能有特定窗口期）  

4. **撰写初版申报书框架**  
   - 针对每个目标基金类型，撰写立项依据、研究内容、技术路线、创新点、研究基础等核心章节  
   - 需结合自身前期成果与团队优势，突出差异化竞争力  

5. **寻求同行专家预评审与修改**  
   - 邀请3-5位领域内资深专家（含已获资助者）对申报书初稿提出修改意见  
   - 根据反馈优化科学问题凝练、可行性论证、预算合理性等  

6. **完成最终申报材料整合与提交**  
   - 按各基金系统要求完成在线填报、附件上传、单位审核等流程  
   - 预留至少1周处理形式审查问题（如格式、超项、合作单位盖章等）  

**说明：**  
由于基金申报涉及高度个性化的研究积累、政策时效性（2026年指南未发布）以及专家人脉互动，我无法直接生成一份可实际提交的路线图或申报书。上述步骤是人工完成该任务所需的必要行动清单。
