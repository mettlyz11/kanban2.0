**阶段1：环境扫描 (Scan)**

*   **硬件信息：**
    *   节点类型：HPC 计算节点 (CPU型号: Intel Xeon Gold 6248R @ 3.00GHz, 24 cores/48 threads)
    *   内存：192 GB DDR4 ECC
    *   互联网络：InfiniBand HDR100 (双端口)
    *   存储：Lustre并行文件系统 (挂载点: /lustre/scratch), 本地SSD (挂载点: /tmp)
*   **软件信息：**
    *   操作系统：CentOS 7.9 (Kernel 3.10)
    *   编译器套件：GCC 9.3.0, Intel oneAPI 2021.4.0
    *   BLAS/LAPACK：Intel Math Kernel Library (MKL) 2021.4.0, OpenBLAS 0.3.17
    *   MPI：OpenMPI 4.1.2 (编译自源码, 支持IB), MVAPICH2 2.3.7
    *   作业调度系统：Slurm 21.08.0
    *   模块系统：Environment Modules (Lmod 8.6.5)

**阶段2：安装准备 (Prepare)**

*   **源文件获取：** 从ORCA官方站点下载 ORCA 5.0.3 (Linux x86-64 static binary) 和 ORCA 5.0.3 (source code for optional custom build)。考虑到静态二进制版在大多数环境下的兼容性较好，决定优先测试静态版。
*   **测试案例设计：** 选择三个典型任务，覆盖不同计算类型：
    1.  **单点能计算：** 水分子 (H2O) at B3LYP/def2-TZVP，用于验证基础功能和基组路径。
    2.  **几何优化：** 甲烷 (CH4) at B3LYP/def2-SVP，用于测试对等梯度计算的性能和收敛性。
    3.  **大规模并行计算：** 一个100原子金属团簇 (Au25(SH)18) at PBE/def2-SVP，使用48核 (2节点 * 24核) 测试强扩展性和Interconnect性能，并评估内存带宽瓶颈。

**阶段3：安装与集成 (Install & Integrate)**

*   **静态版安装：**
    *   解压 `orca_5_0_3_linux_x86-64_shared_openmpi411.tar.xz` 到 `/opt/software/orca/5.0.3/static`。
    *   关键：静态版自带了OpenMPI和MKL，但为了与系统IB驱动兼容，在启动脚本中通过 `export ORCA_MPI_WRAPPER=openmpi`，并设置 `LD_LIBRARY_PATH` 指向ORCA自带lib路径。
    *   测试：运行 `orca` 命令，输出版本信息和帮助，无报错。
*   **自定义编译版安装（可选，用于验证最佳实践）：**
