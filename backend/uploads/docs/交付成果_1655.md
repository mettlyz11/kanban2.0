我需要分析这个任务的具体需求。汉诺威工业展（Hannover Messe）是全球最大的工业技术展会之一，"跟进"任务通常涉及展后客户/线索管理。

## 任务判断

**1. 这个任务最需要什么具体产出？**

展后跟进的**可直接交付成果**通常是：
- 客户线索分级与跟进计划表
- 邮件模板（多语言）
- 会议纪要/客户信息整理模板
- 内部复盘报告框架

**2. 我能否生成这个产出？**

可以生成**通用可用的模板和框架**，但无法获取该企业的实际参展数据（具体接触了哪些客户、谈了什么内容）。

## 可直接交付的工作成果

### 一、客户线索分级跟进表（模板）

| 优先级 | 分级标准 | 跟进时限 | 负责人员 | 跟进动作 |
|:---|:---|:---|:---|:---|
| A级-热点客户 | 明确采购意向/预算/时间表，或现场签MOU | 展后24-48小时内 | 销售总监 | 电话+邮件+LinkedIn；发送定制方案；预约深度会议 |
| B级-意向客户 | 有需求但需内部评估，或技术匹配度高 | 展后3-5个工作日 | 客户经理 | 邮件感谢+产品资料+案例；安排技术交流 |
| C级-潜在客户 | 行业匹配但需求不明确，仅交换名片 | 展后1-2周 | 市场/销售 | 邮件Newsletter+定期EDM培育 |
| D级-一般线索 | 信息收集型访客，匹配度低 | 展后2周 | CRM自动 | 入孵化池，季度触达 |

### 四、展后内部复盘检查清单

**48小时内必须完成：**
- [ ] 所有名片/扫码信息录入CRM
- [ ] A级客户完成首次跟进（电话+邮件）
- [ ] 销售团队内部交接会议（若有人员轮班）
- [ ] 竞争对手动态整理（报价/新品/客户反馈）

**1周内完成：**
- [ ] 完整客户分级会议
- [ ] 邮件群发（C/D级客户）
- [ ] 媒体/分析师关系跟进
- [ ] 展会样品/设备物流清点

**2周内完成：**
- [ ] 深度技术方案发送（B级升A级）
- [ ] 重点客户拜访预约（欧洲本地客户）
- [ ] 展会ROI初步测算
- [ ] 2025年参展评估启动

### 五、德语市场特别注意事项

| 要点 | 执行建议 |
|:---|:---|
| 数据合规 | 确认邮件发送符合GDPR，保留Opt-in记录 |
| 沟通风格 | 德企偏好正式邮件签名、详细技术参数、明确时间承诺 |
| 决策周期 | 普遍较长，需准备多轮技术评审和工厂审核 |
| 本地存在 | 如有德国子公司/代理，抄送本地联系人建立信任 |

## 使用说明

> 以上模板可直接复制到Excel/CRM/邮件系统使用。如需进一步定制：
> 1. 提供贵司具体产品/行业，可优化邮件话术
> 2. 提供实际客户名单，可协助起草个性化跟进邮件（脱敏后）
> 3. 说明主要目标市场（德国/欧洲/全球），可调整策略重点
