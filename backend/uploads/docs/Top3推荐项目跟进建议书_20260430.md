| 技术验证 | 第三方检测机构验证CNT/石墨烯性能指标 | 高 |
| 客户确认 | 访谈2家签约客户，确认订单规模和合作意向 | 高 |

| 专利核实 | 核实8件专利状态（已授权/申请中） | 中 |
| 财务审计 | 审计公司财务状况和资金使用计划 | 中 |
| 团队背调 | 创始人学术成就、产业经验验证 | 中 |

### 2.4 投资建议

- **投资金额**: 500-800万元（占本轮1/4-1/3份额）
- **投资条件**: 
  - 估值不高于2.0亿元
  - 获得董事会观察员席位
  - 优先认购权（下一轮融资）
- **预期回报**: 3-5年A轮估值5-8亿，IRR>50%

### 2.5 风险提示

2. **团队权威**: 大连化物所氢能源团队，国家项目参与经验
3. **技术领先**: 国际领先固态储氢技术，6件核心专利已授权
4. **市场空间巨大**: TAM>1000亿元（氢能全产业链）

| 尽调项目 | 具体内容 | 优先级 |
|----------|----------|--------|
| 技术评估 | 第三方检测机构验证储氢性能指标（储氢密度、循环寿命） | 高 |
| 政策分析 | 评估氢能政策环境和补贴可持续性 | 高 |
| 产线考察 | 评估中试产线和规模化产能规划 | 高 |
| 专利核实 | 核实6件核心专利状态 | 中 |
| 竞争分析 | 对比国内外同类储氢技术 | 中 |

### 4.4 投资建议

- **投资金额**: 500-700万元
- **投资条件**:
  - 估值谈判至1.6-1.8亿元（当前2.0亿偏高）
  - 获得董事会观察员席位
  - 优先认购权
- **预期回报**: 5-7年产业并购或IPO，IRR>40%

### 4.5 风险提示

- 产业化周期长（3-5年规模放量）
- 氢能基础设施建设进度不确定
- 估值偏高（2.0亿），需争取更优条款
