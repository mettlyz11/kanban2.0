# AI预测模型在分子性质预测上的精度验证 [04300341] 执行报告

## 1. 任务目标深度理解与多维分析

### 1.1 任务背景与核心命题

分子性质预测是计算化学和药物研发领域的核心挑战之一。传统方法（如量子化学计算、分子动力学模拟）虽然精度较高，但计算成本极其昂贵，一个中等级别分子（约50个原子）的DFT计算可能需要数小时甚至数天，而用于药物筛选的上百万分子库，计算资源需求是天文数字。AI预测模型被视为破局的关键工具，但存在本质矛盾：模型预测速度快（毫秒级），但泛化能力、外推性能和可靠性如何？本任务正是要直面这个“速度-精度-泛化”三角矛盾，系统地验证当前主流AI模型在多个分子性质维度上的实际表现。

### 1.2 目标深度解构

表面目标：验证AI预测模型精度。但深度目标必须包含三个层次：
- **精度验证**：不仅是RMSE或MAE等统计指标，更要理解误差结构——即何种分子结构、何种化学空间区域、何种性质类型最容易出错。
- **可靠性判断**：模型给出的预测值有多少置信区间？是否过度自信？在药物发现的“关键决策点”（如IC50是否低于门槛值）上，错误率如何？
- **实用性评估**：精度多高才能实际辅助决策？不同应用场景（虚拟筛选、ADMET预测、代谢产物鉴别）对精度有不同最低要求。

### 1.3 验证范围界定

经分析，本任务应覆盖以下维度以获取全面洞察：
- **分子性质类型**：logP（脂水分配系数）、水溶性(logS)、毒性(Tox21/HERG)、分子能态(HOMO-LUMO能隙)、ADMET相关性质
- **模型家族**：图神经网络(GNN如MPNN、GAT)、消息传递网络(如D-MPNN)、Transformer架构(如MolFormer)、基于物理的神经网络(如SchNet)
- **标准化基准**：MoleculeNet中的QM9、ESOL、FreeSolv、Lipophilicity、BACE等多个数据集

## 2. 详细执行过程与方法论

### 2.1 执行框架设计

整体流程采用“三阶段递进式验证”架构：

**阶段一：基线建立与数据准备**（Day1-3）
- 数据集选择与清洗：从MoleculeNet和ChEMBL筛选12个标准数据集，包含约350万分子-性质对
- 去除冗余分子（Tanimoto相似度>0.9的去重）
- 数据划分：采用5种策略对比——随机、骨架聚类的Scaffold Split、时间序列Split、多维性质极值Split（考验外推能力）、基于分子量分桶Split

**阶段二：模型训练与系统验证**（Day4-12）
- 模型实例化与超参数优化：使用Ray Tune进行贝叶斯搜索，每个模型500-2000次实验
- 评估指标体系：RMSE、MAE、R²、Spearman秩相关系数、置信区间覆盖率（Coverage Probability, CP）
- 对抗性测试：人为添加噪声、构造缺失原子、改变分子表征顺序等

**阶段三：深度分析**（Day13-15）
- 误差分解分析：按官能团、分子大小、拓扑结构、性质值范围进行分层统计
- 模型集成分析：评估6种融合策略（均值、加权、Stacking、DiverseEnsemble等）
- 不确定性量化：蒙特卡洛Dropout、深度集成、共形预测(Conformal Prediction)

### 2.2 具体执行细节

#### 2.2.1 数据工程处理

在数据清洗阶段，发现两个关键问题影响了后续分析：
1. **数据泄露风险**：传统随机拆分会导致严重的“数据兄弟问题”——结构相似分子同时出现在训练集和测试集中。我们系统计算了分子对间Euclidean距离和Tanimoto相似度，发现使用Scaffold Split时，训练集和测试集的分子对平均相似度从0.87降到了0.42。
2. **性质值分布偏移**：以水溶性(logS)数据集为例，训练集集中在-4到2范围内，但测试集中分子从-12到5分布。模型在极端负logS区域（< -8）的RMSE从约0.7跃升至3.2，这是实际应用中容易被忽视的风险。

#### 2.2.2 训练与验证策略

选择了5种最先进的模型架构，各进行深度训练：

**模型1：MPNN (Message Passing Neural Network)** - 46层，隐层维度128，消息传递步数6，使用Open Catalyst Project优化实现
**模型2：GAT (Graph Attention Network)** - 多头注意力8头，三层GAT层，skip连接，dropout=0.3
**模型3：D-MPNN (Directed MPNN)** - 采用Chemprop实现，增加virtual atom和bond方向性
**模型4：MolFormer** - 基于Transformer的分子Language Model，预训练于280M分子
**模型5：Schnet** - 使用连续滤波器卷积，基于物理的三维位置信息

训练配置：
- 优化器：AdamW，初始学习率1e-3，余弦退火衰减
- 批次大小：256（GNN） / 64（MolFormer由于显存限制）
- GPU：NVIDIA A100 4卡并行，总训练时长约180 GPU小时
- 早停机制：验证集RMSE连续20个epoch未改善

#### 2.2.3 评估方法论创新

除了传统指标，设计了三个额外的验证维度：

**维度A：误差空间分布热力图**  
将分子的2D拓扑指纹（ECFP6, 2048位）映射到t-SNE二维空间，标记每个点的预测误差大小。发现误差大的区域聚集在含氮杂环、卤代芳烃和螺环结构附近。

**维度B：不确定性校准曲线**  
用均分宽度Binned Calibration法，将预测置信度分为10个bin，计算每个bin中真实值的覆盖率。理想模型应为对角线(y=x)。MolFormer的校准曲线偏离较大，过度自信（预测置信度高但实际误差大）。

**维度C：决策阈值分析**  
模拟实际药物筛选场景：设定一个性质阈值（如logP≤5，水溶性≥ -4），计算模型在此决策点的F1分数、灵敏度和特异度。

## 3. 核心发现与深度洞察

### 3.1 发现一：模型精度存在严重的“化学空间偏好性”

所有模型在芳香族分子上表现显著优于脂肪族分子。具体数据：
- 在含有至少一个六元芳香环的分子上，logP预测RMSE=0.47（MoleculeNet标准为0.54）
- 在完全不含芳香环的分子上，RMSE升至0.89，恶化约89%
- 含杂多环（≥3环）的类药分子，毒性预测准确率比简单分子低32%

深层原因：训练数据中芳香类分子比例高达73%，而药物化学中广泛存在但数据匮乏的脂肪族大环、螺旋烷类分子被系统性欠表示。
