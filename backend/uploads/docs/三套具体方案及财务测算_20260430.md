# 深云智合/硅研新材 三套具体方案及财务测算

> **编制日期**: 2026年4月30日
> **适用案件**: 包头市九原区公司僵局案件
> **保密级别**: 内部机密

---

## 一、方案A：大股东股权回购方案

### 1.1 方案概述

由控股股东（或指定第三方）以公平合理价格收购刘宇宙先生持有的全部/部分深云智合/硅研新材股权，实现有序退出。

### 1.2 适用前提

- 控股股东具备回购意愿和支付能力
- 深云智合公司仍具有存续价值
- 双方对股权定价机制可达成一致或接受第三方评估

### 1.3 定价机制（三选一）

#### 选项A1：净资产评估法
- 以第三方审计机构出具的最近一期净资产审计报告为基准
- 股权价值 = 经审计净资产 × 持股比例
- **优势**: 客观公正，有审计依据支撑
- **适用**: 公司有较完整的财务记录

#### 选项A2：收益法评估
- 以未来3-5年预期收益折现计算公司整体价值
- 股权价值 = 折现后公司整体价值 × 持股比例 × (1 + 控制权溢价/折价系数)
- **优势**: 反映公司未来盈利能力
- **适用**: 公司有稳定盈利预期

#### 选项A3：协商定价+独立专家意见
- 双方协商确定基础价格
- 委托独立财务顾问出具定价合理性意见
- **优势**: 灵活高效
- **适用**: 双方存在一定信任基础

### 1.4 推荐定价方案

**采用"基准价 + 浮动调整"的复合定价机制**:

```
股权回购价格 = min(净资产评估价, 协商基准价) × (1 + 资金占用补偿率)

其中：
- 净资产评估价：由双方共同认可的第三方审计机构出具
- 资金占用补偿率：按同期LPR（贷款市场报价利率）计算，自投资日至回购日
```

**理由**:
- 以较低者定价保护回购方利益
- 资金占用补偿弥补退出方时间成本
- LPR利率客观透明，避免争议

### 1.5 支付安排（两种模式）

#### 模式一：一次性支付
- 回购协议签署后30个工作日内支付全款
- 同时办理工商变更登记
- **优势**: 干净利落，无后续纠纷
- **劣势**: 对回购方资金压力大

#### 模式二：分期支付（推荐）
| 期次 | 支付时间 | 支付比例 | 金额（假设总价500万） |
|------|---------|---------|-------------------|
| 首期 | 协议签署后10个工作日 | 30% | 150万 |
| 第二期 | 工商变更完成后30日内 | 40% | 200万 |
| 尾款 | 变更后12个月内 | 30% | 150万 |

- **保障机制**:
  - 尾款需支付银行保函或提供等值担保物
  - 逾期付款违约金：每日万分之五
  - 工商变更与首期款挂钩
  - 股权在尾款付清前可设置质押

### 1.6 程序步骤

1. 双方签署回购意向书（LOI）
2. 共同委托第三方审计/评估机构
3. 出具评估报告并确认价格
4. 签署正式股权回购协议
5. 首期款支付
6. 办理工商变更登记
7. 后续款项按约支付
8. 向审理法院提交和解协议，申请撤诉

|------|-----------|-----------|-----------|

| 刘宇宙持股比例 | 假设40% | 假设40% | 假设40% |

## 二、方案B：公司减资退出方案

### 2.1 方案概述

深云智合/硅研新材通过定向减资方式，将刘宇宙先生出资额退还，实现其退出公司，公司减资后继续存续。

### 2.2 适用前提

- 公司账面有足够可分配资金或可变现资产
- 减资后注册资本不低于法定最低限额
- 债权人无异议或已妥善安排

### 2.3 法律程序（法定流程）

| 步骤 | 程序 | 时间要求 | 负责方 |
|------|------|---------|--------|
| 1 | 董事会制定减资方案 | - | 董事会 |
| 2 | 编制资产负债表及财产清单 | - | 财务部门 |
| 3 | 股东会决议（需2/3以上表决权通过） | 决议日 | 股东会 |
| 4 | 通知债权人（书面通知已知债权人） | 决议之日起10日内 | 公司 |
| 5 | 报纸/国家企业信用信息公示系统公告 | 决议之日起30日内 | 公司 |
| 6 | 债权人申报债权 | 公告之日起45日内 | 债权人 |
| 7 | 清偿债务或提供担保（如债权人要求） | 申报期内 | 公司 |
| 8 | 办理工商变更登记 | 减资完成后30日内 | 公司 |
| 9 | 向出资人退还减资款 | 法定程序完成后 | 公司 |

### 2.4 减资定价机制

```
减资退还金额 = min(
  实缴出资额 + 资金占用补偿(LPR利率×投资年限),
  减资时公司净资产中对应的份额,
  双方协商确定的金额
)
```

### 2.5 债权人保护方案

#### 风险识别
- 深云智合已停止运营，可能存在未结债务
- 需全面排查：供应商欠款、员工补偿、税务、合同违约等

#### 保护措施
1. **债务清单公示**: 减资前制作完整债务清单
2. **预留偿债资金**: 减资款中预留20%作为偿债准备金
3. **大股东承诺函**: 大股东出具连带责任担保承诺
4. **公证提存**: 将减资款部分提存至公证处，用于可能的债务清偿

### 2.7 时间线

```
Day 0        : 签署减资意向书
Day 1-15     : 编制资产负债表、债务清单
Day 15       : 股东会决议（2/3表决权通过）
Day 15-25    : 通知债权人
Day 15-45    : 登报/公示系统公告
Day 45-90    : 债权人申报期+偿债/担保
Day 90-120   : 办理工商变更登记
Day 120-150  : 支付减资款
```

**预计总周期**: 4-5个月

## 三、方案C：公司分立方案

### 3.1 方案概述

将深云智合/硅研新材按资产和业务划分为两个独立的公司实体，双方各自持有分立后的一家公司股权，实现物理分离。

### 3.2 适用前提

- 公司资产可以明确分割（如不同业务板块、不同地域资产）
- 双方各自有继续经营特定资产的意愿
- 债务可以合理分配

### 3.3 分立方式

#### 存续分立（推荐）
- 原深云智合继续存在（缩小规模）
- 新设一家公司承接部分资产/业务
- 刘宇宙持有新公司股权或退出

#### 新设分立
- 原深云智合注销
- 新设两家公司分别承接不同资产/业务
- 双方各持一家

### 3.4 资产分割方案

| 资产类别 | 分割原则 | 示例 |
|---------|---------|------|
| 货币资金 | 按股权比例分割 | 银行存款、现金 |
| 固定资产 | 按业务关联度分割 | 设备、房产 |
| 无形资产 | 协商或拍卖分割 | 专利、商标、软件 |
| 应收账款 | 按债务人归属分割 | 客户欠款 |
| 对外投资 | 按行业/地域分割 | 子公司股权 |
| 负债 | 按资产归属匹配 | 贷款、应付账款 |

### 3.5 业务划分

鉴于深云智合/硅研新材已停止运营，建议按以下方式划分：

| 业务/资产 | 归属建议 | 理由 |
|----------|---------|------|
| 知识产权/专利 | 按原始贡献方归属 | 谁研发谁持有 |
| 设备资产 | 拍卖变现或一方折价收购 | 已停止运营，设备无直接使用价值 |
| 品牌商标 | 一方收购或共同授权 | 需评估商业价值 |
| 债权债务 | 按比例各自承担 | 公平原则 |

### 3.6 人员安置

| 人员类别 | 安置方案 | 费用承担 |
|---------|---------|---------|
| 在职员工 | 协商解除/转岗至新公司 | 按劳动法规定支付补偿 |
| 离职补偿 | 一次性结清 | 分立前公司承担 |
| 社保公积金 | 补缴欠费后分割 | 按比例各自承担 |

### 3.7 法律程序

1. 董事会制定分立方案
2. 编制资产负债表及财产清单
3. 股东会决议（需2/3以上表决权通过）
4. 通知债权人并公告（同减资程序，45日申报期）
5. 签署分立协议
6. 办理新公司设立登记/原公司变更登记
7. 资产/业务/人员交割
8. 向审理法院提交和解协议

## 五、实施建议

### 5.1 谈判策略

1. **第一轮谈判**: 主推方案A（股权回购），展示法院调解案例的成功率
2. **第二轮谈判**: 如方案A价格分歧大，引入方案B（减资退出）作为替代
3. **第三轮谈判**: 如双方均不愿退让，提出方案C（公司分立）作为最后选项
4. **底线思维**: 任何方案均可接受的前提是获得合理对价和确定付款保障

### 5.2 风险控制

- **价格锁定**: 在协议中明确定价基准日，避免后续争议
- **付款保障**: 分期付款需设置担保（银行保函/股权质押/个人连带保证）
- **违约责任**: 明确违约金计算标准和解除条件
- **税务合规**: 确保股权回购/减资/分立的税务处理合规

### 5.3 关键时间节点

- **2026年5月**: 与律师团队确定最终谈判策略
- **2026年6月**: 启动第一轮正式谈判
- **2026年7-8月**: 完成方案A或B的签署和执行
- **2026年9月**: 向包头九原区法院提交和解协议，申请撤诉
