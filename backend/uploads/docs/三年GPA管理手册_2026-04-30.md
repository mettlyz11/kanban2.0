## 四、GPA预警机制

### 4.1 预警等级

| 等级 | 条件 | 应对措施 |
|------|------|----------|
| 🟢 **正常** | 所有科目≥5分 | 保持当前学习节奏 |
| 🟡 **关注** | 1门科目=4分 | 增加该科目学习时间，寻求老师帮助 |
| 🟠 **警告** | 1门科目≤3分 或 2门科目=4分 | 立即安排补习，调整学习计划 |
| 🔴 **危急** | 2门以上科目≤3分 | 紧急家长会议，考虑是否需要调整选课 |

### 4.2 定期评估节点

| 时间 | 评估内容 | 行动 |
|------|----------|------|
| 每月最后一周 | 各科作业成绩汇总 | 识别薄弱科目 |
| 每学期中 | 期中考试成绩分析 | 调整学习策略 |
| 每学期末 | 期末考试成绩分析 | 制定下学期计划 |
| DP1暑假 | 全年成绩回顾 | 确定DP2重点 |

### 4.3 预警触发后的行动清单

**🟡 关注级**：
- [ ] 分析低分原因（理解问题/时间管理/考试技巧）
- [ ] 增加该科目每周学习时间2-3小时
- [ ] 主动找老师答疑
- [ ] 寻找学习伙伴互助

**🟠 警告级**：
- [ ] 立即安排一对一补习
- [ ] 减少课外活动，专注学业
- [ ] 家长与学校老师沟通
- [ ] 考虑是否需要调整选课级别（HL→SL）

**🔴 危急级**：
- [ ] 紧急家长会，制定补救计划
- [ ] 考虑是否需要休学或重读
- [ ] 评估是否需要调整大学目标
- [ ] 寻求专业学业顾问帮助

## 六、家长支持指南

### 6.1 如何帮助女儿管理GPA

1. **定期沟通**：每周一次学业交流，了解学习进展和困难
2. **环境支持**：提供安静的学习空间，减少干扰
3. **情绪支持**：IB压力大，关注心理健康，及时疏导
4. **资源支持**：根据需要安排补习或购买学习资料
5. **目标管理**：帮助设定合理目标，避免过高压力

### 6.2 家长检查清单（每月）

- [ ] 查看女儿的成绩单和作业反馈
- [ ] 了解是否有未完成的作业或项目
- [ ] 询问是否有需要帮助的科目
- [ ] 检查EE/TOK/IA的进展
- [ ] 确认CAS活动记录是否及时更新
- [ ] 与女儿讨论下月学习计划和目标
