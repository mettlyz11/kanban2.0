## 需要人工完成的事项



该任务“Ni-催化剂筛选”是一个具体的实验/计算研究任务，需要根据特定的反应体系、目标性能（如活性、选择性、稳定性）以及筛选范围（如不同载体、制备方法、Ni负载量、助剂等）来执行。作为一个AI，我无法直接进行实验操作或运行第一性原理计算（如DFT），也无法获取实时的实验数据。

需要人工完成的具体步骤清单如下：

1. **明确筛选目标与参数范围**
   - 确定目标反应（例如：CO₂甲烷化、CH₄干重整、NH₃分解、加氢脱氧等）。
   - 确定关键性能指标（如转化率、选择性、TOF、抗积碳性、成本）。
   - 列出待筛选的变量：Ni负载量（如5wt%, 10wt%, 15wt%）、载体类型（SiO₂, Al₂O₃, CeO₂, ZrO₂, SBA-15等）、制备方法（浸渍法、沉淀法、溶胶凝胶法）、助剂（Fe, Co, Cu, La等）。

2. **收集或生成候选催化剂列表**
   - 根据文献调研或已有数据库，整理出待筛选的Ni基催化剂配方（例如：10%Ni/SiO₂, 5%Ni/CeO₂, Ni-Fe/Al₂O₃等）。
   - 记录每个配方的关键制备参数（煅烧温度、还原温度、前驱体等）。

3. **执行实验或计算筛选**
   - **实验路径**：合成催化剂 → 表征（XRD, BET, TPR, TPD等）→ 反应性能测试（固定床反应器）→ 稳定性测试。
   - **计算路径**：构建表面模型 → 运行DFT计算（吸附能、反应能垒）→ 或运行微观动力学模型。

4. **数据整理与对比分析**
   - 汇总所有催化剂的性能数据（活性、选择性、失活率）。
   - 建立“结构-性能”关联（例如：Ni粒径与活性关系、载体酸碱性对选择性影响）。
   - 根据预设的筛选标准（如：最高转化率、最低积碳率）排序并选出最优候选。

5. **结果验证与复现**
   - 对最优催化剂进行重复实验或更高精度的计算验证。
   - 输出最终筛选报告（含推荐配方、优化方向、风险提示）。
