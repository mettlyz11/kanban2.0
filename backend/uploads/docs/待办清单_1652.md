标准化对接执行包：首次触达话术/邮件模板、对接事项核对清单（Checklist）、会议议程框架、会后跟进记录表。

**2. 你能否生成这个产出？**
能生成全套模板、话术与执行框架，但“获取准确联系方式、实际发送信息、协调时间、主持会议、建立业务关系”必须由人工介入执行。

**3. 人工待办事项清单（附即拿即用内容）**

✅ **步骤1：核实联系人信息（人工）**
- 通过内部CRM/企业通讯录/领英/官网确认“蒋莉”在励英教育科技的准确职务、负责业务线、企业微信/邮箱/电话。
- 确认其是否为该事项的直接决策人或执行接口人。

✅ **步骤2：发送首次触达请求（人工发送，内容已备好）**
- 📱 *微信/短信模板*：
`蒋总/蒋经理您好，我是[你的姓名]（[你的公司] [职务]）。因[具体背景，如：XX项目合作/课程资源对接/系统联调]，希望与您就[核心议题]进行15-20分钟初步沟通。不知您本周三或周四下午是否方便安排电话或线上会议？盼复，感谢！`
- 📧 *邮件模板*：
`主题：[对接/合作] [我方公司] × 励英教育科技 - 关于[具体事项]的沟通邀请`
`正文：蒋莉女士您好，我是[公司][职务][姓名]。基于[合作背景/共同目标]，我方希望就[具体事项]与您团队进行对接。附件为我方简介/初步方案供参考。不知您本周[时间段1]或[时间段2]是否方便安排一次线上/线下沟通？期待您的回复。祝工作顺利！[签名/联系方式]`

✅ **步骤3：会前准备与议程确认（人工协调）**
- 锁定时间后发送日历邀请（含腾讯会议链接/线下地址）。
- 会前核对《对接事项清单》：
  [ ] 明确我方核心诉求、可交付资源/方案底线
  [ ] 调研励英教育近期业务动态及蒋莉负责板块
  [ ] 准备1页纸项目简介/报价框架/技术对接文档（视场景）
  [ ] 预设3个关键问题（合作模式、决策流程、预算/排期预期）

✅ **步骤4：执行对接会议（人工主持）**
- 按议程推进，重点记录：对方核心痛点、内部决策链、预算/时间窗口、下一步指定对接人。

✅ **步骤5：会后24小时内闭环（人工跟进）**
- 发送会议纪要，结构固定为：
  `① 会议共识 ② 双方待办（事项/责任人/截止时间） ③ 下次沟通节点`
- 将信息录入内部CRM或项目管理系统，设置跟进提醒。
