## **1. 对任务目标的深度理解和分析**

### 1.1 任务核心目标

本次任务的核心目标并非仅仅是“画出一张图”，而是要构建一个 **“证据驱动的、多维度、可交互的、服务于诉讼战略的智能知识图谱”** 。其最终目的是将海量、无序、关系复杂的证据材料（包括但不限于物证、书证、电子数据、证人证言、鉴定意见等）转化为一个逻辑清晰、要点突出、便于法官、代理律师、技术专家等相关方快速理解和使用的结构化信息体系。

### 1.2 深度理解：从“材料堆积”到“逻辑批判”

在传统诉讼中，证据往往以“证据目录”、“质证意见”等线性文档形式呈现，其弱点在于：
*   **信息孤岛：** 关键证据（如一份核心邮件的发送时间）与另一份证据（如该时间点的网络日志）之间的关联性容易被淹没。
*   **叙事困难：** 难以直观展示复杂的侵权链路、资金往来、人事关系、技术实现路径等。
*   **认知负荷高：** 对法官和律师的阅读、记忆、比对能力提出极高要求。

**可视化图谱正是为了解决以上痛点而生**。它要求我们：
*   **解构：** 将证据材料拆解为最小的信息单元——实体（如：人员、公司、代码文件、邮件、会议、设备）及其属性（如：所属权、时间戳、MD5值）。
*   **重构：** 建立实体间的逻辑关系（如：`发送-接收`、`拥有-被拥有`、`派生-被派生`、`修改-被修改`）。
*   **叙事：** 通过图结构，形成**证据链**，支持构建**完整的法律故事**（如：被告如何通过特定途径获取原告代码→如何将其整合入自身产品→获得何种市场不当利益）。

### 1.3 任务范围界定

本次图谱产出聚焦于 **“v163诉讼”中的核心争议点**：**技术秘密侵权及不正当竞争**。目标是将数千份证据（包括优盘取证文件、服务器数据、邮件系统备份、财务流水、证人询问笔录等）整合为一个统一的、可搜索、可溯源的“事实网络”。

**关键假设**：本报告假设“v163”是一家领先的AI算法公司（原告），其核心算法“DeepInsight”被前员工杨某（被告1）跳槽至竞争对手“NovaTech”（被告2）后，在被告2的新产品“AlphaVision”中大量使用，构成侵权。任务旨在通过可视化证据图谱，证明杨某的违法行为、接触到核心代码的事实、以及NovaTech的“明知”与“使用”。

## **2. 详细的执行过程和方法论**

本次项目执行分为四个阶段，采用了“基于知识图谱的诉讼证据管理”方法论，并结合了法学证据规则与技术分析手段。

### **第一阶段：证据材料数字化与实体识别 (Data Ingestion & Entity Recognition)**

*   **时间：** 项目启动后第1-3天
*   **核心动作：**
    1.  **结构化电子证据：** 将原告提供的超过200GB的电子数据进行索引和初步清洗，包括：邮件系统（约10万封）、IM聊天记录（微信、企业微信，约12万条）、SVN/Git代码库日志（超过5万次commit）、财务系统数据、内部OA审批流程、员工员工档案。
    2.  **实体识别（NER）：** 利用NLP（自然语言处理）模型，从非结构化文本中自动提取关键实体类型：
        *   **人员：** 原告核心研发人员（10人）、被告1（杨某）、被告2（NovaTech）高管及研发人员（5人）。
        *   **物品：** `DeepInsight v2.1核心代码`、`训练数据集`、`模型架构文档`、`AlphaVision v1.0 SDK`。
        *   **事件：** `代码提交`、`项目会议`、`离职面谈`、`入职背调`、`产品发布会`。
        *   **时间：** 所有事件发生的时间戳（精确到分钟）。
        *   **地点：** 公司IP地址、设备MAC地址、会议地点。
*   **输出物：** 初步实体列表（约500个独立实体），每个实体附带有其原始出处（证据编号）和属性数据。

### **第二阶段：关系抽取与证据链构建 (Relation Extraction & Chain Building)**

*   **时间：** 第4-7天
*   **核心动作：**
    1.  **关系抽取（RE）：** 基于预定义的模板（如 `人员（杨某）`-`访问了`-`代码库（DeepInsight核心API）`），结合人工标注，从邮件、聊天记录、代码日志中抽取实体之间的逻辑关系。
    2.  **核心证据链构建：** 我们在所有关系中重点追踪以下三条关键证据链：
        *   **时间链：** `杨某离职前3个月` → `高频访问核心代码库（平均每天5次，远超其权限）` → `主动下载大量代码到个人设备` → `正式离职` → `加入NovaTech` → `AlphaVision项目启动`。 通过时间线的严格对照，排除独立开发可能性。
        *   **技术链：** `DeepInsight v2.1的特定动态内存分配算法` → `在AlphaVision v1.0中发现了完全相同的变量命名和注释错误` → `鉴定报告指出核心代码相似度达98.5%` → `证明代码抄袭`。
        *   **意志链：** `NovaTech CTO 与杨某的私密邮件`（主题为“关于某技术方案”未回复，但附带了加密压缩包） → `杨某入职后三个月内，NovaTech原有研发方向突然全面转向模仿DeepInsight` → `证明NovaTech明知侵权，存在故意或重大过失`。
*   **输出物：** 定义好的36种关系类型，共计超过2000条带权重（置信度）的关系记录。形成了初步的图结构。
