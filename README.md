# Kanban 2.0

React + Flask 版本的看板系统

## 特性
- React 18 + TypeScript 前端
- Flask REST API 后端
- 与看板1.0共用数据库
- Cloudflare Tunnel 部署
- 响应式设计支持移动端

## 技术栈
- 前端: React 18, Vite, React Router 6
- 后端: Flask, SQLite
- 部署: Cloudflare Tunnel, Nginx

## 安装
```bash
cd frontend
npm install
npm run build

# 后端
cd ../backend
pip install -r requirements.txt
python app.py
```
